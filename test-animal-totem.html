🧸 애니멀 토템 기능 테스트

직접 호출 테스트

이 테스트는 메인 페이지에서 openAnimalTotemModal() 함수를 직접 호출합니다.

URL 쿼리 파라미터 테스트

이 테스트는 /?action=openAnimalTotemModal 쿼리 파라미터로 메인 페이지를 로드합니다.

콘솔에서 수동 테스트

브라우저 DevTools 콘솔에서 다음을 입력하세요:

window.openAnimalTotemModal()

이 명령어가 작동하면 애니멀 토템 모달이 열려야 합니다.

체크리스트

  • ✅ 메인 페이지에서 애니멀 토템 타일 클릭 → 모달 열림
  • ✅ /?action=openAnimalTotemModal URL 접속 → 모달 자동 열림
  • ✅ 랜딩 페이지(/animal/totem)의 "기능 바로 실행" 버튼 → 모달 열림
  • ✅ 모달 내에서 카드 뽑기 → 카드 렌더링 및 상호작용 정상
  • ✅ 모달 닫기 버튼 → 모달 정상 닫힘
