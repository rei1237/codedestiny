# 결과 화면의 개성을 보존하는 읽기 기준

- 신년운세는 기존 질문 답변·명식·분야 카드·달력·월별 편지와 버건디 작전실을 보존한다. 간격·제목 위계·본문·삽화만 정돈한다.
- 모든 서비스를 같은 밤 표지와 종이 본문으로 통일하지 않는다. 자미두수의 별과 명반, 점성술의 관측 기록, 베다의 사프란, 숙요의 두 달집, 인생의 책의 녹색 제본, 연애의 편지, 업의 보랏빛 기록, 네오의 전략실을 각각 유지한다.
- 긴 해설은 기존 본문 서체와 1.9 안팎 행간을 사용한다. 제목은 기존 명조를 유지한다. 문단 중간의 장식은 제목과 첫 해설 사이를 가르지 않는다.
- 전문가 그림은 검증된 서비스 이미지와 정본 마스터 매핑을 재사용한다. 그림은 계산 근거가 아니며 수치를 새로 만들지 않는다.
- 연애 비책의 카드·장별 읽기는 같은 본문을 사용한다. 연이·서한비는 기존 화자 매핑에 따라 전용 초상을 사용하고, 공동 집필인 운명의 업은 두 마스터가 함께 있는 장면을 사용한다.
- 본문은 17px·행간 1.9, 기존 명조 소제목·서비스별 강조색·인용·실천 목록을 사용한다. 긴 장은 저장 원문을 바꾸지 않고 블록 사이에 삽화를 최대 두 번 배치한다.
- 영냥이는 원래 흰 장모·남색 초승달 모자를 유지한다. 새 표지·해석·선택·마무리 장면은 글 없는 WebP이며 웹용과 PDF용을 분리한다. 출처와 생성 문구는 `docs/design/consultation-result-art.json`에 기록한다.
- PDF는 서비스별 표지 색과 그림을 보존한다. 텍스트 조판 리더는 동일 원문·목차를 사용하고, 캡처형 PDF는 글자·그림·표 행을 페이지 경계에서 보호한다.
- 가격·권한·인증·생성·저장·재열람·공유 계약과 비공개 결과의 검색 정책은 이 표시 계층이 소유하지 않는다.

## 검증 범위

- TypeScript와 신년운세 mock 흐름·초융합 PDF 구조 검사를 확인한다.
- 영냥이 실제 ReadingBook/내보내기 컴포넌트는 격리 mock에서 360·390·430·1440px, 글꼴 실패 후 재시도, 저장 결과 위치 복원을 확인한다.
- 실제 Next 개발 라우트는 기존 CommonJS/import.meta 번들 충돌로 별도 미검증이다. 격리 mock·PDF 렌더 판정을 전체 운영 흐름의 검증으로 확대하지 않는다.
- `node scripts/verify-editorial-consultation-browser.mjs`: 실제 연애 장/공통 결과 컴포넌트로 7종×4폭, 브랜드 서체 로드·삽화·긴 원문 보존·PDF를 확인한다. 반복 문단 스트레스 PDF는 디자인 샘플로 제공하지 않는다.
- 캡처 PDF는 소제목과 첫 해설 줄을 함께 넘기며, 하단 여백·테두리만으로 빈 페이지를 만들지 않는다. 짧은 장의 마지막 페이지 여백은 원문과 장별 시작을 보존한 결과일 수 있다.
