# 달빛 부적

- Primary target: app/app/talismans
- Related targets: app/app/_components/AppShell.tsx
- Mode: Operate
- Scope: 기존 달빛 예화의 색과 문체를 이어 가는 앱 배경화면 선택 도구.
- Characters: 영냥이, 연이(꽃돼지). 연꽃과 찻집은 같은 연이의 장면이다.
- Assets: 미승인 시안은 카탈로그에 포함하지 않는다. 새 이미지 생성은 별도 검토 중이다.

## Direction contract

THESIS: 사용자가 마음에 맞는 장면과 바람을 고르고 원본을 기기에 보관한다.

OWN-WORLD: 기존 night-tokens의 밤색·금색·상아색과 명조 제목. 조작부는 48px 이상의 차분한 선택 항목.

STORY: 미리보기에서 기기 배치를 이해하고 장면, 바람, 잠금·홈 구성을 선택한다. 준비되지 않은 이미지에는 저장을 열지 않는다.

FIRST VIEWPORT: 모바일은 짧은 제목 아래 가운데 휴대전화 미리보기, 이어서 세 단계 선택과 저장. 데스크톱은 미리보기 왼쪽, 조작 오른쪽.

FORM: 기존 방향을 확장하는 도구형 구성. 새 방향 추첨 없이 사용자 지정 세계관을 따른다. 주요 상호작용은 저장 원본에 영향을 주지 않는 시계·아이콘 가이드 전환이다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 구현 정본과 범위

- 공통 세계관은 `DESIGN.md`, 제품 맥락은 `PRODUCT.md`를 참조한다. 이 문서는 기존 방향을 확장한 `/app/talismans/`의 국소 기록이며 새 세계관·토큰·디자인 시스템을 정의하지 않는다.
- 화면·동작은 `app/app/talismans/TalismanStudio.tsx`, 배치는 같은 폴더의 `talismans.css`, 선택지·승인 원본 검사는 `catalog.ts`가 소유한다. 색·버튼·타입 크기는 `app/yeongnyangi/night-tokens.css`, 명조 서체 연결은 `styles/globals.css`의 기존 정의를 따른다.
- 캐릭터는 영냥이와 연이(꽃돼지) 두 명이다. 별빛의 길은 영냥이, 연꽃의 품과 찻집의 평온은 같은 연이의 장면이다. 장면 수를 캐릭터 수로 해석하지 않는다.

## 색과 타이포그래피

- `[data-yn-night]`의 기존 밤 팔레트를 사용한다. 배경은 `--yn-deep`, 선택지 기본면은 `--yn-night`, 미리보기·보조 버튼은 `--yn-surface`, 선택면은 `--yn-raised`다. 본문은 `--yn-ivory`, 보조 설명은 `--yn-muted`, 경계는 `--yn-line`을 함께 사용한다.
- `--yn-gold`는 저장 주행동과 선택 상태·단계 안내에 사용한다. 선택지는 금빛 테두리와 글자로 구별하고, 준비되지 않은 저장·공유는 중립 표면으로 표시한다. 별도 색상값이나 장식 그라디언트를 추가하지 않는다.
- 제목은 기존 `--font-serif` 명조 계열에 `--yn-t-display`, 굵기 500, 줄간격 1.3을 적용한다. 본문 서체는 상위 화면을 상속하며 소개문은 `--yn-t-body`, 보조문은 `--yn-t-caption`과 줄간격 1.7을 사용한다. 새로운 폰트를 들이지 않는다.
- 첫 화면은 제목과 설명으로 시작한다. 제거한 장식용 eyebrow를 다시 추가하지 않으며, 실제 선택 순서인 세 `fieldset`의 단계 표시는 유지한다.

## 배치와 조작

- 모바일은 좌우 20px 여백 안에서 제목 → 가운데 휴대전화 미리보기 → 위치 가이드 → 세 단계 선택 → 저장·공유 순서다. 미리보기는 최대 256px, 비율 9:19.5이며 원본 이미지는 `object-fit: contain`으로 보여 준다. 상·하단 안전 영역을 반영한다.
- 740px 이상에서는 좌우 40px 여백, 미리보기 왼쪽·조작 오른쪽의 `1fr / 1.15fr` 두 열과 52px 간격을 사용한다. 미리보기 최대 폭은 300px, 앱 스크롤 영역 최대 폭은 현재 구현의 1060px다. 이 수치는 해당 화면의 배치이며 공통 폭 토큰으로 승격하지 않는다.
- 장면은 세로 목록, 바람은 3열, 잠금·홈 화면은 2열이다. 뒤로가기와 가이드 라벨은 최소 44px, 선택 항목은 최소 48px, 저장·공유는 `--yn-btn-h`(52px)를 확보한다. 선택·행동 반경은 기존 `--yn-btn-radius`다.
- 실제 라디오·체크박스와 `fieldset`/`legend`를 사용한다. 키보드 포커스는 상아색 2px 윤곽선과 3px 간격으로 표시한다. 장식 가이드는 `aria-hidden`과 `pointer-events: none`이며 결과 안내는 `role="status"`, `aria-live="polite"`다.

## 동작과 빈 상태

- 기본 선택은 영냥이·평온·잠금화면이며 시계·아이콘 위치 가이드는 켜져 있다. 가이드 전환과 잠금·홈 구성은 미리보기 안내만 바꾸고 저장 원본에 시계·위젯·아이콘을 합성하지 않는다.
- 한국어·일본어 문구는 같은 컴포넌트의 기존 언어 상태를 따른다. 부적은 마음을 다잡는 상징으로 설명하고 특정 결과를 보장하지 않는다.
- `public/assets/talismans/catalog.json`은 현재 `assets: []`다. 승인된 부적 원본이 없어 준비 안내와 비활성 저장·공유를 표시하는 상태가 의도된 결과다. 미승인 시안이나 iOS 브랜드 이미지를 부적 대신 넣지 않는다.
- 선택한 원본이 있고 PNG 형식·크기·SHA-256 확인까지 통과한 경우에만 저장·공유를 연다. 읽는 중이거나 검증에 실패하면 활성화하지 않는다. 불러오기 실패는 연결 확인과 재선택, 내보내기 실패는 저장 공간·권한 확인과 재시도를 안내한다.
- 저장·공유 진행 중에는 중복 조작을 막고 취소·요청·완료를 구분해 알린다. 웹 다운로드는 요청한 상태로만 안내한다. Android는 배경화면 선택 열기를 제공하고 iOS는 저장 후 기기 설정에서 선택하도록 안내한다. 이 기록은 네이티브 기기 동작 검증을 뜻하지 않는다.

## 자산 출처

- 부적 원본 목록은 비어 있다. 추후 사용자 승인 원본만 `/assets/talismans/originals/`의 PNG와 카탈로그의 장면·바람·구성·크기·해시로 등록한다. 저장·공유에는 검증한 원본 바이트를 그대로 사용하며 재압축·크롭·재조판·가이드 합성을 하지 않는다.
- iOS 아이콘 출처는 `public/images/brand/moonlight-garden-icon-source.png`, 시작 화면 출처는 `apps/mobile/android/app/src/main/res/drawable/splash.png`다. `scripts/build-ios-brand-assets.mjs`가 기존 브랜드 자산을 재사용한다. 앱 아이콘만 1024px로 규격화하며 시작 화면은 원본을 복사한다. 이 자산들은 부적 원본이나 신규 캐릭터 제작물이 아니다.

## 검토 근거와 판정 범위

2026-10-24 시각 검토 담당(`visual_checker`)이 한국어 360·390·430·1280px와 일본어 390px를 검토했다. 명조 토큰 연결과 장식용 eyebrow 제거 두 수정은 `resolved`, 해당 시각 수정의 disposition은 `ship`으로 전달받았다. 이 문서화 작업에서 캡처를 다시 열거나 별도 시각 검증을 수행하지 않았다.

공통 React #418은 외부 브릿지 초기화로 수정했고 부모의 기능 검사에서 Next 출력+수정 후처리 두 화면 오류 0을 확인했다. 전체 재생성 산출물 검증은 별도로 진행한다. 후속 제작된 15장도 수정 요청 중인 미승인 원본이라 현재 카탈로그에 넣지 않았다. 위 시각 판정은 앱 전체 완료·출시 승인, 실제 기기 저장·공유 검증, 부적 이미지 승인 또는 배포 확인으로 확대하지 않는다.
