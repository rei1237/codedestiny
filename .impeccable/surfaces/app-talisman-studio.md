# 달빛 부적

- Primary target: app/app/talismans
- Related targets: app/app/_components/AppShell.tsx
- Mode: Operate
- Scope: 기존 달빛 예화의 색과 문체를 이어 가는 앱 배경화면 선택 도구.
- Characters: 영냥이, 연이(꽃돼지). 연꽃과 찻집은 같은 연이의 장면이다.
- Assets: 사용자가 최종 승인한 v2 PNG 15장을 사용한다. 미승인 시안은 카탈로그에 포함하지 않는다.

## Direction contract

THESIS: 사용자가 마음에 맞는 장면과 바람을 고르고, 그림 전체를 보존한 맞춤 이미지로 기기 배경화면을 설정한다. 원본 보관은 별도 행동으로 제공한다.

OWN-WORLD: 기존 night-tokens의 밤색·금색·상아색과 명조 제목. 조작부는 48px 이상의 차분한 선택 항목.

STORY: 미리보기에서 기기 배치를 이해하고 장면, 바람, 적용 화면, 그림 크기와 위치를 선택한다. 원본 확인이 끝나야 저장·공유·설정을 연다.

FIRST VIEWPORT: 모바일은 짧은 제목 아래 가운데 휴대전화 미리보기, 이어서 네 단계 선택과 적용·저장. 데스크톱은 미리보기 왼쪽, 조작 오른쪽.

FORM: 기존 방향을 확장하는 도구형 구성. 새 방향 추첨 없이 사용자 지정 세계관을 따른다. 원본을 잘라내거나 확대하지 않고 여백 안에서 크기와 위치를 맞춘다. 시계·아이콘 가이드는 화면에만 표시한다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 구현 정본과 범위

- 공통 세계관은 `DESIGN.md`, 제품 맥락은 `PRODUCT.md`를 참조한다. 이 문서는 기존 방향을 확장한 `/app/talismans/`의 국소 기록이며 새 세계관·토큰·디자인 시스템을 정의하지 않는다.
- 화면·동작은 `app/app/talismans/TalismanStudio.tsx`, 배치는 같은 폴더의 `talismans.css`, 선택지·승인 원본 검사는 `catalog.ts`가 소유한다. `wallpaper-fit.ts`의 순수 계산 `wallpaperFit`을 CSS 미리보기와 캔버스 PNG 출력이 함께 사용한다. 색·버튼·타입 크기는 `app/yeongnyangi/night-tokens.css`, 명조 서체 연결은 `styles/globals.css`의 기존 정의를 따른다.
- 캐릭터는 영냥이와 연이(꽃돼지) 두 명이다. 별빛의 길은 영냥이, 연꽃의 품과 찻집의 평온은 같은 연이의 장면이다. 장면 수를 캐릭터 수로 해석하지 않는다.

## 색과 타이포그래피

- `[data-yn-night]`의 기존 밤 팔레트를 사용한다. 배경과 미리보기·맞춤 PNG의 여백은 `--yn-deep`, 선택지 기본면은 `--yn-night`, 보조 버튼은 `--yn-surface`, 선택면은 `--yn-raised`다. 본문은 `--yn-ivory`, 보조 설명은 `--yn-muted`, 경계는 `--yn-line`을 함께 사용한다.
- `--yn-gold`는 적용 또는 맞춤 이미지 저장 주행동과 선택 상태·단계 안내에 사용한다. 선택지는 금빛 테두리와 글자로 구별하고, 준비되지 않은 내보내기는 중립 표면으로 표시한다. 별도 색상값이나 장식 그라디언트를 추가하지 않는다.
- 제목은 기존 `--font-serif` 명조 계열에 `--yn-t-display`, 굵기 500, 줄간격 1.3을 적용한다. 본문 서체는 상위 화면을 상속하며 소개문은 `--yn-t-body`, 보조문은 `--yn-t-caption`과 줄간격 1.7을 사용한다. 새로운 폰트를 들이지 않는다.
- 첫 화면은 제목과 설명으로 시작한다. 제거한 장식용 eyebrow를 다시 추가하지 않으며, 실제 선택 순서인 네 `fieldset`의 단계 표시는 유지한다.

## 배치와 조작

- 모바일은 좌우 20px 여백 안에서 제목 → 가운데 휴대전화 미리보기 → 위치 가이드 → 네 단계 선택 → 적용·저장·공유 순서다. 미리보기는 최대 256px이며 비율은 기기 화면 정보를 정규화한 출력 크기에 맞춘다. 데스크톱 웹의 기본 출력 크기는 1080×2340px이다. 원본 이미지는 공유 계산에서 얻은 위치·크기를 백분율로 적용해 보여 주고 상·하단 안전 영역을 반영한다.
- 740px 이상에서는 좌우 40px 여백, 미리보기 왼쪽·조작 오른쪽의 `1fr / 1.15fr` 두 열과 52px 간격을 사용한다. 미리보기 최대 폭은 300px, 앱 스크롤 영역 최대 폭은 현재 구현의 1060px다. 이 수치는 해당 화면의 배치이며 공통 폭 토큰으로 승격하지 않는다.
- 장면은 세로 목록, 바람과 적용 화면(잠금·홈·둘 다)은 3열이다. 뒤로가기·가이드 라벨·미리보기 전환·크기/위치 슬라이더·iPhone 안내 펼치기는 최소 44px, 라디오 선택 항목은 최소 48px, 적용·저장·공유는 `--yn-btn-h`(52px)를 확보한다. 선택·행동 반경은 기존 `--yn-btn-radius`다.
- 실제 라디오·체크박스·범위 입력과 `fieldset`/`legend`를 사용한다. 라디오·버튼·링크·가이드 체크박스의 명시적 포커스는 상아색 2px 윤곽선과 3px 간격이다. 미리보기 전환은 `aria-pressed`, 장식 가이드는 `aria-hidden`과 `pointer-events: none`, 결과 안내는 `role="status"`와 `aria-live="polite"`를 사용한다.

## 선택과 맞춤 이미지

- 기본 선택은 영냥이·학업·잠금화면, 그림 크기 100%, 위아래 위치 50%이며 가이드는 켜져 있다. 바람은 학업, 재물, 연애, 연락, 취업·합격의 다섯 주제다. 각 주제에 세 장면이 있고, 같은 `composition: shared` 원본을 홈·잠금화면에 사용한다.
- ‘둘 다’를 고르면 잠금/홈 미리보기 전환을 제공한다. 적용 대상과 미리보기 가이드를 구분하며, 전환은 시계·위젯 또는 아이콘 배치 예시만 바꾼다. 시계·아이콘·가이드와 UI 문구는 원본이나 맞춤 PNG에 합성하지 않는다.
- 크기(60~100%)와 위아래 위치(0~100%)를 조절한다. `wallpaperFit`은 원본 비율을 유지하고 전체 그림을 화면 폭 90%·높이 82% 안에 담으며 아트를 원본 픽셀보다 확대하지 않는다. 가로 중앙, 상단 4%·하단 14% 여백 범위에서 위치를 계산한다. 출력 크기는 기기 정보를 기준으로 정규화하므로 원본과 같다는 뜻이 아니다.
- ‘원본 저장’은 검증한 PNG 바이트를 그대로 내보낸다. 적용·맞춤 저장·맞춤 공유는 같은 계산과 밤 배경색으로 새 PNG를 생성한다. 맞춤 파일은 원본의 크롭·늘이기·문구 재조판 없이 여백과 축소 배치를 담으며 원본 파일을 덮어쓰지 않는다.
- UI에 원본 픽셀 크기와 맞춤 출력 픽셀 크기를 함께 표시한다. UI는 한국어·일본어를 지원하지만 승인 아트에 내장된 글자는 한국어이며 일본어 UI에서도 그 사실을 안내한다. 원본을 4K 등 실제보다 높은 해상도로 표현하지 않는다. 부적은 마음을 다잡는 상징이며 특정 결과를 보장하지 않는다.

## 기기 동작과 오류 상태

- 승인 원본의 PNG 형식·크기·SHA-256 확인이 끝난 뒤에만 적용·저장·공유를 연다. 읽는 중이거나 원본이 없거나 검증에 실패하면 내보내기를 비활성화한다. 카탈로그가 비어 있는 상태는 더 이상 현재 제품 상태가 아니다. 불러오기 실패는 연결 확인과 재선택을 안내한다.
- 내보내는 동안 네 단계 선택과 행동 버튼을 비활성화해 중복 조작을 막는다. 취소·다운로드 요청·저장·공유 화면 열기·설정 화면에서 돌아옴·적용 응답을 구별한다. 실패 시 저장 공간·권한·기기 제한에 맞는 다음 행동을 안내한다.
- Android의 명시적인 ‘적용하기’ 탭은 `SET_WALLPAPER` 권한을 사용하는 `CodeDestinyWallpaperPlugin.java`로 맞춤 PNG를 전달한다. 홈은 `FLAG_SYSTEM`, 잠금은 `FLAG_LOCK`, 둘 다는 두 플래그를 함께 사용한다. 기기 지원·관리 제한을 확인하고 시스템이 양의 wallpaper ID를 반환한 경우에만 `applied`를 알린다. 실제 화면 배치는 기기에서 확인하도록 안내한다.
- 별도 ‘시스템 설정 화면에서 적용’은 직접 설정이 지원되지 않을 때도 사용할 수 있는 대안이다. 시스템 chooser에서 돌아온 상태는 `returned`이며 적용 성공이나 취소로 단정하지 않는다. Android 공유 chooser를 연 상태도 `opened`로 구분한다.
- iOS의 `CodeDestinyViewController.swift`는 사용자가 저장을 탭했을 때 사진 추가 전용 권한을 요청한다. 맞춤 사진 추가가 완료되면 기기 설정에서 홈·잠금·둘 다를 마무리하는 안내를 연다. 사진 저장은 배경화면 설정 완료가 아니다. 웹 다운로드 역시 요청 상태로만 안내하며 실제 설정은 기기에서 진행한다.

## 자산 출처

- 사용자 최종 승인 v2 PNG 15장을 `public/assets/talismans/originals/`에 두고 `public/assets/talismans/catalog.json`에서 장면·주제·`approval: approved`·`language: ko`·실제 크기·SHA-256을 관리한다. 941×1672px 14장과 940×1672px 1장(`contact-flower-pig-v2.png`)이며, 다섯 주제×세 장면의 원본이다. 아트 승인 사실과 실제 기기 적용 검증은 구분한다.
- ‘원본 저장’의 무변형 보장과 맞춤 PNG 생성을 분리한다. 맞춤 출력은 승인 원본에서 파생한 별도 파일이며 원본 해시와 같다고 주장하지 않는다. 미승인 시안이나 브랜드 아이콘·시작 화면을 부적 대신 넣지 않는다.
- iOS 아이콘 출처는 `public/images/brand/moonlight-garden-icon-source.png`, 시작 화면 출처는 `apps/mobile/android/app/src/main/res/drawable/splash.png`다. `scripts/build-ios-brand-assets.mjs`가 기존 브랜드 자산을 재사용한다. 앱 아이콘만 1024px로 규격화하며 시작 화면은 원본을 복사한다. 이 자산들은 부적 원본이나 신규 캐릭터 제작물이 아니다.

## 검토 근거와 판정 범위

2026-10-24 초기 화면을 시각 검토 담당(`visual_checker`)이 한국어 360·390·430·1280px와 일본어 390px에서 검토했다. 명조 토큰 연결과 장식용 eyebrow 제거 두 수정은 `resolved`, 해당 시각 수정의 disposition은 `ship`으로 전달받았다. 이 기록을 후속 v2 아트·맞춤 배치·기기 적용 기능 전체의 재검토 결과로 사용하지 않는다.

사용자는 v2 15장의 최종 시각 승인과 앱 배경화면 적용을 명시적으로 요청했다. 현재 후속 구현과 검증은 진행 중이다. 공통 React #418은 외부 브릿지 초기화로 수정되어 이전 부모 기능 검사에서 Next 출력+수정 후처리 두 화면 오류 0을 확인한 이력이 있으며, 최신 전체 산출물 검증과는 구분한다. 이 문서화 작업은 현재 소스와 카탈로그를 확인했으며 캡처 재검토나 Android/iOS 실기기 검증은 수행하지 않았다. 이미지 승인과 이전 시각 판정을 앱 전체 완료·출시 승인·실기기 적용 성공·배포 확인으로 확대하지 않는다.
