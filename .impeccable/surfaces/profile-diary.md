# 프로필 · 달빛 다이어리 표면 계약

상세 정본은 [docs/design/profile-diary.md](../../docs/design/profile-diary.md). 이 파일은 다음 UI 작업자가 재사용할 짧은 표면 지침이다. 전역 DESIGN.md·PRODUCT.md를 대체하지 않는다.

## 사용자와 목적

모바일에서 자신의 프로필로 운세를 시작하고, 모은 꿀방울의 실제 사용처를 확인하며, 오늘의 마음과 약속을 기록하는 사용자다. 운세 시작이 첫 행동이고 다이어리는 일상을 정리하는 독립된 전체 화면 앱이다. 게임 성장 수치가 두 행동보다 먼저 나서지 않는다.

## 확정된 구성

1. 이름·일주 캐릭터·오행·성별과 프로필 바꾸기.
2. `이 프로필로 운세 보기` 주 행동.
3. 기존 출석·꿀방울 지갑과 카탈로그 기반 운세 추천.
4. `/diary/?from=profile`로 여는 달빛 다이어리.
5. 기존 동반자·정령·성장 미션·보상·출생 정보의 보조 구성.

다이어리는 오늘·달력·새로 추가·기록·더보기의 자체 하단 내비게이션을 쓴다. 최초 `from=profile` 진입을 셸 상태로 기억해 같은 셸 수명의 탭 이동에서도 프로필 복귀를 유지한다. 탭 href에 쿼리를 덧붙이는 방식이 아니므로 탭 이동 후 새로고침까지 유지된다고 안내하지 않는다. 오늘은 흐름 → 계획과 일기 → 접힌 작은 실천 순서다. 달력은 월·주·일, 일정과 할 일 편집, 날짜별 흐름·기록·회고로 이어진다. 검색·백업·복원은 기존 기능을 유지한다.

## 시각과 접근성

- 달빛 예화의 크림·로즈·딥 플럼·골드, 얇은 선과 이중 테두리, 기존 꽃가지 마스크를 사용한다. 별도 그림이나 새 팔레트를 만들지 않는다.
- 제목은 기존 주아체, 조작·설명·가격·입력은 Pretendard다. `--font-display`·`--font-body`와 기존 `--cd-sp-*`·`--cd-r-*`를 사용한다.
- 프로필 `--pc-*`, 계정 목록 `--mg-*`, 다이어리 `--dy-*`의 소유 범위를 지킨다. 기본·네오에서 표면과 글자색을 함께 바꾼다.
- 주요 저장/이동 행동 48px, 아이콘 버튼 44px, 입력 글자 16px를 유지한다. 선택은 색 외에 선·배경·상태 속성을 사용하고 포커스 외곽선을 제공한다.
- 1000px 이상에서 오늘의 계획/일기와 달력/날짜 패널은 두 열이다. 작은 화면에서는 한 열로 이어진다. 430px 이하의 여백·요일 버튼 배치를 확인한다.
- 빠른 눌림 반응만으로 조작을 알린다. 장식이 얼굴·본문·터치를 가리지 않게 하고 reduced motion 처리를 유지한다.

## 기능·상태 경계

- 일주: 로딩 → 성공 또는 재확인/프로필 완성. 실패 캐시를 재사용하지 않고 `aria-busy`를 종료한다. 생시 모름과 미입력을 구분한다.
- 꿀방울: 카탈로그의 비용과 실제 잔액을 표시한다. 소유 표시는 현재 프로필의 서버 unlock만 근거로 삼는다. 캠페인 무료 접근을 소유라고 표시하지 않는다. 추천 클릭은 기존 확인·운세 흐름을 사용한다.
- 일정: 시각/종일, 매일/매주/매월 같은 날짜, 종료일, 이번만/반복 전체 편집·이동·삭제. 삭제는 확인한다. 없는 월말 날짜는 건너뛴다.
- 할 일: 내용·날짜·완료·수정·이동·확인 후 삭제. 일정의 반복 기능을 할 일에도 있다고 안내하지 않는다.
- 일기: 기분·한 줄·여러 줄 본문. 공유 `memoNote`의 줄바꿈을 보존한다. `DiarySelfCard`도 여러 줄 입력을 유지한다.
- 저장: 일기는 600ms 지연 저장과 blur/이탈 flush, 일정·할 일은 저장 버튼. 성공·대기·실패를 구분하며 실패 입력을 남긴다. 실패 초안 복구는 메모리 전용이므로 새로고침 후 복구를 약속하지 않는다.
- 보관: 기존 브라우저 localStorage와 날짜별 확장 저장소를 유지한다. 클라우드 동기화·자동 알림을 기능으로 쓰지 않는다. 반복 원본과 예외를 보관하고 조회 범위에서만 전개한다.

## 유지·검수

이용권·월정석·단건 결제, 인증·API 응답·DB·LLM 정책은 변경하지 않는다. 개인 다이어리의 noindex와 광고 제외 계약을 보존한다. 기본 프로필 진입은 전체 화면이며 embedded 책 모달은 선택적 보조 경로다.

검수 축은 360·390·430·1440px 기본/네오, 일주 성공·실패·출생 정보 부족, 꿀방울 조회 실패·소유/비소유, 월주일·반복 예외·이동·삭제, 여러 줄 저장·실패 재시도, 키보드·포커스·넘침이다. 이 파일은 소스 기반 계약이며 자체 브라우저 검수 결과나 CI 통과 증명은 아니다.
