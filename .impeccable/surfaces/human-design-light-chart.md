# 휴먼 디자인 라이트 차트 보드

- Mode: Operate
- Scope: `/human-design/`의 입력·계산·결과 UI만. 홈 카드 이미지, 메인 화면 이미지, 결제, 인증, API, DB, 리포트 생성은 불변.
- Audience/job: 사용자가 출생 정보로 계산한 휴먼 디자인 차트의 핵심 속성과 26개 행성 활성을 한 화면에서 비교하고, 중앙 바디그래프를 눌러 세부 근거를 확인한다.
- Reference: 사용자 제공 밝은 휴먼 디자인 차트의 좌우 활성값 표, 중앙 바디그래프, 넓은 흰 여백과 얇은 구분선.

## Direction contract

THESIS: 연이의 밝은 종이 위에 계산 결과를 펼친다. 첫 화면은 카드 모음이 아니라 하나의 정돈된 차트 보드다.

OWN-WORLD: 꽃돼지 연이의 크림·로즈·샴페인 골드를 셸과 선택 상태에 사용한다. 바디그래프의 퍼스낼리티는 잉크 블랙, 디자인은 코랄 레드로 구분하고 정의된 센터에 절제된 노랑·레드·브라운을 쓴다.

STORY: 차트 속성 → 디자인 활성값 → 중앙 바디그래프 → 퍼스낼리티 활성값 → 상세 해설 순서로 읽는다.

FIRST VIEWPORT: 데스크톱에서 네 영역이 한 줄의 차트 보드로 보인다. 모바일에서는 속성 요약, 바디그래프, 디자인/퍼스낼리티 활성값 순으로 재배치한다.

INTERACTION: 기존 SVG의 확대·이동·센터·게이트·채널 선택과 상세 시트 계약을 그대로 유지한다. 행성 활성값 행도 같은 선택 상태를 연다.

FINISH: 390px 모바일과 1440px 데스크톱을 한 번에 캡처해 오버플로·텍스트 적합·터치 타깃·대비를 확인한다.

## Explicit exclusions

- 홈 및 메인 화면의 휴먼 디자인 이미지 교체 없음
- 연이 마스코트 자산 생성·교체 없음; 기존 앱 로고만 작은 브랜드 표식으로 재사용
- 계산값·해석 문구·가격·결제 진입·리포트 생성 흐름 변경 없음
