# Google Play 한국어 등록정보 이미지

한국어 등록정보의 제목과 설명은 [스토어 문안](../../../apps/mobile/store-listings.json)의 `ko-KR`을 사용한다. 새 첫 화면을 포함한 Android 버전이 트랙에서 설치되는 시점에 아래 이미지를 함께 적용한다.

| 업로드 위치 | 파일 | 소재 |
|---|---|---|
| 그래픽 이미지 | [feature-graphic-ko.jpg](feature-graphic-ko.jpg) | 연이·영냥이가 안내하는 달빛 서재 일러스트. 1024 × 500 JPEG |
| 전화 스크린샷 1 | [01-yeoni-and-yeongnyangi.jpg](01-yeoni-and-yeongnyangi.jpg) | 앱 첫 화면의 두 선택 카드 |
| 전화 스크린샷 2 | [02-six-fortune-tools.jpg](02-six-fortune-tools.jpg) | 앱 탐색 화면의 여섯 운세 |
| 전화 스크린샷 3 | [03-five-masters.jpg](03-five-masters.jpg) | 다섯 마스터의 담당과 공개 분석 기록 안내 |
| 전화 스크린샷 4 | [04-fusion-reading.jpg](04-fusion-reading.jpg) | 초융합 상담의 서비스 소개 |

전화 스크린샷 네 장은 1080 × 1920 JPEG다. 앱 타깃의 로컬 화면을 캡처해 제목과 테두리를 넣었다. 상담 예시는 서비스 소개 화면을 사용했고, 계정·결제 내역은 포함하지 않았다. 앱 아이콘의 업로드 파일은 별도로 관리한다.

연이와 영냥이의 서재 일러스트는 사용자 제공 참고 이미지와 기존 캐릭터 시트를 참고해 제작했다. 다섯 마스터는 기존 앱의 공식 초융합 일러스트를 사용했다. 집행 일정과 비교하고자 하는 스토어 첫 장은 [30일 마케팅 계획](../../../docs/marketing/android-play-launch-20261122.md)을 따른다.
