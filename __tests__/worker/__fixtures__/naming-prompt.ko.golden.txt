## [한국 작명 기준]

### A. 소리오행 (초성 기준)
- 木: ㄱ, ㅋ

### B. 수리(數理) — 원형이정 4격

**획수 기준은 강희자전 원획(原劃)으로 통일하세요.** 부수가 줄어든 형태라도 본래 글자의 획수로 셉니다:
- 氵(삼수변) → 水 4획
- 忄(심방변) → 心 4획
- 扌(재방변) → 手 4획
- 艹(초두머리) → 艸 6획
- 阝(왼쪽) → 阜 8획
- 阝(오른쪽) → 邑 7획
- 月(육달월) → 肉 6획
- 王(구슬옥변) → 玉 5획
- 犭(개사슴록변) → 犬 4획
- 礻(보일시변) → 示 5획
- 衤(옷의변) → 衣 6획
- 辶(책받침) → 辵 7획

**4격 계산식** (성 1자 + 이름 2자 기준):
- 원격(元格, 초년운) = 이름 첫 자 + 이름 끝 자
- 형격(亨格, 청년운) = 성 + 이름 첫 자
- 이격(利格, 장년운) = 성 + 이름 끝 자
- 정격(貞格, 총운·말년운) = 성 + 이름 전체 총획
성이 2자(남궁·황보 등)이거나 이름이 1자·3자면 위 구성 원리를 그대로 적용하되, 어떤 조합으로 셌는지 밝히세요. 합이 81을 넘으면 81을 빼고 다시 봅니다.

**81수리 길흉 분류** (이 목록으로 판정하고, 기억에 의존해 다르게 말하지 마세요):

**수리오행·음양**
- 각 격의 획수 끝자리로 수리오행을 봅니다: 1·2=木, 3·4=火, 5·6=土, 7·8=金, 9·0=水
- 음양은 홀수=양(陽), 짝수=음(陰). 성과 이름 글자의 획수가 전부 양이거나 전부 음으로 쏠리면 흉으로 보고, 음양이 섞이도록 배치하세요.
