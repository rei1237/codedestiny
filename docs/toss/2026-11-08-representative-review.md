## 가격과 콘솔

판매 후보는 연이 `chat_saju` 한 상품과 영냥이 `saju_mackerel`, `saju_salmon`, `saju_flounder`, `saju_tuna` 네 상품이다. 서버 레지스트리 조회값은 순서대로 5,000원·10,000원·15,000원·20,000원·30,000원이다. 각 상품의 원래 가격과 권리를 보존한다. 비게임 상품 30개 한도는 이 구성의 차단 사유에서 해소됐다. 반려동물 상품과 사주 묶음 이용권은 이번 판매 대상에서 제외한다.

2026-11-08 Ego Lite에서 다시 연 앱인토스 콘솔은 꿀꿀운세를 비게임 앱으로 표시했다. 인앱 상품은 등록 전이고 토스 로그인은 ‘등록하기’ 상태였다. 최신 비공개 버전 `20261108-5`는 ‘검토 필요’, 앱 정보는 ‘반려’다. 복원한 콘솔의 파트너 채팅은 ‘대화를 시작해보세요’를 표시했다. 이전에 보낸 문의의 답변 여부는 여기서 확인할 수 없었다.

mTLS 인증서는 토스 콘솔에서 발급을 완료했다. 인증서와 개인키의 일치 및 만료일(2027-12-03 UTC)을 확인했다. 서버의 Cloudflare 계정에 업로드하고 재조회했으며 스테이징 Worker 설정의 `TOSS_MTLS` 바인딩과 만료값을 작성했다. 원본은 현재 Windows 사용자로 암호화해 저장소 밖에 보관한다. 실제 로그인·주문 API 응답 및 운영 바인딩은 별도 검증 대상이다.

운영 사이트에서 [개인정보처리방침](https://code-destiny.com/privacy/)과 [서비스 이용약관](https://code-destiny.com/terms/)의 HTTP 200 및 개인정보 2절 앵커를 확인했다. 앱 설정에는 기존 방침 전문·[수집 항목과 이용 목적](https://code-destiny.com/privacy/#collected-data)·이용약관을 연결했다. 기존 웹 가입 방침에는 이메일 회원과 웹 결제의 정보가 포함되고, 사주 입력용 수집 동의는 웹 홈의 모달에 있다. 토스 로그인 식별자·선택 범위와 국외 이전의 수령자·국가 등은 이 방침에서 확인되지 않았다. 실제 적용 여부와 문구가 확인된 항목만 토스 로그인 약관으로 저장한다. [토스 약관 등록 항목](https://developers-apps-in-toss.toss.im/guide/authentication/intro)

사용자가 요청한 기존 사이트 정책을 토스 로그인 등록 양식에 입력했다. ‘서비스 이용약관’과 ‘꿀꿀운세 개인정보처리방침’(콘솔 유형 ‘개인정보 처리방침 동의’)이 양식 목록에 표시된 것을 확인했다. 별도 수집·이용 동의나 국외 이전 동의를 이 방침으로 대체하지 않았다. 등록 양식을 열어 둔 상태이며 서버에 최종 등록한 증거는 없다.

공급가 입력 단위에서 5,000원과 정확히 일치하는 판매가를 만드는 문제, 최초 구매자 확인, 주문번호를 받기 전 종료된 경우의 복구, 공식 기기에서 무과금 테스트를 할 수 있는 방법은 기존 파트너 문의의 답이 필요하다. [이전 콘솔 측정과 문의 내용](2026-11-04-review-readiness.md)

## 제출 직전 필요한 증거

제품 커밋 `58a8701c9`은 신규 상담·결제의 진입을 선정된 사주 상품으로 제한하고 과거 결과는 현재 계정의 구매 기록과 대조한다. 모의 SDK에서 홈 → 오늘의 운세 → 상단 뒤로가기 → 홈, 최초 만세력 직접 진입 → 상단 뒤로가기 → 닫기를 확인했다. 세 가지 화면 폭(320·390·430px)에서 일곱 서비스가 열렸다. 토스 전체 모의 테스트 1,421개와 타입 검사가 통과했다. 실제 배포용 정적 화면을 로컬에서 열어 홈 일곱 링크와 설정의 사이트 정책 세 링크를 확인했다. 보류한 소설·음악·직업 성향의 미리보기 모듈은 공개 빌드에 포함하지 않는다.

안전 검사까지 포함한 Windows 공식 CLI 빌드 결과는 91,390,283바이트(압축 해제 98,823,514바이트)다. Windows 구분자가 있는 항목 1,245개로 이 산출물의 `verify:release-bundle`은 실패했다. 제출용 AIT는 해당 커밋을 포함한 Linux 공식 검사를 통과해야 한다. 기기 주문 증거에 로컬 모의 주문을 포함하지 않는다. SDK 3.x의 일반 콘솔 QR 구매는 실제 과금된다는 [토스 안내](https://developers-apps-in-toss.toss.im/guide/monetization/in-app-payment)를 따른다.

대표 상담의 입력 안전 검사와 공급자 차단 응답 처리를 추가했다. 한국어 위험 실행 요청과 자해 위기 표현은 초기 준비와 후속 질문에서 안내를 표시하고, 중독 회복이나 타인을 걱정하는 질문은 계속 진행할 수 있다. 두 상담에서 모의 위기 입력의 POST는 0건이었다. 공급자가 차단한 응답은 부분 텍스트가 있어도 반환하지 않는다. 차단된 장은 운영 검토 상태로 두며, 차단된 후속 답변은 같은 요청의 재시도·포함 횟수 차감 없이 지원 안내만 보관한다. 토스 앱 전체 모의 테스트 1,429개 및 타입 검사가 통과했다. 모델이 차단으로 표시하지 않은 유해 답변, 다국어 우회, 운영자의 신고 대응과 실제 기기 동작은 별도 검증할 항목이다. [토스 AI 상담 운영 기준](https://developers-apps-in-toss.toss.im/intro/guide)
