## 테스트 기기에서 누를 순서

비공개 QR은 토스 앱에 로그인한 만 19세 이상 워크스페이스 멤버가 스캔한다. QR 안에서 보이는 모의 계정 A·B는 상담 소유권을 시험하기 위한 로컬 계정이다. [토스앱 테스트 조건](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace#test-in-toss-app)

1. **격리 모의판**에서 상단 ‘비공개 모의 상담 · 실제 결제 없음’과 계정 A를 확인한다. 영냥이 → 사주 상담 → 프로필 선택·수정 → 질문 입력 → 상담과 결제 확인 → 모의 로그인·구매를 누른다. 실제 과금은 0원이다.
2. 생성 중 닫았다가 같은 모의판을 다시 연다. 영냥이 보관함에서 기존 상담을 누르면 이미 저장한 장부터 이어진다. 완료 후 재실행해도 같은 본문이 열린다. 결과 주소를 기록한 뒤 모의 계정 B에서 같은 주소를 열면 본문을 볼 수 없어야 한다.
3. 꿀꿀운세 → 무료 운세 전체 목록 → 기본 궁합에서 두 사람의 정보를 입력한다. 로그인·결제 없이 기본 결과가 열린다. 고급 궁합을 선택하면 별도 입력과 상품을 사용한다. 꿀꿀운세 구매 기록에서 연이 결과를 확인한다.
4. 휴대폰 큰 글씨를 켜고 긴 질문의 마지막 줄에서 키보드를 연다. 입력란과 다음 버튼으로 스크롤할 수 있어야 한다. 토스의 뒤로가기로 입력·선택 화면을 거슬러 올라가고 홈으로 돌아간다.
5. **일반 비공개 테스트판**에서는 홈·로그인 취소·재로그인·기존 구매 재열람·음원 저장 UI만 확인한다. 정상적인 기존 구매 기록을 가진 테스트 계정이 필요하다. 신용카드 등 실제 결제수단이 표시되는 흐름은 이 검수 범위 밖이다.
