## 코드 점검 결과

`npm run launch:status --prefix apps/toss`가 원본 모드 대조표의 110개 ID를 직접 검사하도록 수정했다. 기존 `status=local-partial`은 과거 이식 이력이며 현재 코드 누락 수가 아니다. `implementationReadiness`가 현재 누락과 대조 대기를 구분한다. 원장 행이 빠지거나 중복되면 실패하고, 알 수 없는 대조 상태는 완료로 계산하지 않는다.

11월 15일 원장에는 코드 누락이 기록되지 않은 109개와 음악 1개가 있었다. 당시 개발 상태 분류는 기존 동작 16개, 콘솔·운영 확인 필요 93개, 일부 이식 1개였다. 11월 22일 다시 대조한 116개 기능의 상태와 상품별 검증 근거는 [전체 기능 원장](./full-service-inventory.json)에서 확인할 수 있다.

**후속 실사용 제보와 수정:** 사용자는 프로필 카드 설정이 어렵고, 한 화면에 기능이 몰려 있으며, 운명의 찻집에서 타로만 보인다고 보고했다. 위 109개는 과거 원본 대조의 코드 존재 집계일 뿐 사용성 완료 판정이 아니다. 홈 점진 노출·찻집 전체 모드 선택·프로필 4단계와 계정별 초안 복원은 코드와 모의 동선 검증을 완료했다. [간편 진입 검증](./guided-entry-preview.md)에 홈73·찻집6모드·프로필 복원 근거를 기록했다. 2026-11-16 등록한 QR19(source d38c0997c, 전체 Linux CI43725888081 SUCCESS)의 실제 AIT 홈·원문 재열람·계정B 거부도 PASS이며, 새 UI의 휴대폰 키보드·뒤로가기는 추가 확인한다. 후속 원본 웹툰 설명은 별도 검증을 거쳐 QR20에 포함했다.
