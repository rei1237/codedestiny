# 새 비공개 QR의 휴대폰 확인 경로

최종 Linux AIT와 새 QR의 식별값은 생성 후 전달 기록에 연결한다. 현재 문서는 앱에서 누를 버튼과 기대 결과다. 상단에 **비공개 모의 상담 · 실제 결제 없음**이 보여야 한다. 운영 결제창이 뜨면 진행하지 않는다. 모의판은 실제 계정, 실 LLM, 실제 음원 파일을 사용하지 않는다.

## 대표 상담과 보관함

1. 홈에서 **영냥이** → **서양 점성술 상담**을 고른다.
2. 상담 질문을 입력하고 **상담과 결제 확인하기**를 누른다. 키보드가 열려 있어도 입력 내용과 다음 버튼에 접근할 수 있어야 한다.
3. **토스로 로그인하기**로 모의 로그인한다. 선택한 상담·질문이 복원되어야 한다.
4. 화면의 모의 예시와 모의 구매로 결과를 연다. 모의판 안내를 유지하며 원본 형식의 장/계산 근거가 보여야 한다.
5. 앱을 닫았다가 같은 QR로 다시 연다. 상단 모의 계정 **A**에서 영냥이 **내 상담**을 열면 같은 저장 결과가 보여야 한다. 새 주문·새 생성이 생기지 않아야 한다.
6. 모의 계정 **B**로 바꾸면 A의 기록이 보이지 않아야 한다. A의 결과 링크를 열어도 접근이 거절되어야 한다. 영냥이 기록과 꿀꿀운세 구매 기록은 서로 분리되어야 한다.

## 동물점 원본 상세

홈 → **꿀꿀운세** → 검색 **십이운성 동물점** → 날짜 `2023-02-01`, 달력 **음력 윤달**, **태어난 시각을 몰라요** → **나의 동물 찾기**.

- 로그인·구매 없이 원본 동물 카드가 표시되어야 한다. 상단에 큰 빈 공간이 생기거나 카드가 투명하면 실패다.
- 상세 탭 10개, 도감 동물 12개, 성장 조언과 관계 입력을 확인한다. 상대 생일 `19900101`, 시간 `08:30`을 입력하고 **궁합 확인하기**를 누르면 관계 결과가 보여야 한다.
- 토스 뒤로가기와 **출생정보 다시 보기**는 작성한 출생정보로 돌아와야 한다. 계정 B로 변경하면 A의 입력/결과가 남지 않아야 한다.
- 카드 **이미지로 저장하기**, **결과 공유하기**는 일반 배포판의 실제 토스 SDK 지원을 휴대폰에서 별도 확인한다. 이 동물점 무료 계산은 웹과 같이 구매 보관함에 자동 저장되지 않는다.

## 음악 다운로드의 모의 권리 확인

홈 → **꿀꿀운세** → 검색 **음악** → 첫 곡 → **토스 로그인하기** → **토스로 로그인하기** → 같은 곡으로 복귀 → **단건 결제로 다운로드 열기** → **MP3 파일 저장하기**.

- 모의 저장 요청 안내가 표시되고 실제 파일은 저장되지 않는다. 모의판은 원곡을 다운로드하지 않아 재생 오류가 보일 수 있다.
- 앱을 다시 열고 **꿀꿀운세 구매 기록** → 해당 곡 **다시 보기**로 들어가면 추가 구매 없이 같은 다운로드 권리가 보여야 한다.
- B 계정에서 A의 링크를 열면 **구매 기록 확인** 단계에서 막혀야 한다.
- 실음원 재생·파일 저장·취소/실패 복구는 별도 기기 검증이다. 32MiB 초과 원곡은 현재 SDK 어댑터에서 저장할 수 없으며 곡별 판매를 열기 전 확인해야 한다. 기존 웹 구매 권리는 웹에 그대로 남는다.

## 네이티브 동작 확인

- 작은 화면에서 홈 카드·상담 입력·결과에 가로 스크롤이 생기지 않아야 한다.
- 토스 상단과 콘텐츠가 겹치지 않아야 하며 뒤로가기는 현재 입력/결과 단계에서 한 단계씩 이동해야 한다.
- 질문을 작성한 뒤 다른 화면에 갔다 돌아오거나 앱을 다시 열었을 때 지원되는 상담의 초안이 복원되어야 한다.
- 모의 생성 중 화면 이탈/재진입, 일시 네트워크 차단 후 재시도에서 같은 주문을 이어가야 한다. 완료 결과는 같은 저장 원문을 열어야 한다.
- 실제 위치 허용/거절은 프라슈나의 위치 입력에서 확인한다. 거절해도 위도·경도·시간대 직접 입력으로 이어갈 수 있어야 한다.

데스크톱의 실제 AIT 검사는 위 흐름의 코드·원문·계정 경계를 확인했다. 휴대폰 SDK·키보드·OS 파일 동작은 이 문서의 현장 확인이 완료될 때까지 별도 미검증으로 남긴다.
