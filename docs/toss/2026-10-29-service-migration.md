## 순서와 완료 기준

1. 영냥이: 원본 입력·주문서·ReadingBook·보관함, Toss 인증/승인 SKU/주문 증빙, 동일 생성·저장·복구.
2. 운명의 찻집: 원본 상담 모드·카드 선택·편지·추가 질문·보관함. 화자 변경으로 대체하지 않는다.
3. 네오 전략실: 원본 입력·브리핑·현실 점검·수정 작전·전략서·재열람. 원본 checkpoint와 재시도를 보존한다.
4. 초융합: 원본 입력과 체계별 계산·통합 리포트, 기존 결과·저장 계약을 먼저 추적한 뒤 별도 단위로 검증한다.
5. 인생의 책·연애 비책·전문가 등: 원본 화면과 API 계약 목록을 작성하고 한 서비스의 입력→결과→보관→재열람이 검증되면 다음 서비스로 진행한다.

각 단계는 소유자 격리, 중복 결제/생성 방지, 취소·환불 증빙 재검증, 저장된 원본 재열람 무과금, 모바일/데스크톱 렌더링, CI를 확인한다. 개발 검사는 실 LLM·실결제·운영 DB를 호출하지 않는다. 승인 SKU/검수/실기기 검증은 별도 증거이며 로컬 성공으로 대체하지 않는다.
