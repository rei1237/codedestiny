# 앱인토스 디자인·사용성 기준

status: in-progress

## 표면과 사용 장면

기존 서비스에서 토스로 들어온 사용자가 익숙한 상담가를 알아보고, 질문을 입력하고, 결과를 편하게 읽는 모바일 화면이다. 홈/선택/입력은 Operate, 결과는 Read 모드다. 사용자 요청인 “실제 서비스와 톤앤 매너”, “디자인이 매우 중요하다”, “디자인과 기능 모두 최적화”를 기준으로 삼는다.

## 유지하는 정체성

- 영냥이: 실제 남색 별·달 의상의 흰 고양이 원화. 보라색을 주요 행동에 쓰고, 해석은 차분하고 구체적으로 전달한다.
- 연이: 현재 대표 홈에서 쓰는 한복 연이 원화, 꽃빛과 크림색, 마음과 관계를 다정하게 정리하는 문체. 찻집 고유 기능이 이식되기 전에는 그 기능이 완성됐다고 표시하지 않는다.
- 네오: 현재 대표 홈의 네오 원화, 남색·라벤더·금색, 실행할 전략을 정리하는 문체. 사용자를 모욕하거나 성공을 보장하지 않는다.
- 토스의 밝은 화면과 TDS 입력/버튼, 네이티브 뒤로가기/홈을 유지한다. 기존 웹의 어두운 세계관은 이미지와 작은 색 강조로 전달하며 전체 화면을 어둡게 바꾸지 않는다.

## 자산 출처

`Brand.tsx`는 표시용 이름·이미지·짧은 인사만 관리한다. 가격·결제 권리를 정의하지 않는다.

| 미니앱 자산 | 기존 서비스 원본 |
|---|---|
| `assets/yeongnyangi.webp` | 기존 토스 번들에 포함된 영냥이 원화 |
| `assets/yeoni.webp` | `public/images/home/illustrated/yeoni-hanbok-240.webp` |
| `assets/neo.webp` | `public/images/home/illustrated/neo-human-240.webp` |
| `assets/destiny-flower.webp` | `public/images/service-introductions/destiny-flower-320.webp` |
| `assets/tarot*-320.webp` | `public/images/service-introductions/`의 같은 이름 |

원본을 변형 없이 복사했다. 320px WebP·아래쪽 이미지의 지연 로딩·명시적 크기를 사용한다. CSR 전용 Vite 앱에는 Next Image 런타임을 도입하지 않고 일반 이미지 요소를 사용한다. 공개 웹의 검색용 페이지나 SEO 본문은 바꾸지 않으며 미니앱 진입 문서는 noindex다.

## 화면별 기준

홈은 영냥이와 질문 CTA, 세 상담가 비교, 서비스 이미지, 고민별 진입 순으로 읽힌다. 상담 선택에는 캐릭터별 메시지와 선택됨 상태를 함께 표시한다. 타로 목록은 서비스별 원화를 써서 동일한 텍스트 행의 반복을 줄인다.

카드 선택은 4열 모바일/6열 넓은 화면으로 충분한 터치 영역을 확보한다. 선택 순서·남은 장수·다음 카드의 자리를 텍스트로 알려 색상에만 의존하지 않는다. 선택 중에는 카드 배열이 바뀌지 않는다. 결과는 흐름 요약→카드 자리→해석→현실적인 행동 순서이며 긴 문단의 줄 간격을 넓힌다.

## 검증과 남은 항목

홈·상담가·타로 목록/선택/결과·복구를 360/390/430px와 넓은 화면에서 확인한다. 가로 넘침, 이미지 누락, 카드 해제/재선택, 초점 표시, 글자 확대, 화면 읽기 순서를 점검한다. 토스 실기기와 OS 글자 확대 검증은 별도 증거가 필요하다.

현재 기본 JS 청크는 약 1.34MB(압축 전)여서 크기 경고가 있다. 독립 기능은 지연 로딩하지만 실제 기기의 시작 시간/메모리 성능은 미측정이다. 경고 한도를 올려 성능 개선으로 보고하지 않는다. SDK/TDS 모듈별 비용을 측정한 뒤 기능별 분할을 추가 검토한다.

2026-10-28 확인: Chrome 390px에서 개선한 홈·연이 상담 선택 화면을 직접 확인했다. 초기 타로 선택 흐름의 가로 넘침 없음도 확인했지만, 최종 디자인 변경 후 나머지 360/430/넓은 화면과 결과 화면 검증은 브라우저 연결 지연으로 마치지 못했다. 상담가 배경색과 접근성 이름 보정은 빌드/기능 검사까지 통과했으며 최종 시각 재확인은 남아 있다. 자동 검사가 실기기 디자인 승인을 대신하지 않는다.
