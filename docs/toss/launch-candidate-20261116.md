## 출시 전에 남는 경계

- **신규 결제:** 최초 주문의 구매자 귀속 문제는 [운영 근거](./launch-operational-evidence-20261114.md#최초-주문의-구매자-귀속)를 따른다. 2026-11-16 [공식 주문 API](https://developers-apps-in-toss.toss.im/api/iap)를 다시 확인했으며, 문서의 요청은 `orderId`, 성공 응답은 주문 ID·SKU·상태·확정 시각·설명이고 구매자 식별자는 없다. 클라이언트가 제출한 주문 ID만으로 다른 계정의 권리를 부여하지 않는다. 미등록 상품의 SKU/가격 확정과 독립적인 구매자 검증 계약 또는 승인된 수동 확인 운영 체계가 필요하다.
- **음악:** 32MiB 초과 원곡 저장은 여전히 미완료다. 2026-11-16 [공식 File.saveBase64 문서](https://developers-apps-in-toss.toss.im/documentation/sdk/domains-api/file/file.savebase64)에서도 전체 base64 데이터를 전달하는 계약을 확인했다. 이 수치를 SDK 공식 용량 제한으로 표현하지 않으며, 메모리 상한을 임의로 올리거나 원곡을 잘라 제공하지 않는다.
- **휴대폰:** 새 후보에서 출생정보 입력 중 키보드/다음 버튼, 토스 뒤로가기, PDF·음원 저장, 오디오 중단/복귀를 확인해야 한다. 과거 QR18 로그인·보관함·재진입 사용자 확인은 새 버전 전체 실기기 검증을 대신하지 않는다.
- **운영:** 기존 로그인 수선 릴리스는 반복하지 않는다. 상품 노출·실결제·새 검토 제출·공개 출시는 이 문서 작성으로 실행하지 않는다. 상단 앱 이름은 사용자가 담당한다.
