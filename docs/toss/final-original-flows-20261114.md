## 남은 기술·운영 경계

- 음악 다운로드의 32MiB 초과 원곡 저장은 미완료다. 설치 SDK 3.7.0의 파일 API가 `saveBase64`만 지원하고 URL·스트림·append 저장을 제공하지 않아 메모리 경계에서 차단한다. 새 구매 정책이나 권리 만료가 아니며 기존 구매권리는 보존한다. 실제 곡별 크기와 기기 저장 확인 전 해당 곡의 판매를 열지 않는다.
- 실제 음원 재생·파일 저장, 동물 카드 저장/공유, 키보드·네이티브 상단/뒤로가기는 휴대폰 확인이 남는다. 모의판은 실음원을 가져오지 않아 음악 재생 오류가 보일 수 있으며 구매·보관함 검증과 분리한다.
- 운영 로그인 키·mTLS·DB/개인정보 고지 일치, 개별 SKU 가격, 최초 구매자 독립 증명은 운영 게이트다. 신규 판매는 닫혀 있다. 무료 계산 및 이미 검증된 소유 결과 범위의 출시안은 `launch-operational-evidence-20261114.md`를 따른다.
