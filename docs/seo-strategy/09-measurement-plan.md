## 1. 데이터 소스 접근 상태 (2026-08-11 기준)

| 소스 | 상태 |
|---|---|
| Google Search Console | 코드상 `google-site-verification` placeholder(미인증으로 보임). Cloudflare DNS TXT로 별도 인증됐는지 **사용자 확인 필요** |
| 네이버 서치어드바이저 | `naver-site-verification` 코드 2개 병기, 어느 계정이 유효한지 불명 |
| Google Trends / 네이버 데이터랩 | 정량 수치를 가져올 도구 없음 — 이 세트에서 다루지 않음 |
| 정성적 SERP 체크 | WebSearch로 실제 구글 검색결과 확인 가능(도구 있음) — 이번 세션 범위 밖, §5에 결과 입력 자리만 마련 |

## 2. 추적 지표 정의

| 지표 | 정의 | 소스 | 집계 단위 |
|---|---|---|---|
| Impressions(노출) | 검색결과에 URL이 노출된 횟수 | GSC | 클러스터/URL/로케일 |
| Clicks | 노출 후 클릭 수 | GSC | 클러스터/URL/로케일 |
| CTR | Clicks/Impressions | GSC | 클러스터/URL/로케일 |
| 평균 순위 | 평균 검색 순위 | GSC | 클러스터/URL/로케일 |
| 색인된 페이지 수 | 색인 생성 커버리지 리포트 | GSC | 사이트 전체 |
| non-brand query 수 | 브랜드명이 포함되지 않은 검색어 수 | GSC 검색어 리포트 | 사이트 전체 |
| 롱테일 query 수 | 4어절 이상 검색어 수 | GSC 검색어 리포트 | 사이트 전체 |
