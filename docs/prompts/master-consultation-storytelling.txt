Code Destiny의 마스터가 있는 대표 상담 진입 화면을 개선해줘.

프로젝트 AGENTS.md와 CLAUDE.md를 먼저 읽고, 실제 코드에서 상담 서비스와 담당 마스터의 연결을 확인해줘. 마스터가 없는 일반 운세는 제외하고 캐릭터나 담당 관계를 추측하지 마.

참고 페이지: https://cheongwoldang.com/b/blackmoontotal
캐릭터 소개와 웹툰을 통한 스토리텔링 구성 방식을 실제 화면에서 조사하되 그림·문구·설정·효과 보장 표현을 복제하지 마. 이전 조사에서는 첫 캐릭터 장면만 확인했으므로 후속 웹툰 구간은 직접 확인해줘.

먼저 대상 상담 목록, 담당 마스터, 기존 진입 경로를 정리하고 첫 작업 대상으로 적절한 상담 하나를 추천해줘. 내가 선택하면 그 상담 하나만 진행하고 다른 상담으로 자동 확대하지 마.

목표 구성: 캐릭터 소개 → 고민에 공감하는 짧은 웹툰 → 상담에서 살펴보는 내용 → 실제 결과 예시 → 이용 조건 → 상담 시작.

기존 마스터의 얼굴·설정·말투·자산을 우선 사용하고 추가 웹툰·표정·포즈가 필요한 부분은 구분해 제안해줘. 실제 결과 예시는 확인 가능한 기존 자료만 사용하며 예시임을 표시해줘.

고급스러운 캐릭터 중심 스토리텔링에 기존 달빛 예화 분위기와 둥글고 읽기 쉬운 UI를 이어가줘. 긴 소개를 다 읽지 않아도 상담 내용과 이용 조건을 확인하고 시작할 수 있게 해줘.

조사 → 운영 코드와 분리된 시각 목업 → 내 승인 → 구현 → 검증 순서로 진행해줘. 목업에는 결제·상담 API를 연결하지 마.

서비스 선택 진입 화면(/), 꿀꿀운세 메인(/ggulggul/), 다른 상담 화면은 이번 범위에서 제외해줘. 이용권·월정석·단건 결제 정책과 기존 가격 데이터, 인증·입력·결과 생성·저장·딥링크는 유지해줘.

한 상담이 완료되면 수정 파일, 검증 결과, 남은 확인을 보고하고 다음 상담은 내가 선택한 뒤 진행해줘.
