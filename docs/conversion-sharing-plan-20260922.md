# Code Destiny 구매·검색·공유 개선 계획

## 판단과 범위

운세 종류를 더 늘리기 전에 **상담사 신뢰 → 상담 예시 → 고민 선택 → 가격 확인 → 저장된 결과 → 친구의 새 상담**을 연결한다. 흰 고양이 영냥이, 꽃돼지 연이, 네오의 정체성과 기존 결제 정책은 유지한다. 이 문서는 2026-09-22 공개 페이지와 소스 조사에 따른 계획이며 전환율·매출·검색 순위 상승을 측정한 보고서가 아니다.

경쟁사 내부 전환율, 유료 결과 전문, 실제 공유 수신 과정은 조사하지 않았다. 공개 UX 관찰을 사업 성과의 원인으로 단정하지 않는다.

## 신뢰 메시지 원칙

- 중심 문구: **10년 경력 운세 상담사·명리학자가 만든 서비스.** 경력은 제작자 제공 사실이며 개별 AI 답변의 인적 검수를 뜻하지 않는다.
- 증거 중심 문구: **대통령의 변화가 오기 전, 2025년을 짚은 기록.**
- [2024-05-12 윤석열 분석](https://blog.naver.com/neosaju/223444062729)은 2025년 운세 변화·송사 가능성을, [2024-05-27 이재명 분석](https://blog.naver.com/neosaju/223459696339)은 대통령 가능성과 2025년을 다룬다. 이번 조사에서 모바일 원문과 표시 게시일을 직접 확인했다. 원문의 사후 수정 여부를 독립적으로 검증한 것은 아니다.
- [2022-09-16 윤석열 분석](https://blog.naver.com/neosaju/222876455500)에서도 2025년쯤 정치계 주요 인물의 변화와 사건 가능성을 다룬다. 작성자 네오·표시 게시 시각 18:28·현재 본문을 이번에 직접 확인했다. 사용자가 이미 제공한 활동명과 기존 출처를 다시 요청하지 않는다.
- 과거 글에는 가능성·조건·다른 시기와 예측 실패의 언급도 있다. ‘모든 예측 적중’, ‘유일’, ‘정확한 날짜 보장’으로 확대하지 않는다. 캐릭터 프롤로그와 실제 증거 설명을 구분한다.
- `lib/brand/founder.ts`와 기존 `prediction-records.json`을 정본으로 사용한다. 공개 SEO 구조화 데이터에 적중률·가짜 수상·리뷰 점수를 추가하지 않는다.

## 모든 상담 결과의 공유 기준과 확장 순서

공유 버튼만 붙이는 것으로 완료하지 않는다. 각 결과는 **요약 선택, 전송 전 확인, 필요한 경우 문구 편집, 프로필·질문 필드 자동 첨부 방지, 이미지 또는 문구 폴백, 해당 상품의 공개 진입, 취소 처리**를 갖춰야 한다. 해석 본문에 개인적인 내용이 들어 있을 수 있으므로 편집기에서 전송 전 확인을 안내한다. 결과를 받은 친구에게 소유자 결과나 결제 권한을 넘기지 않는다.

| 상담군 | 이번 상태 | 다음 구현·검증 단위 |
|---|---|---|
| 영냥이 28개 유료 상품 | 공통 공유 편집기 개선, 상품별 URL 단위 검사 | 상품군별 실제 수신 미리보기는 운영 적용 후 사용자 동작으로 확인 |
| 영냥 신점·호라리 | 공통 편집기 추가, 익명 소개에도 해당 모드 링크 | 질문·도시·관계 자동 노출 여부와 취소 확인 |

## 구매 전환 다음 단계

1. 대표 진입을 ‘내 성향’, ‘그 사람’, ‘일과 돈’처럼 고민으로 안내하되 기존 주제·가격 registry를 재사용한다. 홈에 이미 있는 고민 버튼을 재활용하고 검색 도구 링크는 보존한다.
2. 상품 상세에 해당 상품의 질문 예시, 실제 제공 챕터, 명확히 표시한 편집 예시, 가격·결과 재열람을 함께 둔다. 실제 고객인 척하는 예시·후기는 금지한다.
3. 저장 완료 후 짧은 요약을 먼저 보여주고, 공유와 ‘이 질문 더 살펴보기’를 결과 맥락에 맞춘다. 새 결제는 사용자 선택 후에만 진행한다.
4. 후기 수집은 작성 동의·수정·삭제·실제 구매 확인 정책을 정한 뒤 별도 작업으로 한다. 이번 변경에는 후기 DB나 공개 쓰기가 없다.

- 운영 적용일 전후 동일 URL의 28일 GSC 클릭·노출·CTR·평균 순위를 비교한다. 국가·기기·검색어 묶음을 분리하고 계절성·표본 크기를 같이 보고한다. 아직 효과 수치는 없다.

## 측정·검증·롤백

전환 분모는 동의한 적격 방문자 기준으로 정하고 내부 QA·봇·결제 복귀를 구분한다. 상세 보기 → 결제 시작 → 서버 확인 구매 → 저장 완료 → 첫 열람 → 공유 실행 → 공유 유입을 별개로 본다. 구매는 기존 서버 확인 이벤트를 유지한다. 공유 `opened/shared`는 실제 대화방 전송·수신 증명이 아니다. 개인 질문·결과 본문·프로필·주문 ID를 분석 이벤트에 넣지 않는다.

공식 전달은 관련 mock 검사와 `check:fast` 후 독립 커밋 → main 병합 → push → `CI required` 확인이다. 새로운 배포 권한, 가격 변경, 운영 DB 쓰기, 실결제·유료 LLM 호출, 메시지 발송을 포함하지 않는다. 회귀 시 이번 커밋만 revert하며 다른 세션의 작업은 보존한다.

수동 UI 점검은 390·1280px의 홈·신뢰·무료 공유와 기존 360·390·430·1280px 유료 공유 검사를 사용한다. 전체 사이트 접근성·성능 종합 점수는 아직 측정하지 않았으며 일부 화면 점검을 전체 감사로 표현하지 않는다.

## 바로 활용할 마케팅 문구

- 홈·프로필: **10년 경력 명리학자의 상담 경험, 사주보는 고양이 영냥이로 만나보세요.**
- 출처 연결 게시물: **2024년에 쓴 글은 왜 2025년을 짚었을까요? 대통령 운세를 분석한 공개 기록부터 확인해 보세요. 그 상담 경험을 영냥이에 담았습니다.** 게시일과 원문 링크를 함께 둔다.
- 첫 상담 유도: **내 고민에는 어떤 흐름이 있을까. 상담 예시와 가격을 먼저 살펴보고, 영냥이에게 궁금한 이야기를 들려주세요.** 가격을 넣는 UI는 registry 값을 사용한다.
- 단톡방 공유: **나는 이런 흐름이래. 너는 어때?** 다음 줄에 사용자가 고른 요약과 해당 상담의 공개 링크를 둔다.
- 연이 공유 확장: **오늘 내 마음에 남은 한 문장. 너에게도 건네고 싶어서.**
- 네오 공유 확장: **이번 주 내 작전은 이거야. 너라면 어디부터 바꿀래?**

이 문구는 게시용 초안이며 외부 SNS·메신저에 발송하거나 게시하지 않았다.
