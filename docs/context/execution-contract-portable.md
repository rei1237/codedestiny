# 다른 프로젝트에 적용할 실행 계약
이 문서는 Code Destiny 런타임 정책의 정본이 아니다.

- 작업 위험도는 동작 변경과 공유 경계로 판정한다. 파일 수만으로 정하지 않는다.
- 필요한 문서만 읽고 심볼·import·호출부 순으로 범위를 확장한다.
- 동시 편집은 독립 작업 공간으로 격리한다.
- 승인된 범위 안에서는 수정·관련 검증까지 완료한다.
- 검증 누락을 성공으로 처리하지 않는다. 실행 명령과 결과를 보고한다.
- 과금·운영 쓰기는 각 프로젝트의 명시적 승인 경계를 따른다.

Code Destiny의 구체적 규칙은 [CLAUDE.md](../../CLAUDE.md).
