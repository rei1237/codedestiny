# 근거에 연결한 공감 해석

2026-10-07 사용자 요청: 영냥이·연이·네오 상담에서 타고난 성향만 설명하지 않고, 내 이야기처럼 느껴지는 노력과 버거움의 장면을 최우선으로 보강한다.

## 진단과 적용

기존 fortune-master와 consultation-quality에는 가상 생활 장면·강점·부담·단정 금지가 있었다. 체계별로 어떤 계산 근거를 공감 장면에 연결할지 선택하는 공통 경로는 없었다. 새 `prompts/domain/recognition.ts`는 **선택된 기존 사실**의 ID·label·값 존재 여부를 읽어 해석 후보를 구성한다. 별도 계산기·LLM 호출·새 사용자 결과 필드·추가 재시도는 없다.

|---|---|---|---|
|사주|십성 위치, 월령, 원국 작용, 계절·강약·용신·종격, 허용된 시기|맡은 책임과 자기 요구의 간격, 표현·거절에 드는 노력, 익숙한 대응을 바꾸는 부담|십성·오행 하나로 희생·고난을 확정하지 않음. 기존 종격→억부→조후 우선순위|
|자미두수|명궁·신궁·복덕궁·관록궁 등 궁과 별, 사화·삼방사정|밖에서 맡는 역할과 혼자 편안해지는 조건의 차이, 기대·책임이 겹치는 영역|중복 궁을 별도 증거로 세지 않음. 화기=불행 금지|

## 답변 계약

질문에 직접 답하고, 근거의 쉬운 뜻 → 관련 생활 조건 → 그때 들 수 있는 감정·노력 → 작은 행동을 기존 해석·생활 장면 문단에 연결한다. 모든 사람에게 고통이 있다고 전제하지 않는다. 사용자가 밝힌 경험과 조건부 예시를 구분하며 근거 없는 과거를 “수 있어요”로 포장하지 않는다. 맞지 않는 장면은 정정할 수 있게 한다.

최초 답변은 `StructuredChapterProvider`의 `recognition`, 후속은 `questionConversation`의 동일한 계약을 사용한다. 영냥이·연이·네오는 표현만 다르고 근거·판단·불확실성·행동의 의미는 같다. 모든 가격 등급에 제공한다. 확인·정정·지원에는 해석을 억지로 추가하지 않는다. 기존 출력 예산과 저장·횟수 계약을 유지한다.
