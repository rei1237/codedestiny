# 출석 꿀방울과 기본 풀이 — 2026-10-17

사용자 최종 승인: 꿀방울은 결제의 대안이다. 기존 이용권·월정석·단건 결제 경로를 유지한다.

| 상품 | 단건 결제 | 꿀방울 |
|---|---:|---:|
| 나의 매력 클래스·인생 스킬 트리 | 각각 1,000원 | 각각 6개 |
| 전환 목록의 기존 5,000원 콘텐츠 18종 | 각각 5,000원 | 각각 30개 |
| 기본 종합 사주 풀이 | 10,000원 | 60개 |
| 사주 대운 풀이 | 20,000원 | 120개 |

목록·필요 개수는 `worker/lib/honey-unlock-catalog.js`, 현금 가격은 기존 billing registry가 정본이다. 서비스 묶음이 아닌 개별 콘텐츠다. 화폐 교환 가치는 표시하지 않는다. AI 상담·나머지 프리미엄 상품·월정석·사자 휘장은 변경하지 않는다. 프롬프트 1개, 꿀편지·타로 앨범 각 10개와 상담 보상도 유지한다.

출석은 KST 계정별 하루 1개다. 2026-10-24부터 5일 연속 출석(5·10·15…일째)마다 보너스 4개를 더해 그날 총 5개를 준다. 하루라도 빠지면 1일째부터 다시 센다. 보상 수치는 서버 상수(`HONEY_STREAK_EVERY`, `HONEY_STREAK_BONUS`)만 신뢰하고, 홈 출석 카드는 이번 달 출석 달력과 5일 도장판으로 보여 준다. 연속 기록이 없던 기존 출석자는 어제 출석했으면 1일 연속에서 이어 간다. 같은 날 구정책 출석 원장의 amount가 0인 경우에만 1개 보충하고, 이미 1개면 지급하지 않는다. 과거 날짜에는 소급하지 않는다.

해금은 로그인한 계정의 저장 프로필에서 출생 신원을 계산한다. 지갑 차감·요청 원장·영구 권리를 같은 Mongo 트랜잭션에 넣는다. 같은 계정·출생정보의 기존 권리는 재차감 없이 읽는다. 트랜잭션을 사용할 수 없는 환경에서는 지급을 실패시키며 비원자 처리로 폴백하지 않는다. 완료 주문과 저장 결과 원본은 다시 쓰지 않는다.

기본 풀이: 성향·강점·반복 패턴·큰 흐름. 전문가 AI 상담: 현재 질문과 명식을 연결한 핵심 답변·선택 전략·30일 실천 방향. 기본 풀이 구매는 상담 선행 조건이 아니다.

## 측정

해금 원장은 `reason=HONEY_CONTENT_UNLOCK`, `featureKey`, `amount`를 기록한다. 기존 attendance 원장의 보충도 amount에 반영한다. 승인된 익명 원장 내보내기를 `node scripts/report-honey-economy.mjs <file.json>`에 넣으면 출석 지급량·콘텐츠별 소비·실제 제공된 AI 비용을 집계한다. 입력은 `{ ledgers: [...], aiRuns: [{featureKey,costKRW}, ...] }`다. 비용이 누락된 실행은 0원으로 계산하지 않고 미측정 건수로 보고한다. 계정·출생정보는 보고서에 출력하지 않는다.

출석만으로 모으면 6·30·60·120회가 필요하다. 상담 보상 보유자는 더 빨리 열 수 있다. 구정책의 3회당 1개와 비교하면 같은 출석 수에서 장기 지급량은 3배다. 실제 재방문·소비·AI 비용 변화는 배포 후 관측해야 하며 이번 작업은 운영 DB·실결제·실 LLM을 사용하지 않는다.
