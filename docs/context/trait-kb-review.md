# Trait-First 사주 성향 KB 검수표

네오(또는 자문 명리학자) 검수용. 정본은 [saju-kb.js](../../worker/lib/trait-profile/saju-kb.js) (`saju-trait-kb-20261122-v1`)이며 이 표는 그 파일에서 생성했다. 고칠 때는 코드 파일을 고치고 이 표를 다시 만든다.

- 계산 사실(십성 분포·월지 본기·신강약·시주 미상)은 [saju-temperament.js](../../worker/lib/saju-temperament.js), 오행 29%·16% 판정은 [saju-derived-signals.js](../../worker/lib/saju-derived-signals.js)가 정본이다. KB는 해석 재료만 담는다.
- 원천은 [지시서 부록 A](../handoff/trait-first-upgrade.md)다. 건강·질병처럼 들리는 표현(예: 수 과다의 "우울감")은 옮기지 않았고, 오행 문장은 기존 TEMPERAMENT를 그대로 쓴다.
- 희신은 넣지 않았다(게이트 A). 특수 조합(A-4)은 1차에서 판정하지 않고, 함께 관측된 역할만 조건부 힌트로 둔다.
