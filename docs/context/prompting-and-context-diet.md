# 요청과 컨텍스트 범위

현재 실행 계약은 [CLAUDE.md](../../CLAUDE.md)다. 2026-09-08 승인으로 파일 수 기반 RED 판정을 폐기했다.

## 요청
대상 경로 또는 기능, 현재 현상, 원하는 동작, 변경 범위를 전달한다.
한 작업은 하나의 동작 목표로 묶는다. 함께 바뀌어야 하는 파일을 억지로 별도 작업으로 자르지 않는다.
위치가 불명확하면 [작업 지도](../../ARCHITECTURE.md)에서 관련 기능을 찾는다.

## 실행
- 심볼 → import → 호출부 순으로 확인한다. 5~15파일은 목표이지 강제 제한이 아니다.
- 작은 문구·CSS 수정 때문에 전체 문서나 저장소를 읽지 않는다.
- 같은 근거·통과한 검사는 입력이 바뀌지 않았다면 반복하지 않는다.
- 동시 편집의 격리와 코드 위험도를 구분한다. 워크트리는 유지한다.
- 긴 로그·이미지 전문 대신 경로와 필요한 부분을 제공한다.
- 결과는 문제·수정 파일·테스트 결과·남은 위험 중심으로 적는다.

## 측정
과거 2026-09-06 실측은 당시 계약의 결과이며 현재 성능 보장이 아니다.
현재 기준선과 비교 방법은 [개발환경 측정](../dev-environment-baseline.md)에 기록한다.
