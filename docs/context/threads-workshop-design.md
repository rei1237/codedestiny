# Threads 작업실 디자인 기록

2026-10-25에 구현한 `/admin/threads/`만 설명한다. 정본은 `app/admin/threads/page.tsx`이며, 공용 형태는 `app/admin/_hq/components.tsx`, 버튼은 `app/admin/_components/ui.ts`, 토큰은 `app/admin/admin-yehwa.css`를 따른다. 이 문서는 기존 루트 `DESIGN.md`나 전역 디자인 설정을 대체하지 않는다.

## Overview

기존 별빛 운영본부 안에서 Threads의 기존 기록을 확인하고 마케팅 스튜디오의 원고 작성·검토·복사 흐름을 안내한다. 연이의 기존 안내 이미지를 재사용하고 실제 기능명인 “Threads 작업실”을 명확하게 보여 준다.

## Colors

관리자 공용 남색 배경·표면, 아이보리 본문, 보조 글자와 상태색을 유지한다. 새로 보기·내부 이동에는 공용 중립 버튼, Threads 외부 열기에는 공용 보라색 주 버튼을 사용한다. 금색은 기존 본부의 장식 역할을 따르며 스튜디오의 금색 버튼 토큰을 관리자에 복제하지 않는다.

## Typography

제목·설명·패널 제목·기록 보조문은 기존 공용 계층을 사용한다. 화면 제목과 캐릭터 이름을 텍스트로 제공하고 상태 배지에는 아이콘과 상태명을 함께 표시한다. 작은 기존 기록 캡션을 새로운 본문 표준으로 확대하지 않는다.

## Layout

머리말과 새로 보기, 연이 안내, 오늘의 상태, 원고에서 게시까지, 이전 기록과 원문 순으로 세로 배치한다. 패널 사이 간격은 (24px)이며 머리말 행동·기록 행의 제목과 배지·바로가기는 좁은 화면에서 자연스럽게 줄바꿈한다. 게시 ID는 긴 문자열도 줄바꿈한다. 별도 다열 카드 격자나 Threads 전용 반응형 분기를 추가하지 않고 기존 관리자 셸을 따른다.

## Components

- **공용 패널:** `HqPanel`의 표면·테두리·제목 구분선과 기존 모서리를 재사용한다. 첫 패널은 조회 시각·서버 모드·작업 상태·확인된 게시 ID를 표시한다.
- **안내와 행동:** `KeeperLine`은 기존 연이 이미지와 준비 안내를 나란히 배치한다. 작업 순서는 실제 순서가 의미를 가지는 번호 목록이다. 연결 상태, 기존 Threads 증빙, WordPress 원문 링크를 제공한다.
- **상태:** 첫 조회 중에는 공용 로딩, 첫 조회 실패에는 재시도 오류 화면을 표시한다. 갱신 실패 시 이전 결과와 경고를 함께 유지한다. Threads 기록 오류, 자료 없음, 오늘 작업 없음, 서버 자동 발행 꺼짐과 기존 설정 존재를 각각 다른 문구로 설명한다. 새로 보기 중에는 해당 버튼을 비활성화한다.
- **공개 경계:** 이 화면은 기존 서버 기록을 조회한다. 원고 검토·복사·Threads 열기를 게시 완료로 표시하지 않으며 공개 발행·예약·기존 크론 실행·재시도를 호출하는 컨트롤은 없다. 사람의 원고 검토 뒤 실제 Threads에서 계정·글 순서와 공개 여부를 확인하도록 안내한다.

## Do's and Don'ts

- **Do** 기존 공용 토큰·초점·hover·비활성·reduced motion 처리를 유지한다.
- **Do** 기록 없음과 성과 없음, 원고 검토와 공개 완료를 구분한다.
- **Don't** 기존 보관 기록을 새 게시 지시로 재실행하거나 외부 열기를 자동 발행으로 바꿔 설명한다.

이번 완료 리뷰의 시각 판정 범위는 관리자 (1920px/390px) 캡처다. 나열한 상태는 코드에서 확인했으며 모든 상태의 캡처나 전체 관리자 디자인 시스템 승인을 의미하지 않는다. 구현·공용 토큰·캐릭터 원본·전역 DESIGN.md와 sidecar는 이 문서 작업에서 변경하지 않았다.
