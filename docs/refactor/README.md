# 구조 부채 원장

측정일: **2026-09-12** (명시 없는 모든 수치는 이 날짜의 실측)

## 이 폴더가 무엇인가

[ARCHITECTURE.md](../../ARCHITECTURE.md) 는 **탐색 지도**다 — "이 기능을 고치려면 어디서 시작하는가". 이 폴더는 **구조 부채 원장**이다 — "무엇이 왜 고장 나기 쉬운가, 어떤 순서로 고치는가". 둘은 대체 관계가 아니다.

| 문서 | 답하는 질문 |
|---|---|
| [architecture-map.md](architecture-map.md) | 지금 구조가 실제로 어떻게 생겼나(측정값) |
| [regression-risk-map.md](regression-risk-map.md) | 어느 파일을 만지면 위험한가, 등급별로 무엇을 먼저 해야 하나 |
| [structural-issues-top20.md](structural-issues-top20.md) | 고쳐야 할 것 20개, 근거 포함 |
| [phase-plan.md](phase-plan.md) | 어떤 순서로 고치는가, 지금 어디까지 왔나 |

## 운영 규칙

**낡은 리팩터링 문서를 새로 쌓지 않는다.** 이 4개를 갱신한다. Phase 를 끝낼 때마다 [phase-plan.md](phase-plan.md) 의 진행 표와, 해소된 항목의 [structural-issues-top20.md](structural-issues-top20.md) 행을 고친다.

**측정값에는 날짜를 남긴다.** 줄 수·커밋 수·중복 개수는 시간이 지나면 틀린다. 날짜 없는 숫자는 다음 세션이 믿을 수 없고, 그러면 전체를 다시 측정하게 된다 — 이 원장의 존재 이유가 사라진다.

## 🔴 이번 리팩터링의 작업 규칙

> **중복된 판정을 없애는 변경은 한다. 파일을 옮기는 변경은 하지 않는다.**

판정에 정본이 아예 없을 때만 모듈 하나를 새로 **추가**한다(추가는 가드를 깨지 않는다). 정본이 있으면 호출부를 그쪽으로 돌린다.

근거는 [architecture-map.md](architecture-map.md) 의 「왜 폴더를 옮기지 않는가」 절에 있다. 요약하면 이 레포의 안전망이 **경로 모양**이라서, 파일을 옮기면 테스트와 가드가 조용히 꺼진다 — 1순위(회귀 방지)를 깎아 미관을 사는 거래다. 그리고 파일 이동은 중복 판정을 0개 줄인다.

우선순위: **회귀 방지 > 안정성 > 유지보수성 > 코드 미관.**
