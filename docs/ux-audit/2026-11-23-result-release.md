## 상단 로그인·회원가입

대표 홈과 꿀꿀 운세에서는 로그인과 회원가입 버튼으로 해당 화면을 한 번에 연다. 한국어 웹 영냥이에서는 선택한 탭이 열린다. 영냥이의 앱 버전과 다국어 화면에서는 선택한 계정 화면으로 바로 간다. 앱의 소셜 로그인은 기존 네이티브 인증 화면을 사용한다. 가입 또는 로그인 뒤 방문하던 주소로 돌아갈 수 있도록 경로와 검색 조건, 해시를 전달한다.

로그인한 사람은 대표 홈의 ‘내 계정’에서 꿀꿀 운세 기록과 영냥이 상담 기록을 각각 열 수 있다. 각 서비스 홈의 계정 버튼은 기존 회원 메뉴를 연다. 대표 홈에서는 Esc로 계정 목록을 닫으면 ‘내 계정’ 버튼으로 포커스가 돌아온다.

## 결과 화면
