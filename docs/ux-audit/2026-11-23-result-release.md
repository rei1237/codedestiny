# 2026-11-23 결과 화면·상단 계정 진입 검증

## 상단 로그인·회원가입

대표 홈과 꿀꿀 운세에서는 로그인과 회원가입 버튼으로 해당 화면을 한 번에 연다. 한국어 웹 영냥이에서는 선택한 탭이 열린다. 영냥이의 앱 버전과 다국어 화면에서는 선택한 계정 화면으로 바로 간다. 앱의 소셜 로그인은 기존 네이티브 인증 화면을 사용한다. 가입 또는 로그인 뒤 방문하던 주소로 돌아갈 수 있도록 경로와 검색 조건, 해시를 전달한다.

로그인한 사람은 대표 홈의 ‘내 계정’에서 꿀꿀 운세 기록과 영냥이 상담 기록을 각각 열 수 있다. 각 서비스 홈의 계정 버튼은 기존 회원 메뉴를 연다. 대표 홈에서는 Esc로 계정 목록을 닫으면 ‘내 계정’ 버튼으로 포커스가 돌아온다.

## 결과 화면

꿀꿀 기본 사주는 이름과 일지 동물을 연이 정원 그림 옆에 배치했다. 600px 이하에서는 생년월일·음력·지역 시각 보정이 다음 행의 전체 폭을 사용한다. 저장한 기록은 연이와 네오의 공식 그림을 구분한다. 영냥이 일반 결과에는 야간 표지 한 장을 사용하고, 신점의 완료 영수증은 풀이 뒤에서 확인한다.

| 실제 검수 항목 | 변경 전 | 변경 후 |
|---|---:|---:|
| 영냥이 신점 첫 답 위치, 390px | y498px | y203px |
| 영냥이 신점 결과의 로컬 레이아웃 이동, 390px | 1.021 | 약 0.03 |
| 신점·일반·연이·네오 기록의 보관함 진입 적중 | 미검증 | 처음·중간·끝과 4개 폭에서 48/48 |
| 최종 기본 사주 표지의 그림 폭, 360·390·430·1280px | 해당 그림 도입 전 | 85.83·94.53·106.12·178px |

실제 무료 사주 입력과 계산, 모의 주문으로 연 저장 결과를 구분해 확인했다. 7개 화면의 전후 캡처 56장은 360·390·430·1280px에서 열리고 원본 링크와 일치한다. 저장 결과 화면의 가로 넘침과 페이지 오류는 검수한 16개 조합에서 0건이다. 실기기 GPU·배터리와 사용자가 느끼는 눈 깜빡임은 미검증이다.
