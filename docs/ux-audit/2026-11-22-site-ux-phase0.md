### 결제와 검색 노출

- 정본 셸·독립형·React 선택창을 비교했다. `verify:payment-choice-parity`가 10개 렌더러, 107개 CSS 선언과 12개 언어의 87개 키를 대조했다. 결제창을 여는 순서, 상품·가격, 이용권·월정석·단건의 선택과 결제 복귀 동작은 기존 검사를 통과했다.
- 결제 동결 대상 `app/_lib/billing-client.ts`의 공유 스크립트 URL 지문 갱신을 `config/payment-freeze.json`에 반영했다. 감사는 기존 게이트 함수 본문과 변경 후보를 비교하고 공유 키보드 처리가 기존 취소 분기로만 돌아감을 확인했다. 운영 결제·과금 LLM·운영 DB 쓰기 0회.
- 공개 `/`와 `/yeongnyangi/`는 자체 canonical·언어 대체·제목·설명·H1을 유지한다. 꿀꿀의 공개 정적 셸은 기존 라우트 생성기와 미러를 사용한다. `/records/`, `/yeongnyangi/room/`, `/yeongnyangi/result/`, `/yeongnyangi/library/`의 robots는 noindex, nofollow이다.
- 실사용 전 기간 CrUX(2026-10-24~11-20)에서 origin 전체 기기의 p75는 LCP 1,715ms, CLS 0.03이다. 모바일 및 세 개 개별 URL 필드 데이터 없음. INP 수치도 없다. 배포 후 모바일 지표로 사용할 수 있는 자료는 아직 없다.
- K10·K11 실기기 깜빡임 자연스러움과 GPU·배터리는 미검증. 모션 줄이기에서의 시트 요청 0B는 Chromium 계측이다.

### 터치와 첫 방문 동의

동일한 실효 타깃 검사기를 기준·후보에 사용했다. 닫힌 details 안의 컨트롤과 1px 라디오의 연결된 label을 구분하고, 한쪽만 보이는 가로 카드에서도 실제 누를 수 있는 폭을 측정한다.

꿀꿀 셸은 360·430px에서도 각 149개 중 미달·가림 0이다. 1280px는 판정한 154개 중 미달 0, 다른 요소에 가려 판정할 수 없는 2개다. 홈페이지 수치는 원본 React 라우트 fixture에서 측정했다. 영냥이 503 상태의 독립 보관함 링크는 네 폭 모두 실효 높이 45px, 재시도 버튼 57px다.
