# PG사 심사용 테스트 결제 시나리오 (2026-08-11)

> PortOne 등 PG사가 해외카드·해외결제 채널 심사를 진행할 때 참고할 수 있도록, 현재 서비스의 실제
> 결제 플로우를 시나리오 형태로 정리한 문서다. **이 문서는 코드를 근거로 작성한 설명 자료이며,
> 실제 결제 실행 화면 캡처나 라이브 테스트 결제를 포함하지 않는다** — 실호출·실결제는
> [코딩 원칙 8번](../CLAUDE.md)에 따라 사용자의 명시적 1회 승인 없이는 수행하지 않는다.
> 심사관이 실제로 화면을 확인해야 한다면 스테이징/프로덕션 환경에서 아래 절차를 직접 재현하거나,
> 서비스 운영자에게 스크린샷·녹화 제공을 요청해야 한다.

## 0. 결제 정책 원문

절차의 세부 규칙(게이팅 우선순위, 결제창 3옵션, 원자성 보장 등)은 아래 정본 문서를 따른다.
이 문서는 그 정책을 심사 시나리오 형태로 재구성한 것이며, 두 문서가 어긋나면 아래가 정본이다.

- [payment-policy-overview.md](payment-policy-overview.md) — 재화(이용권/월정석/코인) 정의
- [payment-policy-content-access.md](payment-policy-content-access.md) — 잠금 콘텐츠/회당 결제 판별
- [payment-policy-flow.md](payment-policy-flow.md) — 게이팅 우선순위, 결제창 노출 규칙

## 1. 서비스 개요

- **사업자**: 코드 데스티니 (Code Destiny), 대한민국 소재 (사업자 등록 정보는 각 언어 이용약관 16조 참고)
- **서비스 형태**: AI 기반 사주·타로·점성술 운세 해석 콘텐츠 (디지털 콘텐츠, 즉시 제공형)
- **결제 통화**: 대한민국 원화(KRW) 단일 — 다른 통화 결제는 현재 지원하지 않는다
- **결제 수단**: 신용카드 (PortOne V2 경유, PG사: KG이니시스)
- **과금 방식**: (a) 30일 이용권(구독형이나 자동갱신 없음), (b) 상품별 단건 결제, (c) 이벤트로 지급되는 월정석(별도 구매 불가)
- **다국어 지원**: UI 12개 언어(`lib/i18n/locale-normalize.js`), AI 응답 5개 언어(ko/en/ja/zh-CN/zh-TW), 결제 화면 자체는 한국어 UI + 브라우저 번역 오버레이(현재 결제 실행 로직은 언어와 무관하게 항상 KRW로 처리)

## 2. 시나리오 A — 신규 사용자의 단건 결제

1. 로그인한 사용자가 유료 기능(예: 사주 심화 리포트)을 클릭한다.
2. 로컬 구독 스냅샷이 "미보유"를 확답하므로 서버 왕복 없이 즉시 결제창이 열린다(`js/core/pass-verdict.js`).
3. 결제창에는 **[이용권으로 구매] · 단건 결제(KRW) · 월정석** 3옵션이 항상 함께 노출된다(`_cdChooseServicePaymentMode`, `app/_lib/billing-client.ts`의 `openReactPaymentChoiceModalInner`).
4. 사용자가 **단건 결제**를 선택하면 그 시점에만 `/api/billing/checkout`이 1회 POST되어 주문이 생성된다(사전발급 금지 — 결제창을 여는 시점에는 POST하지 않는다).
5. PortOne V2 SDK가 열리고 사용자가 카드 정보를 입력해 결제를 완료한다.
6. 서버가 PortOne 결제 승인을 1회 확인(`confirm`)하고, 성공 시 콘텐츠 생성이 즉시 시작된다.
7. **공급 시점**: 결제 승인 확인과 동시에 디지털 콘텐츠 제공이 시작된다(별도 배송 없음) — 이용약관 12조 "공급시기" 조항과 일치.

검증 포인트: 결제 금액이 서비스 화면에 표시된 금액과 정확히 일치하는지, 통화가 KRW로 명확히 표시되는지, 결제 실패 시 POST가 자동 재시도되지 않고 사용자 행동으로만 재시도되는지(`payment-policy-flow.md` "결제 POST 자동 재시도 금지").

## 3. 시나리오 B — 이용권(30일 패스) 구매 및 소진

1. 사용자가 `/points`(이용권 상점) 또는 결제창의 **[이용권으로 구매]** 카드를 통해 이용권 상점으로 인계된다.
2. 이용권 상품은 **원화 단건 결제로만** 구매 가능하다(월정석으로 이용권을 구매하는 경로는 서버가 `SUBSCRIPTION_MONTHLY_CREDIT_UNSUPPORTED`로 거부).
3. 결제 완료 후 이용권이 즉시 활성화되며, 서버 검증 완료 시각으로부터 30일간 유효하다.
4. 이용권 보유 기간 중 다른 유료 기능을 클릭하면, **결제창의 [이용권으로 구매] 카드**를 눌렀을 때만 서버가 이용권 커버 여부를 확인해 커버되면 결제 없이 무료로 진행된다.
5. 이용권은 **자동갱신되지 않는다** — 30일 경과 후 사용자가 다시 구매해야 하며, 이는 이용약관에 명시된다(자동갱신·구독취소권 관련 문구는 절대 추가하지 않는다 — `lib/market-policy/market-policy-registry.js`의 `prohibitedClaims` 가드 참고).

검증 포인트: 이용권 만료 후 자동 결제가 발생하지 않는지, 이용권 구매 화면에 30일 기간·금액·환불 조건이 결제 전 고지되는지(이용약관 13조).

## 4. 시나리오 C — 환불 / 청약철회

두 갈래로 나뉜다 (이용약관 12조 = [refund-policy 각 언어 페이지](../app/[locale]/refund-policy/page.js)와 동일 실질).

**C-1. 콘텐츠 제공 전 취소**: 결제 완료 후에도 결과 생성·PDF 렌더링·유료 리딩 열람이 시작되지 않았다면 고객센터(`SUPPORT_EMAIL`)를 통해 전액 환불 요청이 가능하다.

**C-2. 콘텐츠 제공 후 청약철회**: 콘텐츠 생성이 이미 시작된 경우, 전자상거래법상 디지털 콘텐츠 제공 개시 예외에 따라 해당 부분의 단순 변심 환불이 제한될 수 있다. 단, (a) 시스템 오류로 결과가 제공되지 않은 경우, (b) 표시·광고와 다르게 이행된 경우(공급일로부터 3개월/인지일로부터 30일 이내), (c) 중복 결제인 경우는 예외 없이 환불 처리한다.

**C-3. 처리 기한**: 환불 대상 확인 후 3영업일 이내 결제 취소/환급 절차 진행. 실제 카드사 반영 시점은 카드사 정책에 따라 달라질 수 있음을 명시한다.

검증 포인트: 환불 요청 접수 채널이 실제로 동작하는지, 환불 조건이 화면에 사전 고지되는지, 대만/일본 등 해외 사용자에게는 [refund-policy 페이지](../app/[locale]/refund-policy/page.js)의 관할 참고 노트(준거법은 대한민국임을 명시)가 함께 보이는지.

## 5. 시나리오 D — 결제 실패/오류

1. 카드 한도 초과, 사용자 취소 등으로 PortOne 결제가 실패하면 서버 confirm이 실패로 응답한다.
2. 클라이언트는 실패를 사용자에게 표시하고, **자동으로 재시도하지 않는다** — 사용자가 다시 시도 버튼을 눌러야 한다.
3. 동일 주문에 대한 중복 결제가 감지되면(같은 상품 중복 승인 등) 서버가 중복분을 환불 처리한다(이용약관 12조).

## 6. 시나리오 E — 다국어 사용자 접근성 확인

1. 일본어 사용자가 `/ja`로 접속 → 이용약관(`/ja/terms-of-service`), 개인정보처리방침(`/ja/privacy-policy`), 환불정책(`/ja/refund-policy`), 특정상거래법 표기(`/ja/tokushoho`)에 각각 접근 가능한지 확인.
2. 영어/중국어(간체)/중국어(번체) 사용자도 동일하게 `/en`, `/zh`, `/zh-tw` 하위에서 이용약관·개인정보처리방침·환불정책에 접근 가능한지 확인.
3. 모든 번역 페이지 상단에 "기계 보조 번역이며 한국어 원문이 우선한다"는 고지가 표시되는지 확인(`translationNotice`).
4. 결제 자체는 언어와 무관하게 KRW로 처리됨을 사용자가 명확히 인지할 수 있는지 확인.

## 7. 현재 알려진 제약 (심사 시 사전 공유 필요)

- **다중 통화 미지원**: 결제는 KRW 단일 통화이며, 해외카드로 결제하더라도 청구 통화는 KRW다. USD/JPY/CNY/TWD 등 현지 통화 결제는 아직 구현되어 있지 않다 (필요 시 별도 승인 후 구현 — 아래 §8 참고).
- **해외 시장별 법률 검토 미완료**: `lib/market-policy/market-policy-registry.js`에 JP/US/EU/GB/CA/AU/NZ/SG/TW/HK/CN 12개 시장이 등록되어 있으나 전부 `enabled: false`(KR만 활성). 실제 서비스 제공 국가를 늘리려면 해당 시장의 법률·세무·PG 검토가 선행되어야 한다.
- **번역 문서의 법적 검토 미완료**: 본 배치에서 추가한 en/ja/zh-CN/zh-TW 약관·정책 번역은 기계 보조 번역이며, 원어민·법률 전문가 검토를 거치지 않았다(`lib/market-policy/legal-packs/legal-market-packs.js`의 `translationReviewStatus: MACHINE_TRANSLATED`, `legalReviewStatus: LEGAL_REVIEW_REQUIRED`로 명시).
