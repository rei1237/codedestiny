# 서비스별 천문 공급자 검증과 교체 조건

2026-11-07 · CR-011 결정은 신규 상품 유지 우선이다. 이미 기간 운세에 쓰이는 `astronomy-engine@2.1.19`를 독립 표본으로 검증했다. 일간·기간 운세가 호출하는 함수의 태양·달 별자리 248건은 전부 일치했다. 유료 명반의 하우스·항성 좌표·경계 판정에는 추가 근거가 필요해 신규 주문의 운영 공급자를 전환하지 않았다.

## 신규 구매, 재열람, 되돌림

1. 어댑터가 제공하는 사실값에 천체·좌표계·시각 기준·옵션·지원 범위·공급자 버전을 명시한다. 경계에서 독립 판정이 갈리는 입력은 보류로 구별한다. 보호된 엔진 변경은 제안 diff와 재현 입력이 있는 별도 CR 승인이 필요하다.
2. 먼저 테스트에서 신규 계산만 허용해 기본 결과와 상담에 동일한 명반 식별값을 전달한다. 결제 준비에서 고정한 명반·버전으로 결제 복귀·재시도·동시 생성·연도 변경·PDF·재열람을 PG/DB/LLM mock으로 대조한다. 기존 완료 구매는 저장 원문을 읽고 공급자 호출 횟수 0을 확인한다. 이 문서는 이들 상품의 통합 검증 완료를 뜻하지 않는다.
3. 필수 장 누락, 설명 없는 경계 차이, 실제 Swiss import·WASM·CDN 사용, 원문 변경, 동일 주문의 버전 불일치가 한 건이라도 발생하면 해당 상품은 승격하지 않는다. 전환 후에는 신규 할당부터 OFF로 되돌린다. 준비된 주문은 최초 버전을 재개하며 공급 불가 시 기존 원문이나 다른 버전으로 덮어쓰지 않는다.
4. 이번 검증은 독립 러너와 기존 서비스 함수에 한정했다. 운영 플래그 기본 OFF, 기존 상품 판매 정책, 이용권·월정석·단건 결제 및 저장 결과를 유지한다. 루트 Swiss 의존성과 배포 자산 검사가 여전히 막히므로 전체 CI 승격·push·배포는 보류한다. [운영 전환 CR](change-requests/CR-011.md) · [격리 검증과 루트 차단 근거](31-swiss-free-release-check.md).
