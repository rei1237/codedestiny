아래는 운영 활성화 이후 사용할 **제안 중단 기준**이며 실제 운영 계측 결과가 아니다.

- 명반 해시/준비 ID/버전 불일치, 중복 과금·사용 처리, 기존 원본 변경, 타 계정 노출, Swiss 또는 비승인 외부 연결은 1건이라도 새 v2 선택을 즉시 OFF한다.
- 적격 입력의 자료 범위 오류, 준비 저장 불명, 전달 실패율·지연이 사전 합의한 기존 경로 기준을 초과하면 다음 확대를 중단하고 요청별 증빙을 확인한다. 관측 없는 숫자 임계값을 만들어 통과로 간주하지 않는다.
- OFF는 새 준비 선택만 중단한다. 이미 준비한 v2 요청은 그 준비 ID/명반/기준 연도로 생성·재시도하고, 완료 결과는 원문을 계속 제공한다. snapshot reader와 신규 자료를 함께 제거하는 롤백은 금지한다.
- 준비가 손상·분실되면 안전하게 보류한다. 다른 버전 생성, 새 결제 유도, 원본 덮어쓰기로 복구하지 않는다. 보상은 기존 정책과 승인 범위대로만 처리한다.
- 사주 유료 소비자·다른 자미 화면, 서양/숙요/베다의 Swiss 연결, 베다 주 검증기 미확보는 여전히 미포함/차단이다. 전체 엔진 정확도 작업이 끝났다고 보고하지 않는다.
