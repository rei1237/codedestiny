# CR-001 — 사주 절입 순간 정밀도

status: implemented-default-off

**2026-11-01 네오 승인 후 기본 OFF로 로컬 구현·검증 완료.** 운영 활성화·push·배포는 하지 않았다. 아래 diff는 승인 당시 제안 기록이며 실제 변경/범위 제한/검증은 [05-final-report.md](../05-final-report.md)를 따른다. `calculateLocalResult()` 수정 금지, prefetch timezone 주입 금지, normalizeSaju timezone 추가 금지는 유지한다.

- 결함: 공식 천문 기준으로 절입 전인 23개 입력에서 연·월주 24필드가 먼저 전환됨.
- 재현: 양력 2023-02-04 11:42, 남성, 서울 126.978°/37.5665°, Asia/Seoul. 서비스 `癸卯/甲寅`, 기대 `壬寅/癸丑`.
- 근거: JPL DE441 지구중심 태양 황경 02:42 UT 314.9995980° → 02:43 315.0003021°. [KASI](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2023) 입춘 11:43. 전체 입력·값은 [decisions-official.json](../results/adjudication-20261101/decisions-official.json).
- 원인 범위: 분 반올림한 천문 표와 분 단위 비교. 생성기는 이미 반올림하므로 ‘절사 제거’ 패치로 해결한다고 단정하지 않음.
- 영향: 신규 사주 원국 및 파생 분석. 저장 결과·결제·인증·학파 정책은 제외.

## 제안 diff — 핵심 계약, 전체 적용 패치 아님

승인 후 실제 초 정밀도 자료와 범위 검증을 먼저 마련한다. 아래 신규 이름은 제안 인터페이스다. 기존 자료/기본 경로를 유지하고 어댑터가 선택한 플래그가 켜진 신규 계산만 v2를 사용한다.

```diff
--- lib/korean-calendar/natal.js
+++ lib/korean-calendar/natal.js (제안)
- const terms=ganji(termClock,{nightZiPolicy:'keep-day'});
+ const terms=ganji(termClock,{
+   nightZiPolicy:'keep-day',
+   termAuthority:options.termAuthority,
+   termInstantUtcMs:instant.timestamp,
+ });
--- lib/korean-calendar/ganji.js
+++ lib/korean-calendar/ganji.js (제안)
- const node = enclosingNodeTerm(year, month, day, hour, minute);
+ const node = options.termAuthority === 'verified-instants-v2'
+   ? enclosingNodeTermAtInstant(options.termInstantUtcMs)
+   : enclosingNodeTerm(year, month, day, hour, minute);
```

추가 승인 대상은 `core.js`의 새 순간 비교 함수, 별도 버전의 검증된 절입 자료, 공개 래퍼에서 옵션을 전달하는 경로, 동일 버전의 절기 근거 표시다. 새 함수는 검증된 범위·유한 timestamp·정렬/중복 없는 자료를 검사하고, 범위 밖에서 정답을 꾸며내지 않는다. 기존 분 테이블을 덮어쓰거나 모든 값에 1분을 더하는 diff는 제안하지 않는다. 기존 생성물/공식 freshness 검사도 임의 변경하지 않는다.

## 승인 후 완료 기준

23개 재현과 ±1초/±1분 골든, 동일 20,000개 표본 영향 확인, 원국/근거 버전 일치, 저장 결과 보존, 허용 경로 회귀 통과. 2028 잠정 자료와 이번 선형 보간값은 그대로 운영 정본으로 승격하지 않는다. 세부 실행 계획은 [03-fix-plan.md](../03-fix-plan.md)의 F1을 따른다.
