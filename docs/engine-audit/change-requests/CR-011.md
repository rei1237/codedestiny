# CR-011 · 운영 천문 공급자 전환과 구매자 보호

2026-11-07 · 사용자 결정: 신규 상품 유지 우선. 허용 공급자의 정확도 검증과 교체안을 먼저 진행한다. 신규 구매 중지는 선택하지 않았다. [독립 표본·서비스별 교체 조건](../32-ephemeris-provider-evaluation.md).

**재현 입력**은 신규 해외 출생 프로필(예: 2000-02-11 12:00 UTC, 경위도 0)과 같은 계정의 기존 완료 리포트 ID다. 다음은 소스 추적 결과다. 운영 요청이나 Swiss 계산은 실행하지 않았다.

| 기능 | 호출 근거 | 변경 시 보호할 동작 |
| --- | --- | --- |
| 서양 명반·Guardian·궁합 | `worker/lib/guardian-fortune/adapters/astrology.js`의 기본 calculator와 `worker/routes/astrology-ai.js`의 브리지 import | 위치·시각·하우스 체계, 두 사람 각각의 명반, 원문 재열람 |
| 베다·낙샤트라·프라슈나 | `worker/lib/vedic-ai-chart.js`, `worker/routes/nakshatra-ai.js`의 `getSwissVedicPlanets`; 이 라우트의 `handleResult`는 소유자·저장 기록을 조회 | 항성 기준·파다·다샤 및 결제 전 준비 버전. 완료 기록 조회에서는 공급자 초기화 0회 |
| 숙요·찻집/월간 | `worker/lib/sukuyo-astronomy.js`, `worker/lib/tea-sukuyo-monthly.js`의 달 경도 요청 | 숙·관계·기간, 최초 계산 결과 고정. 음력만으로 대체하지 않음 |
| 휴먼디자인·오늘의 하늘·카르마·영냥이·융합 | `human-design-ephemeris.js`, `today-sky.js`, `karma-destiny-ai-calculations.js`, 영냥이 천문 도메인과 `relationship-calculation.ts` | 복합 상품의 필수 데이터와 선택 데이터 구분. 유료 상품의 필수 장을 생략한 채 완료 처리하지 않음 |
| 정적 셸/배포 자산 | `scripts/sync-legacy-static-to-public.mjs`는 설치본에서 WASM·천체력 파일을 복사한다. `worker/lib/swiss-ephemeris.js`에는 패키지 import, 로컬 WASM, CDN 대체 경로가 있다 | 루트 설치에서 패키지 한 줄만 제외해도 브라우저·Worker 공급자 경로가 남음 |

**권장 순서**는 검증된 대체 공급자를 먼저 준비하고 신규 주문만 전환하는 것이다. 꺼진 기능 플래그를 전체 제품 차단 증거로 취급하지 않는다. 대안은 제품 소유자의 명시적 결정에 따라 영향 상품의 신규 준비·구매만 보류하고 Swiss 비연결 상품을 먼저 내는 것이다. 두 경우 모두 접근권 확인, 기존 구매 원문·재개 권한, 환불 정책을 보존한다.

**제안 diff의 경계** (구현 전 설계):

```diff
- 계산과 저장 읽기가 같은 진입점에서 Swiss 브리지를 로드
+ 기존 결과 ID → 기존 소유권/환불 검사 → 저장 원문 또는 고정된 명반으로 재개
+ 신규 → 필수 사실·지원 연도·출생 정보의 공급 가능 여부를 결제 전에 확인
+ 검증된 공급자가 있으면 승인 버전의 스냅샷을 최초 준비 시 원자적으로 저장
+ 공급 불가이면 새 결제/차감/LLM 호출 전에 중단 (상품 보류 승인을 받은 경우)
- node_modules → js/vendor → public 미러 / Worker 패키지·CDN 폴백
+ 승인된 공급자만 번들·배포; 기존 저장값은 마이그레이션 없이 읽기
```

승인 뒤 실제 서비스별 caller 표를 완성하고 mock으로 미결제 신규·이미 결제한 부분 생성·완료 원문·권한 회수를 따로 검증한다. 부분 생성에서 공급자 고정값이 유실된 주문은 기존 구매 증빙을 보존하고 복구 대상으로 남긴다. 필수 검사는 대체 근거를 세운 뒤 전환한다. 기존 상품 중지, 규칙 변경, 엔진 브리지 교체, root 잠금 파일 변경 또는 구매자 원문 변경은 이번 CR-010 로컬 작업에서 수행하지 않았다.
