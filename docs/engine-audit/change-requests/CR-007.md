# CR-007 — 전용 로컬 DB 서버 라이선스 예외

status: approved-local-server-only

## 이미 승인된 범위

2026-11-02 사용자가 전용 로컬 테스트 DB 생성, 합성 기록 6건 쓰기, 동시 요청·재시도·저장 결과 보존 검증을 승인했다. 이 실행 권한을 다시 요청하지 않는다. 실제 PG·운영 DB·LLM·push·배포·플래그 ON은 승인 범위 밖이다.

## 새로 확인한 차단점

PATH/표준 설치 위치/캐시/실행 프로세스에서 사용할 MongoDB 서버를 찾지 못했고 Docker/Podman도 확인되지 않았다. WSL은 실행 파일만 있고 설치된 런타임을 사용할 수 없다는 응답이다. 운영 URI나 자격 증명은 읽지 않았다.

기존에 검증한 `mongodb@7.1.0`은 Apache-2.0 **클라이언트 드라이버**다. 별도 서버 `MongoDB Community Server 8.0.34`의 [태그 고정 라이선스 원문](https://raw.githubusercontent.com/mongodb/mongo/r8.0.34/LICENSE-Community.txt)은 **SSPL-1.0**이다. 최초 감사 요청의 “허용 SPDX: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, CC0-1.0, Unlicense, 0BSD” 목록에 없다. 이 목록을 신규 검증 서버 런타임 도입에도 적용하므로 예외 확인이 필요하다. 실제 법적 의무에 관한 단정이나 Swiss 허용 요청이 아니다.

## 한정 예외 제안

- MongoDB Community Server **8.0.34 Windows x86_64** 원본 ZIP을 이번 로컬 DB 실험용 별도 디렉터리에만 압축 해제. OS 서비스 등록·전역 PATH·운영 package/lock/번들 변경 없음.
- 공식 ZIP: `https://fastdl.mongodb.org/windows/mongodb-windows-x86_64-8.0.34.zip`. 2026-11-02 HEAD 200, 807,616,685 bytes 확인.
- 공식 `.sha256`: `6b021a0864494e4decf278b36477a29eb36072432773e4e62c2f42c302630db0`. 다운로드 후 전체 파일 해시 및 포함 LICENSE/NOTICE 확인 전 실행 금지.
- 새 데이터 디렉터리, `127.0.0.1:27186`, standalone/no replica/no config import로 직접 실행. 시작 전 포트 비어 있음, 실행 후 해당 리스너 소유 PID·실행 파일·데이터 경로·명시 인수 대조. 기존 서비스/터널/운영 설정 재사용 없음.
- 새 DB명 `cd_engine_audit_cr006_<고유 run-id>`, 기존 runner sourceDigest 고정, 플래그 false, 최초 컬렉션 생성 및 준비 4 + 상담 2건만 삽입. 삽입 시도 26/읽기 160/동시 준비 20 상한 유지.
- PG/HTTP/LLM/Swiss import는 계속 차단. 실험 뒤 이번 서버 프로세스만 종료하고 합성 DB 파일은 보존. 자동 삭제·기존 자료 수정·추가 쓰기 없음.

## 예외에서 제외

Swiss 및 GPL/AGPL 등 다른 금지 의존성, 운영 서버/번들 채택, 새 결제/환불, 배포나 기능 플래그 활성화는 포함하지 않는다. 이번 DB 검증 성공이 운영 Mongoose/결제 라우트 전체나 모든 운세 엔진 정확도 검증을 대신하지 않는다.

2026-11-02 사용자 답변 **“이번 로컬 DB 서버만 예외 승인”**으로 위 범위가 승인되었다. DB 생성/6건 쓰기 승인과 함께 이번 실험에만 적용한다. 다른 의존성 허용 목록과 Swiss 차단은 그대로다. 서버 도입·실측 결과는 후속 로컬 DB 검증 보고서에 기록한다.
