# CR-010. Swiss를 설치하거나 실행하지 않는 운영 릴리스 경로

2026-11-07 · CI·의존성 분리 단계 진행. 로컬 격리 검증 및 설치 전 차단 구현. 전체 운영 전환은 [31번 실측](../31-swiss-free-release-check.md)과 [CR-011](CR-011.md)의 제품별 조건을 따른다.

## 확인한 충돌

main `3eda017a48b49b9c9ba54b4f231e37469cd5b3e8`에서 다음 연결을 읽기 전용으로 확인했다. 운세 기능을 선택하는 서버 플래그와 빌드·테스트 의존성은 별도다.

| 단계 | 소스와 실제 동작 |
| --- | --- |
| main push | `.github/workflows/pr-ci.yml`의 필수 검사에서 `npm ci` 후 `npm run test:node` 실행 |
| 설치 | 루트 `package.json`에 직접 의존성 `sweph-wasm`이 있음 |
| 테스트 선택 | `scripts/run-mock-tests.mjs` → `scripts/lib/mock-test-config.mjs` → `__tests__/ui/*.test.mjs`. 네트워크 차단만으로 로컬 WASM 실행을 막을 수 없음 |
| 실제 실행 지점 | `__tests__/ui/yeongnyangi-consultation-kinds.test.mjs`가 Swiss 모듈·WASM을 불러 초기화하고 `swe_time_equ` 호출 |
| 운영 승격 | `.github/workflows/cloudflare-pages-deploy.yml`의 릴리스 설치 과정도 루트 의존성을 사용 |

재현 방법은 위 파일의 설치 명령, 테스트 패턴과 import를 소스에서 추적하는 것이다. 금지된 코드를 실행해 재현할 필요가 없다.

## 제안 변경 범위

1. 패키지·잠금 파일과 Swiss 의존 모듈의 소비 경로를 확인한다. 기존 고객이 사용하는 Swiss 연결 상품, 저장 결과 읽기, 비연결 엔진을 분리하고 제품별 영향 계획을 제출한다.
2. 배포 산출물과 검증 환경 모두에 허용된 의존성만 설치하도록 의존성 경계를 설계한다. 신규 명반 계산이 막힌 제품은 저장본 재열람을 보존한다. 엔진 내부·결제 실행 파일을 건드려야 하는 변경은 별도 승인한다.
3. Swiss 기반 검증을 실행하지 않고도 같은 경계를 검증할 수 있는 허용 라이선스의 독립 근거와 골든값을 확보한다. 테스트 대상을 단순 제외하거나 원래 검사를 성공으로 위장하는 변경은 허용하지 않는다.
4. 배포 전 잠금 파일, 전이 라이선스, 번들 import, 실제 설치·실행 기록을 대조한다. 필수 CI와 운영 릴리스가 모두 Swiss 비연결일 때 검증된 커밋을 승격한다.

**승인 요청 범위**는 위 CI·의존성 분리 작업이다. Swiss 사용 예외, 유료 라이선스 구매, 운영 DB 작업, 기존 결과 재생성은 범위 밖이다. 현재 운세 보완은 격리 워크트리에서 검증해 두었다.

## 운영 파이프라인 기존 설치 유지 예외 (사용자 결정 2026-11-07)

사용자가 이번 운세 보완(질문 직답 계약, 결론 먼저 화면, 숙요 IMD 신규 주문, 타로 결제 전 해석 고정 `fdb4924ba`)을 운영에 반영하기로 결정했다. 그래서 운영 CI와 릴리스는 지금처럼 루트 `npm ci`로 `sweph-wasm`을 설치한다.

- `b7cd0a40b`가 10개 워크플로의 `npm ci` 앞에 넣은 `preflight.mjs .`는 되돌렸다. 루트에는 `sweph-wasm`이 있어 이 검사가 의도대로 종료 코드 1을 내고, 그러면 main CI·배포·롤백이 모두 멈춘다.
- 독립 워크플로 `engine-release-check.yml`은 유지한다. 이 워크플로는 `tools/oracle/release-check`와 `ephemeris-candidate`만 검사하고, PR 경로와 수동 실행에서만 돈다. 필수 검사도 아니다.
- 로컬 작업과 검증에서는 Swiss를 설치하거나 실행하지 않는다. Swiss에 닿는 테스트는 main CI에 맡겼다.
- 이 예외로 CR-010의 목표, 곧 Swiss를 설치하지 않는 운영 릴리스가 달성된 것은 아니다. 그 조건은 31번 문서와 CR-011에 그대로 남는다.
