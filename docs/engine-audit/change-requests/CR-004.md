# CR-004 — 검증된 절입과 사주 대운의 제한적 연결

status: implemented-default-off

후속 업데이트 요청으로 서울 양력·원래 14년의 대운 전용 문맥을 기본 OFF로 연결했다. 최신 범위와 회귀 결과는 [07 구현 보고서](../07-expansion-implementation-report.md)를 따른다. 아래 미승인 표기는 승인 전 제안 이력이며 해외/음력/전체 소비자/운영 활성화로 범위를 넓히지 않는다.

작성일: 2026-11-01. 기준 `d1238c68404f639f1222a8f077854952b7353665`. **미승인·미구현**. [전체 계획](../06-expansion-and-daeun-plan.md)의 D1/D2를 따른다. 승인된 CR-001의 원국 절입 수정과 별개로, 엔진 읽기 전용 규칙 3에 대한 추가 예외가 필요하다.

## 연결 제한·재현 입력·기대값

입력: 양력 `2023-02-04 11:42`, 서울 기본 시계, `gender:male`, `sajuTermAuthorityV2:true`.

- 공개 `computeNatalFromInput`은 성별을 내부로 넘기지 않아 대운이 unknown인 상태다. 기존 Phase 2 기록과 현재 전달 소스를 확인했다.
- 내부 `calculateLocalSaju`에 시간/알려진 성별/절입 v2가 함께 들어오면 `TERM_AUTHORITY_DAEUN_NOT_APPROVED`로 차단한다. 이번에는 내부 직접 실행하지 않았다.
- 근거: `sajuAdapter.ts::computeNatalFromInput`, `localSajuCalculator.ts::calculateDaewoonStartFromCore/calculateLocalSaju`, `lib/korean-calendar/daeun.js::daeun/daeunFromFrame`, [기존 공식 판정](../02a-authoritative-adjudication.md).

현재 공식 원국 기대값은 입춘 전 `壬寅/癸丑`이다. 현행 관례를 유지한다면 남성은 순행·다음 節 기준, 첫 대운 간지는 월주 다음 `甲寅`이어야 한다. 같은 시각 여성은 역행·직전 節 기준, 첫 간지는 `壬子`라는 **현행 규칙 기반 검증 가설**을 고정한다. 기운 년월일·시작 양력일·표시 나이는 아직 독립 대조하지 않았으므로 숫자를 지어 넣지 않는다. 이 제한을 전체 서비스 대운 장애나 추가 확정 버그로 세지 않는다.

## 최초 승인 요청 범위

현재 검증된 14년의 **양력·서울 기본 출생 시계·시간/성별 확인 입력**만 파일럿 대상으로 요청한다. 해외 좌표/시간대/별도 offset/진태양시 옵션은 명시 거절하며 누락 좌표의 기존 서울 가정은 근거에 남긴다. 역사 음력·윤달·다른 화면/워커는 후속 검증과 범위 승인 대상이다.

신규 내부 옵션 가칭 `daeunAuthorityV2=false`를 별도 계산 실행 인자에 두는 안이다. `sajuTermAuthorityV2=true`와 검증된 자료 범위를 요구하고, 두 플래그가 맞지 않으면 거절한다. env/UI/저장 설정 스위치를 추가하지 않는다. 기존 두 달력 플래그와 새 옵션은 모두 기본 OFF다. 최종 인자명/타입은 승인 시 확정한다.

**성별을 일반 `input.gender`로 무조건 전달하지 않는다.** `normalizeGender`는 배우자 십신·관계 해석에도 쓰인다(`localSajuCalculator.ts`의 `spouseTenGods`, `spouseElements`, `attractedPersonType`). 대운 전용 실행 문맥으로 성별을 전달하고 대운 계산만 소비하도록 한다. 대운 때문에 비대운 해석이 바뀌면 범위를 넘은 회귀로 판정한다.

## 최소 변경 경로와 제안 diff

변경 후보는 공개 `computeNatalFromInput`의 선택적 실행 인자, `LocalSajuInput`의 대운 전용 문맥, 내부 대운 연결/차단 조건과 기존 근거 필드다. `daeunFromFrame`의 현행 산술은 재사용하고 `daeun.js`의 v1 표 조회/기본 정책은 우선 변경하지 않는 안을 권장한다.

```diff
--- app/saju/animal-destiny/lib/sajuAdapter.ts (제안)
- computeNatalFromInput(input, kasi?)
+ computeNatalFromInput(input, kasi?, executionOptions?)
+ // executionOptions.daeunAuthorityV2 기본 false
+ // ON일 때 허용된 장소/시간대/입력과 term v2를 확인
+ // 성별은 대운 전용 문맥으로 전달; 일반 gender 전달은 그대로
--- app/saju/animal-destiny/engine/localSajuCalculator.ts (제안)
- // 알려진 성별 + v2 term이면 무조건 차단
+ // 기존 경로의 차단 유지; 승인된 대운 옵션/검증 범위만 좁게 허용
- const result = daeun(canonicalNatal.calculationMeta.termClock, ...);
+ const result = daeunOptionEnabled
+   ? daeunFromFrame({
+       birth: canonicalNatal.calculationMeta.termClock,
+       yearStemIndex: /* v2 원국과 같은 연간 인덱스 */,
+       monthPillar: /* v2 원국과 같은 월주 인덱스 */,
+       prevNode: /* 같은 공식 절입 창의 KST 표시 필드 */,
+       nextNode: /* 같은 공식 절입 창의 KST 표시 필드 */,
+       gender: /* 검증한 대운 전용 M/F, 미상은 계산하지 않음 */,
+       birthCivilYear: canonicalNatal.calculationMeta.civil.year,
+     })
+   : daeun(/* 기존 입력과 옵션 그대로 */);
+ // baseTerm은 위 공식 창에서 가져옴; 기존 분 테이블 재검색 금지
+ // 기존 policyVersion/baseTerm 근거에 관례와 자료 버전 식별
```

실행 가능한 패치가 아닌 계약 예시다. 기존 `calculateLocalResult()`의 본문·호출은 변경하지 않으며 기존 두 인자 호출은 동일하게 동작해야 한다. prefetch 함수/요청에는 timezone이나 새 실행 문맥을 주입하지 않는다. `normalizeSaju`도 수정하지 않는다. 대운 옵션을 지원하지 않는 다른 어댑터에 흘려보내지 않는다.

## 관례·미상·경계 처리

- 현행 sect 1, KST 비교 프레임, 시진 단위 환산, 23시 인덱스 11, 세는 나이, 미입운, 년→월→일 덧셈 순서를 유지한다. 초 정밀도 절입을 얻었다고 기운수를 초 비례 환산으로 교체하지 않는다. 다른 관례는 B 결정표와 새 승인 대상으로 남긴다.
- 공식 절입 경계와 원국 연간/월주를 한 번 선택하여 대운과 공유한다. 경계 근처에 표의 분 반올림을 다시 적용하지 않는다. 경계 포함 규칙과 선택한 節의 ID/버전을 검사한다.
- 직접 확인한 경계 구간이 KST 자정/시진 전환을 걸쳐 현행 관례의 입력을 하나로 정할 수 없으면 미확정으로 거절한다. 40 ms 대표값이 모든 파생값을 확정해 준다고 가정하지 않는다.
- 시간 미상/성별 미상은 기존 unknown/null 계약을 유지하고 가짜 시작 나이를 반환하지 않는다. 엄격한 M/F 정규화는 래퍼에서 수행하며 core의 기타값→여성 취급을 타지 않게 한다. 대운 ON인데 원국/자료 범위가 맞지 않으면 전체 요청을 명시 거절하며 v1 대운으로 폴백하지 않는다.

## 완료 기준·보존·남은 승인

1. 계획의 2,016개 대운 절입 전후 입력과 시진/입춘/말일/미상 보강 검사. 공개 표면별로 독립 기대값과 비교하고 절입 사실과 관례 차이를 분리한다.
2. 기존 101건·추가 4건·기본 OFF 40,000비교 불변. 추가 대운 표본 20,000개에서 방향·기운수·시작일·주기·권위 버전 검사. 일반 성별 전달에 따른 배우자/관계 해석 변화가 없는지 전체 투영 비교.
3. `calculateLocalResult`, prefetch, normalizeSaju, 기존 표/저장본/결제/인증/스키마 불변 검사. 옵션 ON에서도 기존 저장·유료 결과 재열람은 원본만 읽고 추가 계산·과금 없음(mock).
4. 허용 소스 그래프/소스 핀은 별도 승인 파일로 고정하고 Swiss·fetch·WASM 차단 유지. 내부 직접 호출로 공개 입력 전달 검증을 대체하지 않는다. 타입/대상 린트/허용 어댑터 빌드·골든만 실행하며 전체 Swiss 연결 CI는 계속 차단한다.
5. 현행 정책과 새 자료 버전을 기존 근거 필드로 표현 가능한지 확인한다. 저장 키/결과 스키마 변경이 필요하면 본 CR로 확장하지 않고 별도 CR 제출 후 멈춘다. 신규 결과만 옵션 적용, 롤백은 옵션 OFF, 기존 저장본은 재계산/삭제하지 않는다.

일반 성별 해석 수정, 출생지/timezone 전달, 학파 변경, 자미 대한/소한 변경, 전체 서비스 소비자 전환, 운영 활성화는 요청 범위 밖이다. **승인 전 구현하지 않으며, 승인되더라도 push·배포·Swiss 실행을 허용하는 요청이 아니다.**
