음력 보호 월은 1899-11/12, 1913-01, 1999-11/12, 2029-01이다. 데이터의 범위와 사주 입력 허용 연도, 절입 지원 연도는 별개이며 실제 양력 교집합에서만 두 달력 플래그를 함께 적용한다. 미래 자료는 수집 시점의 예측 버전으로 취급한다. 40 ms는 모델 부호 구간 폭이며 천문학적 절대 정확도 보장이 아니다.

대운은 현행 sect 1, 시진 환산, 23시 인덱스 11, 세는 나이, 월말/윤년 보정, 미입운 관례를 유지했다. `daeun.js` 산술 자체는 변경하지 않았다. 새 옵션이 없는 기존 성별 기반 v2 내부 경로는 여전히 차단한다. 대운 기준 절입의 불확실성 구간이 KST 날짜/시진을 걸치면 대표값으로 강행하지 않고 거절한다.

이번 공개 결과 연결은 방향·기운수·시작일·나이 및 해당 근거다. 코어의 첫 주기 간지·미입운·10년 주기는 별도 공개 코어 래퍼로 검증했다. **LLM 해석용 대운 간지 입력/전체 대운표를 자동으로 채우거나 모든 소비 화면을 전환하지 않았다.**

## 기존 KASI 표본 예외 재확인

기존 `kasi-24divisions.json`의 2011 입동 `11080926`은 새 JPL 값과 21,063.174초 차이가 났다. 저장소 `scripts/verify-solar-term-frame-kasi.mjs::KASI_KNOWN_ERRATA`에 이미 있는 동일 셀이다. 이번 JPL 직접 부호 구간은 KST **2011-11-08 03:34:56.826** 부근으로 기존 예외 기록을 뒷받침한다. **새 서비스 결함이 아니라 C: 기존 캐시 표본 한계**로 기록했으며 기존 표본·예외 목록은 변경하지 않았다. 초기 비교의 실패를 숨기거나 허용 오차를 넓혀 넘기지 않았다.

나머지 347개는 저장 KASI 분 값과 최대 39.513초 차이이며 25개는 반올림한 분이 다르다. 현재 KASI 공식 API 전체의 오류라고 단정하지 않는다. 기존 표본은 서비스 프록시를 통해 수집된 자료이고, 이번에는 JPL의 명시된 천문 계산을 직접 검증했다. 두 오라클 다수결을 판정 근거로 사용하지 않았다.

KASI의 오래된 월력요항 첨부는 404 또는 파일이 아닌 응답이라 시간 근거로 채택하지 않았다. HKO 월력 PDF도 날짜만 확인되고 화면 확인이 불가능해 시간 근거로 사용하지 않았다. 실패와 분류는 [minute-reference-adjudication.json](results/expansion-20261101/minute-reference-adjudication.json)에 보존했다. 최초 타입 검사에서 `instant`의 nullable 계약을 확인한 뒤 명시적인 거절 조건으로 수정했고 최종 타입 검사를 통과했다.

## 종료와 남은 범위

구현 로컬 커밋은 `9c7d6181727ae732d3c7c2865475ba8abdaf357a`다. 커밋된 트리에서 `npm run check:pre-push` 종료 0: 홈 등록부 63개, 공개 미러 재생성 차이 0, 사이트맵 1,037 URL, llms 생성물, SEO 등록부 검사를 통과했다. 실제 push 명령은 실행하지 않았다. `npm run verify:doc-freshness`, `git diff --check`, 새 도구 구문 검사와 문서 상대 링크 16개 검사도 통과했다. Git에 넣은 증거 1,818파일(이전 224 + 신규 1,594)의 해시는 매니페스트와 일치한다. 대용량 일괄 읽기의 메모리 버퍼 한도 때문에 해시 검사는 스트리밍 방식으로 완료했다.

`check:fast -- --plan`은 전체 검사를 선택했으나 Swiss 연결 전체 Jest/Node/앱 빌드는 실행하지 않았다. 게이트를 바꾸거나 약화하지 않았고 허용 경로만 검증했다. 원격 CI·실서비스·물리 기기 검증은 미실행이다. 공유 main 병합·push·배포 없이 기존 격리 작업 공간에 보존했다.

남은 범위: 1900~1961 절입/역사 시각계, 1962~1999 및 2029~2050 절입 확대, 2051년 이후 공식 음력 근거, 음력/해외 대운, 전체 소비 화면/LLM 대운표 연결, 학파 변경, 베다 주 검증기, Swiss 실행 경계, 운영 활성화. 이 항목들을 완료로 표시하거나 플래그를 자동 ON하지 않는다. 되돌림은 신규 계산 옵션 OFF이며 저장본 롤백/재계산은 하지 않는다.
