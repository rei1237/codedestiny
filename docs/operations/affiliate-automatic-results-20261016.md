# 결과 하단 자동 제휴 추천

- 사용자 요청: 운세 결과에 맞는 광고를 결과 하단에 최대 2개 자동 표시. 추천 서가 유지. 검증 후 운영 배포 1회 승인.
- 사주: 완성된 결과의 `iljuAdviceList`만 실천 태그로 변환하고 저장·공유 영역 뒤에 기존 광고 컴포넌트를 붙인다. 화자·언어 변경 때도 현재 조언으로 갱신한다.
- 점성술·베다: 저장된 assistant 응답의 명시적인 `action_plan` 또는 행동 조언 제목 아래 문장만 사용한다. 베다는 결과 조회 화면과 상담 완료 화면을 모두 연결한다.
- 결과 원문·질문·생년월일은 광고 요청에 넣지 않는다. 기존 부정문·타인·가정·의료 문장 제외 규칙을 유지한다.
- 건강 카드 열기로 사주 결과 광고 영역을 덮어쓰던 호출을 제거한다. 건강기능식품은 계속 명시적인 추천 서가 관심 선택에서만 조회한다.
- 기존 결과 추천 연결·최대 2개 제한·품절/만료/판매처 OFF 차단·제휴 고지·접기·추천 서가는 재사용한다. 관련 상품이 없거나 요청이 실패하면 광고 영역만 숨긴다.
- 결제·인증·운세 계산·LLM 생성·저장/공유 처리·운영 상품/판매처 설정·DB 스키마 변경 없음. 추가 알리 5개는 미공개 상태를 유지한다.
- 검증: 추천 Node 테스트 35개 통과. 실제 legacy 모듈과 mock 상품 응답을 사용한 브라우저에서 360/390/430/1440px 모두 카드 2개, 저장·공유 뒤 배치, 가로 넘침 없음. 접기/빈 조언에서 본문과 기존 버튼 유지 확인. 이 검증은 실제 상담 생성·실결제 검증이 아니다.
- 롤백: 이번 코드 커밋만 revert. 운영 상품의 검수 기록이나 기존 추천 서가는 수정할 필요가 없다.
- 배포 완료 여부는 GitHub 릴리스와 운영 Pages/Worker SHA 증거로 별도 확인한다. 이 문서 자체는 운영 배포 완료 증거가 아니다.
