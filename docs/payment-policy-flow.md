## 게이팅 우선순위

콘텐츠 접근 판정은 다음 순서로 확인하고 하나라도 만족하면 통과한다(구현: `worker/routes/fortune.js`, `app/hooks/useCoinGate.ts`, `worker/routes/billing.js`):

1. **이용권(구독형) 유효** → 가격 상한 이내면 무료 통과(`accessSource: "subscription"` / `code: "PASS_FREE"`), family 이용권은 상한 없이 항상 무료
2. **월정석 잔액 보유** → 월정석 차감(`accessSource: "moonlight_stone"` / `code: "MOONLIGHT_STONE"`)
3. **코인(=원화 환산 잔액) 보유** → 코인 차감(`accessSource: "coin"` / `code: "OK"`), 부족 시 단건 PG 결제 유도

### 잠금 콘텐츠(A유형) 접근 시
```
이용권 유효 여부 확인
  → 유효: 가격이 이용권 커버 범위 이내인지 확인
    → 이내(또는 family): 무료 해제
    → 초과: 단건 PG 결제
  → 무효/없음: 단건 PG 결제
```

### 회당 결제(B유형) 서비스
```
이용권 유무와 무관하게 → 항상 단건 PG 결제(코인 경유 시 코인은 내부 계산 단위일 뿐, 최종 청구는 원화)
```
