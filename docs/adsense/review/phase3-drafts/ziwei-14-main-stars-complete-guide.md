# 검수용 초안: 자미두수 14주성 — 별 하나가 아니라 궁과 조합으로 읽는 법

## 원고

자미두수의 14주성은 명반을 읽는 중심 어휘지만, 별 하나가 성격·직업·관계·인생의 결말을 결정하지는 않습니다. 먼저 어느 궁에 놓였는지 확인하고, 함께 놓인 별과 마주 보는 궁, 삼방사정, 사화처럼 선택한 유파가 사용하는 맥락을 겹쳐야 합니다. 초보자가 기억할 핵심은 “별은 작동 방식, 궁은 그 방식이 나타나는 질문의 영역”이라는 구분입니다.

### 14주성의 ‘별’은 천문 관측값과 다릅니다

자미두수에서 성요는 명반을 구성하는 상징 기호입니다. 서양 점성술처럼 출생 순간 망원경으로 관측한 행성의 황경을 그대로 배치하는 설명과는 다릅니다. 따라서 “태양성”이나 “태음성”이라는 이름을 실제 태양과 달의 천문 위치로 곧바로 바꾸어 설명하지 않습니다.

14주성은 자미·천기·태양·무곡·천동·염정·천부·태음·탐랑·거문·천상·천량·칠살·파군입니다. 아래 표는 사람을 고정하는 성격표가 아니라 명반을 읽을 때 시작할 질문을 정리한 것입니다.

| 주성 | 먼저 살필 작동 방식 | 함께 점검할 그림자 |
|---|---|---|
| 자미 | 중심을 잡고 조율하려 하는가 | 권한과 인정에 예민해지는가 |
| 천기 | 정보를 연결하고 계획을 바꾸는가 | 생각이 많아 실행이 늦어지는가 |
| 태양 | 밖으로 드러내고 책임지려 하는가 | 보여 주어야 한다는 부담이 커지는가 |
| 무곡 | 자원과 일을 측정하고 실행하는가 | 효율만 남아 관계의 맥락을 놓치는가 |
| 천동 | 환경에 맞추고 편안함을 만드는가 | 불편한 결정을 오래 미루는가 |
| 염정 | 원칙·욕구·경계를 강하게 의식하는가 | 흑백 판단이나 긴장이 커지는가 |
| 천부 | 자원을 보관하고 운영하는가 | 안정을 지키느라 변화를 늦추는가 |
| 태음 | 안에서 관찰하고 축적하는가 | 확신이 생길 때까지 표현을 미루는가 |
| 탐랑 | 경험과 사람, 욕구를 확장하는가 | 흥미가 분산되거나 과해지는가 |
| 거문 | 말과 질문으로 문제를 파고드는가 | 설명이 논쟁이나 의심으로 바뀌는가 |
| 천상 | 역할을 조정하고 기준을 맞추는가 | 타인의 평가에 지나치게 기대는가 |
| 천량 | 보호하고 원칙을 지키려 하는가 | 옳음을 앞세워 훈계가 되는가 |
| 칠살 | 빠르게 결단하고 돌파하는가 | 준비되지 않은 위험을 감수하는가 |
| 파군 | 낡은 구조를 깨고 다시 만드는가 | 바꾸는 일 자체가 목적이 되는가 |

이 질문은 전통 주성론을 현대 생활 언어로 옮긴 편집 프레임입니다. 심리검사 결과나 행동 통계가 아니며, 실제 원전의 한 문장을 직역한 표로 표시해서도 안 됩니다.

### 같은 무곡성도 궁에 따라 질문이 달라집니다

가상의 명반에서 무곡성을 예로 들어 보겠습니다.

| 놓인 궁 | 해석의 질문 | 현실에서 확인할 자료 |
|---|---|---|
| 명궁 | 일을 수치와 결과로 정리하는 습관이 자기 표현에 어떻게 나타나는가 | 결정 방식, 목표 기록, 협업 피드백 |
| 재백궁 | 수입 규모가 아니라 돈을 관리하고 배분하는 방식은 어떤가 | 예산, 저축, 지출 기록 |
| 관록궁 | 성과 기준과 책임 범위를 어떻게 세우는가 | 직무 역할, 마감 방식, 평가 기준 |
| 부처궁 | 관계에서 실용성과 책임을 얼마나 중요하게 여기는가 | 대화, 약속, 공동 의사결정 |

이 표는 “무곡성이 재백궁에 있으면 부자가 된다”거나 “부처궁에 있으면 배우자가 이렇다”는 결론을 만들기 위한 것이 아닙니다. 같은 상징이 삶의 어느 영역에서 질문으로 쓰이는지 비교하는 예시입니다. 실제 재정 판단에는 수입·부채·계약 같은 자료가 필요하고, 관계 판단에는 상대의 동의와 행동이 필요합니다.

### 별 하나보다 조합을 먼저 확인합니다

한 궁에는 주성 외에도 보조성·살성 등이 놓일 수 있고, 맞은편과 삼방에서 연결되는 궁이 있습니다. 선택한 유파에 따라 사화가 어느 천간에서 어떤 별에 붙는지와 해석의 강조점도 달라질 수 있습니다. 그래서 주성의 키워드를 읽은 다음에는 다음 순서를 권합니다.

1. 질문하려는 삶의 영역과 해당 궁을 확인합니다.
2. 그 궁의 주성과 동궁한 성요를 확인합니다.
3. 마주 보는 궁과 삼방의 구조를 확인합니다.
4. 사화를 적용한다면 사용한 표와 유파를 먼저 밝힙니다.
5. 대한·유년 같은 시기층은 원국의 성격표와 분리해 읽습니다.

예를 들어 파군의 ‘변화’라는 한 단어만 보고 이직이나 이별을 예언할 수 없습니다. 변화가 필요한 구조인지, 실제 선택지가 무엇인지, 다른 궁과 시기층이 어떤 질문을 더하는지 확인해야 합니다. 상징은 사건의 증거가 아니라 점검 순서를 만드는 언어입니다.

### 북두·남두 분류는 판본을 밝혀야 합니다

기존 원고는 열네 별을 북두와 남두 두 묶음으로 단순하게 나눴습니다. 하지만 성계 분류와 표현은 자료에 따라 차이가 있을 수 있으므로, 공개 원고에서 확정 표를 제시하려면 Code Destiny가 기준으로 삼는 실제 판본과 유파를 먼저 밝혀야 합니다. 판본 확인 전에는 “북두는 경쟁, 남두는 안정”처럼 두 집단의 성격을 고정하지 않습니다.

이 지점은 내용이 부족해서가 아니라 출처 범위가 미확인이라서 보류하는 것입니다. 검수 후 판본이 확인되면 별별 소속을 표로 추가하고, 다른 분류가 존재한다는 주석을 함께 넣습니다.

### 초보자가 피할 세 가지 지름길

첫째, 명궁의 주성 하나를 MBTI처럼 사람 전체의 유형으로 쓰지 않습니다. 명궁은 중요한 출발점이지만 재백궁·관록궁·부처궁·복덕궁 등은 서로 다른 질문을 맡습니다. 둘째, 묘·왕·득·리·평·부·함 같은 밝기 등급을 능력 점수로 바꾸지 않습니다. 등급표는 자료마다 다를 수 있고, 같은 별도 궁과 조합에 따라 질문이 달라집니다. 셋째, 유년이나 대한에서 강하게 보이는 상징을 현실 사건의 확정 날짜로 바꾸지 않습니다. 시기층은 무엇을 점검할지 좁히는 참고이고 실제 사건에는 선택과 환경이 함께 작용합니다.

이 세 가지를 지키면 “좋은 별을 찾는 법”보다 “같은 별이 다른 궁에서 어떤 질문을 만드는가”에 집중할 수 있습니다. 그 비교가 14개 키워드 목록을 Code Destiny에서만 얻을 수 있는 실전 학습 자료로 바꾸는 핵심입니다.

### 14주성을 공부하는 순서

처음에는 열네 개의 키워드를 모두 외우기보다 12궁의 질문을 먼저 익히는 편이 낫습니다. [자미두수 12궁 가이드](/insights/ziwei-life-palaces/)로 영역을 잡고, 이 글의 표에서 주성의 작동 방식을 찾은 다음, [묘왕함 등급 읽기](/insights/ziwei-star-brightness/)에서 등급표의 차이와 한계를 확인하세요. 사화는 [자미두수 사화 실전 가이드](/insights/ziwei-four-transformations-lu-quan-ke-ji-guide/)처럼 별도의 기준표를 밝힌 글에서 이어 읽는 편이 안전합니다. 내 명반의 배치를 확인하려면 [자미두수 시작 페이지](/ziwei/)를 이용하되 한 궁의 한 별만으로 결론을 내리지 마세요.

14주성의 가치는 사람을 열네 유형으로 나누는 데 있지 않습니다. 같은 작동 방식이 일·돈·관계·회복이라는 서로 다른 영역에서 어떻게 달라지는지 비교할 때 명반은 더 구체적인 질문을 제공합니다. 그 질문을 현실 기록과 대조하는 과정이 자미두수 해석의 출발점입니다.
