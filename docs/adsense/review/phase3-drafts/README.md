## 분류 수정안

확인된 운영 증상:

- `/insights/vedic/`에 `astrology-birth-chart-guide`가 노출된다.
- `/insights/sukuyo/`에 `nakshatra-what-is`가 노출된다.

원인은 `app/insights/seed-articles.js`의 `inferCategoryLabel()`이 카테고리·제목·slug·키워드를 한 문자열에 합친 뒤 숙요와 베다 정규식을 점성술보다 먼저 검사하고, `app/insights/articles.js`의 `getTopicKey()`도 비슷한 혼합 문자열로 판정하는 구조다. 한 개의 비교 키워드가 원고의 명시 카테고리를 덮어쓸 수 있다.

제안:

1. `category`를 정규화한 명시 매핑을 가장 먼저 검사한다.
2. 명시 카테고리가 없거나 `기타`일 때만 slug·title·keywords 추론을 사용한다.
3. `astrology-birth-chart-guide → astrology`, `nakshatra-what-is → vedic` 회귀 검사를 추가한다.
4. URL·canonical·sitemap은 바꾸지 않는다. 분류 카드 노출만 바로잡는다.
5. 비교 글은 원고가 명시한 주제 허브 하나를 기본 소유자로 두고, 다른 체계에서는 관련 글 링크로 연결한다.

예상 수정 범위는 위 두 함수와 가까운 단위 검사다. 6개 엔진, 계산 어댑터, 결제·인증·DB·Cloudflare 설정에는 손대지 않는다.
