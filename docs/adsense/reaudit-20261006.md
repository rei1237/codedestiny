# AdSense 재진단과 색인 정책 — 2026-10-06

## 판정과 범위

확인된 거절 사유는 `가치가 별로 없는 콘텐츠`다. Google은 특정 위반 URL이나 내부 점수를 공개하지 않았다. 아래의 오류·반복·설명 부족은 직접 확인한 결함이며, 각각이 거절의 단독 원인이라는 주장은 하지 않는다. AI를 사용했다는 사실 자체, 글자 수, 색인 수만으로 승인 여부를 판정하지 않는다. 탐지기를 속이거나 사람의 검수·경험·자격을 만들어내지 않는다.

AdSense 계정에서 소유권 확인과 ads.txt 승인 상태를 확인했다. 현재 재검토 한도에 도달하여 **2026-10-13부터** 재요청 가능하다. 이번 점검 중 재신청하지 않았다.

## 색인 분류

Google이 AdSense 승인을 위해 특정 페이지의 색인을 반드시 요구하는 것은 아니다. 아래의 ‘우선’은 이 사이트 운영상 우선순위다.

| 분류 | 대상 | 정책 |
|---|---|---|
| 색인 우선 (351 URL) | 메인, 대표 서비스 설명, 고유 가이드·인사이트, 정본 소개 | 200·본문 접근·canonical·내부 링크·sitemap 유지 |
| 공개 접근 필수, 색인 선택 (30) | 개인정보·약관·환불·문의·편집/방법론·면책 | 사용자가 쉽게 읽을 수 있게 유지; 검색 노출을 승인 필수조건으로 보지 않음 |
| 선택 색인 (576) | 기간별 공용 운세, 다국어 자료, 고유 소설·세계관 | 품질과 이용 가치를 유지; 모두 강제 색인 요청하지 않음 |
| 검색 제외 (361) | `/fortune/date` 보관함 | noindex follow·sitemap 제외·광고 제외, robots로 재크롤링을 막지 않음 |
| 기존 검색 제외 유지 (114) | 개인 결과, 계정, 실행 화면 등 기존 noindex | 개인정보·상태 화면의 검색 노출 확대 금지 |
| 오류 복구 (1) | 잘못된 내부 링크 | 정상 면책 설명 페이지로 연결 |

분류는 전수 URL별 CSV에 기록했다. 현행 robots와 권장 정책은 별도 열이며, CSV의 ‘선택 색인’은 Google이 이미 색인했다는 뜻이 아니다. 로컬 생성 sitemap은 950 URL로 감소했다.
