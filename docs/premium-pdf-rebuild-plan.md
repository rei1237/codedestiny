# Premium PDF Rebuild Plan

현재 프리미엄 PDF 생성 기능은 품질 개선을 위해 비활성화되어 있다.

보존된 것:
- UI
- 이미지
- 진입점
- 카드 구조
- 가격/구독 안내 UI

제거된 것:
- 기존 PDF 생성 API 호출 프론트 로직
- 챕터별 생성 로직 프론트 경로
- 코인 차감/결제 연계 생성 흐름
- premium-report 전용 워커 라우트 노출
- premium-report 전용 재시도 특수처리

향후 재구현 원칙:
1. 프론트는 생성 API를 1번만 호출한다.
2. 서버에서 권한 확인, 엔진 계산, 챕터 생성, PDF 렌더링을 일괄 처리한다.
3. 기본 운세 엔진과 PDF 생성 엔진을 분리한다.
4. 결제/차감은 idempotency key로 중복 방지한다.
5. 챕터 실패가 전체 PDF 실패로 이어지지 않게 한다.
