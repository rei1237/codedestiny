## 작업 규칙과 함정

- 성능과 기능 검증은 로컬 mock을 사용한다. 앱에 mock 서버 주소가 들어가지 않게 운영용 빌드를 분리한다.
- 결과 그림과 내 기록은 꿀꿀, 네오와 영냥이의 정체성을 따르고 구매·회원 상태 판단은 기존 코드를 사용한다.
- Play 버전 코드는 전체 App Bundle 목록에서 확인한다. 앱 심사 요청과 사용자 배포 시점은 구분한다.

## 설계

홈은 게스트에게 로그인·회원가입을, 회원에게 계정 진입을 제공한다. 결과의 표지 그림은 기존 공식 자료의 경량 WebP를 사용한다. 영냥이 신점의 완료 영수증은 첫 풀이 다음에 배치한다. 대표 편지는 본문 전체의 스크롤 스타일을 다시 계산하지 않도록 뷰포트를 잠근다.
