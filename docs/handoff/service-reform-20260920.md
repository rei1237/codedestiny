# 서비스 개편 실행 기록

승인 범위: 결제 신뢰 → 공통 입력·휴먼 디자인 → 홈·한국어 대표 랜딩·SEO/GEO. 가격·이용권·월정석·단건 결제 정책 유지. 실결제·유료 LLM·운영 DB·운영 승격은 실행하지 않는다.

## 구현 현황
- 이용권 GRANT_PENDING: HTTP 200이어도 완료·복귀 전에 중단, 원 주문과 복귀 정보 보존. `f9c0a5502`.
- 영냥이: 결제 확인 후 자동 생성·재개, 기존 10분 cron에서 미완료 복구. 결제 유효성 확인과 결과 저장을 트랜잭션으로 묶고 환불 진행 건은 차단한다. `e40796af0`.
- 입력: 날짜의 중첩/평면 표현 동기화, 윤달·자정 보존. 저장 프로필은 필요한 항목만 보완하고, 이번 상담 수정은 세션 handoff로 분리한다. `b806f31a7`, `a697dfd0a`.
- 휴먼 디자인: 입력을 먼저 표시하고 차트를 뒤로 이동, 아이보리·짙은 글자·보라색. 계산 엔진·차트 구조 보존. 공개 `/human-design/guide/` 추가, 개인 도구 noindex 유지.
- 검색: 9개 허브에 무료·유료 범위, 입력·계산 근거·예시·재열람 안내. 사주·자미두수·숙요점은 가상 사례를 실제 엔진으로 검증. 영냥이 상세 보강. `6455694d8`.
- 홈: 영냥이 대표 이미지, 상담·무료 운세·구매 결과 3개 동선. 꿀꿀 운세/꿀꿀운세/영냥이 관계와 운영자의 날짜별 원문 기록, 공식 블로그와 개인 활동 블로그를 구분. `bfddbe8e5`.
- IndexNow: 마지막 성공 제출 이후 변경/삭제 URL, 실패 체크포인트 보존, 운영 호스트·공개 사이트맵에 제출 제한. 언어별 사이트맵 검사 수정. `63b73f3a4`.
- 분석: 서버 승인 기준 purchase, 권한 적용·결과 완료·첫 열람 분리. 질문·출생정보·결과·인증정보 제외. 브라우저 관측의 한계와 28일 지표는 `docs/seo/SERVICE_REFORM_MEASUREMENT.md`. `7a385df50`.

## 화면 검증과 검토
- mock 로컬에서 모바일 360/390/430px 홈·휴먼 디자인 가로 넘침 없음. 홈 주요 동작 48px, 입력 48px/제출 52px. 휴먼 디자인 공개 안내 모바일 본문 확인.
- 데스크톱 1365px에서도 주요 3개 동작 48px, 가로 넘침 없음. 무료 운세 버튼이 실제 입력 화면으로 진입함을 확인.
- 홈 테마 전환 후 영냥이 이미지 유지. 이전 돼지 이미지로 덮어쓰는 기존 런타임 충돌 수정.
- 자정·윤달 입력 보존과 mock 차트 오류/재시도 화면 확인. mock API의 차트 미지원 응답을 실제 계산 성공으로 주장하지 않는다. 저장 프로필 접힘 동작은 소스/회귀 검사 근거이며 모든 계정 상태를 브라우저로 검증한 것은 아니다.
- impeccable finish-review의 임시 편집 저장오염·금색 focus·전체 필드 반복 3개 지적 수정, 소스 재검토에서 해소 확인.
- 기계 디자인 검사에서 새 HD/템플릿 오류 없음. 기존 홈 Batang 서체 및 작은 폰트 크기 경고는 기존 타이포 보존 범위로 기록.
- 운영자 적중률·최고 수준을 독립 검증한 표현으로 넣지 않음. 원문 날짜와 링크, 실제 운영 역할만 표시.

## 남은 운영 확인
- 프로덕션 승격과 실 PG/LLM smoke는 별도 명시 승인 후 실행. 운영 DB·방화벽 변경 없음.
- WAF의 실제 AI 검색봇 요청 차단 여부, GSC/Bing 재수집·색인·인용, 실사용 CWV 75백분위는 운영에서 확인해야 한다.
- 환불 취소 응답이 불명확하면 결과 제공을 멈추는 fail-closed 정책이므로 운영 결제 상태 확인이 필요하다.
- GA 완료/첫 열람은 브라우저 관측이며 서버 cron 완료 전수나 여러 기기 간 최초 열람 집계가 아니다.
- 전체 키워드 1페이지·AI 추천·매출은 보장하지 않으며 배포 후 28일 비교로 검증한다.
