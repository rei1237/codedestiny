# 대표 상담 카드·프로필 홈 버튼 작업 기록

- 초융합·연이 대화·네오 이메일·영냥이 질문 순서의 카드 레일과 고민 기본 열림, 접힘 패널, 모바일 이미지 소스 선택, 프로필 홈 버튼을 구현했다. 기존 상담 탭과 여섯 카드 및 가격·결제·인증·API·DB는 유지했다.
- 로컬 브라우저 360·390·430·1280px에서 카드 순서와 이동, 고민 기본 열림, 가로 넘침을 확인했다. 390px 다크 테마와 키보드 이동, 고민 접기·펼치기 및 프로필 홈 반복 복귀를 확인했다. DPR 3에서 전체 운세 카테고리 표지 8개가 640px 소스를 선택했다. 터치 실기기·모든 개별 이미지·초기 성능 전후 비교는 미검증이다.
- 기존 main CI 실패는 네오 이메일의 전용 안내를 고가 상품 카피 검사에서 누락한 것이었다. 실제 전용 화면과 서버 가격 정본을 확인하도록 수정한 `cd26d665d6ec55510584685f61a0fc19fb7d1f1d`의 main CI가 통과했다: https://github.com/rei1237/codedestiny/actions/runs/40587392428
- `npm run check:fast -- --base=f7995f761447f933727f725d7929303b7d83d7ba` 통과: 90개 회귀 검사, Node 3,812건, Jest 6,995건, lint·typecheck·워커 빌드 등. 실결제·실 LLM·운영 DB는 사용하지 않았다.
- 기존 `scripts/design/verify-home-funnel.cjs` 전체 실행은 탭의 숨김 상태를 항상 보이는 것으로 기대하는 오래된 단언에서 실패한다. 그 단언을 임시 조정하면 기존 히어로 그라디언트 기대도 실패한다. 별도의 수동 브라우저 확인과 관련 Node 회귀 검사를 수행했으며 이 스크립트의 전면 갱신은 남는다.
