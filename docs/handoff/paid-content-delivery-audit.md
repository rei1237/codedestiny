# 유료 콘텐츠 전달 경로 감사 (2026-08-24)

> "결제는 서버가 차감하는데 콘텐츠는 누가 만드는가"를 유료 기능 전수로 확인한 기록.
> 재현 명령과 그날의 측정값을 함께 남긴다 — 인용하라는 뜻이지 다시 재라는 뜻이 아니다.

## 왜 이 감사를 했나

운명의 꽃에서 발견한 모양이 출발점이다. 결제는 서버(`coin-gate`/`unlockedFeatures`)가
처리하는데 **결과물은 브라우저가 만들어서**, 콘솔 한 줄이면 유료 산출물이 공짜로 나왔다.
같은 모양이 몇 개나 더 있는지 몰랐다.

## 결론 — 세 가지 실패 모양

| 모양 | 무엇이 문제인가 | 확인된 사례 |
|---|---|---|
| **A. 브라우저가 결과를 만든다** | 막을 라우트 자체가 없다. 생성기를 워커로 옮겨야 닫힌다 | 운명의 꽃(#1044) · 커리어 전환 타로(#1057) |
| **B. 서버가 주는데 결제를 안 본다** | 라우트는 있는데 증빙 조회가 없다. 게이트만 달면 닫힌다 | `/api/tarot/crystal-soul` · `/api/tarot/mindscan` |
| **C. 등록만 되고 아무도 청구 안 한다** | 우회가 아니라 레지스트리/구현 불일치 | `flower-studio-per-use` · `destiny-bias-*` 4종 (#1051 에서 정리) |

## 실측 (2026-08-24)

재현: `worker/lib/paid-feature-registry.js` 의 `PER_USE_PAID_FEATURE_KEY_LIST` 를 뽑아
각 키의 문자열이 `worker/**`(레지스트리·리뷰 카탈로그 제외)에 등장하는지, 그 파일에 증빙
어휘(`verifyPerUsePayment` · `requirePremiumReportAccess` · `canAccessPaidFeature` ·
`getUnlockedContentSnapshot` · `unlockedFeatures` · `findMoonstoneSpendEvidence`)가 있는지 본다.

```
회당결제 키 95개
  워커에 등장하지 않음            46
  워커에 있으나 증빙 어휘 없음      6
  증빙 어휘가 있는 파일에 등장     43
```

🔴 **이 숫자를 그대로 "46개가 우회 가능"으로 읽지 말 것.** 문자열 대조는 오탐이 많다.
AI 프롬프트 생성기처럼 **프롬프트 문자열 자체가 상품**이라 브라우저 생성이 설계인 것,
공유 게이트를 타는 것, 키가 죽어 있는 것이 섞여 있다. 키마다 코드를 열어야 확정된다.

### 엔드포인트 단위 대조

파일 단위로 보면 "다른 엔드포인트에는 인증이 있고 이 엔드포인트에는 없는" 구멍을 놓친다.
`worker/routes/**` 의 `if (path === "...")` 블록을 중괄호 균형으로 잘라 각 블록에 인증·증빙
어휘가 있는지 봤다(`라우트 블록 118개`).

🔴 **이 방식에도 함정이 있다.** `worker/routes/tarot.js` 는 라우터 상단에서
`if (path !== "/mindscan" && path !== "/draw" && ...) await requireAuth(...)` 를 돌린다 —
**블록 밖에 있는 공유 인증**이라 블록만 보면 "인증 없음"으로 잡힌다. 실제로 그렇게 오판했다가
`/crystal-soul` 이 이미 인증 뒤에 있다는 것을 테스트가 500 을 내면서 알려 줬다.
위임 블록(`return await handleX(...)`)도 3~5줄짜리라 전부 오탐으로 잡힌다 —
`animal-totem.js /reading` · `dream.js /psycho-analysis` 를 직접 열어 확인했다(둘 다 막고 있다).

## 이번에 닫은 것

- **`/api/tarot/crystal-soul`** — 로그인은 되어 있었지만 결제 확인이 없었다. 로그인 사용자면
  결제 없이 직접 POST 해 유료 리딩을 받을 수 있었다.
- **`/api/tarot/mindscan`** — 상단 인증에서 **명시적으로 제외**돼 있었고 결제 확인도 없었다.
  게다가 `lib/tarot/mindscan-reading.mjs` 가 **Gemini 를 직접 부른다**(`:832`) — 유료 우회에
  더해 누구나 LLM 비용을 태울 수 있는 경로였다.
- **`/api/destiny-compass/narrate`** — 무료 기능이라 유료 우회는 아니지만 무인증 Gemini 경로다.
  한도가 모듈 스코프 `Map` 이라 아이솔레이트마다 따로 세어 전역 방어가 아니었다.
  Mongo `abuse_scores` 로 옮겼다. 🔴 **로그인을 요구하지 않았다** — 비로그인 방문자가 무료
  해설을 잃고, `scripts/verify-ai-locale-live.mjs` 가 이 라우트의 무인증성에 기대어 돈다.

## 🔴 아직 확인하지 않은 것

- 위 46개 중 나머지 키가 A(브라우저 생성)인지 설계상 정상인지 **미검증**.
- `UNLOCK_PAID_FEATURE_KEYS` 쪽은 이번 감사 범위 밖이다(회당결제만 봤다).
- 실제 우회 시도는 하지 않았다. 코드 판독까지이며 **실결제·실호출 없음**.

## 다음에 이 작업을 이어받는다면

1. 46개를 훑을 때는 **키 이름이 아니라 화면**부터 본다 — 그 기능의 클라이언트가
   콘텐츠 API 를 부르는가, 아니면 로컬에서 만드는가. `git grep -l "<featureKey>"` 로
   화면을 찾고 그 파일에서 `fetch("/api/` 를 본다.
2. 모양 B(서버가 주는데 안 본다)를 먼저 처리한다 — 게이트만 달면 되고, 서버가 이미 비용을
   쓰고 있어 손해가 크다.
3. 모양 A 는 생성기 이전이 필요해 PR 하나에 하나씩이다. 정본 예시:
   `worker/lib/tarot-ijik-reading.js` + `__tests__/ui/tarot-ijik-server-gate.static.test.js`.
4. 🔴 **정적 가드는 배치만 본다.** 게이트가 실제로 막는지는 라우트를 돌리는 테스트가 봐야 한다
   — 증빙 확인을 `if (false)` 로 무력화해도 문자열 가드는 통과한다(실측).
5. 🔴 **미러(`public/**`)를 함께 지운다.** `sync:public` 은 소스에서 사라진 파일을 미러에서
   지우지 않아, 소스만 정리하면 배포본에 그대로 남아 우회가 열려 있다(꽃 작업에서 실제로 겪었다).
