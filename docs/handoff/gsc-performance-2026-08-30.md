# GSC 실적 3개월 판정 — 병목은 색인도 CTR 도 아니고 **노출 모수** (2026-08-30)

## 2. 판정 — 고칠 지점은 어디가 **아닌가**

- **CTR 문제가 아니다.** 1페이지(≤10위)에 든 76개 페이지가 263노출에 클릭 4(CTR 1.5%)인 것은 사실이나, 그 76개의 노출을 다 합쳐도 263이다. 제목·설명을 갈아 CTR 을 3배로 올려도 클릭은 두 자릿수다.
- **색인 문제도 아니다.** 커버리지 축은 종결이고 사이트맵 439개는 제출돼 있다.
- 🔴 **모수가 없다.** 3개월 546노출은 사실상 "검색에 존재하지 않음"이다. 메모리 [[conversion-bottleneck-is-audience-not-funnel]] 가 말하던 것이 실적으로 확인됐다 — **전환 UI·CTA·카피 튜닝에 더 투자하지 말 것.**

## 3. 유일하게 작동하는 축: 숙요

sukuyo 계열 24개 페이지가 **비홈 노출의 29.1%(139)** 를 가져간다. 최다 검색어도 `숙요점` 45노출·평균 9.71위다(클릭 0 — 1페이지 하단). 경쟁이 얕은 니치라 순위가 잡히는 유일한 주제다.

PR #1308 로 `/sukuyo/calendar` 를 색인에 되돌렸고(본문 1,668자 → 3,662자), 이어서 **검색 의도 기반 메타 재작성**을 했다. **다음 투자도 여기다.**

### 3-1. 검색 의도 재매칭 (완료)

실측 검색어와 페이지 메타가 어긋나 있었다. 관계 6페이지는 **3개월 노출 0**인데 같은 용어의 검색은 다른 페이지로 잡히고 있었다(`중거리 안괴` 4노출/28.5위, `숙요점 업태` 3/8, `숙요점 영친` 3/8.67, `원거리 안괴` 3/6).

- **원인**: 제목이 `안괴관계(安壞關係) — 가장 운명적인 인연` 처럼 **한자 표제어로 시작**했고, 사용자가 실제로 치는 `숙요점`·`거리`가 제목에 없었다. 본문에는 근거리/중거리/원거리 H2 가 이미 있었다 — **콘텐츠가 아니라 표기 매칭 문제였다.**
- **조치**: `INSIGHT_SEO_TITLES`·`INSIGHT_SEO_DESCRIPTIONS` 8개를 검색어 표기형으로 재작성(제목 폭 41~48 / 한계 60). 🔴 **거리별은 근거리·중거리·원거리 H2 가 실제로 있는 안괴·업태·위성 3개에만 넣었다** — 영친·명성·우쇠는 본문에 없어 넣지 않았다.
- 표기 변형 `숙요 점성술`·`숙요점성술` 은 허브 본문에 **0회**였다 → `/sukuyo` 허브 인트로와 키워드에 추가.
- `sukuyo-what-is` 는 클러스터 최박(2,866자)이면서 관계 6유형을 한 번도 언급하지 않아 관계 페이지로 내려가는 길이 없었다 → 관계 6유형 절과 내부링크 8개 추가.
- 곁가지로 고친 결함: `article()` 헬퍼가 `updatedAt: "2026-07-04"` 를 **하드코딩**해 어떤 기사를 고쳐도 사이트맵에 재크롤 신호가 안 나갔다. 선택 인자로 바꾸고(기본값 동일) 이번에 고친 8개만 올렸다.
