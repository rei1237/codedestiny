## 함정

- `db.js` 는 `autoIndex:false` — 스키마 선언은 아무것도 만들지 않는다. 정적 가드 `verify:mongo-query-index-shapes` 는 **선언 + 마이그레이션 리터럴**을 원장으로 쓰므로 선언이 거짓이면 가드가 거짓 통과한다. 새 인덱스는 선언과 마이그레이션 둘 다 넣는다.
- `verify:reconcile-index-drift` 의 `unused` 는 "리터럴 쿼리가 없다"이지 "쿼리가 없다"가 아니다 — 변수로 조립하는 필터는 `DYNAMIC_READERS` 에 파일:줄 근거로 올린다(예: `fortuneChatSessions.anonymousSessionId`, 비회원 bootstrap).
- 워크트리엔 `.env.local` 이 없다. `MONGO_URI`·`CD_PREVIEW_TEST_EMAIL` 은 루트 `.env.local` 에서 PowerShell 로 환경변수에 주입해 돌린다(값 비출력, `.env*` 수정 금지).
- 로컬 `check:quick` 의 `build:worker` 는 `workers-og` 미설치로 실패한다(회귀 아님, PR CI 로 확인).
