## 후속 과제(이번 범위 밖, 고치지 않았다)

- `verify:reconcile-index-drift` 는 **TTL 선언을 `unused` 로 판정한다** — `classifyCollection` 이 `unique` 선언만 조회와 무관하게 `create` 로 강제하고(`scripts/migrations/20260906-reconcile-index-drift.mjs:113`) `expireAfterSeconds` 에는 같은 예외가 없다. 그래서 실물을 만들기 전까지 위 TTL 선언이 "거짓 선언, 지워라"로 찍힌다(마이그레이션을 돌리면 실물과 일치해 사라진다). 고치려면 `:113` 옆에 TTL 케이스 한 줄 + `--self-test` 한 줄. 이번 범위 밖이라 손대지 않았다(프로덕션에 쓰는 스크립트의 판정 규칙 변경이라 별도 확인이 필요하다).
- **D 잔존 — 풀 포화 축 2건(미해결, 조사 여부는 사용자 결정)**: ⓐ **자기 요청이 detach 한 클라이언트 위의 op** 이 `lastCheckOutFailReason:"poolClosed"` 로 8000ms 예산을 다 태운다(`db.js` 상단 2026-08-08 주석과 같은 사유 — detach 는 즉시 실패로 이어지지 않는다). ⓑ fresh 유지 뒤 **같은 요청의 op 2건이 8000ms**(`checkOutFailed 1~2 · maxCheckoutWaitMs 2754~2841 · commandStarted 52~54 / Succeeded 49 · maxCommandMs 181`) — 명령은 빠른데 체크아웃이 막힌다. 라우트 쿼리는 `find`+`countDocuments` 2건뿐이라(`worker/routes/reviews.js:178`) 52~54건의 출처는 **미확인**(추정: SDAM 하트비트 + 이웃 + 떼어낸 풀의 이벤트 합산).
- `worker/routes/insights.js:385` 공개 목록 로드가 `connectDb` 뒤 `Insight.find` 를 **`withMongoRetry` 없이** 부른다(파일 내 `withMongoRetry` 0건, 검색 범위 그 파일) — 1회차에서 `MongoWaitQueueTimeoutError` 가 `[worker-unhandled]` 500 으로 나갔다(다른 라우트는 503+`Retry-After`).
- 라우트가 `connectDb(env)` 를 부른 뒤 `withMongoRetry` 가 다시 `connectDb` 를 부르므로 **콜드 요청이 방금 세운 커넥션에 300ms ping 을 던진다**(5회차 `summary`: 연결 +2968ms → +3268ms ping 실패 → detach → 재수립 2353ms, 요청 5.3s). 새 풀은 첫 소켓 생성(socketReadyMs≈1300)이 필요해 예산 안에 못 돌아온다. `lastHealthyAt` 은 수립 직후 찍히지만 `MONGO_PING_MIN_INTERVAL_MS=0` 이라 무효.
- 스테이징 tail 에 `Possible EventEmitter memory leak detected` 43건 — `observeConnectPhases` 리스너 누적 추정(미검증).
- 동시 3요청 중 한 요청이 별도 아이솔레이트에 떨어져 자기 커넥션을 새로 세운 회차가 있다(1·3·5회차 `insights`) — 추정, tail 에 아이솔레이트 식별자가 없다.

## 함정

- `db.js` 는 `autoIndex:false` — 스키마 선언은 아무것도 만들지 않는다. 새 인덱스는 선언과 마이그레이션 둘 다 넣는다(`verify:mongo-query-index-shapes` 는 선언+리터럴을 원장으로 쓴다).
- `verify:reconcile-index-drift` 의 `unused` 는 "리터럴 쿼리가 없다"이지 "쿼리가 없다"가 아니다 — 변수 조립 필터는 `DYNAMIC_READERS` 에 근거를 올린다.
- 워크트리엔 `.env.local`·`node_modules` 가 없다. `MONGO_URI` 는 루트 `.env.local` 에서 셸 환경변수로 주입(값 비출력, `.env*` 수정 금지). `wrangler`·`mongodb` 는 루트 `node_modules` 절대 경로로 부른다.
- 로컬 `check:quick` 의 `build:worker` 는 `workers-og` 미설치로 실패한다(회귀 아님, PR CI 로 확인).
- `wrangler tail --format json` 은 NDJSON 이 아니다 — `scripts/report-worker-tail-latency.mjs` 의 괄호 깊이 파서를 쓴다.
