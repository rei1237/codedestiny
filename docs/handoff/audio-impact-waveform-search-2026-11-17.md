## 작업 규칙과 함정

- 오래된 `전체통화_확대본`의 6개 전체 WAV는 PyAV resampler 누적 시간 밀림이 있다. 정확한 타임스탬프 근거로 사용하지 않는다.
- 반드시 `전체통화_확대본_원본시간정렬/10_...원음PCM.wav`를 검색 기준으로 사용한다.
- 타격음은 음성의 파열음·웃음·기침·AAC 블록 왜곡과 혼동될 수 있다. 파형 유사도만으로 원인을 확정하지 않는다.
- raw waveform 상관은 극성·미세 시프트·음량에 민감하다. 절대값 envelope와 다중대역 로그 에너지 특징을 함께 사용한다.
- 템플릿 구간의 정확한 타격 시각은 파일명 시작시각과 피크의 로컬 위치를 더해 계산한다.
- 반복 타격은 개별 hit 유사도뿐 아니라 hit 간격 패턴(약 45 ms-1.25 s)을 별도 점수로 계산한다.
- 강한 보정은 말소리 자음도 타격처럼 키운다. 원음/강조본을 항상 함께 제공한다.
- 새 소리 생성 금지. 보정 기록에 `synthesis: false`를 남긴다.
- 같은 명령 실패를 두 번 반복하지 않는다.

## 설계

### 1. 템플릿 추출

- S04-S10 각각에서 high-pass onset score를 계산한다.
- prominence, ratio, amplitude 조건을 통과한 피크를 뽑는다.
- 각 피크 주변 240 ms(예: -40 ms/+200 ms)의 특징을 저장한다.
- 특징 예시:
  - 정규화 절대 파형 envelope 64 bin
  - 80-500, 500-1500, 1500-3500, 3500-7000 Hz 대역별 로그 에너지 16 bin
  - attack/decay 시간, spectral centroid, spectral flatness, zero crossing
- 파일 전체의 모든 피크를 그대로 템플릿으로 쓰지 말고, 속기록 표기 중심 근처의 강한 피크와 반복 cluster를 우선한다.

### 2. 전체 검색

- 기존 6000 transient 후보를 1차 후보군으로 사용한다.
- 누락 방지를 위해 시간정렬 PCM에서 같은 검출기를 더 낮은 문턱으로 다시 돌려 전체 후보를 만든다.
- 각 후보를 템플릿 bank와 비교해 최고 유사도, 평균 상위 3개 유사도, 대응 기준(S04-S10)을 기록한다.
- 2초 이내 중복을 합치되 반복 cluster는 개별 hit와 cluster 양쪽을 보존한다.
