# PG 결제창 지연 — 실측 기준선 (2026-08-16)

> 이 문서만 읽고 다음 라운드를 시작할 수 있게 쓴다. 수치는 전부 그날의 측정값이므로
> **인용하되 근거로 재사용하기 전에 재측정**할 것(CLAUDE.md 원칙 8).

## 한 줄

클릭→PG창 지연의 **100%가 `POST /api/billing/checkout` 왕복 하나**이고, 그 안에서 실제로 시간을 쓰는 것은
쿼리·인덱스·admission 이 아니라 **웜 Mongo 커넥션을 검증 없이 재사용하다 죽은 소켓을 밟는 비용**이었다.

## 재현 명령


## ① 프로덕션 퍼널 (n=5, 계측 배포 2026-08-15 이후 전량)

| 단계 | p50 | p90 | max |
|---|---|---|---|
| `checkout` | **2187ms** | **9963ms** | 9963ms |
| `sdk` | 0 | 0 | 0 |
| `config` | 0 | 0 | 0 |
| `customer` | 0 | 0 | 0 |

- 클라이언트 구간(PortOne SDK 로드·`/api/payments/config`·구매자 정보)은 **전 표본 0ms**.
  라운드 1(#691 예열)·라운드 2(인라인 config/customer)가 의도대로 동작 중이며 **더 짜낼 것이 없다**.
- 같은 기간 `checkout_opened` 5건 → `checkout_pg_opened` 5건. 결제창~PG창 사이 이탈 0.
  🔴 `--days 30` 으로 보면 도달률이 1.8% 로 보이는데 이는 **계측 배포일이 달라서 생기는 착시**다
  (`checkout_pg_opened` 만 08-15 부터). 비율을 볼 때는 반드시 같은 기간으로 자를 것.

## ② 서버 내부 분해 (E2E n=3)

| run | checkout | cd(서버 총) | cdadm(admission) | cdconn(커넥션) | cdop(쿼리) |
|---|---|---|---|---|---|
| 1 (cold) | 9889ms | 9714 | **0** | 1306 | 287 |
| 2 | 4291ms | 3604 | **0** | 1292 | 2312 |
| 3 | 4199ms | 3621 | **0** | 1307 | 2314 |

- `cdadm=0` — admission 대기는 병목이 **아니다**(레인 분리는 제 역할을 하고 있다).
- `net tcp+tls connect = 0ms` — 클라↔엣지 커넥션 재사용됨. 웹은 동일출처라 **preflight 없음**.
- run 1 의 미귀속 8121ms 는 아이솔레이트 콜드가 아니라 **op 타임아웃 1회 + 재시도**다
  (9714 − 1306 − 287 = 8121, 아래 ③에서 같은 값이 반복 관측된다).

## ③ 결정적 측정 — 커넥션 재사용 (쓰기 0회)

`GET /api/payments/orders/:id`(Mongo **읽기 1건**짜리 V2 라우트)를 간격만 바꿔 7회:

```
#1 gap=    0ms  net=8001ms   cdconn=0     cdop=7843
#2 gap=  300ms  net=4450ms   cdconn=1416  cdop=2218
#3 gap=  300ms  net=9693ms   cdconn=1269  cdop=135    ← 앞 시도 8121ms 타임아웃 후 새 커넥션에서 재시도
#4 gap= 1000ms  net=4283ms   cdconn=1302  cdop=2212
#5 gap= 3000ms  net=9722ms   cdconn=1285  cdop=139    ← 위와 동일
#6 gap=10000ms  net=8013ms   cdconn=0     cdop=7852
#7 gap=30000ms  net=7992ms   cdconn=0     cdop=7833
```

읽어야 할 것:

1. **읽기 한 건짜리 라우트가 3.5~9.7초.** 쿼리가 느린 게 아니다.
2. `cdconn=0` 행(#1·#6·#7)이 "최근에 확인했으니 ping 생략"으로 곧장 재사용한 요청이고,
   그 대가를 **쿼리에서 7.8초**로 냈다. 7843/7852/7833 은 고정비 = 타임아웃이다.
3. **300ms 뒤 요청(#2)도 죽은 소켓을 만난다.** 원인이 Atlas 유휴 리핑이었다면 `maxIdleTimeMS`(60초)
   안에서는 살아 있어야 한다 → 유휴 시간 가설은 **반증됐다**. 요청 컨텍스트가 끝나면 그 컨텍스트에서
   연 소켓이 못 쓰게 되는 Cloudflare 의 성질과 정합한다.
4. **그 요청 안에서 새로 세운 커넥션은 빠르다** — #3·#5 의 재시도(cdconn≈1280 + cdop≈137 = **1.4초**),
   그리고 E2E run 1(1306+287 = 1.59초). n=3, 편차 200ms 이내.

→ **재사용 시도 3.5~9.7초 vs 새로 세우기 1.4~1.6초.** 웜 커넥션 재사용이 순이익이 아니라 순손실이다.

## 이번에 한 수정

`worker/lib/db.js` `connectDb` 웜 분기 하나. 자세한 근거는 그 자리 주석.

1. `MONGO_PING_MIN_INTERVAL_MS` **50000 → 0** (코드 기본값 + `[vars]` 함께) — 매 요청 검증.
2. `MONGO_PING_TIMEOUT_MS` **3500 → 1000** — 죽은 커넥션을 빨리 포기한다.
3. 검증에 **실패한** 커넥션을 그대로 돌려주지 않고 리셋 후 재수립.
   🔴 단 **동시 요청이 있으면 끊지 않는다**(2026-08-08 재연결 폭풍 사고의 가드 유지).
   그 판정을 위해 `connectDb(env, { activeOpsOwned })` 를 추가했다 — `withMongoRetry` 는 슬롯을 잡은
   뒤 부르므로 `1`, 라우트 직접 호출은 기본 `0`. 이걸 구분하지 않으면 직접 호출 경로가 **동시 요청
   하나를 자기 자신으로 착각해** 남의 소켓을 끊는다(테스트 3번이 그것을 고정한다).

되돌리기는 `MONGO_PING_MIN_INTERVAL_MS` 를 올리는 것 하나다(코드 기본값과 `[vars]` 를 **함께**).

## 아직 안 한 것 (다음 라운드 후보)

- 🔴 **머지 후 재측정이 남아 있다.** 위 ①③ 명령을 그대로 다시 돌려 전후를 비교할 것.
  기대: `cdop` 의 7.8초 행이 사라지고, 재사용 실패 시 `1000(ping) + 리셋 + 1280(connect) + 쿼리` 로 수렴.
  기대대로가 아니면 되돌리기 노브가 위에 있다.
- `maxIdleTimeMS`(60000) 의 코드 주석은 "좀비 소켓의 1차 방어선"이라고 주장하는데 ③이 그것을
  반증했다. 값 자체는 커넥션 생성률 예산 때문에 이번에 건드리지 않았다 — **주석과 실측이 어긋난 상태**다.
- **인증 401 → `/api/auth/refresh` → 재전송**(H2). 액세스 토큰 수명 30분이라 긴 결과를 읽다 결제하면
  왕복 3회가 된다(refresh 상한 15초). 이번 프로브는 갓 로그인 상태라 이 경로를 밟지 않았다 — **미측정**.
  사용자는 "결제창 열 때 선제 세션 갱신"을 하지 않기로 결정했다(2026-08-16).
- **`/points` 이용권 구매 경로의 SDK 로더 결함 2건** (범위에서 제외, 미수정):
  - `app/points/PointsClient.tsx:1435-1454` `ensurePortoneSdk` 가 이미 존재하는 `#portone-v2-sdk`
    태그에 리스너만 붙인다. 폴링도 예산도 없어 **이미 `load` 가 끝난 태그면 promise 가 영영 안 풀린다**.
    셸·dp 로더(`index.html:23855-23907`)가 문서로 남기고 고친 그 결함이며 `/points` 만 남았다.
  - `app/points/PointsClient.tsx:2990-3000` preconnect 가 `crossOrigin="anonymous"` 인데 실제
    `<script>` 는 crossOrigin 미지정(no-cors)이라 **예열한 TLS 소켓을 재사용하지 못한다**.
    #691 이 셸·dp 에서 고친 것과 같은 결함.
- `MONGO_SOCKET_TIMEOUT_MS`(7000)가 ③의 7.8초 중 대부분을 설명하는 것으로 **보이나 미검증**.
  이번 수정이 그 경로에 도달하기 전에 막으므로 값은 건드리지 않았다.
