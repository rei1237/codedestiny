3. 편집 → `npm run novel:build` → §8 의 검증 전량 → `npm run sitemap:generate`.
4. 커밋 전 `git diff --numstat` 로 **정본 외에 바뀐 파일이 산출물 4계통 + sitemap 3종뿐인지** 확인한다.
5. 끝나면 **이 문서에 결과와 벗어난 판단을 적고** 다음 세션 표를 갱신한다. 세션 1·2 항이 그 서식이다.

## 10. 다시 하지 말 것 (실패·오판 기록)

- **"박 없는 지은"을 겹침 허용 없는 정규식으로 세지 말 것.** `.{25}지은.{20}` 으로 5건이라 판정했으나 실제는 12건이다. 정규식이 겹치는 매치를 건너뛴다.
- **치환 규칙표를 "이름 + 조사"만으로 세우지 말 것**(세션 2 실측). `'박지은'이라는` 처럼 **인용부호가 사이에 끼면** 조사 규칙이 안 걸리고 일반 규칙이 먹어 비문이 된다. 이름 치환을 짤 때는 `이름([구두점]{1,2})([가-힣])` 로 **한 번 훑고 시작**할 것.
- **기술명을 바꿨으면 그 기술을 부르는 지문도 함께 볼 것**(세션 2 실측). EP.38 #131 의 「화룡」을 「화염 스텝」으로 고치자 #132 지문의 「모카의 불룡이」가 없는 기술을 가리키게 됐다. 카드만 고치고 끝내면 조용히 어긋난다.
- **후반 아크의 개행은 파일마다 다르다**(세션 2 실측). 정본 JSON·`public/codedestiny-novel.html` 은 **LF**, `scripts/**`·`lib/**`·`app/**` 는 **CRLF**. 문자열로 줄을 끼워 넣을 때 `\n` 을 그냥 쓰면 짝 없는 LF 가 생겨 git 정규화가 꺼진다.
- **EP.33 #68 「저는 누구의 아들입니까」를 잔재로 오해하지 말 것.** 서브에이전트가 "폐기된 모자 설정의 잔재"라고 보고했으나, 본문을 열어 확인한 결과 결함이 아니다(§4 마지막). **돌아온 보고는 재료지 결론이 아니다.**
- **소망 서사를 삭제하지 말 것.** EP.41 정점이 무너진다. 사용자 표현("사서의 아들")을 문자 그대로 받아 삭제 대상으로 잡으면 안 된다.
- **연애 시뮬의 「박지은」에 전역 치환을 돌리지 말 것.** 12개 로케일 번역까지 오염된다.
- **`verify:novel-runtime` 의 "실브라우저 필요"라는 미배선 사유를 믿지 말 것.** 순수 정적 검사이며, 이 거짓 사유 때문에 회귀가 오래 방치됐다.
- **`public/codedestiny-novel.html` 의 대본을 직접 고치지 말 것.** PR #1166 이후 플레이어는 청크를 fetch 하므로 정본만 고치고 `novel:build` 를 돌린다.
- **근거를 못 찾으면 추측하지 말고 사용자에게 물을 것.**
