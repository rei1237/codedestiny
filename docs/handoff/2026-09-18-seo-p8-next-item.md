# SEO 개편 요청 — P8: 원 요청 22개 중 남은 4개 중 다음 항목 선정

## 왜

`docs/handoff/2026-09-17-seo-p1-followup.md`의 "원 요청 22개 항목 중 미착수"
목록에서 P7(경쟁사 SERP 조사·검색의도 키워드 확장, 완료
[2026-09-18-seo-p7-next-item.md](2026-09-18-seo-p7-next-item.md) 및 결과물
[docs/seo/COMPETITOR-SERP-AUDIT.md](../seo/COMPETITOR-SERP-AUDIT.md))까지
끝남. 남은 4개 중 어느 것을 다음으로 할지는 아직 사용자가 지정하지 않음.

## 남은 4개 (우선순위 미지정)

1. 허브 콘텐츠 재작성.
2. 내부링크 재설계.
3. E-E-A-T 강화.
4. Core Web Vitals 실측.

## 다음 세션이 할 일

1. 이 목록을 사용자에게 제시하고 AskUserQuestion으로 다음 착수 항목을
   지정받는다(P4~P7 때와 동일한 패턴 — 원 요청이 항목별 구체 범위를 정하지
   않았으므로 추측 금지).
2. "허브 콘텐츠 재작성"을 고를 경우: P7 결과물
   [COMPETITOR-SERP-AUDIT.md](../seo/COMPETITOR-SERP-AUDIT.md) 3절의 검색의도
   확장 키워드(숙요 27수 쌍별 궁합 351개, 사주 십간 조합 95개 포함)를 실제
   page title/meta에 반영하는 작업이 여기서 처음 코드/콘텐츠 변경으로
   이어진다. **현재 네이버 노출이 양호한 페이지가 있으므로(사용자 확인),
   무분별한 메타 변경으로 기존 순위를 흔들지 않도록 변경 전 위험도·영향범위
   판단을 먼저 보고한다.** 351개 궁합 키워드를 페이지 351개로 만들라는
   뜻이 아니다 — 우선순위·구현 단위(허브+동적 라우트 vs 개별 페이지 등)를
   사용자와 먼저 정한다.
3. 위험도(GREEN/RED)를 조사 후 먼저 판단·보고, 그다음 구현. 허브 콘텐츠
   재작성·내부링크 재설계는 라우팅/공유 동작에 걸치면 RED로 격상될 수 있다.
4. 완료 후 이번 문서와 같은 패턴으로 `docs/handoff/<날짜>-seo-p9-next-item.md`
   를 만들어 남은 항목과 다음 세션 시작 문장을 남긴다(사용자 지시 유지: 매
   P단계 완료마다 다음 단계용 인수인계 문서 자동 생성).

## 위험도

미확인 — 항목마다 다름(내부링크 재설계·허브 콘텐츠 재작성은 라우팅/공유
동작에 걸치면 RED일 수 있음, Core Web Vitals 실측은 조사 위주라 GREEN에
가까움). 항목 지정 후 재판단.
