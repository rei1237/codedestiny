## 작업 규칙과 함정

- `/`는 Next의 서비스 선택 화면이고 `/ggulggul/`는 정적 셸이다. `/yeongnyangi/room/`은 이야기·무료 운세를 제공하는 방이다. 방문자가 바로 질문을 쓰는 곳은 `/yeongnyangi/#questions`다. 각 경로에서 실제 선택해야 하는 컨트롤에 맞춰 테스트한다.
- 결제 선택창은 기존 취소 함수로 닫고 포커스를 복귀시킨다. 연관 정본·미러·독립 런타임의 캐시 지문을 맞춰야 한다. 이용권, 월정석, 단건, 주문/환불별 안내는 기존 정책을 따른다.
- 포스터·아바타·소개장 시트와 스크롤·모션 설정을 나눠 센다. 같은 자료를 HTTP 헤더 포함 바이트와 응답 본문 바이트로 중복 집계하지 않는다. 제한망 시뮬레이션, 직접 관측, CrUX 수치는 분리한다.
- 검증은 loopback 정적 출시 빌드와 합성 프로필·주문을 사용했다. 컴파일에 필요한 API origin은 `.invalid`, 네트워크는 mock guard로 차단했다. Next의 출력 정리와 25ms manifest 복구가 경합해 임시 측정 래퍼가 출력 정리 후에 기존 복구를 시작하게 했다. SSR과 내보내기 완전성 검사를 통과했다.
- SEO는 추적된 원장을 기준으로 생성한다. 다른 세션의 미발행 커밋을 원격에 함께 보내거나 작업 트리를 정리하지 않는다.
