# 운기 다이어리 앱

## 왜

기존 "운기·기일 다이어리"(정적 셸의 바닐라 IIFE 모달)를 **운기 → 계획 → 행동 → 기록 → 회고가 반복되는 다이어리 앱**으로 바꾼다. 사용자 확정: App Router 신규 `/diary` · localStorage 유지 + 확장 키 + 백업 · 기일 = 기존 일운 등급 승격 · 부가기능 전부 보존('더보기') · ko 전용 + en 폴백 · 신규 `verify:*` 0개(테스트로 대체).

🔴 **기존 사용자의 기록을 한 건도 잃지 않는다.** 🔴 **기존 운기 엔진을 중복 구현하지 않는다.** 🔴 **운기가 결과를 결정한다고 쓰지 않는다** — 사용자가 자기 기록과 운기를 스스로 관찰하는 도구다.

- **통계에 원국이 없는 사람을 위한 등록 CTA 는 안 넣었다**(목업과 다른 점) — `/diary` 에 생년월일 등록 라우트가 없어서 기존 두 자리(`DiaryFlowCard`·`DiaryDayView`)처럼 안내 문장만 둔다. 등록 화면이 생기는 PR 에서 세 곳을 같이 잇는다.
