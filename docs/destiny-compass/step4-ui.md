# 운명의 나침반 하우스 — STEP 4 UI/UX 설계

> 상태: 설계 문서 + 단독 HTML 목업(`docs/destiny-compass/mockup.html`). 프로덕션 코드 아님. 승인 후 STEP 5 구현.
> 디자인 시스템: `styles/theme-tokens.css`(--cd-*) · `DESIGN.md` 재사용. 신규 토큰 없음.

## 0. 비주얼 방향

**노스스타 계승**: DESIGN.md "달빛 아래 두 권의 책". 이 기능은 **한 흐름 안에서 두 표지를 오가는 여정** — 찻집(연이·핑크)에서 위로받고, 전략실(네오·퍼플)에서 실행 명령을 받는다.

- **레지스터 판단**: 기본은 product(도구)지만, 이 라우트는 브랜드 몰입 모먼트다. 그래서 모션은 **상태·진행·리빌 전달**(안개=진행 피드백, 나침반 회전=결과 리빌, 존 전환=구역 변경 신호)에 한정하고 장식 모션은 배제 → product 규칙("motion conveys state")과 충돌하지 않는다. 프롤로그만 1회성 내러티브(스킵 가능).
- **안티슬롭 가드레일**(PRODUCT.md·DESIGN.md):
  - 클리셰 미스틱 보라 그라디언트 배경 금지 → 네오 퍼플은 브랜드 정본(`#0a0818→#13102a`) + **Glow-Not-Shadow** + 실제 캐릭터/히어로 아트 + Veil(반투명 깊이)로 표현.
  - Two Covers(표면·텍스트·강조 한 세트 전환), One Accent(모드당 강조 1), Hue-Stays(대비는 명도/채도로만).
  - 그라디언트 텍스트·사이드스트라이프·동일 카드 그리드·eyebrow/번호 스캐폴딩 금지.
- **컨테이너 폭**: `.wrap`(960px) 미사용. `--cd-w-wide`(1440px) 대시보드 + `--cd-w-prose`(760px) 해설 프로즈. 기존 960px 라우트 무영향.

## 4. 애니메이션 명세

| 대상 | duration | easing | trigger | reduced-motion |
|---|---|---|---|---|
| 비트 전환(프롤로그) | 220ms `--cd-dur-base` | `--cd-ease-out` | 다음 비트 | 즉시 크로스페이드 |
| 캐릭터 등장 | 320ms | `--cd-ease-snap` | 화자 등장 | opacity만 |
| 감정 칩 선택 | 120ms `--cd-dur-fast` | ease-out | click | 색만 |
| **안개 해제** | 500ms | ease-out-quart | 질문 응답 | 최종 해제 상태 즉시 |
| **나침반 바늘** | 900ms | cubic-bezier(.16,1,.3,1) | 결과 진입 | 최종 각도 즉시 |
| 방사형 스코어 채우기 | 600ms stagger 60ms | ease-out | 결과 진입 | 즉시 |
| 존 전환(찻집↔전략실) | 400ms `--cd-dur-emph`+ | ease-out | [4] 진입 | 즉시 스왑 |
| 프레스 | scale `--cd-press-scale` | ease-out | active | scale 1 |

- **성능**: transform/opacity/clip-path/mask만 애니메이트(레이아웃 속성 금지). 60fps 목표.
- **안개 기법**: `backdrop-filter`/무거운 blur 금지(WebView 비용). 레이어드 radial-gradient + `mask-image`(또는 `clip-path` 원형 확장) + opacity 전이. 사전 렌더 텍스처 1장 위에 그라디언트 베일 opacity로 해제.
- **리빌 가시성**: 콘텐츠는 기본 표시 상태로 두고 그 위에 안개/바늘을 얹는다(클래스 트리거로 콘텐츠 자체를 숨기지 않음 — 헤드리스/탭 비활성 시 빈 화면 방지).

## 5. 접근성 (WCAG AA)

- 본문 명암비 ≥4.5:1(큰 텍스트·UI 3:1). 네오 뮤트/프로즈는 `--cd-prose-body-color(#ded7f5)` 사용해 AA 확보. Hue-Stays로 회색 도피 금지.
- 모든 캐릭터/히어로 이미지 `alt`(예: "전략실의 네오"), 나침반은 `role="img"`+`aria-label`(대표 방향·점수 텍스트 등가물 제공).
- 감정 칩=radiogroup, 안개 선택=버튼, 나침반 결과 영역 포커스 가능, 오늘의 한 걸음 액션=버튼. 키보드 내비 완비(데스크톱).
- 터치 타깃 ≥44×44. `prefers-reduced-motion` 전 애니 대체.
- 스크린리더: 나침반 시각 다이얼은 텍스트 등가물(대표 방향+방향별 점수)과 병기.
