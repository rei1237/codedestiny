# 네오 결제 복구와 전략서 검증

## 운영 승격 범위

- 긴급 복구: 신규 상담의 결제창 앞 서버 선확인 제거, 공용 결제 게이트 사용, 중복 제출 차단, 기존 요청 ID·복귀 정보 유지.
- 추가 승인된 홈 메타 설명 최소 수정과 생성 미러·사이트맵 정합성 수정 포함.
- main SHA `29323c27e9f17de8b2940dbbcc98d8f8a5c32e79`의 필수 CI 성공: https://github.com/rei1237/codedestiny/actions/runs/37307257907
- 동시 세션의 후속 main 변경을 포함하지 않도록 위 SHA에 `release/neo-checkout-20261005` 태그를 고정했다.
- 승인된 운영 승격 1회 실행: https://github.com/rei1237/codedestiny/actions/runs/37309140934
- 실행 후 배포 상태를 폴링하지 않았다. 이 문서는 운영 완료·실결제 성공의 증거가 아니다.
- 아래 UI·전략서·결과 화면 변경은 해당 운영 승격에 포함하지 않는다.

## 구현과 유지 계약

- 소개 → 받을 결과 → 고민 입력. 네 장면의 건너뛸 수 있는 소개, 고민·주제 우선 입력, 원래 계산·입력 계약 유지.
- 홈의 연이·네오·영냥이 상담 카드는 두 테마에서 모두 표시한다.
- 결과는 핵심 판단과 첫 행동을 먼저 표시하고, 긴 전략 요약·판단 근거와 원문은 펼쳐 읽는다. 공유는 하단에 둔다.
- 본인의 완료 상담 1~5건을 선택해 휘장 5개로 전략서 발급. 저장된 판단·강점·주의점·실행안만 편집하며 추가 AI 호출·새 예측은 없다.
- 소유권·완료 상태·열람권 회수 여부 검증. 휘장 차감, 차감 원장, 스냅샷, 멱등 요청 기록은 하나의 Mongo 트랜잭션이다.
- 같은 상담 조합은 같은 발급본을 반환한다. 이후 상담 수정은 발급본을 바꾸지 않는다. PDF 재시도는 재차감하지 않는다.
- 기존 개별 PDF·편지 해금과 잔액·이력 유지. 새 개별 특전 교환 요청은 차감 없이 전략서 경로로 안내한다.
- 가격 registry의 20,000원 및 이용권·월정석·단건 결제 정책 유지.
- 전략서 화면은 noindex/nofollow와 no-store로 공개 검색·캐시에서 제외한다.

## 로컬·mock 증거

- `npm run check:fast -- --plan`: 변경 범위와 위험 승격 계획 확인.
- `npm run check:fast`: 자동 승격한 결제 게이트 88/88 및 lint 통과. 실행 중 추가한 결과 화면 수정으로 사이트맵 원장 드리프트를 검출했다. 원장을 재생성한 뒤 실패한 `npm run verify:sitemap-drift` 재검사 통과. 전체 게이트를 반복하지 않았다.
- worker targeted Jest 6 suites / 143 tests 통과: 전략서 원자성·잔액 4/5·소유권·미완료·권한 회수·동시 발급·저장 실패·응답 유실·고정 스냅샷·기존 해금, 기록 필터, 결제·환불·전달·라우트 제한.
- UI targeted Node 16 tests 통과: 결제 취소/실패/중복 제출, 공용 게이트 우선, 동일 요청·복귀, 계정 변경·백그라운드 복귀, 시각 요약·원문 보존.
- `npm run typecheck`, 변경 파일 ESLint, `verify:neo`, `verify:neo-output-safety` 통과.
- 홈 registry 57개, sitemap 1,311 URL 정합성 통과. 생성 미러는 sync 두 번 후 별도 fresh guard로 확인한다.
- Playwright mock: 360/390/430/1280px, 휘장 0개 정상 입력 후 실제 공용 결제창의 20,000원 표시, 결제 전 `/start` 호출 0, 가로 넘침·제목/CTA 겹침 없음.
- 홈 두 테마 390/1280px에서 상담 카드 3개 노출. 결과 1차·수정 전략 네 폭에서 키보드 펼침, 원문 링크 이동, 가로 넘침 없음.
- 전략서 네 폭에서 넘침 없음. 발급 응답 유실 뒤 같은 멱등키 재시도, 표지 다운로드 실패 뒤 PDF 재시도에서 추가 발급 요청 없음.
- ko/en/ja/zh-CN/zh-TW 긴 문장 PDF 생성·렌더 확인. 영어 9쪽, 나머지 각 8쪽, 빈 페이지 0, 원문 링크 보존. PDF는 브라우저 글꼴을 그린 이미지 방식이다.
- 독립 UI 리뷰 `ship`: 입구·결제·홈·전략서·PDF 및 결과 화면. 전용 프리셋 대신 일반 리뷰 에이전트 사용. 글자 크기 advisory 5건은 비차단.
- 이미지 출처와 정확한 생성 프롬프트: `docs/design/neo-strategy-assets.json`, 각 신규 WebP의 JSON sidecar.

## 범위와 제한

실결제, 유료 LLM, 운영 DB 수동 변경, 실기기·스크린리더 검증은 수행하지 않았다. mock과 코드 검증을 운영 실측으로 해석하지 않는다. 후속 변경의 main 필수 CI 결과는 전달 메시지에서 정확한 SHA와 함께 보고한다.

화면·PDF 검토본은 로컬 `output/neo-strategy-20261005/`에 보관한다. 테스트용 상담 문구는 합성 데이터다.
