# 구매 여정 최적화 — 조사·목업 단계

전체 구현은 **미완료**다. 이 변경은 소스 후보 조사표와 클릭형 목업이며 서비스 런타임 변경을 포함하지 않는다. 목업 확인 후 제품 적용과 전체 화면 감사·결제 회귀 검증을 이어간다.

## 실행

워크트리: `D:\Development\code-destiny-purchase-journey`

브랜치: `codex/purchase-journey` · 시작 기준: `f90fe7fc5a41f77b2ce7438b27375361a1352948`

```powershell
Set-Location D:\Development\code-destiny-purchase-journey
node scripts/build-purchase-journey-review.mjs
python -m http.server 4319 --bind 127.0.0.1 --directory docs/purchase-journey
```

브라우저에서 `http://127.0.0.1:4319/review.html`을 연다. 이 서버는 검토 자료 폴더만 제공한다. 결제 안내 버튼은 의도적으로 비활성화했다. 홈의 고민 선택, 상세 보기, 화면 이동, 조사표 검색은 동작한다.

`inventory.json`은 기존 추출기·시각 상세 생성기·가격 해석 함수를 읽기 전용으로 사용한다. 프로필 액션과 상품 키의 호출부 후보도 수집한다. 문자열 참조와 라우트 파일 존재는 실제 동작 증거가 아니므로, 모든 구매 6단계 점수는 `null`이다. 파일 밖의 동적 액션·라우팅 별칭·카테고리별 가격은 수동 추적이 남아 있다.

현재 단순 키 연결 기준으로 진입점 미연결 후보 98개, 개별 카피 미연결 후보 108개가 있다. 이는 **실제 화면이 없다는 판정이 아니다**. 하위 상품·공용 상세·동적 진입의 연결 확인 목록이다. 숫자를 기능 누락률이나 서비스 수로 홍보하면 안 된다.

기존 카피에서 분량·기간·추가 제공·경력 관련 문장이 있는 16개 후보를 근거 확인 대상으로 표시했다. 이 역시 거짓 주장이라는 판정이 아니다. `existingCopy`는 현재 소스의 기록이며 승인된 새 카피가 아니다.

## 목업의 결정

- 홈은 고민 선택을 첫 행동으로 삼는다. 기존 전체 검색과 프로필 결과 복귀는 제품 적용 시 유지한다.
- 대표 상세는 숙요·자미두수·초융합이다. 질문·가치·도식은 서로 다르게 구성한다.
- 개인 결과를 흉내 내는 문장 대신 기존 결과 항목의 구성 도식을 사용한다. 공개 범위를 늘리거나 개인 결과를 생성하지 않는다.
- 결제 안내는 세 이용 방식의 설명 위치만 정한다. 실제 가격·잔액·이용권 판정을 목업에 복제하지 않는다.
- 결과 하단은 원래 결과를 보존하면서 관련 체계로 이동할 이유를 제시한다. 자동 생성·구매·공유는 없다.
- 검토 도구 설명과 데이터 연결 자리표시는 제품 문구가 아니다. 검토 헤더는 제품 화면에 추가하지 않는다.

숙요와 자미두수 구성의 출발 근거는 `index.html`의 `FEATURE_VISUAL_DETAILS`, `FEATURE_MARKETING_COPY`와 기존 시각 상세다. 최종 카피 확정에는 해당 계산·결과 렌더러 검증이 추가로 필요하다. 초융합도 각 체계의 실제 전달 데이터와 결과 렌더러를 대조한 후 게시한다.

## 아직 해야 할 일

1. 후보를 최종 사용자 서비스·하위 상품·별칭·비서비스 라우트로 확정하고 전체 화면을 mock으로 순회한다.
2. 각 서비스의 소개·입력·결과·잠금·결제·복귀·저장·추천을 연결하고 근거 있는 6단계 점수표를 작성한다.
3. 전 상품의 Hook 3~8개·가치·제공 결과·FAQ·추천 근거를 작성한다. 현재 목업의 세 상품만으로 완료 처리하지 않는다.
4. 목업 방향 확인 후 홈 정본과 기존 상세 렌더러에 적용한다. 공통 파일의 다른 작업과 순차 통합한다.
5. 이용권 상점·실제 결제 주변 설명·결과 추천·기존 공유·analytics 이벤트 연결을 구현한다.
6. 다른 언어와 SEO 경계, A~E 사용자 여정 및 서비스별 결제·잠금·resume를 mock에서 검증한다.
7. 생성 미러, 최신 main 정합과 필수 CI까지 통과시킨다. 머지·운영 승격은 별도 승인이다.
