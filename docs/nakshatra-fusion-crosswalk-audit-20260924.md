# 나크샤트라 융합 해설 27/27 대조 (2026-09-24)

범위: `constants/nakshatra-fusion.js` 의 27개 통합 제목·해설을 서비스 계산 정렬(`CROSSWALK_OFFSET = 11`, `nakshatraIdx = (sukuyoIdx + 11) % 27`)과 대조했다. 계산 원천(`constants/nakshatra-crosswalk.js`, `worker/lib/nakshatra-codex.js`, 속성표)은 바꾸지 않았고, 해설 문구만 최소 수정했다.

## 방법

- 실측: 세 상수 모듈을 esbuild CJS 번들로 적재해(`scripts/verify-nakshatra-flow.mjs` 와 같은 방식) 27행을 출력했다. 각 행은 정렬 나크샤트라의 신격 키워드·상징·샥티, 역사 대응(오프셋 13) 이름, 런타임 적용 여부, 제목·해설 첫 문장이다.
- 런타임 적용 여부: `FUSION_DEEP_DEFAULT`(역사 대응 오프셋 13 원고)는 정렬 나크샤트라 이름을 포함할 때만 덮어쓴다. 실측 결과 27/27 모두 미적용이었고, CMS 오버라이드(`app/_content/cms.generated.json`)도 비어 있다. 런타임 해설에 역사 대응 나크샤트라 이름이 섞인 행은 0건이다.
- 이름 정렬: `verify-nakshatra-flow.mjs` 8절이 27개 황경 중간값으로 숙요·나크샤트라 계산이 오프셋 정렬과 맞는지, 제목·해설·정/역방향 조회가 같은 이름을 쓰는지 이미 강제한다. 이번에 조사 정합 단언을 같은 절에 더했다(변이로 실패 확인).
- 주제 적합: 제목(titleLead)과 행동 조언(guidance)이 정렬 나크샤트라의 신격 키워드·상징·샥티, 또는 숙요 측 키워드 가운데 어디에서 나왔는지 행마다 판정했다. 숙요 측에서 온 표현은 숙요 해설과 겹치므로 허용한다.

## 결과 요약

- 이름 정렬 27/27 일치. 역사 대응 혼입 0/27.
- 결함 2종, 5행 수정:
  - 조사: 받침 없는 제목 4행(저·심·두·삼)에 `이`·`이라는`이 붙어 "목표이 중요하게", "'…풍요'이라는" 으로 나왔다. 받침 판정으로 `가`·`라는`을 고르게 고쳤다.
  - 여(女) 1행: 제목 "귀 기울여 설득하는 완성"과 조언 "무엇이 필요한지 먼저 듣고"의 '경청'은 역사 대응(슈라바나)의 주제였다. 정렬 나크샤트라 푸르바 아샤다의 상징(키, winnow)과 샥티(기운을 북돋는 힘)에 맞춰 "가려내어 북돋는 완성" / "키질하듯 남길 것과 덜어낼 것을 먼저 가르고…"로 바꿨다. 숙요 키워드(정제·완성·세밀)는 그대로다.
