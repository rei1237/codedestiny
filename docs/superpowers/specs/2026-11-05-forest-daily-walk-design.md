# 오늘의 숲길 설계

- 작성: 2026-11-05. 사용자 승인: 2026-11-05(계획 승인을 설계 승인으로 합의).
- 선행 작업: 연이 게임형 다이어리(`docs/handoff/daily-home-claude-20261105.md`).

## 의도

공개 홈의 다이어리 카드를 "입력 폼"에서 "연이와 영냥이가 안내하는 미지의 숲길"로 바꾼다. 사용자가 매일 짧게 들어와 출석, 작은 실천, 한 줄 기록을 하고 싶게 만드는 것이 목적이다. 서비스의 고급스러운 톤을 유지한다.

## 목표

- `/`의 타로 카드 두 장 아래에 숲 입구를 두고, 누르면 전체 화면 숲길이 열린다.
- 세 걸음(등불=출석, 오솔길=작은 실천, 샘터=기분·한 줄 기록)과 완주 장면으로 하루를 묶는다.
- 기존 다이어리, 꿀방울, 프로필 카드의 레벨·경험치를 한 흐름에서 보여 준다.

## 비목표

- 새 보상, 서버 원장, API·DB·결제·인증 변경.
- 퀘스트 꿀방울 신설.
- 출생 프로필 입력 재구현. 카드가 없으면 `/ggulggul/?action=dpOpenList`로 안내한다.

## 반목표 (동작해도 실패인 경우)

- 두 타로 카드의 첫 화면, H1, LCP를 해친다.
- 숲 조각이 재화처럼 보이거나 꿀방울과 혼동된다.
- 토토로·지브리의 캐릭터, 이름, 화풍을 직접 지정한다. 분위기(거대한 고목, 안개, 반딧불, 이끼, 등불)만 쓴다.
- 확정 예언이나 결제 압박 문구가 들어간다.

## 접근안과 선택

| 안 | 장단점 | 결정 |
|---|---|---|
| 카드 아래 숲 입구 + 전체 화면 | 첫 화면 속도, SEO, 서비스 선택 흐름 유지 | **사용자 선택** |
| 첫 화면 전체를 숲으로 교체 | 인상은 가장 강하나 첫 화면 정본 변경, LCP 위험 | 제외 |
| 첫 방문 전체 화면 인트로 | 몰입은 크나 진입을 가로막고 검색·광고 심사 위험 | 제외 |

입력 범위는 "오늘의 기록 중심"을 사용자가 선택했다.

## 동작

- 입구: `h2#daily-home-title`, 오늘 걸음 n/3, 등불 현황, "숲길 들어가기".
- 전체 화면: 네이티브 `<dialog>`. `#forest-walk` 해시로 뒤로가기 시 닫힌다. `#daily-home-title`은 첫 걸음, `#diary-today-record`는 셋째 걸음을 연다.
- 걸음은 잠그지 않는다. 스테퍼와 스와이프로 이동한다. 비로그인도 실천과 기록을 할 수 있다.
- `/diary/`는 같은 패널을 인라인으로 보여 주고 기존 상세 카드를 유지한다.

## 재미 요소

1. 등불 숲길: `streakEvery`개의 등불, 마지막은 꿀단지. 숫자는 전부 API 값.
2. 이번 주 숲 지도: 요일별 조각 7칸. 그날 실천 완료 + 기록이 있으면 채운다. 기존 저장소(`store`, `ext`)에서 계산하고 새 저장소를 만들지 않는다. 교환 가치가 없는 기념품임을 명시한다.
3. 숲 구역 이름: 레벨에 따른 표시 전용.
4. 프로필 카드 연결: 이름, Lv, 경험치 막대. `/api/rpg/progress` 재조회로 갱신. `awardRpg`가 금액을 돌려주지 않으므로 수치를 지어내지 않는다.
5. 캐릭터 대사: 연이는 존댓말과 호칭 "당신", 영냥이는 반말에 짧은 한마디만 `~냥`. 요일별로 돌린다.

## 제약

- 디자인: `docs/context/design-canon.md`, DESIGN.md §7·§9. 새 색은 `--cd-forest-*` 토큰, `dark:` 금지, 탭 44px, 입력 16px, 가로 넘침 없음, `prefers-reduced-motion` 준수, 새 장식 이모지 금지. 기분 이모지 6종은 기존 공유 정본이라 유지한다.
- 이미지: 실제 원본을 첨부해 생성하고 나란히 비교한다. 영냥이는 원본 크기로 귀 2개를 센다. 제작 기록은 `docs/design/forest-walk-art.md`.
- 성능: 입구 이미지는 lazy에 크기 고정. 전체 화면 코드는 클릭 시 동적 로드. API 호출은 입구가 화면에 들어온 뒤.
- 전달: main 빨간불 위에 push하지 않는다. 옆 세션 미커밋 8개는 보존한다. 운영 승격 전 미승격 커밋 목록을 보여 드리고 1회 승인을 받는다.

대사 문구의 세부, 숲 구역 경계 레벨, 애니메이션의 세부, 파일 내부 구조.
