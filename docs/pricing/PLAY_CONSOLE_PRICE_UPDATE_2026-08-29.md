# Play Console 가격 최신화 작업표 — 앱가를 웹가와 동일하게

> ✅ **2026-08-29 완료.** Play Console 인하는 사용자가 끝냈고, 코드 쪽 동일화도 뒤이어 들어갔다
> (`worker/lib/app-store-pricing.js` 의 `CONTENT_TIER_TABLE`). 아래 표는 그때 등록한 값의 기록이다.
>
> 🔴 **이 문서의 작업은 코드가 하지 않는다.** Play Console 의 가격·이름·설명 변경은 사람이 직접 한다.
> `npm run play:products:apply` 는 Play 에 실제로 쓰므로 **실행하지 않는다.**

## 왜 Play 를 먼저 고치나

앱 화면에 뜨는 금액은 코드(`worker/lib/app-store-pricing.js`)가 정하고, **실제 청구 금액은 Play Console 등록가**가 정한다. 둘이 어긋날 때:

- Play 가 **더 싸면** — 표시 ₩3,900 / 청구 ₩3,000. 사용자에게 손해가 없다. (안전한 방향)
- Play 가 **더 비싸면** — 표시 ₩3,000 / 청구 ₩3,900. **정책 위반이다.**

그래서 **Play 인하 → 코드 배포** 순서다. 반대로 하면 그 사이 기간이 전부 위반 구간이 된다.

## 2. 이용권 설명 문구 — 커버 금액이 같이 내려간다

이용권 **가격은 0절에서 끝났고**, 여기는 **설명 문구만**이다. "N원 이하"는 그 이용권이 덮는 콘텐츠 티어의 앱가라서 1절의 인하를 따라 내려간다.

| 상품 ID | 현재 설명의 커버 | **새 커버** | 확인 |
|---|---|---|:--:|
| `cd_pass_standard_30d` | 6,000원 이하 | **5,000원 이하** | ☐ |
| `cd_pass_premium_30d` | 13,000원 이하 | **10,000원 이하** | ☐ |
| `cd_pass_vvip_30d` | 25,000원 이하 | **20,000원 이하** | ☐ |
| `cd_pass_family_30d` | 이용권 대상 전체 | 변동 없음 | — |

**새 설명 전문** (그대로 붙여 넣으면 된다):

- `cd_pass_standard_30d` — 30일간 5,000원 이하 유료 기능을 월 최대 30,000원 상당까지 이용합니다. 프로필 3개. 자동 갱신되지 않습니다.
- `cd_pass_premium_30d` — 30일간 10,000원 이하 유료 기능을 월 최대 100,000원 상당까지 이용합니다. 프로필 7개. 자동 갱신되지 않습니다.
- `cd_pass_vvip_30d` — 30일간 20,000원 이하 유료 기능을 월 최대 200,000원 상당까지 이용합니다. 프로필 15개. 자동 갱신되지 않습니다.
- `cd_pass_family_30d` — (변경 없음)

> "월 최대 N원"은 웹 정본 월 한도라서 이번 인하와 무관하다. 건드리지 않는다.
