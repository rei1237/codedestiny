# C-1 유료 기능 설명 문구 — 대표·전문가 상담 18종 진단 (2026-11-18)

Phase 1 진단 전용 문서다. 소스는 한 글자도 바꾸지 않았다. 기준은 [README](README.md)의 "유료 기능 문구 기준 (C)"과 sepia professional-pass + style-pass §2–3·§5를 따른다.

- **범위**: `worker/lib/paid-feature-registry.js`에 등록된 30,000원 이상 상담·리포트 18종.
- **근거 표기**
  - 숫자는 모두 코드에서 실측한 값이다. 표 안의 `파일:줄`이 근거다.
  - 코드로 확인하지 못한 항목은 "확인 필요"로 표시했다.
- **제외**: `public/` 미러, `*.generated.*`.
- **결제 정책 공통 사실** (모든 카드의 "이용 조건"은 이 사실에서 나왔다)
  - `getPaidFeaturePaymentPolicy` (`worker/lib/paid-feature-registry.js:498-513`)
    - `direct_only` 상품은 단건 결제만 된다.
    - 나머지 상품은 이용권 / 단건 / 월정석 순으로 결제할 수 있다.
    - 월정석은 10,000원 이상 상품에만 쓸 수 있다 (`MOONSTONE_MIN_PRODUCT_KRW` :427).
  - 이용권 1회 한도 (`worker/lib/profile-limits.js:106`)

    | 이용권 | 1회 한도 |
    |---|---|
    | 스탠다드 | 50코인(5,000원) |
    | 프리미엄 | 100코인 |
    | VVIP | 200코인 |
    | 패밀리 | 한도 없음 |

    - 따라서 300코인(30,000원) 이상 상품을 이용권으로 바로 결제할 수 있는 것은 **패밀리 이용권뿐**이다 (registry :386-392 주석에도 같은 내용이 있다).
    - 이용권 기간은 무기한이다. 한도를 다 쓰면 끝난다.

## 3. 고친 소개 카드 (기능별)

### 연애 비책 (love-secret)
- **한 줄 정의**: 사주로 지금 연애 고민에 맞춘 행동 계획을 알려줘요 (29자)
  - 비율: 목록 "지금 연애의 흐름과 마음을 짚는 AI 상담" 23자 대비 126% — 레이아웃 ±20% 초과(26%)
  - 대안 (23자, 100%): "연애 고민에 맞춘 행동 계획을 사주로 짚어요"
- **넣는 것**: 생년월일·태어난 시간(몰라도 돼요), 지금 관계 상태, 고민 영역, 질문(1,200자까지), 상대 정보(선택)
- **받는 것**: 7묶음 30개 주제, 35,000~45,000자 리포트와 PDF. 같은 상담 안에서 이어 묻기(추가 차감 없음)
- **이용 조건**: 공통 30,000원 문구. 로그인 필요
- **분위기 한 줄**: 연이가 당신의 마음부터 차례로 짚어 드려요.
