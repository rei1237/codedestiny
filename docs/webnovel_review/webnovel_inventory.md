## 2. 0단계 긴급 복구 이력

계획 승인 직후, 진단 전에 아래 2건의 데이터 무결성 문제를 발견 즉시 수정함 (백업: `docs/webnovel_review/webnovel_backup/stub-originals/`):

1. **14화~44화 스텁 문제**: 서빙되던 `codeDestinyChapterNRevised`(N=14~44)가 실제 본문이 아니라 "편집 지시서만 남고 본문은 4문장 반복"인 깨진 스텁이었음. 구버전 완성 원고 `codeDestinyChapterN`이 파일에 남아있어, `codeDestinyChapterNRevised = codeDestinyChapterN;`로 참조 교체해 복구.
2. **58화~61화 orphan 배열 버그**: 완결부 4개 회차가 `getChaptersByStoryId()`가 조회하지 않는 `mockStories` 배열에 잘못 들어가 있어 전부 404였음. `mockChapters` 배열의 57화 뒤로 이동해 복구.

두 건 모두 `npm run typecheck` 통과 및 로컬 렌더링(`/stories/code-destiny/chapter-*`) 확인 완료. 현재 프롤로그+1~61화(총 62개 엔트리) 전체가 정상 서빙된다.
