# 라이트 노벨 모바일·서사 개선 기록

2026-09-27. 정본은 `content/novel/episodes.source.json`이며 텍스트 리더와 삽화 플레이어가 같은 원고를 읽는다.

## 반영 범위

- 44화·8,844비트 → 60화·9,124비트. 새 원고 8화와 긴 기존 화의 분할 8화다. 16화를 모두 신규 집필한 것으로 세지 않는다.
- 새 원고는 호랑이 첫 조우, 박수를 빌린 아이, 전투 뒤 간호, 귀환의 유혹, 인간형 재회, 계약의 덫, 정류장 전투, 탈출 뒤 증거 회수로 구성한다.
- 서한비는 악역이다. 작은 호랑이의 외형은 경계를 낮추며 관계의 약점을 관찰하는 장치다. 인간 세계에서는 후원자의 사회적 신뢰와 계약을 이용한다. 과거의 상처는 설명이며 가해의 면책 사유가 아니다.
- 연이·네오의 사랑은 서로를 위해 무조건 소진하는 방식에서, 한계를 알리고 함께 돌아오는 방식으로 발전한다. 서한비는 이를 약점으로 계산했다가 두 사람이 힘을 거둘 줄 안다는 점 때문에 패한다.
- 최종전은 물길 봉쇄, 이름 회수, 매듭 소각, 연이의 탈출이 함께 성공해야 끝난다. 포옹만으로 개심하거나 자동 화해하지 않는다. 마지막에도 서한비의 권한은 봉인되고 반환 기록은 피해 당사자와 대조한다.
- 이세계 왕복·동행·로맨스·전투라는 장르적 구조를 활용한 자체 원고다. 타 작품의 고유 인물·대사·사건을 옮기지 않았다.

## 성능과 표현

- 기존 배경 46개: 원본 합계 9,031,870바이트 → 모바일 파생물 5,495,836바이트(약 39.2% 감소). 이는 에셋 파일 합계 비교이며 첫 로딩 전송량이나 FPS 측정치가 아니다.
- 인간 세계의 배경 2개를 추가하여 모바일 배경은 총 48개. 최대 1280×960 안에 맞추고 원본을 보존한다.
- 기존 대형 캐릭터 시트에서 사용 표정 59개를 개별 WebP로 추출. 가장 큰 프레임은 225,000픽셀이다. 전체 시트 대신 현재 표정만 디코딩한다.
- 서한비 호랑이 표정 6개는 투명 WebP 384×384로 제작. 생성 시트 전체를 런타임에서 읽지 않는다.
- 다음 8비트에서 필요한 표정 최대 3개만 미리 읽는다. 에피소드 데이터 캐시는 최대 4개로 제한한다.
- 매니페스트와 청크는 HTTP 캐시를 재검증한다. 이전 원고를 강제로 재사용하여 새 배경과 대사가 누락되는 경우를 브라우저에서 재현하고 수정했다.
- 장면을 넘길 때 효과 타이머와 애니메이션 프레임을 취소한다. 최소 모션은 움직이는 효과를 생성하지 않는다. 백그라운드 탭에서 타이핑·자동 진행·음악을 멈춘다.
- 타이핑은 하나의 텍스트 노드를 갱신한다. 모바일 지속 배경 확대와 무거운 블러를 줄이고, 넓은 컷·인물 강조·정적 컷·충격 컷의 구도를 원고에서 지정한다.

## 저장 호환성

기존 8,844개 비트 ID를 유지한다. 긴 화를 분할해도 예전 ID와 숫자형 저장 위치가 해당 비트를 찾아간다. 변신 시점·직진입 배경·BGM도 새 화 순서에 맞춰 복원한다.

## 에셋 제작 경로와 프롬프트 명세

built-in image generation을 사용했다. 사용자 첨부 `박지은 캐릭터.png`의 검은 호랑이, 붉은 눈과 문양, 금장·붉은 망토를 서한비 동물형의 기준으로 삼았다. 원본 첨부는 수정하지 않았다. 아래는 재제작용 정리 명세다.

1. 호랑이: 첨부 캐릭터와 동일한 정체성을 유지한 검은 호랑이 6표정 시트. 3열×2행, 셀마다 온전한 몸과 꼬리를 담고 겹치지 않는다. 기본·대화·놀람·분노·슬픔·검은 물 마법. 붉은 눈과 이마 문양, 금장, 붉은 안감의 검은 망토. 투명 배경, 텍스트와 별도 소품 패널 없음. 셀별 여백과 일관된 크기를 유지한다.
2. 정류장: 해질녘 비 오는 한국 도시의 버스 정류장. 물웅덩이에 이계의 별빛이 비치며 현대와 환상의 경계가 흔들린다. 읽을 수 있는 광고 문구·사람은 제외하고 전경 캐릭터를 배치할 공간을 둔다. 세로 화면에서도 주요 구조가 남는 구도.
3. 재단: 현대 재단의 고급 사무 공간. 창 너머 도시, 차분하고 위압적인 조명, 붉은 보석과 어울리는 절제된 색감. 인물·로고·읽을 수 있는 글자 없음. 가운데와 양옆에 캐릭터를 세울 여유를 둔다.

런타임 파일:

- `public/images/novel/hanbi/{base,talk,surprise,angry,sad,water}.webp`
- `public/images/novel/remaster/{foundation,rainStop}.webp`
- `public/images/novel/mobile/*.webp`
- 규격·용량·원본 대응표: `content/novel/mobile-assets.json`

모바일 기존 에셋 재생성: `node scripts/build-novel-mobile-assets.mjs`. 공개 배경·캐릭터 원본을 읽고 Sharp로 파생물을 생성하며, 플레이어 표정 경로표까지 동기화한다. 이미지 생성 API를 호출하는 명령이 아니다.

## 검증과 한계

실행 대상: `npm run novel:build`, `node scripts/verify-novel-runtime.mjs`, `node scripts/verify-novel-player-start.mjs`, `node scripts/verify-story-text-sync.mjs`, `npm run verify:sitemap-drift`, `npm run check:fast`. GitHub main CI를 전달 완료 기준으로 확인한다.

브라우저 뷰포트 검증과 실제 저사양 Android/iOS의 메모리·프레임 측정은 구분한다. 실기기 FPS, 전체 BGM 청취, 운영 배포 후 체감 속도는 이 로컬 작업만으로 확인되지 않는다. 기존 외국어 번역은 이번 한국어 추가 원고의 번역 완료를 의미하지 않으며 별도 갱신이 필요하다. 과금 번역 API를 호출하지 않았다.

360×800, 390×844, 430×932 모바일 크기와 1280×800 데스크톱 구도를 브라우저에서 확인했다. 8,844개 기존 비트 ID 보존도 이전 커밋과 전수 대조했다.

결제·이용권·월정석·단건 결제 정책, 인증, API 응답, DB 스키마는 변경 대상이 아니다.
