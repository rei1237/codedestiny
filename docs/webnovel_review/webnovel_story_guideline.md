> 이 서비스의 **웹소설/비주얼 노벨은 브랜드 정체성**이다. 신규 화·개편·리라이팅을 할 때 이 문서의 "전체 흐름"에 맞춘다.
> 텍스트 웹소설: `lib/stories/chapters/*.ts`(+ `lib/stories/data.ts`) → `app/stories/*`.

## 전체 스토리 흐름 = 만화 「이누야샤」 구조 참조

전반적 서사 골격은 **이누야샤의 흐름을 참조**한다 — **고유명사·고유설정은 차용하지 않고 "구조(아키타입)"만** 가져온다. 대응은 다음과 같다:

| 이누야샤(구조) | Code Destiny 소설 |
|---|---|
| 현대의 소녀가 우물을 통해 이세계(전국시대)로 전이 | 현대 대학생 **연이**가 이상한 앱→타로 문/사주의 강을 통해 **운명(사주) 세계**로 전이, 꽃돼지로 변신 |
| 인외(반요) 동료와 동행 | **네오**(운명 세계에선 금빛 사자, 현실엔 흰 고양이 임시 현현체)와 동행 |
| 흩어진 구슬(사혼) 조각을 여정 속에서 회수 | 흩어진 **사주 기둥·글자 조각**(일주 `乙亥` 등)을 섬을 돌며 회수 |
| 뒤틀린 집착에서 태어난 그림자 흑막(나라쿠-온기구모) | **무성**(=흑막 본체의 억눌린 그림자 자아/도구), 검은 손을 부리는 존재 |
| 인간 주인공이 이계에 남는 결말 | 연이가 현실 복귀 거래를 스스로 거절하고 운명 세계에 남는 결말 |

이 구조 매핑의 **상세 설정·결말 설계**(네오=레온의 진명·시간여행자 정체, 흑막 진명 묘아, 무성=그림자 자아, 검은 비 속 남자=레온의 인간 잔상, 이누야샤식 엔딩)는 이미 [webnovel_ending_arc_outline.md](webnovel_ending_arc_outline.md)의 **§0·§4 "이누야샤 아키타입 매핑"**에 확정돼 있다. 신규 집필은 그 문서를 정본으로 따른다.

## VN(비주얼 노벨) 현재 범위 — 비겁의 섬 아크(EP1~5)

`public/codedestiny-novel.html` EP1~5는 `d586c1c` 원본을 정본으로 리라이팅한 **비겁의 섬 아크**다(프롤로그 포함 총 934비트).

- **프롤로그** 이상한 앱이 깔렸다 → **EP1** 꽃돼지가 되었다(사주의 강·네오 등장) → **EP2** 갈기 있는 고양이? 네오(비겁의 섬·거울 속 인간 연이·을해일주 `乙亥`) → **EP3** 본체 인증 실패(3항목 인증·을목 `乙` 획득) → **EP4** 해수의 심연(자기수용·을해 완성) → **EP5** 같은 나의 편(비견↔겁재 구분·최종전 시작).
- **가짜 연이(거울자아)** = 운명 찻집 연이 스프라이트(`DestinyCafe/nobackground/연이 스프라이트1-Photoroom.png` 4×2 시트의 한 프레임 크롭).
- **무성/각성 아크는 후속**(EP6~) — VN EP1~5 범위에는 아직 등장하지 않는다(네오의 진명·시간여행 정체도 미공개 유지).

## 집필 원칙 (요약)

- 사건·순서·클리프행어는 정본(`d586c1c` 및 위 outline) 유지, 문장은 라이트노벨 호흡(감정=신체감각/사물 치환, 대사:지문≈6:4)으로 다듬는다.
- 이누야샤는 **구조만** 참조 — 고유명사·대사·고유설정을 그대로 옮기지 않는다.
- 운세 용어(비겁/식상/일주 등)는 네오/시스템이 첫 등장 시 1문장으로 자연스럽게 풀이한다.
