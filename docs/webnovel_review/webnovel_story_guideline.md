## 전체 스토리 흐름 = 만화 「이누야샤」 구조 참조

전반적 서사 골격은 **이누야샤의 흐름을 참조**한다 — **고유명사·고유설정은 차용하지 않고 "구조(아키타입)"만** 가져온다. 대응은 다음과 같다:

| 이누야샤(구조) | Code Destiny 소설 |
|---|---|
| 현대의 소녀가 우물을 통해 이세계(전국시대)로 전이 | 현대 대학생 **연이**가 이상한 앱→타로 문/사주의 강을 통해 **운명(사주) 세계**로 전이, 꽃돼지로 변신 |
| 인외(반요) 동료와 동행 | **네오**(운명 세계에선 금빛 사자, 현실엔 흰 고양이 임시 현현체)와 동행 |
| 흩어진 구슬(사혼) 조각을 여정 속에서 회수 | 흩어진 **사주 기둥·글자 조각**(일주 `乙亥` 등)을 섬을 돌며 회수 |
| 뒤틀린 집착에서 태어난 그림자 흑막(나라쿠-온기구모) | **무성**(=흑막 본체의 억눌린 그림자 자아/도구), 검은 손을 부리는 존재 |
| 인간 주인공이 이계에 남는 결말 | 🔴 **두 각색의 확정 분기점** — [텍스트 소설] 연이가 현실 복귀 거래를 스스로 거절하고 **운명 세계에 잔류** / [VN] 의도적 반전 — 연이는 현실로 돌아오고 병하가 연이 쪽으로 건너온다(**현실 재회**, EP.42). 연이는 남는 대신 **문을 열어 두는 쪽**을 고르고, 그 선택을 EP.42 에서 직접 선언한다. VN 정본은 [SAJU_SERIES_BIBLE.md](SAJU_SERIES_BIBLE.md) §5 |

이 구조 매핑의 **상세 설정·결말 설계**(네오=레온의 진명·시간여행자 정체, 흑막 진명 묘아, 무성=그림자 자아, 검은 비 속 남자=레온의 인간 잔상, 이누야샤식 엔딩)는 이미 [webnovel_ending_arc_outline.md](webnovel_ending_arc_outline.md)의 **§0·§4 "이누야샤 아키타입 매핑"**에 확정돼 있다. 신규 집필은 그 문서를 정본으로 따른다.

## VN(비주얼 노벨) 현재 범위 — 7부 완결 아크

VN은 비겁의 섬에서 시작해 식상·재성·인성·계약과 귀환·자미두수·숙요 결말까지 이어지는 완결판이다. 에피소드·비트 ID와 순서는 정본에서만 관리하고, 정적 플레이어의 인라인 대본을 직접 수정하지 않는다.

- **1부 비겁**: 프롤로그 이상한 앱 → 꽃돼지 변신·사주의 강·네오·거울자아·을해일주 인증.
- **2부 식상**: 표현과 무대, 모카 합류, 식신·상관의 섬.
- **3부 재성**: 청토끼 금융그룹·계약·회중시계와 소유/선택의 갈등.
- **4부 인성**: 도서관의 기억·보호·네 번째 기둥. EP.23 은 백문이 제 과거를 들려주는 구조가 아니라 **연이가 기억을 열람해 문지방 밖의 「두 번째 그림자」를 목격**하는 구조다(PR #1175, 제목 「안 도망가는 물고기」). 소망의 종이 물고기가 EP.41 정체 회수의 열쇠가 된다.
- **5부 계약과 귀환**: 원본 계약서·재성의 발톱·현실 귀환 이후의 두 번째 부름.
- **6부 자미두수**: 별들의 궁, 그릇과 이름의 진실.
- **7부 숙요·결말**: 붉은 실·서한비·박병하·운명의 신·벚꽃 강가의 약속.
- **가짜 연이(거울자아)** = 운명 찻집 연이 스프라이트(`DestinyCafe/nobackground/연이 스프라이트1-Photoroom.png` 4×2 시트의 한 프레임 크롭).
- **정체 공개의 순서**는 정본의 해당 화를 따른다. 초반 비겁 아크의 장면만 수정할 때도 후반의 진명·시간여행 정보를 앞당겨 노출하지 않는다.

## 오행 호흡(五行息) 설정 정본

> 액션 체계의 **정본**. 신규 화·개편에서 전투/능력을 다룰 때 이 표와 3원칙을 그대로 따른다.
> **「귀멸의 칼날」은 "명명된 호흡 유파"라는 구조(아키타입)만 참조**하고, 고유명사·기술명·유파 설정은 전혀 차용하지 않는다(이누야샤 참조 원칙과 동일).

운명 세계의 존재는 **제 일간(日干)의 기운**을 숨으로 돌려 형(形)으로 꺼낸다.

### 3원칙

1. **제1칙 — 숨은 제 일간에서만 나온다.** 남의 기운은 흉내 낼 수 있어도 꺼낼 수 없다. 숨은 조건: *제 일간을 제가 알고 있어야 한다*(글자를 되찾는 것 ≠ 읽는 것). 연이만 예외 — 회수한 기둥의 기운을 빌려 쓰는 **그릇**.
2. **제2칙 — 상생은 합기(合氣), 상극은 파훼(破).** 팀 조합에 물리적 대가가 따른다.
   - `木生火` 연이 → 모카 **증폭**(합기 성립)
   - `水生木` 흑막 → 연이 **유혹/증폭**(무성이 연이에게 접근하는 명분)
   - `金克木` 네오 → 연이 **지키는 검** ← 최대 드라마 축. 금(金)은 본디 목(木)을 베지만, 네오는 그 칼을 **연이를 위협하는 것(검은 실·흑막의 공격)에만** 쓰고 **연이는 절대 베지 않는다.** 오히려 제 금이 연이에게 위험이 될까 봐 인간의 몸을 버리고 파수꾼(수호검)이 됐다 — 상극을 사랑으로 넘어선 축. [ending_arc_outline](webnovel_ending_arc_outline.md) §0(네오가 연이를 구하려 인간의 몸을 잃음)과 직결. 🔴 **VN 회수 라인(6단, 전부 정본에 들어가 있다)**: EP.14 사고(연이의 앞발에 선을 긋는다) → EP.32 상성 때문에 칼을 봉인 → EP.37 고백 → EP.38 **검은 실이 연이의 넝쿨을 관통해 있어 칼을 버리고 맨손으로 붙든다** → EP.39 **반 걸음을 비워 둔 진짜 이유를 말한다** → EP.42 **그 반 걸음이 사라진다**. 이 축을 건드리는 개편은 여섯 지점을 함께 본다.
   - `火克金` 모카 → 네오 **손상** / `水克火` 흑막 → 모카 **봉쇄**
3. **제3칙 — 숨은 나눠 쓰는 것이다.** 형을 뽑을수록 제 숨이 줄고, 숨이 다하면 몸이 먼저 무너진다.

- 🔴 **멸(滅)은 흑막 전용 단위다.** 루나는 같은 水 이지만 삼키는 쪽이 아니라 씻는 쪽이라 **류(流)** 를 쓴다. VN EP.41 `#26`(루나가 재성의 물을 통째로 쏟아 세계의 오염을 씻는 자리)이 **삼의 류 청류**다. 루나에게 「멸」을 붙이면 물의 아이가 흑막과 같은 문법을 쓰게 된다.

- **VN 이름·동기 정본**: 네오 진명=**박병하**(옛 레온), 흑막=**서한비**(徐寒霏 — 옛 표기 묘아 → 박지은 → **서한비**, 2026-08-27 확정). 🔴 **「박지은」은 실명 위험 때문에 폐기된 이름이다. 되살리지 말 것.** 다만 **R2 이미지 자산 파일명 9종(`박지은 기본.webp` 등)은 실물 파일명이라 구명을 그대로 쓴다** — 바꾸면 흑막이 나오는 전 컷이 404 다(`public/codedestiny-novel.html` 의 `var PJE`, `scripts/fetch-novel-assets.mjs`). 화자 키 `pje` 도 데이터 키라 유지한다. 「서한비」는 '찬 비'라는 뜻이라 수식(水息)·검은 비 이미지와 직결된다. 🔴 **연애 시뮬(`app/saju/love-simulation/**`)의 「박지은」은 계수 일간·1998-12-12생의 완전히 무관한 별개 캐릭터다. 전역 치환 금지.** 서한비 동기 = ①미래에서 박병하가 **연이의 밝음**(구김살 없는 웃음·어둠 속 햇빛)에 반한 것을 질투 + ②세상의 시간·운명·인연을 제 것으로 긁어모으는 **탐욕**, 자기 악행을 질서·자비로 포장하는 **위선**. **병든 딸·어미 설정은 폐기**(무자녀). 무성=서한비가 만든 그림자 자아/그릇(유지).
