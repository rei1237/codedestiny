# Code Destiny 라이트 노벨 — 현행 스토리 가이드

> 2026-11-08 정체 공개 시점(EP.42)·은발을 바이블 개정에 맞춤. 2026-11-03 설정 정합성 정리. 텍스트 리더와 비주얼 노벨은 같은 73화 대본을 사용한다. 실제 대본은 `content/novel/episodes.source.json`, 인물·규칙은 [SAJU_SERIES_BIBLE.md](SAJU_SERIES_BIBLE.md), 회차별 개요는 `lib/stories/vn/index.ts`가 관리한다. 폐기한 100화 초안은 현재 집필 근거로 사용하지 않는다.

## 작품의 중심

현대 대학생 연이가 꽃돼지가 되어 운세 세계에 떨어지고, 사주 글자를 되찾는 여행을 통해 자기 삶의 선택권을 되찾는다. 안내자 네오, 수달 요리사 모카, 시간을 잃은 윤달과 함께 타인의 목소리·시간·이름을 돌려준다. 마지막에는 운명을 읽는 사람에서 스물세 번째 카드에 운명을 쓰는 사람으로 성장한다.

이세계 전이, 동료 여행, 시련을 넘은 사랑이라는 장르 구조만 참고한다. 다른 작품의 고유명사·설정·장면·대사를 차용하지 않는다. 전투 기술 역시 기존 작품의 명명법을 복제하지 않는다.

## 4부 11아크

| 부 | 구간 | 핵심 사건 |
|---|---|---|
| 1부 사주의 세계 | PRO~EP.27B | 비겁 → 식상 → 재성 → 인성 → 다섯 번째 빛. 사주 글자를 회수하고 동료를 만난다. 흑월이 모습을 드러내며 연이와 네오가 인간형을 되찾는다. |
| 2부 돌아온 방 | EP.28~28D | 현실에서 검은 우산·말버릇·손목 흉터·이름을 연결해 연이가 서한비를 알아본다. |
| 3부 네 개의 하늘 | EP.29~45 | 자미두수의 무성 해방, 점성술의 윤달 생시 추적, 베다의 첫 번째 봄과 서한비 개심, 타로의 네오 고백·희생·별 카드. |
| 4부 결전과 선택 | EP.46~53·EP.51S~53S | 다섯 기운의 협력과 을경합, 흑월 소멸, 이름 반환. 현실 귀환과 운세 세계 잔류 중 연이가 선택하고 두 분기 모두 결혼으로 완결한다. |

73화에는 프롤로그·막간·두 엔딩이 포함된다. 화수와 비트 수는 대본에서 계산하며, 옛 문서의 고정 수치를 복사하지 않는다. 생성물 `public/data/novel/**`, `lib/stories/vn/episodes.generated.json`은 직접 편집하지 않는다.

## 인물 관계와 악역

- 영냥이·네오·박병하는 한 사람이다. 인간 박병하는 어느 세계에서나 은발이다. 연이가 소멸한 첫 번째 봄을 바꾸려고 인간의 몸과 이름을 대가로 한 번 회귀했다. 연이를 다치게 할까 두려워 힘을 절제하는 태도와 회귀의 대가는 구분한다.
- 서한비는 실패한 시간선에서 함께 넘어온 동반 시간 이동자다. 흑월이 연이의 얼굴로 저지른 배신에 속아 고리와 장부를 받았다. 연모·질투나 병든 딸을 구하려는 동기는 사용하지 않는다.
- 무성은 노래를 비웃음받은 독립된 소년이자 까마귀다. 서한비의 그림자 자아나 그릇이 아니다. 흑월의 깃털이 그를 살리면서 통제하며, EP.32~32A에서 모카의 사과와 노래로 해방된다.
- 최종 적은 흑월이다. 남의 얼굴을 쓰고 운명 코드를 먹으며, 연이를 자신의 그릇으로 삼으려 한다. 청토끼는 윤달의 생시를 훔친 시간 도둑이다. 이들을 별도의 사천왕 조직으로 묶지 않는다.
- 루나와 루나 언니는 재성의 섬 빵집 자매다. 옛 각색의 전투 동료·루나블룸 설정을 가져오지 않는다.
- 우주는 운명 고객센터 상담원이고, 네오는 수호자다.

## 형태·정체·기억의 순서

1. EP.01에서 연이가 꽃돼지가 된다. EP.26에서 인간형을 회복한 뒤 두 엔딩까지 유지한다.
2. 네오는 EP.27에서 인간형을 회복한다. 이후 사자님·고양이님은 별명이며, 과거 회상 외에는 앞발·꼬리로 행동하지 않는다.
3. EP.38A는 서한비가 첫 번째 봄의 동반자였고 가짜 연이가 흑월이었음을 보여 주는 장면이다. 우산 든 남자는 얼굴·이름·머리색 없이 나온다. 독자와 연이는 EP.42에서 네오의 직접 고백으로 정체와 대가를 함께 안다. 그 전까지 윤달이 미끼 용의자다(바이블 §3 '네오 정체 공개 설계').
4. EP.43에서 네오가 흑월에게 삼켜지며 그에 대한 기억이 흐려진다. EP.44의 메모가 길잡이가 되고, EP.48에서 존재와 기억을 회복한다.
5. EP.50의 카드 작성 전에는 기억을 두고 귀환하는 옛 규정이 위기다. 연이가 쓴 이름 반환 규칙이 수호자의 기억까지 보존하도록 바꾼다. 선택 이후에는 어느 분기에서도 다시 기억을 빼앗지 않는다.
6. 현실 분기에서 연이가 찾는 것은 잊은 이름이나 얼굴이 아니라 서로의 소재와 연락처다. EP.52는 기억을 지킨 두 사람의 재회와 다시 하는 자기소개다.
7. 현재 연이가 첫 번째 봄을 직접 살았던 기억이 없는 것과, 이번 여행의 기억을 잃는 것은 다르다. 서한비에게 들은 이야기는 기억한다.

## 사주와 오행 호흡

연이 명식은 **壬午年 丙午月 乙亥日 庚辰時**다. 수치의 근거는 [vn-divination-facts.md](vn-divination-facts.md)를 따른다. 옛 丁未 설정을 가져오지 않는다.

- 비겁의 乙亥 → 식상의 丙午 → 재성의 辰 → 인성의 壬午 → 관성의 庚 순으로 채운다. 네오가 마지막 庚이며, EP.43에서 잃었다가 EP.48에 8/8을 회복한다.
- 연이는 乙木의 덩굴처럼 감고 잇는 힘을 쓴다. 혼자 버티는 데서 동료와 숨을 나누는 쪽으로 성장한다.
- 모카는 火의 박, 윤달은 土의 봉, 네오는 金의 형, 서한비는 水의 멸에서 단비로 변하는 흐름을 따른다. 루나에게 옛 전투 기술을 배정하지 않는다.
- 제 일간의 기운을 숨으로 돌려 쓰며, 연이는 회수한 기둥의 기운을 담는 그릇 예외다. 힘에는 소모와 대가가 있다.
- 상생은 협력, 상극은 갈등의 근거다. 金克木은 네오의 절제, 傷官見官은 연이의 불이 네오를 다치게 하는 갈등, 관인상생은 물이 두 사람을 이어 주는 해법이다.
- EP.47의 다섯 기운 → EP.48의 乙庚合 → EP.49의 세계수와 윤달의 공망으로 결전이 이어진다. 옛 회차 번호와 기술표를 현행 전투에 덧붙이지 않는다.
- 이 규칙은 작품의 판타지 각색이다. 실제 상담의 점술 체계를 혼합하거나 확정적인 예언으로 설명하지 않는다.

## 집필·유지보수 원칙

- 감정은 신체 감각·사물·대사로 보여 주고, 운세 용어는 첫 등장에 쉬운 한 문장으로 설명한다. 따뜻한 판타지와 일상 코미디의 호흡을 유지한다.
- 연이는 자기 선택을 되찾고, 네오는 혼자 희생하는 방식에서 함께 사는 방식으로 변한다. 서한비는 책임 인정과 피해 반환 없이 용서받지 않는다.
- 이름·우산·양말·메모장·별점·빵의 복선을 유지한다. 현실 귀환과 잔류는 모두 유효한 선택이다.
- 회차 ID, 비트 ID, 순서, 분기, rev는 문구 정리만으로 바꾸지 않는다. 실제 대본과 번역 원문 해시를 함께 수정한 뒤 기존 생성기로 산출한다.
- 폐기 인물명은 본문에 복원하지 않는다. 옛 이름이 포함된 실물 이미지 파일명과 `pje` 등 데이터 키, 별도 연애 시뮬레이션 인물은 전역 치환하지 않는다.
- 검증: `node scripts/merge-novel-authored.mjs --write` → `npm run novel:build` → 관련 동기화 검사와 `npm run check:fast`.
