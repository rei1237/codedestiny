# 콘텐츠 전략

2026-09-08. 새 URL보다 기존 유입 페이지를 우선한다. 명리/점술은 해석 체계로 설명하며 사건·상대 마음·건강을 사실처럼 예측하지 않는다. 전문성 70·분위기 20·세계관 10을 기준으로, 첫 답→근거→조건→내 경우의 확인 순서를 사용한다.

## 브랜드

초융합운세는 현재 서비스가 사용하는 여섯 체계의 관점을 함께 읽는 방식으로 설명한다. 기존 FUSION_FORTUNE_PROFILE와 서비스 SEO 콘텐츠를 정본으로 삼는다. 체계 간 같은 단어를 같은 계산값처럼 다루지 않는다. 일치/충돌한 결과가 무엇인지, 출생시간 누락 때 무엇이 제한되는지 보여주는 편이 근거 없는 정확도 주장보다 가치 있다. `/insights/fusion/`은 방법론, `/fusion-fortune/`는 체험 역할. 홈 첫 안내에 설명을 연결했고 검색 의도와 무관한 브랜드 반복은 하지 않는다.

꿀꿀운세는 꽃돼지 세계관을 통해 CODE DESTINY를 기억하게 하는 기존 브랜드다. 네이버에서 이미 34회 노출·10클릭이 관찰됐다. `/kkul-kkul-unse/`에서 꿀꿀만세력과 현재 서비스로 연결한다. 코드데스티니/CODE DESTINY/CODEDESTINY를 같은 브랜드의 표기 변형으로 다루며 각 표기마다 URL을 만들지 않는다. 주간/띠별 신규 묶음은 콘텐츠 가치와 재방문 데이터가 확보될 때만 검토한다.

## 경쟁 비교의 범위

검색 도구에서 `숙요점 영친/사이트`로 확인한 [cottagegarden](https://cottagegarden.kr/)은 사이트 선택·관계 유형을 한 글에 묶는 구조였다. 이는 실제 Google/Naver 고정 순위 수집이 아니며 상위 순위로 단정하지 않는다. CODE DESTINY는 생년월일 입력→본명숙→관계 설명→사주 비교까지 실제 기능으로 이어지는 점을 활용한다. 원고를 복사하거나 상대 글의 단정적 표현을 가져오지 않는다. 엔진별 모바일 상위 5개 직접 SERP 비교는 남은 조사다.

## 원고 품질과 사실 확인

113개 seed 글의 실제 렌더링 목록을 저장했다. 원문 유지 플래그가 없는 글은 buildMysticSections가 템플릿 본문을 만들 수 있으므로 원본의 존재만으로 고유 콘텐츠라고 판단하지 않는다. 반복 서론/결론은 원문과 렌더링을 비교해 편집한다. 기존 검수 원고의 reviewedAt을 임의 갱신하지 않는다. 유명인 156개를 신규 색인으로 열거나 표면적 키워드 조합 글을 만들지 않는다.
