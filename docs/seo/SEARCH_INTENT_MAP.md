## 대표 역할과 잠식 후보

- `/manse/`: 명식 계산. `/saju/`: 계산된 명식의 풀이. `/insights/saju/`: 설명 탐색. 동일 키워드 반복 대신 다음 단계 링크를 사용한다.
- `/sukuyo/`: 내 본명숙. `/sukuyo/compatibility/`: 두 사람 계산. `/insights/sukuyo/`: 체계별 글 찾기. `/insights/sukuyo-compatibility-guide/`: 결과 읽는 순서. 단어 중복 자체는 잠식의 증거가 아니다.
- `/insights/sukuyo-vs-saju-compatibility/`: 두 체계 비교. 기존 리듬/체크리스트 URL은 가이드로 통합된 이력이 있어 복원하지 않는다.
- `/insights/fusion/`: 초융합 방식 설명·관련 지식. `/fusion-fortune/`: 입력·분석 서비스. 현재 서비스 noindex는 기존 의도이며 이번에 승격하지 않는다.
- `/kkul-kkul-unse/`: 브랜드 이해. `/fortune/` 계열: 시점별 운세. 이미 날짜·띠 쿼리가 있어도 얇은 문서 확장으로 대응하지 않는다.

같은 Query로 두 URL이 번갈아 노출되는 추세와 내용 역할이 겹칠 때 잠식으로 확정한다. 외부 링크/기존 이용 URL 확인 없이 삭제·redirect·noindex를 추가하지 않는다.

## 전략 키워드 전체 의도 분류
