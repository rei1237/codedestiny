# 꿀꿀 운세 → 꿀꿀 사주 개명 — 검색 반영 관측 (2026-10-10)

## 무엇이 바뀌었나

- 한국어 서비스 공식명은 **꿀꿀 사주**이고, 별칭은 꿀꿀사주다. 옛 이름은 꿀꿀 운세·꿀꿀운세이고, 그 전 이름은 꿀꿀 만세력·꿀꿀만세력, 캐릭터로 기억되던 이름은 꽃돼지 운세다.
- 플랫폼·회사 이름은 CODE DESTINY로 바꾸지 않았다. 법적 상호 "코드 데스티니 (Code Destiny)"도 그대로다.
- 사이트 이름 신호를 모두 "꿀꿀 사주"로 맞췄다. 대상은 WebSite.name(`#website`), og:site_name, application-name, manifest, 한국어 title 접미사다.
  - og:site_name과 WebSite.name은 모든 로케일에서 같은 값이다.
  - 외국어 화면의 제목과 UI는 Code Destiny를 유지한다.
- WebSite.alternateName에는 실제로 쓰였거나 쓰는 이름만 넣었다: 꿀꿀사주, 꿀꿀 운세, 꿀꿀운세, Ggulggul Fortune, CODE DESTINY, CodeDestiny, 코드데스티니, 코드 데스티니. 사주·궁합 같은 일반 검색어는 넣지 않는다.
- `@id`(`#website`, `#organization`)는 그대로다. Organization은 WebSite와 따로 둔다.
- 경로는 바꾸지 않았다(`/ggulggul/`, `/kkul-kkul-unse/` 포함). DB·쿠키·로컬스토리지 키, 상품·주문 ID, 이벤트명, 앱 패키지명, API 경로도 그대로다.

### /kkul-kkul-unse/ 브랜드 전환 안내

- 경로는 유지했다(삭제·리다이렉트하지 않음). canonical과 JSON-LD url을 끝 슬래시로 맞췄다.
- H1은 "꿀꿀 운세는 이제 꿀꿀 사주예요"이고, 첫 문장은 "꿀꿀 사주는 기존 꿀꿀 운세의 새 이름입니다. CODE DESTINY에서 제공하던 사주·타로·궁합과 영냥이·연이 상담을 같은 서비스에서 이용할 수 있습니다."이다.
- 화면 FAQ와 FAQPage JSON-LD는 같은 목록에서 만든다. 앞의 네 문항이 개명 안내다.
- 계정·구매 내역·보관함을 그대로 이용할 수 있다는 답은, 이번 변경이 로그인·보관함 경로와 저장 키를 건드리지 않았고 스테이징에서 `/records/`·`/yeongnyangi/library/` 응답을 확인한 뒤에 유지했다.

## 운영자 수동 작업

### Google Search Console (`https://code-destiny.com/` 속성)

1. Sitemaps에서 `https://code-destiny.com/sitemap-index.xml`을 다시 제출한다.
2. URL 검사에서 아래 다섯 URL을 하나씩 검사하고, "실제 URL 테스트"로 새 title이 보이는지 확인한 뒤 "색인 생성 요청"을 누른다. 할당량이 있으므로 이 다섯 개만 요청한다.
   - https://code-destiny.com/ggulggul/
   - https://code-destiny.com/kkul-kkul-unse/
   - https://code-destiny.com/yeongnyangi/
   - https://code-destiny.com/saju/basic/
   - https://code-destiny.com/manse/
3. Google 사이트 이름은 WebSite 구조화 데이터와 og:site_name을 근거로 자동으로 정해진다. 별도로 입력하는 곳은 없다. 반영에는 수 주가 걸릴 수 있다.

### 네이버 서치어드바이저

1. 요청 → 사이트맵 제출에서 `https://code-destiny.com/sitemap-index.xml`을 다시 제출한다.
2. 요청 → 웹 페이지 수집에서 위 다섯 URL을 요청한다.
3. 설정 → 사이트 정보에 사이트 이름 항목이 있으면 "꿀꿀 사주", 설명은 "꿀꿀 사주에서 사주풀이와 궁합, 타로, 자미두수, 숙요점을 만나보세요."로 맞춘다. 항목이 없으면 건너뛴다.

### 그 밖의 외부 명칭 (코드 변경과 별개)

- 카카오 채널명 "꿀꿀 운세" → "꿀꿀 사주": 파트너센터에서 바꾼다. 바꾼 뒤 `lib/marketing/kakao-crm.mjs`의 `name`과 동의 문구, 동의 문구 버전을 함께 고친다.
- PG 가맹점명·결제창 표시명: PG 계약 변경 사항이다. 이번 코드 변경에 포함하지 않았다.
- Google Play 등록정보: 앱 표시명은 코드(`strings.xml`, `capacitor.config.ts`)만 "꿀꿀 사주"로 바꿨다. 스토어 제목·설명은 다음 심사 제출 때 아래 초안으로 바꾼다.
  - 짧은 설명 초안: "꿀꿀 사주 — 사주·궁합·타로와 영냥이·연이 상담"
  - 전체 설명 첫 문장 초안: "꿀꿀 사주(옛 꿀꿀 운세)는 CODE DESTINY가 만든 사주·운세 상담 앱입니다."
- 네이버 블로그 이름, Threads 프로필 이름·소개: 각 서비스에서 바꾼다. SNS 게시물을 발행하는 일은 이번 작업에 포함하지 않았다.
- 카카오 공유 미리보기: OG 카드 파일명은 고정이고 `?v=` 값만 `42dedf5c85` → `aa88d371b4`로 바꿨다. 이미 공유된 링크는 카카오 디버거에서 캐시를 초기화해야 바로 바뀐다(`docs/handoff/og-share-cache-refresh-2026-10-03.md` 절차).
