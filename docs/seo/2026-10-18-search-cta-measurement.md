# 검색 유입과 서비스 CTA 측정 계약

현재 변경의 운영 반영일: **미확인**. 소스·mock 통과는 운영 이벤트 수집 완료를 뜻하지 않는다. 과거 누락된 클릭을 신규 코드가 복구하지는 못한다.

## 지표를 분리해서 읽기

- 검색 CTR: 네이버 서치어드바이저 또는 GSC의 클릭 ÷ 노출. 같은 검색엔진·완료된 기간·기기·검색어군·URL 기준으로 비교한다. 전체 CTR만 보고 제목 효과로 단정하지 않는다.
- 서비스 CTA율: GA4의 같은 organic landing 세션 중 주 CTA를 한 번 이상 클릭한 세션 ÷ 해당 랜딩 세션. 이벤트 횟수를 세션 수로 나누지 않는다. 반복 클릭은 분자에서 세션당 한 번으로 센다.
- 유입 분류: 기존 GA4 세션 source/medium 또는 Organic Search 채널을 사용하고 Google·Naver를 분리한다. 사이트 내부 링크에 UTM을 추가하지 않는다.
- 오늘 일부가 섞인 기간은 비교하지 않는다. 완료된 7일을 동일 요일의 직전 7일과, 완료된 28일을 직전 28일과 비교한다. 검색 도구가 30일을 제공하면 그대로 30일로 기록하고 28일 수치라고 부르지 않는다.
- 세션/동의/차단/태그 로드 전 이탈의 한계가 있는 GA4 수치와 서버 전체 매출을 같은 분모로 결합하지 않는다. 실제 결제·결과 완료 정본은 기존 서버 원장을 유지한다.

## 기존 이벤트 확장

`page_view`와 기존 `cross_sell_click`을 재사용한다. 새 SDK·유입 이벤트·별도 수집 API를 추가하지 않는다.

| 필드 | 허용값/의미 |
|---|---|
| `from_service` | 공개 허브의 정규 경로. 쿼리/fragment 없음 |
| `to_service` | 실제 링크 목적지의 공개 경로. 쿼리/fragment 없음 |
| `placement` | `primary`, `related`, `directory`, `next_step` |
| `target_service` | 사전 정의한 공개 서비스 키. 여러 도구가 `/ggulggul/?action=...`로 들어가는 경우 구분 |

마크업 계약은 `data-cd-cross-sell`, `data-cd-cta-placement`, `data-cd-target-service`다. 새 분류가 붙은 링크는 source/target 경로와 서비스/배치 enum을 모두 검사한다. 값이 누락되거나 허용 목록 밖이면 해당 클릭을 보내지 않는다. 이름·생년월일·개인 질문·결과 ID·인증값·검색어 원문을 전송하지 않는다. 기존 분류 없는 크로스셀 계약은 유지한다.

동의 초기화·변경·태그 로드 시점은 기존 `js/core/analytics.js`가 맡는다. `essential` 또는 동의 전에는 기존 `analytics_storage=denied` 동작을 유지하며 신규 저장소나 식별자를 만들지 않는다. 기존 스크립트가 두 번 로드되어도 리스너는 하나만 설치된다.

## 검증과 기준선

`npm run verify:analytics-events`는 jsdom에서 실제 위임 리스너를 실행하고 dataLayer를 확인한다. 외부 GA 전송은 없다. 다음을 검증한다: 동의 3상태, 주 CTA 단일 발화, 보조 배치 구분, 실제 홈/서비스/관련 링크 카탈로그의 허용 목록 누락, 4기간×24띠·별자리의 공개 결과 경로, 민감 쿼리 제거, 외부·개인 결과 링크 차단.

날짜 결과의 품질 검사는 수집 이벤트와 분리했다. `verify:fortune-period-axis -- --dist=out`과 기존 AdSense postbuild 게이트는 96개 생성 HTML의 title 날짜·H1 기간·가시 time 날짜·Article 날짜가 실제 렌더러 기준과 일치하는지 검사한다. 오늘/내일은 `fortune/data/run-manifest.json`을 먼저 읽고, 기존 주간/월간 렌더러는 KST 현재 시계를 사용하므로 그 기준을 한 번 고정한다. 배포 워크플로의 `RUN_DATE_KST`나 데이터 생성기의 `FORTUNE_DATE`를 렌더러가 지원하는 날짜 override로 오인하지 않는다. 정상·제목만 낡음·본문만 낡음·스키마/H1 불일치·월말/연말·자정 후 manifest 유지·부분 manifest 거부 fixture가 있으며 날짜 계산·운세 산출 코드는 변경하지 않았다.

현재/이전 네이버·GSC 실측과 운영 반영 시각은 별도 SEO 기준선 기록을 따른다. 미조회 수치를 0으로 채우지 않는다. D+7 기술 이상 점검, D+14/D+28 동일 조건 관측으로 변화와 불확실성을 함께 기록한다. 여러 메타·본문·동선을 함께 변경했으므로 결과를 제목 한 요소의 효과로 해석하지 않는다.
