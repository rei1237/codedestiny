## 측정 계약과 후속 비교

- 검색 CTR: 동일 검색엔진·기간·검색어군·정규 페이지·기기의 클릭/노출. UI 평균 CTR과 합산 CTR을 섞지 않는다.
- 주 CTA 전환율: 오가닉 랜딩 세션 중 `cross_sell_click`의 `placement=primary`가 있는 고유 세션/해당 오가닉 랜딩 세션. 클릭 이벤트 수를 세션 수로 나누지 않는다.
- 관련 링크(`related`), 분야 탐색(`directory`), 결과 후 이동(`next_step`)은 주 CTA와 별도 집계한다. 실제 시작은 기존 서비스 시작 이벤트로 따로 비교한다.
- 추가 속성은 허용된 공개 경로·서비스 키·위치 enum만 사용한다. 이름·생년월일·질문·개인결과·query/hash는 보내지 않는다. 기존 동의 상태를 유지한다.
- 운영 반영 시 full SHA·KST 시각·페이지군·계측 버전을 기록하고 D+7·14·28에 같은 요일 구성으로 전기와 비교한다. 이번에는 제목·본문·화면을 함께 바꾸므로 제목 하나의 효과로 귀속하지 않는다.
- 현재 CTA 기준선은 계측 공백으로 미확인이다. 검색 클릭과 분석 세션은 정의·동의·차단 차이로 일치하지 않을 수 있다.
- 실사용 CWV 목표: LCP≤2.5초, INP≤200ms, CLS≤0.1. 개발 모드·실험실 자료는 실제 사용자 p75 성과와 구분한다.
