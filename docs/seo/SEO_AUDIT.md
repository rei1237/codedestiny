## 번역 가설과 P0 조치

운영 `/ja/` 브라우저에 한국어 첫 화면·설명이 남아 있었다. 그러나 운영 배포 SHA와 현행 main 차이를 제거한 인과 검증은 아직 아니다. 최근 main에는 언어별 정적 셸 번역이 이미 추가되었고, 새 홈 funnel에는 번역 마커가 없었다. 그 누락을 교정했다.

- 첫 화면 핵심 안내 8개 키를 기존 지원 언어 12개 사전에 추가하고 영어·일본어·간체·번체 정적 HTML로 반영한다. 누락 키는 빌드 실패로 회귀를 잡는다. 모든 모달과 모든 콘텐츠의 번역 완료를 의미하지 않는다.
- 앱 갱신 직후 자체 reload guard와 일치하는 `v`만 주소 표시에서 제거한다. 캐시 버전 요청·자산 버전·action·결제 재개 파라미터·hash·history state는 보존한다. canonical은 이미 안정 URL이다. 과거 URL의 즉각적인 색인 제거는 보장하지 않는다.
- 기존 hreflang helper는 실제 canonical 생성기를 사용하고 미존재 대응 페이지를 제외한다. 번역 페이지 전체를 한국어 canonical로 합치거나 일괄 noindex하지 않는다.
- 운영/스테이징 일반 HTTP 요청은 403. 브라우저 운영 접근은 가능하다. 이를 Googlebot 차단으로 단정하지 않는다. WAF 정책을 임의 변경하지 않았다.

Google은 페이지 언어 판단에 실제 콘텐츠를 사용하며 hreflang만으로 본문 번역을 대신할 수 없다. [다국어 공식 지침](https://developers.google.com/search/docs/specialty/international/localized-versions). 중복 URL은 canonical과 내부링크 신호를 일치시킨다. [canonical 공식 지침](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

## 구현·유지 경계

[빌드 HTML 전수 목록](PAGE_INVENTORY.md)은 777개 index.html의 title·H1·canonical·meta robots·hreflang·JSON-LD·alt를 대조한다. React의 S:* 스트리밍 컨테이너 안에 전달된 H1과 실제 hidden UI를 구분한다. JS 비활성 상태에서 React 스트리밍 영역이 아직 숨겨진 점은 일반 정적 셸과 다르며, 원본 HTML이 비어 있다는 뜻은 아니다.

홈 디자인/캐릭터/입력 UI 유지. 핵심 안내만 초융합운세의 여섯 관점과 오늘 운세로 정리했다. 숙요점 랜딩은 개인 본명숙, 궁합 서비스는 두 사람, 가이드는 해석 방법으로 구분했다. `/insights/fusion/`은 방법론 설명, `/fusion-fortune/`는 기존 서비스 및 noindex 정책 유지. 꿀꿀운세에서 만세력 명칭을 명확히 연결했다.

신규 콘텐츠 URL, 색인 정책, 가격, 이용권, 월정석, 단건 결제, 공개 API, DB 변경 없음. 검증 결과는 VALIDATION.md에 기록한다. 운영 배포/URL 검사/필드 CWV는 PR 이후 별도 단계다.

## 성과 측정

배포일 D와 SHA를 기록한 뒤 D+7/28/90에서 같은 길이 이전 기간과 비교한다. 전체·비브랜드·기기·국가·URL 언어를 분리한다. 브랜드 정규식은 코드데스티니/CODE[ -]?DESTINY/초융합/꿀꿀/꽃돼지. 국가를 언어로 사용하지 않는다.

같은 Query–Page 쌍의 클릭·노출·CTR·순위를 보존한다. Top10 검색어 수는 최소 노출 기준(예: 5회) 적용/미적용을 같이 보고한다. 가치 있는 페이지 색인 수, Crawled not indexed, 기존 analytics의 organic landing→service→conversion도 추적한다. 동의·세션·표본 누락을 명시한다. 기존 analytics 이벤트를 재사용하고 수집 로직은 이번에 변경하지 않았다. CWV 필드 데이터는 Google 보고서에 부족하여 INP/LCP/CLS 개선 수치를 주장하지 않는다.
