### 기준선과 비교 조건

2026-10-04에 확보한 네이버 최근 30일 검색어 표에서 ‘내일운세’는 노출 14,509회·클릭 23회·표시 CTR 0.2%였다. 이는 검색어 전체 수치이며 이 허브의 CTR이나 시장 검색량이 아니다. 검색어 표와 페이지 표를 임의로 결합하지 않는다.

운영 배포 시 D0·배포 SHA와 실제 제목을 기록하고, GSC/Bing/네이버에서 해당 URL의 변경 전 28일 데이터를 확보한다. 가능한 경우 쿼리·기기·국가와 순위 구간을 맞춘다. 데이터가 없으면 수치를 비워 두고 성공 판정을 보류한다.

D0 이후 완결된 14일과 그 직전 동일 요일 구성 14일을 비교한다. 최근 2~3일 집계 지연을 제외하므로 첫 판정은 D0+17일 이후에 수행한다. 노출·클릭·CTR·순위 및 시즌성, 다른 배포를 함께 기록한다. CTR 악화만으로 자동 롤백하지 않고 순위·유입 구성 변화를 먼저 확인한다.

기존 10월 18일 점검은 중간 점검이다. 실제 D0로부터 14일이 지나지 않았다면 최종 효과를 판정하지 않는다.

### 로컬 검증 (운영 성과 아님)

- mock 네트워크 차단 환경에서 일일 데이터를 생성한 뒤 Next.js 개발 서버를 curl로 조회했다. 허브 4개와 상세 2개 모두 정상 응답, H1은 각각 1개였다.
- `/fortune/tomorrow/`: `내일 운세 10월 8일 | 나의 띠·별자리 운세는?` 확인.
- 범띠·처녀자리 상세의 한국어 비교 설명을 확인했고 번체 폴백 문장은 없었다.
- 기존 상세 제목·다국어 테스트 10개 통과. 새 허브 제목의 월일 조합 최대 폭은 저장소 휴리스틱 기준 44/60이다. 실제 검색 결과의 잘림 여부와 동일한 측정은 아니다.
- 사이트맵은 공유 페이지의 한국어 허브 4개 소스 지문만 갱신했다. 내용이 바뀐 내일 허브만 변경일을 기록했다. 날짜 경과만으로 생기는 다른 경로의 갱신은 이번 커밋에서 제외한다.
- 개발 서버는 기존 동기식 Next.js params 접근 경고를 출력했다. 이번 제목 변경과 무관한 기존 라우팅 코드는 수정하지 않았다.
