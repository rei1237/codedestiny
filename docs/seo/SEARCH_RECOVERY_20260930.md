# Google 노출 진단과 검색 의도 개선

2026-09-30 최종 상태: SEO 수정 `5e730cbba` 운영 승격 완료. Pages·Worker SHA 일치, 공개 URL 11개·스타일시트 56개·운영 브라우저 검사 통과. Google·네이버 대표 URL 4개씩 재수집 요청 접수 완료. 실제 색인 갱신과 검색 실적 변화는 후속 측정 대상이다.

## 판정

Google 노출 부족은 실제다. 다만 사이트 전체가 차단되거나 천원 상담 페이지가 미색인인 상태는 아니다. **확인된 병목은 많은 URL의 미수집·미색인과, 색인된 주요 페이지의 작은 노출량**이다. 이를 모두 한 가지 코드 결함 탓으로 확정할 근거는 없다.

이번 수정은 대표 홈의 검색 의도·내부 링크, 새 홈 이동 회귀 위험, 정적 셸의 URL 신호 불일치, 무료 범위 오표시를 바로잡는다. 코드 변경으로 순위·트래픽 증가를 보장하지 않는다. 신규 키워드별 페이지 증설·일괄 noindex·검색엔진별 다른 콘텐츠 제공은 하지 않는다.

## 운영 HTTP 실측과 코드의 차이

[원본 요약 JSON](SEARCH_RECOVERY_LIVE_20260930.json)에 응답 시각과 경로별 HTTP·메타·사이트맵 신호를 보존했다. 주요 6개(`/`, `/ggulggul/`, `/today/`, `/saju/`, `/sukuyo/`, 천원 허브)는 HTTP 200, self-canonical, index/follow이며 sitemap에 포함됐다. 대표 sitemap 1,300개, 한국어 sitemap 803개. 이 표본에서 전면 robots 차단·noindex·챌린지는 관측되지 않았다.

Pages·Worker 운영 SHA는 모두 `d8b2fa284798a592d60f59b297b1ad5ac98b4d0e`. 조사 시작 코드 `dd8788d3f3c50a8251e2e3475af6e9f335cfc179`와 다르다. 운영 홈은 영냥이 화면이고, 현재 코드 홈은 사주 달빛정원 안내다. **코드에서 발견한 `/ → /ggulggul/` 자동 이동은 운영의 과거 부진 원인으로 단정할 수 없다.** Googlebot UA를 흉내 낸 일반 요청 성공도 Google이 검증한 봇의 실제 접근 성공과 구분한다.

대표 4개(`/`, `/saju/`, `/today/`, 천원 허브)는 운영 초기 HTML에 본문·링크·JSON-LD가 포함되며 일반 Chrome 렌더 후에도 요청 URL·title·canonical·robots가 유지됐다. 사주 FAQ 5개, 오늘 7개, 천원 10개의 질문·답은 렌더 DOM 본문과 일치했다(접힌 details 포함). 이는 일반 브라우저 표본 검증이며 Googlebot 렌더 또는 모바일 전수 검사로 확대하지 않는다.

## 운영 후 확인 계획

1. main에 통합한 정확한 SHA의 `CI required` 성공까지 전달한다. 운영 승격은 저장소 계약에 따른 별도 1회 승인이다.
2. 승인된 운영 릴리스 후 주요 6페이지의 HTML·최종 URL·canonical을 다시 확인한다. GSC 저장 색인과 실제 URL 테스트 결과를 각각 기록한다.
3. 변경된 대표 URL만 Google 재색인·네이버 수집을 요청한다. 이미 색인된 URL을 반복 제출하지 않는다. sitemap 제출만으로 색인·순위가 보장되지는 않는다.
4. 반영일 D를 기준으로 D+7에는 크롤링·색인·선택 canonical을, D+28에는 같은 길이의 전후 기간 클릭·노출·CTR·query/page를 비교한다. 검색어를 브랜드/무료/천원/체계별로 구분한다. 확인 가능한 organic 서비스 이동 이벤트도 함께 본다.
5. 발견됨 미색인 전체 URL과 현재 sitemap의 교집합을 CSV로 확보하여 번역·반복 페이지의 실제 수요를 평가한다. 100개 표본만으로 삭제·noindex하지 않는다. 기존 콘텐츠를 개선하고 새 URL 증설은 관측 결과를 본 뒤 결정한다.
6. 기존 네이버 블로그 등 공식 채널의 관련 원문에서 해당 서비스·방법론·천원 상담 예시로 연결할 수 있는 문맥을 검토한다. 무차별 링크 구매·댓글 홍보·허위 후기 없이 실제 유용한 내용과 출처를 늘린다. 외부 게시 행위는 이번 작업에서 수행하지 않는다.

## 유지 영역과 검증
