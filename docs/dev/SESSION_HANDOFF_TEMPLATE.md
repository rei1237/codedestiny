## 다음 세션 시작 프롬프트

아래 문장을 그대로 새 세션에 붙여넣을 수 있게, 이 세션의 실제 handoff 경로와 첫 TODO를 채운다.

```text
이전 세션의 인수인계 문서를 먼저 읽고 이어서 작업해줘.

반드시 먼저 확인할 것:
1. docs/handoff/<현재 작업 handoff>.md
2. docs/dev/SESSION_WORKFLOW.md
3. git status
4. 현재 브랜치와 origin/main 차이
5. 직전 세션의 미완료 TODO

절대 원칙:
- main 직접 push 금지
- 결제/권한/월정석/이용권 로직은 최소 변경
- LLM 실제 호출 금지, mock 테스트만 허용
- production deploy, secret 변경, 결제 실테스트는 사용자 승인 전 금지

인수인계 문서의 “다음 세션에서 바로 할 일”부터 진행하고, 작업 종료 전 반드시 handoff 문서를 업데이트해줘.
```
