# 영냥이 읽기 계약 v5

신규 일반 상담 28개 상품은 `destiny-book-v5`를 사용한다. 가격·상품 구성·챕터 수는
변경하지 않는다. 기존 구매 스냅샷과 신점/질문 순간 상담은 v4 계약을 유지한다.

## 분량과 생성

| 등급 | 본문 목표 | 최소 |
|---|---:|---:|
| 고등어 | 3,200–4,000 | 3,000 |
| 연어 | 7,000–9,000 | 6,000 |
| 광어 | 13,000–17,000 | 11,000 |
| 참치 | 36,000–44,000 | 32,000 |
| 모둠 | 55,000–65,000 | 48,000 |
| 오마카세 | 90,000–110,000 | 80,000 |

`reading-policy.ts`의 버전별 정책 → `reading-manifest.ts`의 챕터 가중치 →
`reading-sections.ts`의 소절별 배분 → `reading-quality.ts`의 검증이 연결된다.
일반 챕터는 해석/사례/실행 60/20/20%, 실행 챕터는 25/25/50%다.
소절별 올림 오차로 합산 목표가 표보다 소폭 높을 수 있다.

v5 본문은 `blocks`에만 저장한다. `analysis=[]`, `example=''`, `advice=''`이며
각 block에는 `id`, 자연어 `title`, `paragraphs`, 사용한 `sources`가 있다.
제목·요약·질문 답변은 분량에 산입하지 않는다. 소절 ID/순서/최소량/출처,
500자 문단 상한, 중복·전문 범위·주장·시기 검증을 거친다.
복합 상담은 근거가 제공된 각 체계의 출처를 evidence 소절에 포함한다.
광어 이상은 제공된 근거가 충분하면 최소 두 근거를 연결한다.

출력 예산은 기존 한국어 토큰 계산기로 본문·질문별 답변·JSON 여유를 계산한다.
v5 한 챕터 상한은 24,576토큰이며 초과 시 공급자를 호출하지 않는다.
실제 공급자의 잘림 응답은 기존 검증에서 거부한다. 재시도 횟수·결제·저장 후
재조회 및 완료 규칙은 기존 구현 그대로다. 실문장 품질·비용·지연은 mock 결과로
입증되지 않으며 별도 승인된 실호출 평가가 필요하다.

## 기존 엔진과 보완한 연결

| 운세 | 재사용 엔진 | 보완 |
|---|---|---|
| 사주 | saju/runtime, life-book-ai-saju | 월령·오행의 양면·합충·시기 근거의 연결 지시 |
| 자미두수 | ziwei-ai-chart | 부부궁·노복궁 정본 명칭으로 신호 누락 수정 |
| 숙요 | sukuyo-astronomy, sukuyo-relation-core | 개인/궁합 구분·양방향 역할·실천 대화 |
| 베다 | vedic-ai-chart | 라그나·행성·달 및 다샤의 조건과 한계 |
| 서양 점성술 | swiss-ephemeris | 황경·하우스·각·오브 표시, 미계산 트랜짓 창작 금지 |
| 타로 | tarot-interpretation-engine | 저장된 카드·정역·자리 연결, 대안과 관찰 신호 |

LLM이 계산을 대체하지 않는다. 계산 엔진을 복제하거나 운영 데이터에 새 계산을 쓰지 않는다.

## 결과 화면과 호환

기존 `ChartView`를 확장한 `ReadingChart`는 구매 당시 스냅샷에서 명시적 필드만
투영한다. 원본 출생정보·내부 프롬프트는 응답에 포함하지 않는다. 계산된 시기는
구매 등급의 근거 선택기를 통과한 값만 표시한다. 미결제·환불·별도 질문형에는
일반 차트를 노출하지 않는다. 과거 기록에 차트가 없으면 텍스트 결과를 유지한다.

모바일 접이식 목차, 데스크톱 옆 목차, 결과 ID별 선택적 기기 읽기 위치,
차트 선택과 관련 장 이동을 제공한다. 7종 신규 일러스트의 정본은
`public/assets/yeongnyangi/readings/README.md`에 기록한다.

## 검증

- `node --test __tests__/ui/yeongnyangi-reading-v5.test.mjs`: 분량·소절 실패·출처·이전 버전·토큰·개인정보.
- `node scripts/verify-yeongnyangi-engines.mjs`: 6개 실제 로컬 계산과 28개 상품의 전체 챕터 mock 검증.
- `node scripts/verify-yeongnyangi-reading-v5-ui.mjs`: mock 개발 서버에서 360/390/430/1280px, 7개 대표 상품 읽기·차트·입력·위치 복원.
- 기존 영냥이 질문형·결제·저장·복구 테스트와 변경 검사, 최종 main GitHub CI.

브라우저 스크립트는 기본 `http://127.0.0.1:18122`를 사용하며 외부 요청을 차단한다.
결과와 캡처는 `build-cache/yeongnyangi-v5/`에 저장하며 버전 관리에 넣지 않는다.

타로의 실제 카드 이미지는 연이의 운명 찻집 src/features/fortune-tea-house/lib/tarotCardImageMap.ts 정본을 재사용한다. 저장된 카드 ID·배열·정역방향은 유지하며, 알 수 없는 카드를 임의의 이미지로 대체하지 않는다. 78장 전체 대응은 v5 회귀 검사에서 확인한다.
