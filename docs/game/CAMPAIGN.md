# 사주의 강에서 비겁의 섬까지

게임의 첫 장은 원작 EP.02 마지막의 본체 인증 대기에서 끝난다. 비겁의 섬 전체를 클리어했다는 표시를 쓰지 않는다. 편집 원본은 `content/novel/episodes.source.json`이다. 게임 대사·선택·소규모 전투·의뢰는 모두 별도 게임 각색이다. 모카, 윤달, 루나, 서한비의 소환과 본편 합류는 독립적으로 처리한다.

## 저장과 의뢰

계정별 개발 IndexedDB 트랜잭션으로 읽은 노드, 선택, 현재 장면, 챕터 완료, 의뢰 완료 횟수, 인연과 전투 영수증을 저장한다. 서고와 로그는 읽기 전용이며 자동 읽기는 선택·전투·챕터 종료에서 멈춘다. 모르는 노드나 콘텐츠 버전은 마지막 완료 챕터 경계로 돌아간다. 초상·화자 말투는 연이의 변신 전후 및 고양이 영냥이의 공개 시점에 맞춘다. 변신 후 대화는 원작의 꽃돼지 중립·발화·결의·슬픔 원화를 쓴다.

첫 수업 → 예장 수업 → 영냥이 교류 → 스킬 수업과 선착장 등불 이벤트가 열린다. 보스 도전은 예장 수업 다음에 열리고, 성장 수업 보상은 강화 화면에서 쓸 수 있다. 의뢰별 전투, 선행 조건과 첫/반복 조각은 `campaignQuests`에 정의한다. 등불 행사는 게임용 상시 각색이므로 종료 시각을 표시하지 않는다. 스킬 수업 첫 승리는 모카 기본 버전 첫 스킬을 최소 레벨 2로 올린다. 완료 이력은 전투 수첩에서 결말과 함께 다시 읽을 수 있다.

운영 보상·월정석·공통 계정 XP와의 연동은 없다. 검증은 기기별 개발 저장을 대상으로 하며 기기 간 책갈피 동기화는 별도 서버 작업이다.
