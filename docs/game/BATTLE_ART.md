## 파일과 재생

전투 시트는 `public/images/card-rpg/battle/<외형 키>.webp`다. 각 1280×640 투명 WebP 한 장에 320×320 셀 8개를 담는다. 왼쪽 위부터 대기·퀵·아츠·버스터·피격·쓰러짐·승리·스킬 순서다. 투명 여백과 같은 행의 발 위치를 맞췄다. 등장과 대기를 같은 포즈에서 시작하고 약한 피격과 강한 피격은 반동 거리·각도와 타격광 크기를 구분한다. 운명해방은 해당 버전의 궁극기 유형 포즈에 전용 빛과 컷인을 합성한다. 대기 미세 움직임, 루나의 도약, 모카의 두 박자, 서한비의 우산 회전은 CSS에서 다룬다. 이미지 디코딩 실패 시 캐릭터가 사라진 자리에 원화 누락이 표시된다.

`BattleActor.tsx`의 손 위치·궤적 각도와 캐릭터별 문양이 소품의 궤적을 조정한다. 실제 타격 수만큼 궤적을 엇갈려 재생한다. 궤적 애니메이션은 별도 판정 콜백을 호출하지 않는다. 일반·2배·간소 설정은 셋 모두 같은 전투 이벤트에서 시작한다. 추가 의상은 기본 음성 설정을 상속한다. 성우 녹음은 없다.

여섯 기본 버전의 소환 앞면과 도감 카드는 `CharacterCard.tsx`에서 `public/images/card-rpg/<원작 인물 키>-moonlit-card.webp`로 연결한다. 각 원화는 700×1050이다. 달빛 찻상의 연이, 작전판을 읽는 영냥이, 운세를 풀이하는 윤달, 빗길의 서한비, 랩과 요리를 하는 모카, 꽃빵을 배달하는 루나를 그렸다. 이 그림들은 게임 각색 장면이다. 의상 카드, 편성 초상, 전투 컷인은 전투 버전 및 선택 의상의 `costumeArt`에서 읽는다. 연이의 전투 운명해방 컷인은 꽃돼지 시점의 `remaster/v2/yeoni/vine-magic.webp`다. 새 순수 의상 3점과 새 전투 버전의 초상은 `public/images/card-rpg/wardrobe/<키>.webp`, 모카의 축제 앞치마는 이전 단계의 `moka-festival.webp`를 쓴다. 대사 시트는 추가 외형 다섯 개 각각 `wardrobe/<키>-dialogue.webp`이며 한 장에 320×384 셀 4개를 담는다. 시선과 옷을 고정하고 입을 닫은 상태·살짝 연 상태·발화 상태만 전환한다. 로비의 대표 전투 버전과 현재 계정 소유 의상, 개인 이야기에서 선택한 소유 동료를 조회한다. 원작 프롤로그의 복장은 해당 장면 기준이다.

## 제작·검증

원작 몸체·소품 기준은 소설의 yeoni, yun, pje, yeongnyangi, moka, ln 원화와 기존 축제 앞치마를 직접 대조했다. 내장 imagegen으로 원작 레퍼런스에 맞춘 전신, 손과 소품이 이동하는 8개 포즈, 추가 콘셉트와 대화용 입모양을 제작했다. 생성 지시의 핵심은 투명 배경·같은 옷과 얼굴·화면 오른쪽을 향한 동작·발이 보이는 전신·시트 전체 동일 축척이다. 원화의 연결된 인물 실루엣을 잘라 정렬하고 WebP로 패킹했다. 경량화를 위해 출전한 동료의 시트만 불러온다.

- `node scripts/verify-card-rpg-art.cjs`로 11가지 외형의 88포즈와 5개 대사 시트 셀을 디코딩하고 121가지 외형·동작 조합을 검사한다. 기본 소장 카드 6장도 디코딩하고 추가 외형 5개의 소장 카드 경로를 검사한다.
- `--browser`를 더하면 격리 Chromium에 같은 컴포넌트와 CSS를 올려 실제 CSS 애니메이션 실행, 이미지 디코딩, 모션 줄이기 정지 상태를 검사한다. 기본 속도에서 아츠·쓰러짐·승리 장면과 소장 카드 6장 도판의 캡처는 `RPG_CAPTURE_DIR`로 지정한다. 실기기 GPU 속도·프레임율은 별도 검증 대상이다.
