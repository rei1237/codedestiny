# 달빛 카드 전투 개발 밸런스

## 수련 수치와 보호

게임 전용 훈련 조각은 첫 수업에서 12개를 얻고, 선착장의 물결로 2개씩 다시 얻는다. 수련은 브라우저의 계정별 IndexedDB에 대상·요청 ID·미리보기 상태를 연결해 재검증하고 한 번에 기록한다. 3단계 데이터에 신규 속성이 없으면 수련 레벨 1, 각성·돌파·추가 의상 미해금으로 읽는다.

|과정|조건과 비용|실제 변화|
|---|---|---|
|동료 훈련|연잎의 첫 수업, 조각 2+현재 레벨|레벨 +1, 캐릭터 XP +100. Lv.1 기준 레벨마다 HP +8%, 공격 +4%를 각각 정수 반올림|
|각성|동료 Lv.5, 조각 10|레벨 상한 5 → 10, 전투 버전 유지|
|스킬 수련|한 박자 먼저 의뢰, 조각 3+현재 스킬 레벨|각 스킬 별도 Lv.1~5. 일반 효과 +10%/레벨. 지연 스킬은 자신 게이지 +2/레벨, Lv.3에 쿨다운 1턴 단축|
|운명해방 수련|같은 의뢰, 조각 5+현재 해방 레벨|독립 Lv.1~5, 계수 2.60~3.32|
|예장 강화|첫 수업, 조각 2+현재 예장 레벨|HP·공격 보정마다 Lv.1 기준 +15%/레벨, 정수 반올림|
|한계 돌파|자명종이 울릴 때 의뢰, 예장 현재 상한 도달|최대 2회. 조각 9개 또는 조각 4개와 선택 예장 1개. 상한 Lv.3 → 5 → 7. 매 돌파 방어·게이지 효과와 상한 +2, 회복 +10|
|의상 제작|첫 수업·해당 기본 전투 버전 소유·조각 6개|윤달 여행복, 서한비 비옷, 루나 축제복. 제작 후 동료 상세에서 선택. 모카의 축제 앞치마는 기존 소유 접근 유지|
|무대 모카 영입|한 박자 먼저 의뢰·기본 모카 보유·조각 12개|별도 소유 카드, Q/Q/A/A/B 지원 전투 버전. 기본 버전 Q/Q/A/B/B보다 체력·공격이 낮고 전열 게이지 및 아츠 지원에 특화|

모든 저장 편성에서 장착 여부를 확인하며 잠금·즐겨찾기·장착 상태 또는 강화 대상 자신은 돌파 재료 선택에서 제외한다. 확인 뒤 상태 변경도 같은 거래 안에서 거절한다. 보호한 예장 자체의 레벨 수련은 가능하다. 아이템 대신 조각만 쓰는 경로로 중복 획득 없이 돌파할 수 있다. 개발 컬렉션 조각과 캐릭터 XP는 기존 월정석 및 공통 계정 XP와 별개다.

수련 검사는 `node --test scripts/verify-card-rpg-growth.cjs`로 재현한다. 예장을 장착한 모카의 Lv.1→2는 HP 1000→1080, 공격 270→280으로 확인했다. 같은 시드와 같은 카드로 실제 피해가 증가했다. 두 브라우저 탭이 오래된 미리보기로 동일 동료를 수련했을 때 두 번째 저장은 거절됐고 보호 설정은 새로고침 뒤에도 복원됐다. 이 화면 검사는 독립 브라우저 컨텍스트에 첫 수업 완료 상태를 심은 `node scripts/verify-card-rpg-growth-ui.cjs`로 재현한다.

## 전투 실측

규칙 v1의 첫 실험. `node --test scripts/verify-card-rpg-battle.cjs`가 시드 1~12, 편성 3개, 전투 2개, 카드 우선순위 3개로 216전을 실행한다. 스킬이 열리면 사용하되 체력이 모두 찼을 때 회복, 차지가 0인 적에게 지연은 생략한다. 해방 우선 → 지정 카드 유형 우선 → 치명타 확률순으로 최대 세 장을 선택한다. 신규 개체의 초기 스탯과 레벨 1 스킬로 측정한다.

모든 조합이 실험을 클리어했다. 기본 편성은 버스터 우선 시 단기 피해, 아츠 우선 시 해방 빈도의 차이가 나타났다. 게이지 지원이 있는 루나·윤달·서한비 팀은 아츠와 버스터 우선의 평균 종료 턴이 같았다. 선택한 전투에서는 회복 스킬을 보류할 수 있는 여유가 있다. 이 측정은 필수 캐릭터나 중복 소환 없이 진행할 초기 수치의 기준으로 남긴다. 패배 경로는 별도로 동시 전멸과 턴 초과 경계 검사에서 확인한다. 실제 플레이어의 전략 선호, 장시간 체감 난도와 재미는 미측정이다.
