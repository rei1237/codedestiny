# 대학생 일 스타일 리포트 캠페인 검토안

확인일: 2026-10-28 KST. 상태: 조사와 초안 완료, 발송·게시·배포 보류.

가입 후 무료로 이용하는 **사주로 찾는 나의 일 스타일**을 대학생의 자기이해 콘텐츠로 소개한다. 직업을 판정하는 검사나 학교가 보증하는 상담으로 홍보하지 않는다. 운영 목적에는 콘텐츠 체험뿐 아니라 꿀꿀 운세의 자연 유입과 브랜드 인지도 확대가 포함된다.

## 소개할 기능과 이용 조건

- 안내 주소: https://code-destiny.com/saju/career-style/ — 이번 로컬 변경의 운영 반영을 확인한 뒤 외부에 안내한다.
- 이용 순서: 가입 또는 로그인 → 현재 계정의 프로필 선택 → 리포트 확인. 프로필이 없으면 서비스의 프로필 등록 흐름을 이용한다. 기관이 학생 출생정보를 취합하지 않는다.
- 내용: 성향과 작업 방식, 월지로 읽는 환경, 여섯 업무 조건, 탐색할 역할과 작은 행동 실험을 여덟 장으로 제공한다.
- 이 기능에는 결제·LLM 생성·후기 작성·공유 의무가 없다. 서비스의 다른 유료 상담까지 무료라는 뜻은 아니다.
- 사주는 전통적 해석 체계이며, 결과는 실제 경험과 비교하는 질문으로 활용한다. 전문 진로검사·심리상담을 대체하거나 취업 결과를 보장하지 않는다.
- 공유는 자율이다. 출생정보·계정 화면·개인 리포트 원문 제출을 참여 조건으로 삼지 않는다.

근거 코드: `app/saju/career-style/page.tsx`, `CareerStyleClient.tsx`, `lib/saju/career-style/report.mjs`. 기존 프로필·결제·개인정보 정책을 수정하는 캠페인이 아니다.

## 채널별 적용 규칙

서울대 총동아리연합회의 경우 제휴는 공식 이메일로 접수한다. 동아리 대표의 개인 연락처를 대신 모으거나 일괄 전달해 달라고 요청하지 않는다. [공식 규정](https://dongari.snu.ac.kr/category/board-154-FAQ-OczVT5QS-20230705161717/)

에브리타임·캠퍼스픽은 공식 운영사의 제휴·광고 문의 경로가 있다. 제휴 양식에는 캠페인 내용, 기간, 예산과 필수 동의가 요구되며 제안서 첨부는 선택이다. 이번 계획의 기간은 미정, 유료 광고 예산은 미승인으로 기재한다. 허용 여부가 확인되기 전 학생 계정 대리 게시, 후기 위장, 여러 학교 게시판 반복 등록을 실행하지 않는다. [운영사 제휴 양식](https://www.vinuteam.com/contact/partner?inquiry_media=2)

대학의 외부 프로그램 게시판이나 학생회 제휴 사례는 이 캠페인의 허가를 의미하지 않는다. 각 담당자에게 사주 기반 콘텐츠라는 점, 가입 조건, 운영자의 홍보 목적을 함께 제시하고 적합성 검토를 요청한다. 대학 로고·추천 표현은 승인 범위가 확인된 뒤에만 사용한다.

## 실행 순서 제안

1. 배포 보류 해제 후 원격 CI와 반영 상태를 확인하고, 지정한 테스트 계정으로 가입·프로필·리포트 진입을 검수한다. 학생 출생정보를 임의로 만들지 않는다.
2. 아래 초안 중 승인된 수신처에 맞춘 한 통을 보낸다. 우선 검토 후보는 서울대 총동아리연합회, 연세대 미래캠퍼스 총학생회, 한림대 센터다. 기관의 허용 기준이 맞지 않으면 진행하지 않는다.
3. 수신처가 허용한 위치와 문구로만 안내한다. 운영자를 밝히고 결과보다 체험의 범위와 조건을 먼저 전달한다.
4. 게시 후 7일·14일에 허용된 집계 자료로 유입과 문의를 살핀다. 기간은 제안이며 예약이나 자동화는 만들지 않았다. 현재 전환 측정의 준비 여부는 미검증이다. 신규 추적기·회원정보 추출을 이번 작업에 추가하지 않는다.

성공 여부는 허가 받은 게시 수, 확인 가능한 집계 방문 수, 불편 문의, 자발적 의견으로 판단한다. 검색 순위·가입률 상승이나 목표 수치를 미리 확정하지 않는다. 체험 완료 수를 실제로 측정할 수 없으면 미측정으로 남긴다.
