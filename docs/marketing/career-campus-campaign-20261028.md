## 콘텐츠와 참여 조건

캠페인 이름은 **사주로 찾는 나의 일 스타일**이다. 직업을 정해 주기보다 일하는 성향, 환경, 자율성·규칙·협업·몰입·변화 속도·피드백의 여섯 업무 조건을 돌아보는 여덟 장의 자기이해 리포트다. 읽은 뒤 실제 경험과 비교하고 작은 진로 실험을 골라보도록 안내한다.

- 소개 주소: https://code-destiny.com/saju/career-style/ — 캠페인에 사용하기 전 운영 반영 확인 필요.
- 가입·로그인 후 현재 계정에 저장한 프로필을 선택한다. 프로필이 없으면 기존 프로필 만들기를 이용한다. 별도 대학 인증이나 학생 명단 제공을 요구하는 캠페인 구조는 만들지 않는다.
- 이 리포트에는 이용권·월정석·단건 결제가 필요 없다. 후기 작성·홍보·친구 초대·공유도 이용 조건이 아니다. 다른 유료 서비스는 기존 정책을 따른다.
- 공유는 선택이다. 유형 요약과 소개 주소만 전달하며 이름·출생정보·개인 리포트 본문은 공유에 넣지 않는다. 대학에 개인 결과나 프로필 명단을 제공하는 사업으로 제안하지 않는다.
- 사주 기반 자기이해 콘텐츠이며, 전문 진로검사·심리상담을 대체하지 않는다. 과학적 적성 진단, 직업 적합도 보장, 취업·합격 예측으로 설명하지 않는다.
- 운영 주체는 CODE DESTINY, 서비스 브랜드는 꿀꿀 운세다. 학생의 탐색 경험 제공과 함께 서비스의 자연 유입·브랜드 인지도 확대도 기대한다는 목적을 공개한다.

공식 규칙은 홍보게시판, 동아리·학회 게시판, 그 외 게시판을 구분한다. 일반 게시판에서는 웹사이트·서비스 홍보와 회원가입·링크 클릭 요청 등이 금지된다. 홍보게시판에서도 유사 서비스 홍보, 계정 공유나 대리 게시를 통한 여러 학교의 동일 주제 바이럴 홍보 등이 금지된다. 따라서 학생에게 대신 올려 달라고 하거나 무료 이용을 게시의 대가로 삼는 방식은 채택하지 않는다. 홍보게시판이 있다는 사실만으로 외부 운영자의 게시 자격이나 이번 콘텐츠의 허용을 확정하지 않는다. ## 소규모 진행안

1. 운영 반영과 가입→프로필→무료 결과 흐름을 승인된 범위에서 확인한 뒤, 발송할 기관과 문안을 운영자가 선택한다. 현재는 로컬 검증 단계다.
2. 첫 묶음은 외부 제휴 전용 창구가 있는 부경대 총학생회, 기관 연락처가 있는 건국대 총학생회·숭실대 동아리연합회 중 최대 3곳으로 제안한다. 학생 개인 계정에 홍보를 부탁하는 방식은 사용하지 않는다.
3. 담당자가 허용한 채널과 문구로만 게시한다. 학교·학생회의 추천이나 공식 제휴로 보일 표현과 로고는 기관의 별도 허락 없이는 사용하지 않는다. 일괄 발송, 미응답 기관의 자동 재발송, 자동 게시를 설정하지 않는다.
4. 첫 게시 후 2주를 검토 구간으로 제안한다. 이는 행사 마감이나 서비스 무료 기간이 아니다. 담당자의 수용·거절 이유와 이용자의 자발적인 의견을 먼저 정리한다.
5. 방문량은 배포 후 기존 분석 설정과 동의 범위 안에서 관찰할 수 있는 지표만 사용한다. 현재 `CareerStyleClient.tsx`에는 전용 리포트 완료·공유 계측이 확인되지 않았으므로 완료율·공유 전환율을 이미 측정 가능한 지표로 약속하지 않는다. 외부 채널 클릭과 실제 결과 열람도 구분한다.
