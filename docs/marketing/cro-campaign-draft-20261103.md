# 꿀꿀 운세 광고·상품 전환 초안

기준일: 2026-11-03 (한국 시간). 상태: 로컬 검토용, 미집행. 기준 코드: origin/main `79ef4a4ed`에서 시작한 CRO 작업. 예산 금액은 미정이며 계정·캠페인·입찰·청구 설정은 변경하지 않았다.

## 확인된 상품 기반과 우선순위

실제 매출, 키워드 검색량, 기간별 광고비, 환불률, 상품별 생성 원가를 확보하지 않았으므로 다음 순서는 **검증 착수 순서**이며 매출 순위나 예상 ROAS가 아니다.

1. 무료 사주: `/saju/`의 기존 무료 시작 경험. 무료 완료와 이후 관련 유료 상품 선택을 구분해 측정한다.
2. 2027 신년운세: `/new-year-ai-consultation/`. `page.tsx`의 `SEASON_YEAR=2027`, 클라이언트 기본 연도 `현재+1`, 서버 허용 범위 1900~2100을 확인했다. 2027년 계산 경로는 기존 세운 계산을 사용한다. 가격은 `PriceBadge`와 서버 가격표에서 읽는다.
3. 연애·궁합: `/love-secret-ai/`, `/master-love-codex/`. 관계를 돌아보는 해석을 제공하며 재회·연락·상대의 속마음 확정을 약속하지 않는다.
4. 질문 상담: `/yeongnyangi/`. 질문·상황에 따라 기존 상품과 체계로 이어지는 경로를 사용한다. 생선 등급 가격을 광고에서 별도 복제하지 않는다.
5. 인생의 책: `/life-book-ai/`. 장문 리포트 구성과 예시를 먼저 확인하게 한다. 가격은 선택한 모드의 기존 상품 키를 따른다.

## 랜딩의 약속과 구성

새 광고 전용 페이지를 복제하지 않고 위 기존 페이지의 상품 소개를 사용한다. 광고와 같은 상품명 → 고민 공감 → 계산·해석 방식 → 제공 챕터·결과 예시 → 기존 가격·이용 조건 → 입력 CTA → FAQ 순으로 확인한다. 모바일에서는 예시 링크를 입력 전에 찾을 수 있어야 한다.

- 신년·연애·인생의 책 hero에 페이지 내 결과 예시와 `/records/` 재열람 링크를 추가했다. 예시는 기존 `ResultSamples`를 사용한다.
- 꿀꿀 결과는 `/records/`, 영냥이 결과는 `/yeongnyangi/library/`로 분리한다. 완료 결과를 다시 생성하는 CTA로 대체하지 않는다.
- 소개의 `10년 경력 명리학자의 풀이 기준`은 기존 `lib/brand/founder.ts`에 운영자 제공 경력으로 기록되어 있다. 광고의 차별 표현으로 제출하기 전 공개 소개와 증빙을 다시 대조한다. 이 경력은 모든 결과를 사람이 개별 검수한다는 뜻이 아니다.
- 대통령 운세 분석 사례는 이번 초안에서 제외했다. 공개 원문 시점·사건·빗나간 부분까지 검증하기 전에는 적중률·예언·추천 보증 문구로 확대하지 않는다.
- 자동 해설과 사람 검수 이메일 상담을 구별하며, 상담이 질병·투자·법률·관계 결과를 보장한다고 말하지 않는다.

## 채널 정책 확인

- Google은 광고와 랜딩의 불일치, 중요한 가격·상품 정보 누락, 확인되지 않는 성과 약속을 제한한다. 광고 제목의 서비스와 실제 도착 상품을 맞추고 무료 기능과 유료 상담의 범위를 분리한다. [Google Misrepresentation](https://support.google.com/adspolicy/answer/6020955?hl=en)
- 관계의 어려움은 Google 개인 맞춤 광고의 민감 관심사에 해당할 수 있다. 해당 소재·랜딩에는 고객 일치, 자체 방문자 세그먼트, 유사·확장 타기팅을 사용하지 않는 초안으로 준비한다. 이는 운세 검색광고 전체가 금지된다는 판정이 아니다. [Google Relationship hardships](https://support.google.com/adspolicy/answer/16700849?hl=en-IE)
- 네이버 파워링크는 허위·과장 및 확인되지 않는 차별적 표현을 제한한다. 경력·설계 기준 같은 차별점은 사이트 또는 객관적인 근거에서 확인 가능해야 한다. [네이버 파워링크 허위·과장 기준](https://ads.naver.com/help/faq/317)
- 별도로 확인한 네이버 운세·역술 업종 가이드는 **디스플레이 광고** 문서다. 웹 운세 제공은 조건부 허용하되 공포 조장·확정 적중·검증 불가 능력·불투명 결제 등을 제한한다. 파워링크 승인 기준으로 혼동하지 않고 향후 디스플레이 확장 시 적용한다. [네이버 운세·역술 디스플레이 기준](https://ads.naver.com/adguide/1648)

정책 문서는 기준일에 열람했다. 실제 승인 여부는 등록할 소재·계정·랜딩 심사를 거쳐야 하며 이 초안은 승인 보장이 아니다.

## 예산 배분과 보고 기준

금액과 비율을 미리 고정하지 않는다. 첫 배분은 구매가 정상 완료되는 상품만 대상으로, Google·네이버의 동일 의도 그룹을 별도 비교할 수 있게 나눈다. 무료 사주는 무료 완료 및 후속 상품 선택, 유료 상품은 검증된 구매·순매출·실패율로 평가한다. 생성 원가·환불·결제 수수료를 확보하기 전에는 매출 ROAS를 이익으로 표시하지 않는다.

확대 조건은 상품별 구매 추적·금액 대사 통과, 충분한 전환 관찰, 수용 가능한 결과 생성·결제 실패율이다. 실패 또는 추적 누락이 있는 상품은 예산 확대 대상에서 제외하고 경로를 먼저 수정한다. 현재는 데이터가 없어 확대·중단 수치 기준과 예상 성과를 제시하지 않는다.

보고서는 날짜·채널·캠페인·랜딩·상품별로 방문, 상세 조회, 결제 시작, 구매, 매출, 실패, 비용을 함께 본다. 전환율의 분모와 환불 반영 여부를 표기하고 무료 완료를 구매로 합산하지 않는다. 공개 캠페인 코드만 UTM으로 사용하며 검색 원문·상담 내용·생년월일·연락처는 전달하지 않는다. 실제 집행 전 기존 캠페인 허용 목록에 맞춘 코드를 확정한다.

## 계정에서 확인한 기준 수치

담당 조사자가 Ego Lite의 로그인된 네이버 광고 대시보드를 읽기 전용으로 확인했다. 표시 기간은 **2026-10-27~2026-11-02**, 총 노출 **567**, 클릭 **12**, 전환 **0**이다. CTR **약 2.12%**는 `12 ÷ 567 × 100`으로 계산했다. 전환 0은 광고 플랫폼의 집계이며 실제 서비스 구매가 0이었다는 검증이 아니다. 프로모션 누적 패널의 소진 금액 4,087원은 해당 기간 광고비로 사용하지 않는다. 계정 식별자는 기록하지 않는다.

같은 조사자가 Ego Lite에서 로그인된 GA4 홈의 **지난 28일** 요약을 확인했다. 활성 사용자 **345**, 이벤트 **1.5만**(화면의 축약값으로 정확한 정수 미확인), 새 사용자 **329**, 구매 **16**이 표시되었다. 이는 GA4에 수집된 표시값으로 실제 결제 영수증·매출과 대사하지 않았으며, 테스트 혼입과 중복 여부도 확인하지 않았다. 상대 기간만 확인했으므로 시작·종료 날짜를 추정하지 않는다.

Search Console의 `code-destiny.com` 개요에서 총 웹 검색 클릭 **43**, 색인된 페이지 **403**, 색인되지 않은 페이지 **1,779**를 확인했다. 개요 차트에 8/1~10/24 눈금이 보였지만 정확한 선택 기간은 확인하지 못했으므로 해당 기간의 실적으로 단정하지 않는다. 미색인 수치 전체를 오류로 해석하지 않는다. 의도된 noindex·중복 URL·리디렉션과 실제 색인 문제의 구분은 추가 점검 사항이다.

Google Ads는 공개 홍보 페이지와 로그인 버튼만 확인했으며 광고 계정에는 접근하지 못했다. 개인 계정 정보·광고 계정 ID·GA4 속성 ID는 저장하지 않는다.

GA4와 네이버의 관찰 기간이 다르고 GSC의 정확한 기간도 미확인이다. 이 자료를 합쳐 광고별 구매 전환율·방문자당 매출·ROAS를 산출하지 않는다. GA4 수신값과 실제 결제·매출 대사, 기간 광고비, 이탈률 및 개선 성과는 아직 미검증이다. 푸시·배포·광고 집행·고객 메시지 발송은 수행하지 않았다.

## 무료 이후와 결과 복구 추가 감사

- 무료 사주 결과의 `index.html`에는 `data-cd-cross-sell="saju_question"` 후속 질문 영역이 이미 있다. 돈·진로·관계 질문으로 이어지며 기존 명식·해석을 다시 볼 수 있다고 안내한다. 같은 결과 화면의 `.lifebook-tile.saju-entry-card`는 실제 `/life-book-ai/`와 `life-book-ai-consultation` 상품 키로 연결한다. 새 추천 팝업이나 무료 결과 제한을 추가하지 않았다. 이 연결의 현재 운영 클릭·구매 성과는 미측정이다.
- `js/core/saju/reportDashboard.js:renderReportDashboard`는 결과 이후 기존 콘텐츠를 표시한다. `js/recommendations-*`는 외부 제휴 상품 추천 계층이므로 유료 운세 전환과 혼동해 신규 도입하거나 변경하지 않았다.
- 신년 상담의 `pollNewYearResult`와 진행 안내는 저장된 분야를 유지하며 다시 결제하지 않는다고 안내한다. 연애 비책의 한국어 `resultTimeout`은 결과 페이지 재확인을 안내한다. 인생의 책은 기존 일시 오류 재시도·확정 실패 분기를 유지했다. 이번 hero의 구매 결과 바로가기는 별도 결제나 생성 없이 `/records/`로 연결한다.
- 영냥이 `result-state-copy.ts`는 결제 확인 대기, 기존 저장 챕터, 복구 중지, 상담 ID 불일치, 문의 시 주문번호, 재결제 금지를 구분한다. 기존 mock 복구 검사를 통과했으며 문구를 중복 추가하지 않았다.
- 기록 소유자 검증·환불 접근 회수·외부 PG 복귀는 이번 UI 변경으로 수정하지 않았다. 실사용 계정의 이전 구매 결과·실제 PG·운영 DB 대사는 미검증이다.
