# 영냥이·신년운세 주의점 상담 계약

새 상담의 근거·목차·프롬프트 표식은 `prevention-20260930-v1`이다. 운영 적용이나 실제 LLM 문장 품질을 입증하는 문서는 아니다.

## 적용과 저장

- 영냥이 광어·참치·모둠·오마카세의 일반·연애·궁합·타로·자유질문 준비 경로에 주의점 챕터를 하나 추가한다. 고등어·연어 및 별도 신점/질문천문 2단계 계약은 유지한다.
- 기존 목차 ID와 순서는 유지하고 마지막에 독립 챕터를 붙인다. 모든 새 대상 챕터에는 주의점 해석 규칙을 전달한다.
- 계산된 근거와 기간은 구매 스냅샷에 저장한다. 원래 저장된 보고서를 다시 계산하거나 기존 목차에 새 장을 삽입하지 않는다. 복구는 기존 저장 결과와 시도 예산을 그대로 사용한다.
- 새 신년운세는 기존 다섯 생성 단위를 유지하며 총운에 필수 소제목을 둔다. 소제목 누락은 기존 보완 예산 내에서 총운 부분에만 배정한다.

## 해석 경계

- 묘오파/오묘파는 같은 관계다. 빠른 몰입과 관계 온도 변화는 조건부 해석이며, 실제 성격·이별·호르몬 상태를 확정하지 않는다.
- 원국과 운의 합충형파해를 구분하고, 완전 성립한 형·삼합·방합만 계산한다. 부분 구성은 완전한 관계로 내보내지 않는다. 합은 자동 합화나 길운이 아니다.
- 천간 편관의 위치·통근·월주와 기존 조건부 용신/기신 판단을 제공한다. 인신사해의 존재와 역마 성립은 구별한다.
- 식신제살·살인상생 등 복합 판정은 이 버전에서 별도로 검증하지 않았으므로 성립·효과를 단정하지 않는다. 새로운 신강약·용신 계산기를 만들지 않는다.
- 광어의 용신 설명은 사주 주의점 챕터의 조건부 균형 근거에만 허용한다. 다른 전문 근거와 상위 등급 전용 시기를 개방하지 않는다.
- 다른 점술은 자체 계산 근거만 사용한다. 퓨전의 체계별 근거를 합쳐 적중 확률로 표현하지 않는다. 타로는 저장된 카드·방향·위치를 유지한다.

## 검증

`__tests__/ui/yeongnyangi-prevention.test.mjs`는 성립/미성립, 편관·역마 구분, 모든 상품/상담 종류의 등급 경계, 출력 언어, 필수 행동 섹션, 신년운세의 대상 연도·혼합 판정·누락 보완을 mock으로 검사한다. 기존 invariance 테스트는 대상 새 상담의 해시만 갱신하고 하위 등급·기존 카탈로그 해시는 유지한다. 퓨전 전달 테스트는 새 장까지 저장·복구·재열람을 검증한다.

실제 생성 문장의 전문성·개인화·비반복성은 승인된 실호출과 사람의 검수가 필요한 별도 품질 단계다. 결제·가격·DB 스키마·운영 배포는 이 작업 범위 밖이다.
