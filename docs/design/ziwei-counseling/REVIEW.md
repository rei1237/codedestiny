# 심화 자미두수 승인용 목업

현재 상태: **2026-09-08 사용자 승인 완료 — 실제 서비스 구현 및 회귀 검증 중**. 사용자 답변 “오케이 이렇게 진행해줘”에 따라 아래 목업 방향으로 적용했다. 이 문서 아래의 목업 수치는 승인 당시 기록이며 실제 구현 증거는 `implementation/`에 있다.

## 확인 방법

워크트리에서 `node docs/design/ziwei-counseling/serve.mjs`를 실행하고 출력된 로컬 주소를 연다. 상단 검토 도구에서 상담 결과·상담 시작·PDF 디자인·상태와 색상을 전환한다. 이 상단 검토 도구는 실제 서비스에 넣지 않는다.

- 결과: 질문 8개 전환 → 명반 근거 펼치기 → 관련 궁 선택. 선택한 질문은 Hero에도 반영된다.
- 입력: 주제 선택과 긴 이름·시각 미상 상태를 확인할 수 있다. 입력값은 저장·전송하지 않는다. 날짜를 바꿔도 목업의 고정 명반은 다시 계산하지 않는다.
- 공유: 선택한 질문·답변만 미리 본다. 이름·출생정보·자유 질문을 제외한다. 목업의 복사 버튼은 완료 안내만 표시한다.
- PDF: 표지·15장 목차·본문을 보여주는 A4 디자인 3장이다. 실제 생성 PDF나 15장 전체 상담 결과가 아니다.

## 문장과 근거

`sample-chart.json`은 가상의 서윤(1990-05-15 10:00, 여성, 양력)을 기존 엔진으로 계산한 결과다. 목업 문장은 이 명반의 파군(명궁), 탐랑(관록궁), 칠살(재백궁), 무곡(부부궁) 등 실제 배치를 바탕으로 직접 편집했다. LLM 상담 결과가 아니다.

첫 답변을 문서형 안내에서 삶의 태도로 바꾸고, 질문마다 결론·생활 장면·행동·명반 근거를 분리했다. 같은 조언을 하단에 반복하지 않는다. 출생년 간지나 정적 궁 점수를 올해의 예측으로 표시하지 않는다.

## 시각 계약

- 먹빛 남색과 절제된 금색. 장문 읽기형 화면. 전역 테마는 변경하지 않는다.
- 기존 브랜드 `CodeDestinySerifKR`(기존 serif CSS)로 제목을 표시하고 기존 시스템 고딕 폴백을 본문에 쓴다. 새 폰트 공급자는 없다.
- 별도 이미지 한 벌을 Hero·상담서 표지에 재사용한다. 장식 그림은 실제 명반이 아니며 alt는 비운다.
- 모바일 Hero 본문은 불투명 남색 계열 오버레이 위에 표시한다. 계산한 대비는 무늬 없는 기준 표면 대비이며, 배경 위 실제 렌더도 별도 캡처 검토했다.
- 색상과 기본·hover·active·focus·disabled·loading·error·empty 상태는 목업의 ‘상태·색상’ 탭에서 확인한다.
- 본문/바탕 대비 15.83:1, 보조 문장/바탕 9.81:1, 보조 문장/펼친 표면 8.92:1. PDF는 먹색 본문과 밝은 종이색을 사용한다. 정확한 재측정 값은 검증 로그를 우선한다.
- prototype에서 허용한 타입 크기는 서비스 적용 시 이 표면 전용 타입 토큰으로 옮긴다. 전체 DESIGN.md의 공용 스케일은 변경하지 않는다. detector의 literal font-size advisory는 이 이관 항목으로 남긴다.

## 검증과 한계

`node docs/design/ziwei-counseling/verify-mockup.mjs <로컬 주소>`

360·390·430·768·1440px의 가로 넘침 0. 390×844에서 Hero 버튼 하단 약 587px. 기본 목업 길이 3,633px. **기존 실제 앱의 32,171px와는 콘텐츠·기능이 다른 목업 수치이며 앱 개선 실측이 아니다.**

질문 8개 전환, 선택 궁 연결, 공유 미리보기의 프로필 제외, Escape 닫기, 시각 미상, 긴 이름, 입력 주제 전달, PDF 3장과 모바일 쪽번호 겹침을 확인했다. `captures/metrics.json`에 결과를 기록했다(2026-09-12 정리에서 삭제, git 히스토리 참조).

독립 시각 검토에서 지적된 프로필명과 질문 주제 라벨의 순서를 수정했다. 최신 모바일·데스크톱 캡처 재검토 결과, 승인용 목업에 추가 필수 수정 없음으로 판정했다. 실제 앱·생성 PDF 검증을 뜻하지 않는다.

실제 생성·결제·인증·저장·새로고침·다국어·PDF 추출·생산 빌드 회귀는 승인 후 서비스 구현에서 검증해야 한다. `npm ci --ignore-scripts --no-audit --no-fund`로 이 워크트리의 잠금파일에 맞는 의존성을 설치했다. 의존성 deprecation 경고는 기존 패키지에서 발생했다.

## 승인 후 구현 순서

문장 정본과 표시 모델 → 입력 주제와 질문형 결과 → 궁별 상세 → PDF 프롬프트·텍스트 조판 → 공유·캐시 복원 → Mock 회귀 → 커밋·푸시·PR. 계산·점수·궁 배치·결제·DB 계약을 유지한다. 구체적인 남은 작업은 `docs/handoff/ziwei-counseling-premium.md`를 따른다.

## 실제 구현 검증 (2026-09-08)

사용자 승인 후 실제 /ziwei/chart 컴포넌트로 검증했다. 결과는 implementation/browser-metrics.json과 pdf-metrics.json에 기록한다. 5개 폭 모두 가로 넘침0,390px Hero 버튼 하단512px·기본 높이3239px. 8개 질문·프로필 변경/계산 취소·시각 미상·공유 성공/취소/복사 실패/미지원·기존 앵커·저장본15장과 부분9장·폰트 재시도를 Mock으로 확인했다.

실제 exporter로 저장한 ziwei-mock-report.pdf(2026-09-12 정리에서 삭제, `scripts/verify-ziwei-consultation-browser.mjs` 로 재생성)는 표지/목차 포함19쪽이며, 첫 장의 긴 문단을 페이지 사이로 나눈다. 모든 15장 마지막 문장과 한글25871자를 추출했고 전체 글자가 페이지 경계 안에 있다. PDF의 반복 문장은 분할 스트레스 검사용 합성 문장이다.

독립 일반 리뷰어가 실제 캡처10개를 검토했다. 천문도 노출과 펼침 SVG아이콘 2건을 수정한 뒤 두 항목 모두 resolved, disposition: ship. 이 판정은 수정 항목 재검토 범위이며 제품 전체 무결함 보장은 아니다. 이 표면의 확정 디자인은 같은 폴더 DESIGN.md와 .impeccable/design.json에 기록했다.
