# 캐릭터·홈·숲길 정리

## 목표

캐릭터 시트에 맞춰 웹툰을 교정하고, 지난 상담 찾기와 서비스 안내를 강조하며 숲길 안에서 기존 프로필 작성기를 사용한다.

## 자산 검토

- 상담 본편 13종, 표지 14종, 흑월 컷 31종을 비교했다.
- 무성 후드와 서한비 복식이 어긋난 자미두수·초융합·숙요점·연애 비책·운명의 업 본편 5종을 교정했다. 대사와 컷 순서를 대조했다.
- 현재 main의 자미두수·초융합 표지는 원화의 후드·여성형 서한비가 이미 반영되어 있다. 본편은 이번 변경에서 맞춘다.
- 무성·윤달·흑월 시트는 D:\CodeDestiny-Build에 저장했다. 기존 서한비 시트를 재사용한다.
- 이용 안내는 꽃돼지 연이·영냥이 원본 시트로 만든 네 장이다. 대사는 이미지 밖 HTML로 제공한다.

## 동작 경계

기존 프로필 작성기를 같은 출처의 숲길 패널로 연다. 카드 추가·선택 정책과 저장 요청은 기존 구현을 재사용한다. 저장 확인 메시지는 출처와 해당 프레임을 모두 검증한다. 프로필 조회 실패는 빈 목록과 구별한다.

## 검증 진행

- 상담 웹툰 진입 테스트 6개 통과.
- 홈 375·430·768·1440px 기존 브라우저 검사 통과.
- 질문·안내 웹툰 360·390·430·1120px, 확대, 닫기·뒤로·초점 복귀 및 상담 질문 전달 검사 통과.
- check:fast에서 독립 페이지의 프로필 스크립트 캐시 핀 불일치를 검출해 내용 해시로 갱신했다.
- 숲길 실제 작성기 입력·취소, 저장 실패 후 재시도, 저장 확인 후 복귀, 기존 카드 전환을 mock API로 검증했다. 출처가 다른 완료 메시지는 무시한다. 360·390·430·1280px 가로 넘침 검사 통과.
- 프레임 저장 후 부모의 프로필 조회 캐시를 기존 invalidateProfileCache로 비워 새 카드 이름을 반영한다.
- typecheck 통과. 변경 React 파일 ESLint 오류 0개, 기존 저장소 함수의 미사용 인자 경고 1개.
- check:fast는 77개 가드 중 캐시 핀 검사 1개에서 중단했다. 수정 후 해당 검사 자체와 6개 프로필 진입 회귀 테스트가 통과했다. 전체 재실행으로 표기하지 않는다.
- 최신 main 병합 후 npm run check:pre-push 전체 통과. 원격 main 복구 커밋 c14490387의 CI 통과 후 병합하고 정적 미러를 다시 생성했다.

## SEO

공개 주소·검색 의도·메타데이터 구조를 유지한다. 안내 그림은 HTML 대사와 대체 텍스트를 갖추고, 본편 링크는 기존 상담 주소를 사용한다. 사이트맵은 생성기로 갱신한다.
