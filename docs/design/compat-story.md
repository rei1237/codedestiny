# 궁합 이야기 리포트

- 가격: 관계 성향 상품은 서버 정본 1회 10,000원 유지. 본인 정보 추가에도 동일 요금.
- 계산: 두 명식 16개 교차 위치와 원국 내부 관계를 분리. 완성 삼합과 부분 관계를 구분하고 점수를 추가 가감하지 않는다. 출생시간 미상은 시주에서 제외한다.
- 결과: v2/p2부터 계산 근거와 기승전결(배경, 사회생활, 가까운 관계, 미래 계획)을 제공한다. 기존 v1 및 진행 중 입력 버전을 보존한다.
- 이미지: compat-story-assets.json의 사전 생성 삽화 10종을 사용한다. 개인의 실제 외모나 전생의 증거가 아닌 상징적 장면이다.
- 결제 이후: 선택 본인 정보를 요청 해시와 재개 데이터에 포함한다. 대상자 단독 기존 해시와 저장 결과는 유지한다. 완료 결과는 다시 생성하지 않는다.

## 검증 (2026-10-15)

- node --test: 명리/스키마/입력/렌더 37개 및 가격 배지 1개 통과.
- test:jest: 궁합 생성/프롬프트/관계 성향/결제 전달 4 suite, 65개 통과.
- npm run typecheck: 통과.
- 변경 TS/서버 eslint: 오류 0, 기존 미사용 변수 경고 3.
- node scripts/verify-compat-story-browser.mjs: 로컬 API/결제 mock. 결제 진입→본인 입력 보존→부분 생성 재개→저장 결과→새로고침 재열람 통과. 360/390/430/1280 폭, 키보드 상세 펼침, 이미지 실패 시 본문 표시 통과.
- 시각 검수: 6개 캡처에서 변경 범위 P1/P2 결함 없음.
- npm run sync:public 및 git diff --check: 통과.
- check:fast -- --plan: 위험 변경으로 전체 검사 선택. check:fast는 전체 테스트 단계에서 중단했으므로 통과로 간주하지 않는다. 전체 검사는 공식 GitHub CI에서 판정한다.
- 실결제, 실 LLM, 운영 DB 및 운영 배포는 검증하지 않았다.
