# 영냥이 마이너 카드 콘셉트

2026-09-28. 메이저 22장 전체 승인 후 사용자가 마이너 제작을 요청했다. 「원래대로 슈트별 14장 승인」 결정에 따라 완드 → 컵 → 소드 → 펜타클 순으로 배치를 검수·제출하고 승인 후 다음 슈트로 넘어간다.

## 완드 14장 — 제작 전 제출한 콘셉트

확정 스타일 바이블의 밤색·호박빛 팔레트와 별빛 깃털 낚싯대 장난감 모티프를 사용한다. 숫자 카드의 막대 수는 카드 숫자와 같아야 한다. 코트 카드의 주연은 조연이며 영냥이는 작은 배경 카메오로만 등장한다.

| 카드 | 주연 | 장면·필수 상징 |
|---|---|---|
| 에이스 | 영냥이 앞발 | 구름에서 나온 앞발, 새싹 돋은 낚싯대 1개, 먼 정원 |
| 2 | 영냥이 | 해안 테라스, 낚싯대 2개, 작은 지구본을 보며 계획 |
| 3 | 영냥이 | 낚싯대 3개, 뒷모습으로 먼 배와 항로를 관찰 |
| 4 | 영냥이·귤이 | 낚싯대 4개를 잇는 꽃 화환, 축제의 문 |
| 5 | 영냥이·귤이·까미·진주·보리 | 각자 1개씩 든 낚싯대 총 5개, 다치지 않는 연습 경쟁 |
| 6 | 영냥이 | 월계관, 작은 밤색 조랑말, 든 낚싯대 1개와 뒤의 5개 |
| 7 | 영냥이 | 낮은 바위, 든 낚싯대 1개와 아래쪽 6개, 경계 지키기 |
| 8 | 영냥이 | 작은 영냥이가 바라보는 낚싯대 8개의 평행 비행, 강과 계곡 |
| 9 | 영냥이 | 피 없는 작은 이마 붕대, 든 낚싯대 1개와 울타리의 8개 |
| 10 | 영냥이 | 작은 수레에 좌우 각 5개씩 실은 낚싯대 10개를 목적지로 나르는 부담, 여분 발 금지 |
| 시종 | 귤이 | 주황 태비 견습생, 새싹과 깃털을 발견하는 낚싯대 1개 |
| 기사 | 까미 | 검은 청년 고양이, 진홍 여행 망토, 조랑말과 낚싯대 1개 |
| 여왕 | 보리 | 성숙한 삼색 폴드, 낚싯대 1개·해바라기·작은 검은 고양이 |
| 왕 | 호두 | 성숙한 갈색 메인쿤, 낚싯대 1개·사자/도롱뇽 왕좌·작은 도롱뇽 |

각 장은 개별 프롬프트로 생성한다. 글자·숫자·워터마크·사람·유혈은 금지하고 상단 10%·하단 14%를 프레임 안전 영역으로 검수한다. 정확한 개수·해부학·상징을 통과하지 못한 후보는 채택하지 않는다.

10번의 최초 콘셉트는 막대 10개를 안고 나르는 모습이었다. 첫 두 후보에서 묶음이 겹쳐 정확한 수를 검증할 수 없어, 부담을 운반한다는 의미를 유지하면서 각각의 막대가 보이는 작은 수레 장면으로 보완했다. 탈락 후보와 실제 프롬프트는 원장에 보존한다.

## 이후 배치

컵·소드·펜타클의 콘셉트는 직전 슈트 승인 후 해당 배치 제작 전에 제출한다. 컵 에이스와 펜타클 5의 Phase 2 채택본은 해당 슈트에서 재사용 여부를 확인한다. 아직 미제작인 배치를 완료로 표시하지 않는다.

## 컵 14장 — 완드 승인 후 제작 전 제출한 콘셉트

2026-09-28 사용자 「승인하고 다음 단계 진행해」로 완드14 현 채택본 전체 승인. 컵 에이스는 기존 Phase2 채택본을 재사용한다. 청록빛 물과 초승달 손잡이 달빛 찻잔을 통일하고, 코트 카드의 영냥이는 작은 카메오로만 둔다.
