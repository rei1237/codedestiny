# 토스 계정·CTA 동선 정리

## 사용자 목적과 범위

2026-11-15 사용자 요청: 로그인과 CTA 배치를 더 직관적이고 편리하게 개선한다. 기존 달빛 예화·연이/영냥이 원본·서비스 구분을 유지하는 Operate 화면 개선이다. 공개 웹 홈의 구성이나 디자인 정본을 바꾸지 않는다.

- 홈의 두 캐릭터 카드가 서비스 선택을 담당한다. 첫 홈의 중복 공간 탭은 생략하고, 공간 진입 후에는 홈/꿀꿀운세/영냥이 이동을 유지한다.
- 상단 계정 진입은 48px 윤곽 버튼과 아이콘으로 구분한다. 로그인 전에는 `토스 로그인`, 이후에는 `내 보관함`이다. 무료 탐색에 로그인을 강제하지 않는다.
- SPA 로그인과 `/login` 재진입은 같은 `LoginPanel`을 사용한다. 짧은 목적 → 전체 폭 로그인 → 돌아갈 곳 → 둘러보기 → 개인정보 안내 순서다. 기존 계정·개인정보 문구를 접을 수 있는 안내에 보존한다.
- 그림은 제목 옆의 보조 역할이다. 기존 브랜드 주아체/본문 서체를 패널이 직접 로드하여 진입 방식에 따라 서체나 버튼 표면이 바뀌지 않는다.
- 보관함은 로그인/기록/더 보기 먼저, 누락 구매 복구는 그 뒤의 보조 행동이다. 설정의 로그아웃도 보조 버튼이다.

## 보존한 경계

인증 함수, 중복 요청 잠금, 계정 전환과 이탈 보호, 작성 내용 복원, 허용된 복귀 경로, 구매 소유권, 서버 API, 가격·이용권·월정석 정책은 변경하지 않았다. 기존 TDS 버튼의 loading/disabled 동작과 토스 네이티브 내비게이션을 사용한다. 로그인 표현만 공유하며 각 어댑터가 기존 인증 콜백을 계속 소유한다.

## 검증 근거

- 모바일 360/390/430 및 데스크톱 1280px 로컬 mock 화면 검수. 로그인 버튼 높이 54px, 360px 폭 324px, 첫 화면 내 위치. 가로 넘침 없음.
- 별도 읽기 전용 시각 검수에서 SPA/재진입 서체 차이를 발견해 한 번에 보정 후 최종 통과. 추가 재디자인 반복 없음.
- 보조 본문 대비 5.00:1, 주요 버튼 7.35:1. 개인정보 펼침 및 오류 안내가 CTA와 겹치지 않는다.
- 실제 브라우저에서 홈 → 로그인 → 새로고침 → mock 로그인 → 보관함 → 홈 재진입 → 보관함을 확인했다. 키보드로 주요 버튼을 실행했고 로그인 버튼의 `:focus-visible` 및 solid outline을 확인했다. 외부 네트워크는 offline CSP와 mock network guard로 차단한다.
- 기존 통합 테스트가 공통 로그인 패널을 실제 렌더링하도록 연결해 중복 클릭, 이탈, 계정 경계, 질문 복원을 계속 검증한다. 보관함 제목 검사는 전체 안내 문구 대신 실제 기록 제목을 검사한다.
- 디자인 감지기 경고 2개는 기존 공간 탭의 선택 밑줄과 기존 결과 인용문 테두리다. 이번 로그인 패널의 경고는 없으며 관련 없는 결과 디자인은 보존한다.
- 개발 서버 HMR 직후 한 번 동적 import가 실패했으나 같은 모듈 GET 200 및 새로고침 이후 전체 동선이 통과했다. 실 배포 번들 검증과 구분한다. 기존 브라우저의 과거 숙요 mock 주문에는 날짜/챕터 메타가 없어 원문 재열람 성공 근거로 사용하지 않았다. 운영 library serializer는 해당 필드를 제공하며 이번 작업에서 변경하지 않았다.
- 관련 로그인·복구·네이티브 입력 통합 검사 133건을 확인했다(컴포넌트 분리 후 실제 패널을 렌더링하도록 fixture 연결을 조정하고 실패 항목 재검증). 앱 typecheck 통과. `check:fast` 최초 Node 검사 5086/5087 통과, 1건은 새 워크트리의 무시된 일일 계산 데이터 누락이었다. 공식 `fortune:build-data` 실행 후 해당 7건 모두 통과했으며 소스 우회나 테스트 기대값 완화는 하지 않았다.

## 전달 경계

운영 로그인 수정 `08103bec6`은 이미 반영되고 사용자가 로그인·보관함 복귀·재진입 정상임을 확인했다. 이 문서의 후속 UI 변경은 별도 AIT 등록이 필요하다. 기존 QR17에 새 UI가 이미 표시된다고 보고하지 않는다. 콘솔 버전 등록은 검토 중 잠김 상태이며, 이번 UI 작업으로 검토 취소·재제출·실결제·운영 재배포를 수행하지 않는다.
