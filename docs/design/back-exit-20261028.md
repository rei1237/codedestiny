# 두 서비스 뒤로가기·종료 계약 (2026-10-28)

## 범위와 환경

- 꿀꿀운세 정적 셸과 영냥이 App Router를 함께 처리한다.
- 실제 Android 앱은 Capacitor 8의 App 플러그인이 보내는 `backButton`과 `exitApp`을 쓴다. `scripts/app-native-bridge.js`는 앱 HTML에만 주입된다. 웹·설치형 PWA에는 실제 종료 기능을 가정하지 않는다.
- 공식 API 근거: https://capacitorjs.com/docs/apis/app (backButton 구독 시 기본 뒤로가기를 직접 처리해야 함).

## 사용자 동작

1. 등록된 결제 선택창·팝업이 먼저 뒤로가기를 소비한다. 기존 단계 이동과 잠금 판정은 그대로 사용한다.
2. 이용 안내·영상의 HTML dialog는 cancel 이벤트로 닫아 해당 화면의 상태 기록과 포커스 복원을 보존한다.
3. 상담 입력 단계와 내부 이전 화면으로 돌아간다. 처리 중 상담의 이탈 보호를 유지한다.
4. Android의 꿀꿀운세·영냥이 루트에서 첫 입력은 `뒤로가기를 한 번 더 누르면 종료돼요`를 2초간 표시한다. 그 안의 두 번째 입력만 App.exitApp을 호출한다.
5. 만료, 화면 이동, 재진입, 포그라운드 복귀, 다른 사용자 조작 때 종료 의도를 지운다.
6. 일반 브라우저·PWA에서는 종료 안내나 window.close를 쓰지 않는다. 셸의 임시 가드를 소비한 뒤 원래 브라우저 뒤로가기를 이어 가며 루트에서 가드를 반복 삽입하지 않는다.
7. 뒤로가기에 가입 권유 팝업을 새로 띄우지 않는다. 기존 혜택 콘텐츠와 가입 정책은 수정하지 않는다.

## 변경 위치

- `scripts/app-native-bridge.js`: 앱 종료의 단일 소유자, 두 서비스 루트 판정, lifecycle 초기화, 접근 가능한 안내, dialog cancel 처리.
- `app/providers/NavigationProvider.tsx`: 루트 종료 가드 제거, 네이티브 이벤트를 기존 overlay/wizard/analysis 처리에 연결, HTML dialog 공통 연결.
- `js/mobile-backstack-navigation.js`: 웹/PWA 종료 오인 안내 제거, 루트 이탈 존중, 앱의 셸 팝업/내부 화면 처리 연결.
- `app/app/_lib/useAndroidBackButton.ts`: 주입 브릿지와의 중복 처리 제거. 구형 폴백도 실제 Android 런타임에서만 작동.
- `js/mobile-interaction-patch.js`, `index.html`, `public/` 대응 미러: 기존 생성기의 캐시 키와 미러 갱신. 본문·SEO 메타데이터 의미 변경 없음.
- `__tests__/ui/app-entry-navigation.test.js`, `back-navigation-contract.test.js`, `signup-benefit-exit.static.test.js`: 환경·수명주기·보호 동작 회귀 검사.
