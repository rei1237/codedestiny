# 시빌라 연간 대비 리포트

## 구현 계약

- 신규 단건 가격은 `worker/lib/paid-feature-registry.js`의 200 단위(20,000원)를 정본으로 한다. 정적 홈 가격과 서비스 목록은 `sync:public`에서 같은 서버 가격으로 생성한다.
- 기존 출생정보 단위 권한을 읽는다. 같은 출생정보의 다른 연도에는 다시 차감하지 않는다. FPTI 가격과 분석 방식은 유지한다.
- 무료 `/api/sibyl/preview`는 규칙 계산만 수행한다. 유료 `/api/sibyl/report`는 소유한 저장 프로필을 다시 읽고 계산한다. 클라이언트 점수는 사용하지 않는다.
- 한국 시간의 현재 연도부터 9년 후까지 생성한다. 분석 구간은 입춘부터 다음 입춘이며 월운은 실제 절입 경계를 사용한다. 생시 미상은 시주·대운을 만들어 채우지 않는다.
- 주의 우선순위는 명리 신호의 관련도를 정리한 순서다. 사건 발생 확률·손실률이 아니다. 계산 사실과 AI 상담문은 분리하며 숫자·간지·미등록 근거가 포함된 상담은 저장하지 않는다. 의미 전체의 정확성을 보장하는 검증기는 아니다.
- `ServiceExecutionTransaction`의 계정+출생키+연도 유일 키와 원자적 잠금으로 중복 생성을 막는다. 저장 성공 후에만 완료를 응답한다. 영구 권한의 생성 작업은 회당 차감 환불 스위퍼 대상에 넣지 않는다.
- 실패·진행 중 결과도 보관함에 남는다. 같은 권한으로 재시도하며 완료본 재열람은 생성기를 호출하지 않는다. 이전 FPTI 결과는 스키마 버전을 이유로 재생성하지 않는다.

## 이미지

도구: 내장 `image_gen`으로 신규 생성. 인물·텍스트·실제 수치·작품 로고 없이 네 기둥과 시간의 궤도를 관측하는 공간으로 제작했다.

프롬프트 요지: “Premium cinematic 16:9 futuristic quiet observatory; four luminous pillars; transparent orbital time ribbons and twelve subtle segments; dark glass, pale cyan and platinum; no human, text, logo or movie props.”

적용 원본: `public/images/feature-details/saju-sibyl-observatory.webp`. 홈·결과·상세 이미지는 이 원본에서 공식 생성 절차로 파생한다. 상세 원본은 `content/product-details/sibyl-dominator/`에 있다.

## 검증 범위

- mock 단위 검사: 동일 입력, 연도·절입 경계, 윤달 변환, 생시 미상, 무료 투영, 20,000원 가격, 기존 출생 권한, 동시 요청, 저장 실패, 소유자 격리, 환불 원본 차단, 원본 재열람 시 AI 재호출 없음.
- mock 화면 검사: 360·390·430·1280px 홈·기본 결과·잠금·유료 결과. 제목/뒤로 버튼 겹침, 가로 넘침, 오류 후 재시도, 202 진행 확인, 구매 권한 확인 후 자동 재개를 확인했다.
- 보관함의 실제 TSX/CSS도 390·1280px mock harness에서 확인했다. 목차·근거 펼치기·미완료 재개와 저장 후 reload, 완료본의 추가 API 호출 없음을 확인했다. 보관함 harness는 대체 폰트이므로 실제 앱 폰트의 세부 줄바꿈은 포함하지 않는다.
- 상세 이미지 9장 생성 시 넘침 없음. 저장 리포트는 텍스트 목차와 접을 수 있는 근거를 제공한다.
- 실제 결제·실제 LLM·운영 데이터·운영 승격은 검증하지 않았다. 전체 공식 게이트와 전달 결과는 커밋 시 최종 보고를 따른다.
