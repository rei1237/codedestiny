# 관리자 운영 길드

- 상태: 로컬 구현·검증 완료. 운영 배포 없음.
- 대상: /admin, /admin/wordpress, /admin/quests, /admin/connections.
- 목표: 실제 운영 증빙을 퀘스트·기존 XP에 연결하고 WordPress에 집중한다.
- 디자인: 기존 별빛 운영본부의 네이비·아이보리·금빛과 연이·네오·영냥이 자산을 유지한다. 마스터 선택 → 대화 → 명확한 다음 행동의 구조.
- 데이터: 연이 편집, 네오 결제·제공, 영냥이 검색·측정. 미확인·12시간 이상 지난 동기화는 무매출 판단에서 제외. 상담/결제 이벤트와 고유 주문의 전환율은 계산하지 않는다.
- 성능: NPC 안내는 순수 함수, LLM·새 폴링 없음. 기존 1분 알림 폴링 제거. 홈의 중복 요약 요청 제거. 이미지 lazy load 유지.
- 접근성: 버튼 44px 이상, 키보드 포커스, 선택 상태 텍스트/aria-pressed, 모바일 단일 열, reduced-motion 지원.
- 기록: 과거 SNS 퀘스트와 XP 보존. 신규 작업은 WordPress 또는 서비스 운영. 공개 발행은 기존 WordPress 편집기에서 직접 수행.
- 검증: 서버 증빙·레벨 규칙 유지. 격리 렌더는 실제 View 컴포넌트 + 예시 데이터, CSP connect-src none. 실제 관리자 인증·운영 저장과 구분한다.

## 관리자 운영 길드 검증 범위

- 홈 NPC 대화와 WordPress 작업실은 실제 View 컴포넌트를 격리 렌더링했다. 예시 데이터이며 실제 계정 화면이 아니다. 네트워크 정책은 `connect-src none`이다.
- 데스크톱·390px 홈에서 마스터 선택, 문구와 이동 링크, 모바일 제목 줄바꿈을 확인했다. 별도 visual-checker가 캡처를 판정했고 제목 수정을 재확인했다.
- 작업실의 3개 실제 초안 편집 링크를 DOM에서 확인했다. WordPress 실시간 상태 동기화는 제공하지 않는다.
- 서버 저장·중복 방지·기존 XP 규칙은 mock 검사로 확인한다. 실제 운영 퀘스트를 생성하거나 XP를 지급하지 않았다.
- 신규 동작은 운영 배포 전이며 로그인 포함 통합 브라우저 검증, 작업실 전체 모바일·하단 화면은 별도 확인 대상이다.
- 자동 감지기의 선택 탭 강조선 경고는 상태 표시 용도로 유지했다. 선택은 색 외에도 aria-pressed로 제공한다. CLI polish 명령은 설치판에 없어 해당 reference 지침과 별도 시각 판정으로 마무리했다.
# 2026-10-21 추가 통합 검증

- 관리자 전용 영냥이 우는 표정을 투명 WebP로 교체했다. 원래 공용 표정 파일은 유지한다.
- `node scripts/preview-admin-guild.mjs`는 실제 관리자 React 화면·adminFetch·HQ 라우트를 메모리 DB에 연결한다. 로컬 토큰만 사용하며 외부 네트워크 차단, API 허용 목록, CSP를 적용한다. 운영 인증·Mongo 영속성의 검증 도구가 아니다.
- `node scripts/preview-admin-guild.mjs --verify`는 동일한 실제 라우트에서 생성 중복 방지, 증빙 없는 완료 거절, 완료 XP, 완료 되돌림, 재완료, 업적, 레벨 2 및 레벨업 확인 처리를 검증한다.
- 브라우저에서 신규 퀘스트 생성→증빙 없는 완료 차단→증빙 저장→완료 30 XP→되돌림→재완료 30 XP를 확인했다. 서버 통합 검증으로 만든 총 120 XP·레벨 2·첫 완료 업적도 실제 성장 화면과 홈에서 확인했다.
- 발견한 회귀: 퀘스트 완료 후 XP는 갱신되지만 업적 동기화는 호출되지 않았다. `refreshTaskXp`에서 XP 갱신 뒤 기존 `syncAchievements`를 호출하도록 수정했다. 업적은 기존 규칙대로 XP를 주지 않으며 완료를 되돌려도 유지한다.
- 원장·결제·환불·권한 지급·GA 송신·운영 배포는 실행하지 않았다. 실제 운영 저장, 운영 동시성, 페이지 전체 모바일 검증은 별도 확인 대상이다.
