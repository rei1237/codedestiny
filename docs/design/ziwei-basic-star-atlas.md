# 기본 자미두수 · 별 지도

## Overview

승인된 방향은 어두운 천문 지도 위에서 명반을 먼저 읽고, 궁별 풀이와 상담으로 이어지는 독립형 읽기 화면이다. 적용 범위는 기존 홈의 기본 자미두수 모달이며, 전역 디자인이나 `/ziwei` SEO 화면의 교체가 아니다.
구현 정본은 `styles/basic-fortune-library.css`의 자미두수 모달 전용 범위와 `js/core/saju/basicFortunePresentation.js`이다. 계산 데이터는 기존 엔진이 소유한다.

## Colors

짙은 바탕과 한 단계 밝은 읽기 면을 사용한다. 따뜻한 본문색은 긴 해석에, 금색은 선택된 궁·별 이름·탐색 링크에 사용한다. 구분선과 보조 설명은 각각 전용 중립색을 따른다.

## Typography

기존 글꼴을 재사용한다. 긴 해석 본문은 16px 읽기 크기를 유지하고, 해석 제목은 모바일에서 22px로 조정한다. 영문 소제목은 보조 표식이며 한국어 제목을 대신하지 않는다.
명반의 압축 정보는 모바일에서 궁명·주성 12px, 상세 별 표기 10px까지 사용한다. 이 밀도를 일반 해석 본문으로 확장하지 않는다.

## Layout

최대 본문 너비는 1100px이며 데스크톱 좌우 여백은 24px, 600px 이하에서는 10px이다.
프로필·출생 핵심 정보 → 내부 탐색 → 전체 명반 → 궁별 해석 → 인생 흐름 → 맞춤 상담 순서다.
명반은 처음부터 열린 4×4 격자이며 중앙 2×2를 제외한 12궁을 동시에 배치한다. 기본 간소 보기는 가로 스크롤 없이 주성을 보여주고 상세 전환을 제공한다. 각 셀은 애니메이션 실행 여부와 무관하게 보인다.
궁 선택은 데스크톱 6열, 모바일 4열로 12개를 모두 제공한다. 선택 시 해당 해석으로 이동한다. 인생 흐름표는 데스크톱 4열, 모바일 2열이다.

## Elevation & Depth

강한 그림자보다 면의 밝기와 얇은 경계로 구조를 만든다. 천문 지도는 도입부와 명반 중앙에만 분위기를 더하며 정보의 대비를 해치지 않게 어둡게 겹친다.

## Shapes

해석 면은 부드러운 모서리, 명반 셀은 작은 모서리로 역할을 구분한다. 선택된 궁에는 금색 경계와 명확한 선택 상태를 함께 제공한다.

## Components

- 명반·궁 선택: 모든 궁은 클릭 및 키보드로 선택하며 선택 상태를 전달한다. 홈 하단 탐색이 모달 조작을 덮지 않는다.
- 궁별 풀이: 12궁의 역할 → 실제 배치된 주성의 쉬운 뜻 → 강점과 조율점 → 생활 적용 → 함께 읽는 궁 순서다. 14주성 설명을 재사용한다.
- 별 구성 스펙트럼: 실제 주성·보조성·살성 개수를 보여준다. 차성은 대궁에서 참고하는 별임을 표시하고 본궁 주성 개수에서 제외한다. 공궁을 성향의 결핍으로 설명하지 않는다.
- 인생 흐름: 실제 `daHanList`의 나이 구간과 궁을 사용한다. 점수나 사건 예언을 만들지 않는다. 기본 풀이에서 대한 상세 안내로 연결하되 원래 리포트와 항목별 잠금·결제 동작을 유지한다.
- 상담: 14개 주제 선택과 상황별 질문 예시를 제공한다. 명시적인 주제는 요청·멱등 식별자·결제 복귀에 함께 전달한다. 실제 명반 근거와 현실적인 선택지를 구분한다.
- 언어: 기존 주요 탐색의 다국어 표기는 유지한다. 이번에 추가한 긴 궁별 설명과 상담 안내는 한국어이며 전체 번역 완료를 의미하지 않는다.

## Do's and Don'ts

- 사용할 장식 이미지: `/images/ziwei/celestial-atlas.webp` 하나뿐이다. 사용자 첨부 원본은 `C:/Users/user/AppData/Local/Temp/codex-clipboard-d948f086-b5b6-48e3-9d72-4ce51f0df95f.png`이며, 일치하는 기존 WebP를 재사용했다. 새 이미지 생성·편집은 하지 않았다.
- `ziwei-basic-chart-redesign-mockup.html`은 승인용 예시이며 가상 데이터다. 계산 결과나 해석 근거로 재사용하지 않는다.
- 에너지를 성공 확률·건강 진단·사람의 우열로 표현하지 않는다. 무료 미리보기를 위해 잠금 본문이나 결제 정책을 우회하지 않는다.
- 로컬 렌더 기록: `.impeccable/basic-fortune/after/`의 `ziwei-390.png`, `ziwei-1280.png`, `ziwei-energy-390.png`, `ziwei-flow-390.png`, `ziwei-consult-390.png`를 확인했다. 이는 배포 증거가 아니다.
- 기계 탐지는 한 차례 시행됐다. 측면 강조선 경고와 글자 크기 권고는 승인된 정보 강조 및 압축 명반의 지역적 예외로 기록하며, 일반 본문은 16px를 유지한다.
- 마무리 검토의 홈 탐색 겹침, 궁 선택 후 이동, 예전 레이더 안내, 공궁의 차성 안내, 상담 캡처 시점 등 다섯 항목은 수정됐다. CI·스테이징·운영 상태는 이 디자인 문서에서 보장하지 않는다.
