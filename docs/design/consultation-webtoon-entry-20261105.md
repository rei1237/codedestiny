## 요청과 구현

- 사용자 요청: 기존 인생의 책·신년운세 등 상담 전 웹툰을 활용해 공감과 재미를 높이고, 상담의 성격과 얻는 도움을 직관적으로 보여준다. 공식 홈과 꿀꿀운세 진입점에 기존 설치 기능을 활용한 홈 화면 추가 버튼을 제공한다.
- 13종 이야기와 도움 3가지는 `lib/brand/consultation-stories.mjs`에서 공유한다. 기존 상담 주소·가격·전문가 배정은 registry와 기존 데이터가 정본이다.
- 상담 상세는 제목·고민·도움·웹툰/상담 선택 다음에 원본 웹툰을 넓게 표시한다. 긴 서장은 뒤로 옮기고 HTML 대사를 선택해서 읽게 한다. 그림은 개인 결과가 아닌 예화임을 표시한다.
- 상담 목록과 공식 홈은 전체 웹툰을 축소하지 않고 첫 컷을 미리보기로 사용한다. 기존 자산 13종을 직접 확인했으며 첫 컷 높이는 724px 너비 기준의 시각 검토값이다. 그림 파일은 변경하지 않는다.
- 정적 홈의 기존 직접 상담 링크·대표 팝업용 속성은 유지하고, 그 밖에 웹툰 링크를 둔다. 다른 전문가 상담 7종은 같은 소개 데이터로 연결한다.
- 기존 PWA lifecycle을 재사용한다. 수동 설치 진입점을 동기화하고 standalone·native·appinstalled 상태에서 기존/신규 진입점을 숨긴다. 자동 배너·서비스워커 안전 판정·업데이트 정책은 유지한다.
- 인생의 책의 ‘이번엔 진짜!’, 신년운세의 ‘계획표는 벌써 과로 중’처럼 상황에 웃을 수 있는 대사를 사용한다. 사용자를 비하하거나 운세 결과를 보장하지 않는다.
