## 구현된 홈 구성

정적 셸 `/ggulggul/`의 홈 마크업은 `templates/home-funnel.html`, 스타일은 `styles/home-funnel.css`에서 관리한다. 템플릿을 `scripts/design/build-home-funnel.mjs`로 반영한 `index.html`과 public 미러를 사용한다. 전역 디자인 토큰이나 다른 서비스의 화면 구성으로 이 배치를 확대하지 않는다.

| 영역 | 현재 표현 |
|---|---|
| 헤더와 모드 | 브랜드·로그인/내 계정·언어 선택 아래에 상담가 이름으로 구분하는 연이/네오 전환을 둔다. 기존 모드 슬롯과 컨트롤러를 사용한다. |
| 히어로 | 왼쪽에 HTML 제목·짧은 소개·`운세 골라보기`, 오른쪽에 투명 캐릭터. 배경은 별도 이미지다. 연이는 연꽃 정원, 네오는 자주빛 천문 서재로 전환한다. |
| 여섯 운세 | 사주·자미두수·숙요점·베다점·점성술·타로의 그림과 이름을 함께 표시한다. 640px 이하에서는 3열 2행, 그 위에서는 6열이다. 타로는 기존 타로 컬렉션으로 연결한다. |
| 검색 | 여섯 바로가기 아래에 작은 검색 영역을 둔다. 장식형 대형 패널을 쓰지 않고 검색 입력과 기존 필터를 유지한다. 시각 검토의 최종 네오 캡처에서 390/1440px 검색 영역 높이는 110px로 보고됐다. |
| 이어지는 콘텐츠 | 고민 선택, 모드별 상담실 링크, 영냥이 입구를 이어 놓고 부가 콘텐츠는 기존 `더 둘러보기` 안에서 제공한다. |

모바일 히어로는 최소 높이 246px, 좌우 60:40 구성이다. 데스크톱은 최소 높이 400px, 좌우 1.2:0.8 구성이다. 제목은 기존 `CodeDestinySerifKR`, 조작 요소는 기존 본문 글꼴을 사용한다. 운세 그림의 표시 크기는 모바일 52px, 데스크톱 64px이며 각 원본은 160px WebP다. 이 수치는 홈 소스에서 확인한 값이며 제품 전체의 새 스케일 규칙은 아니다.

## 보존할 계약

중복 CTA·인사·장식의 노출을 정리하되 카탈로그와 DOM 검색 대상을 보존한다. 언어·모드·프로필·결제 복귀·보관함은 기존 컨트롤러를 사용한다. 결제 정책, 이용권·월정석·단건 결제 구조, 인증, 계산 엔진, API·DB·결과 계약은 이 디자인의 변경 범위에 포함하지 않는다. 실제 클릭 경로와 회귀 검사는 mock 검증으로 별도 확인한다.

## 에셋 출처

신규 원화는 built-in `image_gen`으로 생성했다. 사용자가 제공한 꽃돼지 프로필 `image-1.png`와 사자 프로필 `image-2.png`를 캐릭터 정본으로 사용했다. 이미지 안에 UI 문구를 넣지 않고, 제목과 버튼은 HTML로 유지한다.

| 자산 | 출처와 변환 |
|---|---|
| 연이·네오 캐릭터 | 연꽃·보라 스카프의 꽃돼지, 갈기·이마 네 무늬·붉은 망토의 사자. 투명 배경 원화를 Sharp로 320/480/800px WebP로 변환하고 `srcset`으로 제공한다. |
| 연이 정원·네오 서재 | 캐릭터 없는 별도 배경 원화. 왼쪽 문구 공간을 비워 두며 640/1280px WebP를 뷰포트에 맞춰 사용한다. |
| 여섯 운세 그림 | 3열 2행 스프라이트 원화 생성 후 `image_gen`으로 배경을 제거했다. Sharp로 셀을 분리하고 각각 160×160px WebP(quality 85, alpha 100)로 변환했다. |

배포 자산 위치는 `public/images/home/illustrated/`다. 프롬프트·참조 이미지·원화 파일명·출력 경로는 [홈 캐릭터와 배경 명세](ggulggul-home-art.json), [여섯 운세 그림 명세](ggulggul-method-art.json)가 정본이다. 생성 원본은 저장소 밖에 보존하며 이 문서는 원화 자체를 포함하지 않는다. 헤더의 연이 마크와 영냥이 입구 그림은 기존 자산을 재사용한다.

## 시각 검토 결과와 증거

2026-10-03 finish review에서 **SHIP** 판정을 받았다. 설치된 이름 전용 프리셋이 아닌 일반 협업 에이전트가 시각 검토를 수행했다. 검토 범위는 연이·네오 두 모드의 360/390/430/1440px 화면과 마지막 검색 영역 축소다.

로컬 캡처는 `build-cache/home-art/`에 있다.

- 양 모드 기본 화면: `yeoni-{360,390,430,1440}.png`, `neo-{360,390,430,1440}.png`
- 전체 페이지: `yeoni-{390,1440}-full.png`, `neo-{390,1440}-full.png`
- 마지막 검색 조정: `search-neo-390.png`, `search-neo-1440.png`

위 경로는 로컬 검토 산출물이며 저장소에 포함된 배포 이미지가 아니다. SHIP은 캐릭터 식별, 장면과 문구 분리, 바로가기 밀도, 모드 구분, 검색 크기의 시각적 수용 판정이다. 기능 검사와 CI 결과는 별도 실행 증거로 보고하며, 이 문서만으로 실결제·실 LLM·운영 DB·운영 화면의 검증을 주장하지 않는다.
