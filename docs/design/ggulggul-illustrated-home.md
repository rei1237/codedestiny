## 구현된 홈 구성

정적 셸 `/ggulggul/`의 홈 마크업은 `templates/home-funnel.html`, 스타일은 `styles/home-funnel.css`에서 관리한다. 템플릿을 `scripts/design/build-home-funnel.mjs`로 반영한 `index.html`과 public 미러를 사용한다. 전역 디자인 토큰이나 다른 서비스의 화면 구성으로 이 배치를 확대하지 않는다.

| 영역 | 현재 표현 |
|---|---|
| 헤더와 모드 | 브랜드·로그인/내 계정·언어 선택 아래에 상담가 이름으로 구분하는 연이/네오 전환을 둔다. 기존 모드 슬롯과 컨트롤러를 사용한다. |
| 히어로 | 왼쪽에 HTML 제목·짧은 소개·`운세 골라보기`, 오른쪽에 투명 캐릭터. 배경은 별도 이미지다. 연이는 연꽃 정원, 네오는 자주빛 천문 서재로 전환한다. |
| 여섯 운세 | 사주·자미두수·숙요점·베다점·점성술·타로의 그림과 이름을 함께 표시한다. 640px 이하에서는 3열 2행, 그 위에서는 6열이다. 타로는 기존 타로 컬렉션으로 연결한다. |
| 검색 | 여섯 바로가기 아래에 작은 검색 영역을 둔다. 장식형 대형 패널을 쓰지 않고 검색 입력과 기존 필터를 유지한다. 이전 시각 검토의 네오 캡처에서 390/1440px 검색 영역 높이는 110px로 보고됐다. |
| 상담실 포털 | 고민 선택 다음에 모드별 운명의 찻집/팩폭 전략실과 영냥이 입구를 그림 카드로 묶는다. 큰 공백을 줄이고 데스크톱 2열, 640px 이하 모바일 1열로 배치한다. |
| 대표 상담 | 대표 상담·초융합은 `더 둘러보기` 외부에 상시 노출한다. 모바일에서 기존 96px 세로 크롭을 제거하고 원화 전체 비율을 보존한 이미지 아래에 텍스트를 놓는다. 마스터 인연·네오 두 서비스도 접기 영역 밖에서 모드에 관계없이 노출한다. |
| 페이지 배경 | 달꽃 WebP를 홈 배경의 별도 레이어로 적용한다. 위쪽 기준 한 장만 표시하며 반복하지 않고 불투명도는 0.32다. |
| 더 둘러보기 | 이름은 `연이의 아틀리에 더 둘러보기`로 정리하고 기존 달꽃 WebP를 재사용한다. 부가 콘텐츠는 이 접기 영역에 둔다. |
| 구독과 푸터 | 이메일 구독은 편지형 표면으로 표현한다. 푸터 가이드는 데스크톱 4열로 정리하며 기존 모바일 아코디언을 유지한다. |

모바일 히어로는 최소 높이 246px, 좌우 60:40 구성이다. 데스크톱은 최소 높이 400px, 좌우 1.2:0.8 구성이다. 제목은 기존 `CodeDestinySerifKR`, 조작 요소는 기존 본문 글꼴을 사용한다. 운세 그림의 표시 크기는 모바일 52px, 데스크톱 64px이며 각 원본은 160px WebP다. 이 수치는 홈 소스에서 확인한 값이며 제품 전체의 새 스케일 규칙은 아니다.

포털 카드는 데스크톱 최소 높이 212px·간격 18px, 모바일 최소 높이 176px·간격 14px다. 운명의 찻집 카드에는 인간 연이의 한복 이미지를, 네오 모드 입구에는 은발 인간 네오를 사용한다. 첫 히어로의 꽃돼지 연이와 사자 네오는 유지한다. 모드 전환 행은 콘텐츠가 들어오기 전부터 최소 높이 48px를 확보한다.

## 보존할 계약

중복 CTA·인사·장식의 노출을 정리하되 카탈로그와 DOM 검색 대상을 보존한다. 언어·모드·프로필·결제 복귀·보관함은 기존 컨트롤러를 사용한다. 결제 정책, 이용권·월정석·단건 결제 구조, 인증, 계산 엔진, API·DB·결과 계약은 이 디자인의 변경 범위에 포함하지 않는다. 실제 클릭 경로와 회귀 검사는 mock 검증으로 별도 확인한다.

## 시각 검토 결과와 증거

2026-10-03 최초 finish review에서 **SHIP** 판정을 받았다. 설치된 이름 전용 프리셋이 아닌 일반 협업 에이전트가 시각 검토를 수행했다. 이때 범위는 연이·네오 두 모드의 360/390/430/1440px 화면과 검색 영역 축소이며, 이후 추가한 달꽃 배경·인간 연이 포털·대표 상담 상시 노출까지 승인한 판정은 아니다.

로컬 캡처는 `build-cache/home-art/`에 있다.

- 양 모드 기본 화면: `yeoni-{360,390,430,1440}.png`, `neo-{360,390,430,1440}.png`
- 전체 페이지: `yeoni-{390,1440}-full.png`, `neo-{390,1440}-full.png`
- 마지막 검색 조정: `search-neo-390.png`, `search-neo-1440.png`

달꽃·포털·대표 상담 노출판 캡처는 같은 디렉터리의 `moon-{pig,neo}-{390,1440}.png`, `portals-{pig,neo}-{390,1440}.png`, `featured-{pig,neo}-{390,1440}.png`다. 이 단계는 후속 finish review에서 **SHIP** 판정을 받았다. 모바일 대표 상담·초융합의 실제 스크롤 노출과 기존 CDN 카드 이미지 로딩을 확인했다. 초기 캡처의 공백과 이미지 실패는 캡처 대기 및 외부 자산 차단에 따른 것으로, 수정된 캡처에서는 재현되지 않았다.

그 이후의 최종 추가 캡처는 `cards-{pig,neo}-{360,390,430,1440}.png`, `atelier-{pig,neo}-{360,390,430,1440}.png`, `letter-{pig,neo}-{360,390,430,1440}.png`, `footer-{pig,neo}-{360,390,430,1440}.png`다. **이 최신 추가판도 별도 시각 검토에서 SHIP**으로 판정됐다. 대표 상담의 원화 보존, 새 인물 이미지, 아틀리에, 이메일과 푸터를 확인했다. 인물의 최종 증거는 회색 배경을 제거한 `master-{pig,neo}-{390,1440}.png`와 `neo-service-{pig,neo}-{390,1440}.png`다.

## 성능 확인 범위와 한계

확인 범위는 홈·운명의 찻집·네오·영냥이 4개 표면이다. 찻집의 모바일 무한 반복 입자는 16개에서 0개로 줄였고 데스크톱 16개는 유지했다. 네오의 원격 캐릭터에는 640px 리사이즈를 적용했다.

네오 원격 이미지의 정적 CDN GET에서 원본 WebP 176,026bytes와 리사이즈 응답 AVIF 60,411bytes를 확인했다. 해당 응답 바이트는 65.7% 작지만 CDN 자동 포맷 변환이 섞인 비교이므로 리사이즈만의 효과나 페이지 전체 속도 개선율로 해석하지 않는다.

모드 행의 48px 예약 높이 적용 후 로컬 mock·CPU 4배 감속 조건에서 CLS 0.0423이 보고됐다. 실제 사용자 현장 측정이나 운영 성능 수치가 아니며, 비교 가능한 전후 기준이 없으므로 개선율을 주장하지 않는다.

Next 개발 서버에서 얻은 수치를 운영 LCP로 제시하지 않는다. 큰 초기 JavaScript는 코드 분리·의존성 범위의 별도 과제여서 이번에 수정하지 않았으며 잔여 과제로 남긴다. 이 기록은 네 표면의 전체 성능 해결이나 운영 측정 완료를 뜻하지 않는다.

위 경로는 로컬 검토 산출물이며 저장소에 포함된 배포 이미지가 아니다. 이전 SHIP은 캐릭터 식별, 장면과 문구 분리, 바로가기 밀도, 모드 구분, 검색 크기의 시각적 수용 판정이다. 기능 검사와 CI 결과는 별도 실행 증거로 보고하며, 이 문서만으로 실결제·실 LLM·운영 DB·운영 화면의 검증을 주장하지 않는다.

아틀리에 앞에는 기존 yeoni-character-320.webp를 52×52px로 재사용한다. 지연 로딩과 고정 치수로 추가 원화 다운로드와 레이아웃 이동을 피한다.
