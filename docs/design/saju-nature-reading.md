# 사주 물상 리딩

## Overview

실제 일간·월지·대운 간지를 자연 도판으로 풀어내는 사주 읽기 화면이다. 반복 캐릭터 장식을 자연의 물상으로 바꾸고, 일간 → 태어난 월의 계절 → 해석 근거 → 현재 흐름 → 권한 확인된 종합·대운 상세 순서로 읽는다.

적용 범위는 사주 무료 풀이와 유료 종합·대운 결과 화면이다. 전역 디자인 체계는 변경하지 않으며, 이 문서가 해당 로컬 화면의 구현 기록이다. CSS 정본은 `styles/saju-reading.css`, 도판 매핑은 `js/core/saju/reading-rich.js`에 있다.

## Colors

오행은 색과 문자 이름을 함께 표시한다. 은백 계열 금은 밝은 화면에서도 식별되도록 회청색을 사용한다.

| 오행 | 기본 화면 | 네오 화면 |
| --- | --- | --- |
| 목 · 청록 | `#17766b` | `#8bd4ba` |
| 화 · 주홍 | `#c24732` | `#f29b85` |
| 토 · 황토 | `#a87925` | `#dfbd73` |
| 금 · 은백 | `#8196a5` | `#dce4ed` |
| 수 · 청색 | `#285e94` | `#9ac7ef` |

`--reading-el-*`를 참조하며 도판 캡션은 오행색 12%, 테두리는 45% 혼합으로 연결한다. 본문은 기존 `--reading-ink`, 보조 설명은 `--reading-muted`를 따른다.

## Typography

기존 명조 `--font-serif`와 본문 `--font-body`를 유지한다. 도판 제목은 `clamp(1.2rem,3vw,1.65rem)`, 굵기 700, 줄높이 1.5이며 캡션 설명은 `.875rem`, 줄높이 1.7이다. 유료 대운 본문은 `1rem`, 줄높이 1.9로 읽고 최대 폭을 `72ch`로 제한한다. 한글은 `word-break:keep-all`을 사용하고 긴 본문은 `overflow-wrap:anywhere`로 넘침을 막는다.

## Layout

도판 → 물상 제목·오행 이름 → 요약 → 단일 열 해석 순서다. 기존 계산 근거 펼치기를 유지한다. 도판은 3:2 비율이며 480/960 너비 `srcset`, 명시적 크기, 지연 로딩을 사용한다. 캡션 패딩은 `20px 24px`, 600px 이하에서는 `16px`이다. 오행 범례는 줄바꿈을 허용한다.

## Elevation & Depth

신규 그림자 없이 기존 카드 배경, 얇은 테두리와 오행색의 옅은 면으로 구역을 나눈다. 유료 본문은 도판 사이 여백과 소제목 구분선으로 읽기 흐름을 만든다.

## Shapes

도판은 기존 `--cd-r-md`(fallback 16px), 대운 썸네일은 `--cd-r-sm`(fallback 8px)을 따른다. 오행 범례의 원형 표시는 12px이며 문자 라벨과 항상 함께 놓는다.

## Components

- 일간 도판: 갑 큰 나무, 을 풀과 꽃, 병 태양, 정 등불, 무 산, 기 흙, 경 원석, 신 보석, 임 바다, 계 비와 이슬. 실제 일간 천간에 대응하며 무작위 선택을 하지 않는다.
- 계절 도판: 실제 월지 `寅卯辰`은 봄, `巳午未`는 여름, `申酉戌`은 가을, `亥子丑`은 겨울이다. 달력 월이 아닌 절기 기준 월지를 사용한다.
- 대운 도판: 선택한 대운 천간에 대응한다. 서버 응답으로 전달된 대운 본문의 천간이 있으면 이를 우선한다.
- 유료 결과 장식: 권한 확인 후 받은 본문에 `decorateDelivered`가 도판을 붙인다. 요약 fallback은 장식하지 않는다. 서버 본문과 요청·권한 판정을 변경하지 않는다.
- 이미지 출처: 네이티브 `image_gen` 생성 원본 14종(일간 10종·계절 4종), 배포용 WebP 28개(480/960). 각 WebP에 XMP 프롬프트 메타데이터를 보존하며 `docs/design/saju-nature-assets.json`에 프롬프트·원본·출력 경로를 기록한다.

## Do's and Don'ts

- 도판은 성질을 이해하는 자연의 비유다. 새로운 길흉 판정이나 결과를 추가하지 않는다.
- 계산 결과를 읽어서 표시한다. 사주 계산, 인증, 서버 권한, API·DB 계약을 바꾸지 않는다.
- 이용권·월정석·단건 결제 정책, 가격, 차감과 결제 후 전달 절차를 유지한다.
- 물상과 오행 이름을 문자로 제공하고 기존 해석 본문과 근거를 보존한다.

## 2026-10-18 종합 풀이 챕터 도판 보완

기존 5개 챕터 앞 도판을 16개 전체 챕터 본문 안의 도판으로 연결한다. 총평은 실제 일간, 조후·월령은 실제 월지의 계절을 쓰며, 억부·오행·십성·성격·진로·연애·신살·회복·재물·귀인·개운·전략·올해와 내년은 각 주제의 자연 비유를 쓴다. 상징 그림이 새로운 계산 결과나 예측으로 읽히지 않도록 캡션에서 구분한다. 기존 480/960 WebP와 지연 로딩을 재사용한다.

도판은 챕터의 접기·펼치기를 따르고, 재장식 시 중복되지 않는다. 본문 문자열·챕터 순서·계산·권한·결제 로직은 유지한다. 요약 fallback에는 이미지를 넣지 않으며, 종합 결과의 중복 일간 표지는 제거하고 대운 표지는 유지한다.

검증: 한국어·다국어 Node 테스트 26개 통과. mock Chromium 360·390·430·1440px에서 16개 챕터 이미지 로딩, 접기·펼치기, 가로 넘침 없음, 계산값 유지 확인. 실결제·운영 권한 변경 없이 서버 렌더러의 응답 fixture로 검증했다.
