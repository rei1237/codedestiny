# 초융합 프리미엄 읽기 경험

2026-10-08 · 대상 `/fusion-fortune`, 초융합 보관함 · 모드: 생성 Experience, 결과 Read.

## 결정

- 여섯 체계의 해석이 교차 종합으로 모이는 장면을 한 곳에 둔다. `stageStates`, 저장된 `result.*Section.content`, `composeProgress`만 진행 근거로 쓴다. 경과 시간으로 완료율을 올리지 않는다.
- 상태 표시는 실제 결과와 함께 남으며, 도착한 첫 해석으로 이동할 수 있다. 애니메이션은 본문 표시나 재시도를 지연하지 않는다. 반복되는 생성 말풍선은 이 장면으로 대체한다.
- 화면 밖·숨긴 탭·중단 상태에서는 모션을 정지한다. 사용자의 정지 버튼과 reduced-motion을 지원한다.
- 제목은 기존 자체 호스팅 명조·Cinzel 스택, 본문은 1.06rem(데스크톱 1.125rem), 행간 1.95를 유지한다. 챕터 제목을 키우고 조작 문구는 본문 산세리프로 분리한다. 핵심 문장은 중첩 카드 대신 여백과 가는 구분선으로 정리한다.
- 기존 `public/images/fusion-fortune/orbs/*.webp`를 72px 챕터 삽화로 재사용한다. 종합은 core, 마지막 메시지는 `fusion-guardian-celestial-hero.webp`를 한 번 쓴다. 타로는 실제 저장된 카드만 결과 근거로 보여주며 새 카드를 만들지 않는다.
- 챕터 삽화는 장식이므로 빈 alt/aria-hidden, lazy loading, 고정 비율을 사용한다. 텍스트 PDF에는 넣지 않고 캡처 내보내기에서도 제외한다. 기존 결과 본문·근거·목차·접힘 해제 계약은 유지한다.
- 첫 챕터의 기본 열린 상태와 사용자가 명시적으로 닫은 상태를 구분한다. 첫 챕터도 키보드와 버튼으로 닫고 다시 열 수 있다.
- 공감 프롬프트는 질문의 선택·망설임 → 실제 근거 → 강점이 부담이 되는 조건 → 작은 행동으로 연결한다. 원문 질문·개인정보를 추가 전송하지 않는다. 분량 하한이나 재시도 횟수는 올리지 않으며, 기존 저장본을 재생성하지 않는다.

## 보존 경계

계산 엔진, 결제·이용권·월정석·단건 결제 정책, 인증, API 응답, DB 스키마, 고객 복구 결과를 유지한다. 한국어·영어·일본어·중국어 카피를 제공하고 나머지 로케일은 기존 로케일 방식에 따라 영어로 폴백한다.
