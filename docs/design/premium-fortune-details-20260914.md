# 프리미엄 상품 상세 개편 검증 기록

## 적용 위치

유료 서비스 실행 전 정적 셸 상세창과 React 상품 상세 모달이 주 적용 대상이다. 독립 소개 URL과 마스터 인연의 서 시작 전 본인편·궁합편 소개도 같은 표시 시스템을 사용한다. 기존 한국어 설명 블록과 공통 SVG 미리보기는 새 상세에서 노출하지 않는다. 비한국어 기존 표시와 상품 실행 컨트롤러는 유지한다.

## 디자인과 제작

달빛 아래 펼치는 운명 화집: 아이보리·잉크 네이비와 상품별 강조색, 자체 장면 일러스트, HTML 제목과 핵심 결과, 고민, 실제 구성, 검증 가능한 상품의 샘플·풀이 방식. 청월당의 짧은 고민과 이미지 중심 정보 구조만 참고했으며 경쟁사 이미지나 문구를 사용하지 않았다.

74개 공개 상세에 서로 다른 Hero를 배정했다. 본인편·궁합편 및 스토리 컷을 포함한 원본 77장의 제작 기록은 fortune-detail-art.jsonl에 있다. 76개 조사 항목 중 points·saju-animal은 기존 미검증 상태를 유지한다. 정적 D의 유료 상세 키는 모두 공개 카탈로그 별칭에 대응한다.

## 확인한 결과

- 정적/React 상세: 360·390·430px 가로 넘침 없음. 데스크톱 이미지·본문 분할 확인.
- React 상세: 첫 CTA가 화면을 벗어난 후 하단 CTA 표시, Escape 닫기, 트리거 포커스 복귀, 브라우저 뒤로가기 확인.
- 정적 상세: 기존 터치 모바일 backstack 유지. 비터치 브라우저 뒤로가기 닫기·앞으로가기 재열기 확인.
- Pilot: 본인편·궁합편의 가격·이미지·목차 구분과 기존 프롤로그 1/9 진입 확인. 실제 과금/LLM 실행 없음.
- 상세 전용 node 검사 10/10, Pilot mock flow 통과. 결제 mock suite 88/88 통과.
- Hero 최대 104,260 bytes, 카드 최대 15,418 bytes, OG 최대 164,840 bytes. Hero 480/960 srcset, 하단 lazy 이미지, 고정 치수 사용. 공통 renderer 8,569 bytes. 새 폰트/캔버스 없음.
- 카탈로그와 상품 요청은 promise cache, 실패 시 재시도. CTA는 기존 가격 상태를 공유하며 자체 결제/생성 요청을 만들지 않는다. 가격 실패를 무료로 표시하지 않는다.

## 검증 범위의 한계

로컬 개발 화면과 mock 회귀는 실기기 결제·실제 카카오 공유·현장 INP·운영 전환율의 증명이 아니다. 동일한 production build에서 변경 전후 LCP/CLS 반복 측정, 전체 상품의 개별 수동 키보드/스크린리더/200% 확대 확인은 별도 증거가 필요하다. 자동 에셋·스키마·URL 검사는 전체 공개 상품에 적용했으며 모든 상품을 각각 수동으로 완주했다고 주장하지 않는다.
