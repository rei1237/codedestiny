## 화면 계약

- 영냥이 한국어 상품 안내: 고민 → 선택 구성의 가격 → 펼쳐진 결과 예시 → 사주 상품에 한정한 참치 이용자 후기 → 제공 내용·등급 비교 → 기존 상담 준비 경로.
- 영냥이 예시는 `product-curiosity.ts`의 기존 문체 정본을 사용한다. 개인 결과로 표시하지 않는다. 선택 등급은 가격·목차·하단 진입 URL에 함께 반영한다.
- 참치 이메일은 `lib/brand/trust-stories.mjs` 원문을 재사용한다. 명식 오류 정정 후 재분석한 경험임을 표시하고 전체 원문을 읽을 수 있게 한다. 타로·다른 체계에는 이 후기를 넣지 않는다.
- 공통 소개: 기존 상품 hero 다음에 결과 예시를 펼쳐 보여준다. 목차·제공 내용·계산 방식은 그대로 유지한다. 사람 1:1 상담 후기는 AI 상품 후기와 구분한다.
- 운명의 찻집: 연이의 이야기·찻잔 선택을 유지하며 첫 화면에서 상담 예시로 바로 이동한다. 예시는 상담 방식 선택보다 앞에 둔다.
- 마스코트 원본과 세계관은 유지한다. 영냥이 독립 상품 안내의 그림 높이만 제한해 결과 설명까지의 거리를 줄인다.

## 콘텐츠와 범위

`index.html`의 `FEATURE_VISUAL_DETAILS`가 공통 상세의 정본이다. 신규 샘플 24개는 기존 상품 목차를 바탕으로 작성한 가상의 편집 예시이며 실제 고객 결과가 아니다. 개인화된 예측이나 효과 보장을 추가하지 않는다.

구현 시 로컬 집계: 공개 소개 74개, 본문 예시 52개. 무료로 분류되지 않았고 기존 결제 레지스트리에서 확인되거나 paid로 표시된 소개 51개 모두에 예시가 있다. 이 수치는 주문 가능한 모든 SKU·등급·상담 종류를 전수 구매한 결과가 아니다. 무료 계산기 안의 추가 유료 기능, 허브, 별칭은 별도 범위다.

동기화: `npm run sync:public`. 생성 JSON과 public 미러를 직접 편집하지 않는다. 커버리지·HTML escaping·기존 CTA 위임은 `__tests__/ui/feature-visual-details.test.mjs`, `feature-detail-preview.test.mjs`에서 확인한다.

## 계측 해석

영냥이 안내의 `content_id`는 `result-preview-v2`다.

- `product_detail_view`: 기존 상세 진입 이벤트.
- `product_sample_open`: 이번 버전에서는 펼쳐진 예시로 이동하는 버튼 클릭. 이전 버전의 details 열기와 동일한 행동으로 비교하지 않는다. 자동 스크롤 노출이나 완독률이 아니다.
- `product_review_open`: 이메일 원문 펼치기. 사주 안내에만 적용한다.
- `product_tier_select`: 구성 선택. 선택된 상품 item_id를 전달한다.
- `product_start_click`: 기존 상담 준비로 이동. 구매 확정이 아니다.

입력 질문·출생 정보·후기 본문은 계측 파라미터에 넣지 않는다. 기존 동의·GA 초기화 경로를 그대로 사용한다. 구매는 서버 확인 주문과 중복 제거된 구매 이벤트를 대조하며 이용권·월정석 사용과 신규 현금 구매를 구분한다.

## 실제 성과 확인
