# 화면을 채우는 나만의 연화당

2026-11-16 사용자 요청: 작은 장면 카드 대신 전체 화면 몰입, 직관적인 힐링 UI, 무료 실제 목탁 녹음 적용.

## Direction contract

- THESIS: 설명을 읽는 페이지에서 직접 머무는 사찰로 전환한다. 풍경이 첫 화면 전체를 차지한다.
- OWN-WORLD: 기존 금빛 사찰 그림과 연이 원본, 남색·옥빛·연보라·금빛 조작부, 기존 주아체·Pretendard를 유지한다.
- STORY: 장소 선택 → 명상·기도·108배·확언 → 필요할 때만 활동 패널. 혼자만의 공간이라는 안내는 짧게 남긴다.
- FIRST VIEWPORT: 상단 작은 제목·장소 전환, 중앙 큰 캐릭터와 풍경, 하단 활동 메뉴. 목탁·음악·사진은 명확한 이름으로 제공한다. 패널은 데스크톱 옆, 모바일 하단에 열리고 풍경은 뒤에 유지된다.
- FORM: 승인된 달빛 예화 세계의 몰입형 공간을 코드로 구현한다. 새로운 콘셉트 선택이나 원본 그림 재제작은 하지 않는다.
- FINISH: 실제 화면·모바일 폭·키보드·음원 실패·음소거·중복 재생·사진 저장을 검수한다. 미확인 실기기는 미검증으로 남긴다.

## 기능 경계

기존 프로필·세션·기록·음악 컨트롤러를 재사용한다. URL/뒤로 가기와 noindex 정책을 유지한다. 전체 화면 API는 사용자 버튼으로만 요청하고 지원하지 않는 기기에서도 화면을 채우는 레이아웃은 사용 가능하다. 회전은 강제하지 않는다.

목탁 음원은 jonopodmore의 Mokugyo.wav, Freesound 607215, CC0. 일본 고야산의 작은 목어를 실제 타격한 녹음이며 한국 사찰 현장 녹음이라고 표현하지 않는다. 공개 HQ MP3 프리뷰를 변형 없이 자체 호스팅하며 출처와 해시를 자산 manifest에 기록한다. 자동 재생 없음.

롤백은 이 작업 커밋만 revert 후 정규 CI/릴리스 절차를 따른다. 데이터 변경 없음.

## 구현 검수 — 2026-11-16

- Chromium 에뮬레이션 360×800, 390×844, 430×932, 844×390와 데스크톱 1440×900에서 가로 넘침 없음. 별도 시각 검수에서 캐릭터·패널 겹침 없음. 짧은 가로 화면은 원본 비율을 유지하고 같은 풍경을 흐린 측면으로 확장하며, 소품 기능은 하단 메뉴로 제공한다.
- 브라우저 전체 화면 진입·종료, 미지원 안내, 풍경 모드와 메뉴 복귀, 108배 시작·일시정지, 장소 이동 완료, 명상·확언·운세·기록·음악·꾸미기 패널을 확인했다. 모바일 패널이 열린 채 풍경 모드에서 복귀하면 숨겨진 상단 버튼 대신 활동 제목으로 키보드 초점을 돌린다.
- 실제 음원 디코딩 길이 1.827초, 스테레오. 연속 타격에서 이전 소스 정지 후 새 소스 시작, 음소거 정지, 파일 차단 오류 안내와 차단 해제 후 재시도 성공을 확인했다. 음악 재생 상태와 별개다.
- 변경된 장면에서 인증샷 촬영·캐릭터 위치 변경·918×612 PNG 다운로드 확인. 저장 그림에는 UI가 섞이지 않고 캐릭터가 한 번만 출력된다.
- Android·iPhone 실기기 및 실제 사진첩·공유 대상 저장은 연결 환경 부재로 미검증이다. 브라우저 에뮬레이션을 실기기 결과로 보고하지 않는다.
- 캐릭터 원본·108배 집계/복원·개인 기록 저장·음악 컨트롤러·인증·결제·API·DB 변경 없음. 기존 noindex 및 링크 목적지를 유지한다.
