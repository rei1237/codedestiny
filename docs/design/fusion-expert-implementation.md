# 초융합 전문 데이터 고도화 검증 기록

기준: 2026-09-10. 사용자 승인 범위는 전문 데이터 최소 확장, 독립 분석/근거 비교, 같은 결제 요청의 복구, 승인된 960px 목업 구현이다.

## 변경 의도

- 기존 격국 판정 경로를 재사용하고 용신·대운·세운, 자미 12궁·사화, 서양 하우스·트랜짓, 숙요 일진 관계, 베다 다샤 기간을 어댑터에 연결했다. 신규 요청은 전문 데이터가 준비돼야 생성한다.
- 여섯 계산은 병렬이며 전문가 입력은 자기 체계로 한정한다. 근거 경로를 검증한 독립 결론만 주제·시기별로 비교한다. 심리의 타로 등 영역별 우선 근거를 사용하고 실제 차이가 없는 상충을 만들지 않는다.
- v2에는 임의 월별 점수·합의율 도표가 없다. 실패 그룹을 mock 문구로 채우는 실생성 경로를 제거했다. 완료된 그룹은 기존 요청 보관 구조에 체크포인트로 저장하고 누락 그룹만 재시도한다.
- 요청·언어·계산/프롬프트 버전·계산 기준일을 고정한다. 신규 생시·출생지 필수 검사는 결제 게이트 앞에 위치한다. 이전 저장본과 결제 요청은 v1 경로를 유지한다.
- 요청 ID 기반 타로 카드를 정역방향·여섯 포지션과 함께 보존하고 기존 이미지로 뒤집기 공개를 제공한다. 960px 폭과 키보드·reduced-motion 대응을 유지한다. 새 UI 문구는 로케일 키(한국어/영어 기본 번역, 다른 로케일은 영어 폴백)를 사용한다.

## 검증 출력

- `npm ci --ignore-scripts --no-audit --no-fund`: 성공. lockfile 변경 없음.
- `npm run worktree:status`: 격리 워크트리, active uncommitted overlap 0. 다른 완료 브랜치의 Fusion client 중첩은 존재하므로 main과 순서 통합한다.
- `npm run check:fast -- --plan`: critical 승격. `npm run check:fast`: exit 0, Node 1,008/1,008, Jest 222 suites / 2,456 tests 통과. lint는 기존 경고 포함, typecheck·결제 정책·Worker build 통과.
- `node scripts/verify-fusion-expert.mjs`: PASS. 실제 로컬 사주/자미/숙요 계산, mock 천문 경로, 6개 병렬 진입, 입력 격리, 근거 참조 거절, 영역별 우선순위, 실패 그룹만 재시도, 2단계 완료 메타, 동일 카드/동일 언어 요청 보존 검사.
- Fusion quality / stage-flow / retry-payload / reopen / PDF / delivery-floor 스크립트: PASS. delivery-floor의 캐시 요청까지 fetch 차단을 추가했다.
- `node scripts/verify-app-no-portone.mjs`: 앱 환경 SDK 무력화·Play 상점 인계·복귀 의도·연타/타임아웃 mock 검사 통과. 실제 Android 기기 검증은 미실행.
- 로컬 mock 개발 서버에서 360·390·430·1440px 가로 넘침 없음, 데스크톱 히어로 폭 960px, 모바일 CTA 48px 높이 및 첫 화면 접근 확인. 카드 6장·이미지 로드·버튼 공개 상태 확인.

## 유지한 영역

`calculateLocalResult()`·KASI prefetch·normalizeSaju 타임존·격국 판정 규칙·기둥/절기 계산은 수정하지 않았다. 사주 계산의 기존 기본 동작을 유지하면서 Fusion 재시도용 기준 연도 옵션과 전문 근거 응답만 추가했다. 가격표·결제 실행·인증·스키마/마이그레이션은 변경하지 않았다. 사주 엔진의 실제 경력 10년차 명리학자 설계·자문 문구는 보존했다.

## 실환경 확인

실결제(단건/카카오페이/이용권/월정석), 유료 LLM 생성, 운영 DB, 머지/배포는 실행하지 않는다. 4배 CPU 브라우저 에뮬레이션 프레임은 개발 서버/브라우저 재접속의 큰 변동이 있어 실기기 성능 통과 근거로 사용하지 않는다. Android WebView의 최종 화면 및 저사양 기기 성능, 다국어 장문 품질은 별도 실환경 확인이 필요하다.
