# 질문 우선 상품 탐색: 인벤토리·질문 IA·카피

확인일: 2026-10-02 KST. 코드와 레지스트리를 읽어 정리했다. 실결제, 유료 LLM 호출, 운영 DB 조회는 하지 않았다. 화면 실측 결과는 10절, 운영 지표 전후 비교 방법은 8절에 있다.

**목표**: "운세 종류를 고르는 사이트"를 "지금 가장 궁금한 질문을 고르면, 그 질문에 맞는 운세 엔진이 답하는 사이트"로 바꾼다.

**바꾸는 것**: 고객이 보는 것만 바꾼다.
- 상품명·부제·카드·CTA
- 상세 히어로·카테고리·추천 문구
- 홈 노출 순서
- SEO 설명문

**바꾸지 않는 것**
- 계산·LLM·가격·결제·결과 생성 로직
- 내부 상품 ID, DB 키, 라우트, API, 결제 상품 ID
- 인덱싱된 URL. 그래서 redirect·canonical·sitemap 구조도 그대로다.

계획 정본은 세션 계획 파일이다. 이 문서는 그 1단계 산출물이며, 이후 단계의 문구는 이 문서를 원천으로 쓴다.
