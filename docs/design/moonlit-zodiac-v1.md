## 동작·접근성 계약
- 큰절 그림은 기존 session.elapsed/CYCLE_MS를 따른다. 카운터·완료 이벤트·복원·소유권 로직은 변경하지 않았다.
- 미리보기는 독립 시간이며 완료 기록을 쓰지 않는다. 비활성 탭 시간을 몰아서 반영하지 않는다.
- 이동 프레임은 기존 이동거리 기준. 새 루트 이동이나 횟수 계산기를 만들지 않는다.
- 경량/동작 감소는 같은 동물의 정지 그림을 사용하고 추가 동작 시트 디코딩을 피한다. 이미지 실패 시 정지 그림과 안내를 제공한다.
- 14개 선택 버튼은 이름·aria-pressed를 제공한다. 동작 버튼은 키보드 조작 가능하다.
