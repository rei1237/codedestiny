# 관리자 화면 콘텐츠 편집

- 표면: `/admin/cms/`, Operate. 기존 관리자 테마를 유지한다.
- 진입점: `app/admin/cms/page.tsx`; 화면 연결은 `_components/VisualPreview.tsx`, 전체 검색은 `_components/GlobalCopySearch.tsx`가 소유한다.
- 스타일: `app/admin/cms/cms-workspace.module.css`. 공통 버튼·입력은 `app/admin/_components/ui.ts`, 색상은 `app/admin/admin-yehwa.css`의 `--cd-adm-*`를 재사용한다.

## 배치와 읽기

280px 목록과 유동 편집 영역의 두 열을 사용한다. 1280px 이상에서는 미리보기와 260–320px 편집 패널을 나란히 놓는다. 그보다 좁으면 편집 패널을 아래로 옮기고, 767px 이하에서는 목록도 위로 쌓아 높이를 220px로 제한한다. 입력은 16px, 행간 1.7이며 원문의 줄바꿈을 보존한다. 문장 행은 최소 44px이고 선택과 키보드 포커스를 표시한다. 저장 영역은 하단 sticky로 유지한다.

## 찾기와 편집

- 현재 그룹 검색은 이름·키·기본 문장·수정본을 포함한다. 띄어쓰기·줄바꿈·대소문자 차이를 정규화한다.
- 전체 검색은 사용자가 요청할 때 AI 프롬프트를 제외한 등록 그룹을 읽는다. 실패한 그룹을 별도로 안내하며 검색 결과에서 해당 문구 위치를 연다.
- 정적 결과는 모든 설정 문장을 기본으로 보여준다. 실제 페이지에 현재 나오지 않는 문장도 선택할 수 있다.
- 실제 페이지에서는 선택한 그룹에 등록된 문구·이미지를 연결한다. 다른 항목을 클릭하면 해당 편집 항목을 연다. 중복 원문은 후보를 표시한다.
- 기본 문장 비교와 기존 원본 항목 편집을 제공한다. 부분 수정본은 원본의 나머지 항목을 유지한다.

## 상태와 저장

입력 중인 문장, 초안에 적용한 문장, 서버 발행본을 구분한다. 입력만 바꾼 상태에서는 저장·발행·항목 전환·운영 반영을 막고 초안 적용 또는 입력 되돌리기를 안내한다. 화면 편집의 적용된 초안은 브라우저에 보관되며, 명시적 발행 전에는 서버를 변경하지 않는다. 원본 편집 모드의 기존 자동저장 정책은 유지한다.

기존 runtime/build 채널과 배포 절차를 유지한다. 발행과 운영 반영은 별도이며 배포 요청 접수를 성공한 배포로 표시하지 않는다. 로딩, 빈 검색 결과, 기본 문장 불러오기 실패·재시도, 일부 그룹 검색 실패, 저장 오류를 구분한다.

## 검증 범위

- `node --test __tests__/ui/cms-visual-editor.test.mjs __tests__/ui/cms-static-results.test.mjs`
- `node scripts/verify-admin-cms-browser.mjs` (새 화면 캡처를 생략하려면 `--no-capture`)
- `npm run check:fast`, `npm run typecheck`

브라우저 검증은 실제 관리자 컴포넌트와 adminFetch를 사용하지만 데이터·API 응답·공개 미리보기는 로컬 테스트용이다. 외부 네트워크, 운영 DB, 실제 결제와 LLM을 사용하지 않는다. 운영 인증, 전체 공개 페이지, 실제 이미지 업로드와 운영 배포는 미검증이다. 등록되지 않은 페이지 문구와 결제·인증·계산 로직을 임의 편집하는 기능은 제공하지 않는다.
