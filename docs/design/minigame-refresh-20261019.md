# 미니게임 이미지·카드 경험 개선

- 화투는 타짜 모티브의 인물·대사·검붉은 패방을 유지한다. 데스티니 포커만 달빛 카드 살롱을 사용한다.
- 왕게임은 `/destiny-poker.html` 내부 모드다. 왕 1장으로 주제를 정하고 중복 없는 비왕 카드 2장으로 흐름·행동을 읽는 창작 운세다. 기존 마스터 포커의 하루 이용 횟수와 분리된다.
- 화투의 세 패 운세는 기존 하루 10회 한도를 공유한다. 기존 섯다·운수 떼기·인생 패 결과 체계는 유지한다.
- 포춘 피쉬는 실제 물고기 움직임을, 오미쿠지는 제비통·막대·종이를, 연이의 마음 별자리는 기존 꽃돼지 연이를 이미지로 보여준다. 생성 그림에는 한글 설명을 넣지 않고 UI에서 안내한다.

## 이미지 출처와 최적화

생성 도구·정확한 프롬프트·원본·적용 파일은 [JSON 기록](minigame-refresh-20261019.json)에 있다. 원본 화투 48장은 보존하고 화면용 240px WebP를 추가했다. 합계 3,926,818 → 450,822 bytes(88.52% 감소)다. 실제 기기의 FPS 개선 수치는 측정하지 않았다.
