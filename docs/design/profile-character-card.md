# Design System: 프로필 캐릭터 카드

## Overview

**Creative North Star: "나의 작은 운세 게임 카드"**

한국어 꿀꿀운세의 따뜻함과 전문성을, 플럼 바탕·크림 글자·골드 강조의 응집된 프로필 카드로 표현한다. 귀여운 평면 2D 동물과 정령은 개인의 프로필을 친근하게 만들고, 일간 오행 배지는 계산된 정체성을 별도로 설명한다. 캐릭터 장식이 본문 운세나 행동 버튼보다 먼저 읽기를 방해하지 않게 한다.

이 문서는 **프로필 카드에만 적용**한다. 전역 `DESIGN.md`나 다른 상담가 화면의 기준을 대체하지 않는다. `PRODUCT.md`의 따뜻함·전문성·모바일 우선 원칙을 계승하며, 정책의 정본으로 사용하지 않는다.

근거: `js/destiny-profile.js`의 `renderMasterCard`, `styles/profile-characters.css`, `js/core/profile-character-card.mjs`, `js/core/profile-element-badge.mjs`. 구현 완료 시 390px/1280px 검수 이미지와 finish reviewer의 **ship** 판정을 참고했다. CTA 색과 펼친 도감은 해당 검수에서 확인되었으며, 운영 배포나 실제 계정 지급 증거를 뜻하지 않는다.

## Colors

깊은 플럼에 따뜻한 크림을 얹고 골드로 행동과 진행 상태를 표시한다. 토큰 값은 frontmatter와 구현 CSS를 따른다.

- **Primary — 골드:** 운세 보기 CTA, 레벨, 진행 막대, 링크, 요약 펼치기, 포커스 링.
- **Neutral — 플럼과 크림:** 카드 배경과 기본 글자. 보조 설명은 흐린 장밋빛, 구분선은 플럼 계열 선색을 사용한다.
- **Secondary — 초상화 크림:** 동물·정령을 받치는 작은 초상화 표면. 카드 전체를 밝은 배경으로 바꾸는 역할이 아니다.
- 도감 버튼은 보조 표면색을 사용하고, 활성 hover에서 표면을 한 단계 밝힌다. 비활성 버튼은 보조 글자색과 기본 커서를 사용한다.

**오행 독립 규칙.** 목·화·토·금·수 배지는 일간 오행을 나타낸다. 가장 많은 오행, 오늘의 운세, 현재 장착한 정령의 속성으로 바꾸지 않는다. 배지의 색과 어두운 에나멜 색은 `profile-element-badge.mjs`가 관리하며 텍스트 이름과 각기 다른 SVG 문양을 함께 표시한다.

## Typography

이름·레벨·섹션 제목은 기존 명조 토큰을, 설명·상태·버튼은 기존 산세리프 토큰을 사용한다. 폴백은 각각 고운바탕과 고운돋움이다.

- 이름: 굵은 명조, 모바일 좁은 화면에서는 (19px). 긴 이름은 줄바꿈하고 한글 단어를 가능한 유지한다.
- 레벨: 굵은 명조 (24px / 1.2). 오늘의 흐름 제목: 굵은 명조 (16px / 1.5).
- 주요 CTA: (14px, 700). 본문은 frontmatter의 body 기준.
- 일주 설명·성장 안내: (12px). 보조 정보는 (11px), 초상화 라벨·오행 캡션은 (10px).

작은 글자는 정체성 보조 정보에 한정한다. 주요 행동과 운세 해석은 작은 배지 글자로 축소하지 않는다.

## Layout

단일 카드 안에 정체성 → 계정 레벨·미션 → 오늘의 흐름 → 접힌 캐릭터 소개·도감 → 운세 보기 → 접힌 출생 정보 순으로 배치한다. 외부 시트의 폭을 따르며 카드 자체는 (width: 100%, max-width: none)이다. 데스크톱에서도 내부 내용을 여러 독립 카드로 쪼개지 않는다.

정체성 행은 초상화·이름과 오행·메뉴의 3열 (88px / minmax(0,1fr) / 44px), 간격 (14px)이다. 화면 폭 (430px) 이하에서는 첫 열 (80px), 간격 (10px), 모바일 내부 여백을 사용한다. 초상화 스프라이트 기본 크기는 (80px), (380px) 이하에서는 (64px)이다.

도감은 기본 2열, 화면 폭 (600px) 이상에서 3열이며 간격은 세로 (16px), 가로 (10px)이다. 기본 상태에서 도감을 접어 주요 행동까지의 길이를 줄인다. 출생 정보도 네이티브 `details`로 별도 접는다.

## Elevation & Depth

평면 일러스트와 얇은 구분선을 중심으로, 카드 바깥의 부드러운 그림자와 얕은 금빛 안쪽 하이라이트만 더한다. 카드 그림자는 `0 16px 34px #29152726, inset 0 1px 0 #efd4a333`, CTA는 `0 4px 10px #150b1720`이다. 오행 배지에 작은 드롭 섀도를 적용해 금속 테두리와 에나멜 중심을 분리한다. 각 정보 행마다 별도 그림자를 추가하지 않는다.

## Shapes

카드는 둥근 모서리와 얇은 금빛 테두리 (1px)로 감싼다. 초상화는 상단이 더 둥근 프레임 (24px 24px 16px 16px), 좁은 화면에서는 (20px 20px 12px 12px)이다. 오행은 원형 이모지 대신 다각형 금속 테두리·에나멜·문양으로 구성된 봉인형 배지 (36px)다. 진행 막대는 낮고 긴 형태 (높이 8px)를 유지한다.

## Components

### 정체성과 캐릭터

12동물 및 12정령은 4프레임 스프라이트로 제공한다. 대표 초상화는 장착 상태에 따라 동물 또는 정령을 표시하며, 아래 라벨로 `나의 일주`와 `정령 장착`을 구분한다. 일주 이름과 타고난 오행은 장비 변경과 독립적으로 남는다.

대표 초상화만 (4.8s, step-end, infinite)로 간헐적으로 움직인다. 프레임은 시작·62%·100%에서 기본, 68%·76%·84%에서 나머지 세 프레임을 사용한다. 도감 썸네일은 정지한다. `prefers-reduced-motion: reduce`에서는 스프라이트 애니메이션을 끈다.

### 성장과 미션

기존 계정 공통 레벨·출석·미션·보상 컨트롤을 카드 안에 통합한다. 미션 펼치기와 보상은 선으로 구분된 행으로 표현한다. 새로운 프로필별 레벨이나 별도 결제 혜택을 시각 문구에서 암시하지 않는다. 정령 비용·보너스·소유·장착 상태는 기존 모듈 및 서버 상태를 표시하며 이 문서에 숫자 정책을 복제하지 않는다.

### 행동과 상세

`이 프로필로 운세 보기`는 골드 바탕과 플럼 글자의 전체 폭 CTA이며 최소 높이 (48px)다. 메뉴는 (44px × 44px), 링크·도감 버튼·요약 행은 최소 높이 (44px)를 확보한다. 캐릭터 소개·정령 도감과 출생 정보는 키보드로 조작 가능한 네이티브 `details` / `summary`를 사용한다.

모든 버튼·링크·요약의 키보드 포커스는 골드 외곽선 (2px, offset 3px)으로 표시한다. 스프라이트는 `role="img"`와 이름 `aria-label`을 제공한다. 장식 SVG 배지는 `aria-hidden`이며 옆의 오행 이름이 의미를 전달한다. 불러오기·실패·장착 피드백은 상태 텍스트를 제공하고, 변경 상태에는 `aria-live="polite"`를 사용한다. 오행과 소유 상태를 색만으로 전달하지 않는다.

## Do's and Don'ts

- **Do** 계산된 일주·일간 오행, 현재 초상화 장비, 계정 공통 성장을 각각 명확한 라벨로 구분한다.
- **Do** 어두운 표면을 수정할 때 본문·보조 글자·CTA·펼친 도감의 실제 색을 함께 검증한다.
- **Do** 긴 한국어 이름, 390px 모바일, 넓은 화면, 펼친 도감, 키보드 포커스, 모션 감소 상태를 확인한다.
- **Don't** 오행을 동물 색·정령 장비·오늘 운세에 맞춰 다시 계산하거나 덮어쓴다.
- **Don't** 기본 화면에 정령 도감 전체를 펼쳐 CTA를 밀어내거나 모든 썸네일을 동시에 애니메이션한다.
- **Don't** 이 디자인 문서를 근거로 가격·결제·지급·해금 정책을 추가하거나 변경한다.
