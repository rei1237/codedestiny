# 인증샷 터치 편집

2026-11-16. 기존 15종 캐릭터·60개 사진 포즈, 스티커와 배경 자산을 그대로 사용한다.

## 이용 흐름

`/moonlit-lotus/` → 인증샷 꾸미기 → 캐릭터·스티커 선택 → 한 손가락 이동 / 두 손가락 확대·회전 → PNG 저장 또는 기기 공유.
겹친 요소는 `편집할 대상`에서 고른다. 슬라이더·방향 버튼·캔버스 방향키로 동일하게 조절할 수 있다. 포즈 변경은 편집 위치를 유지한다.

## 좌표와 저장 계약

- 배경 촬영 시 캐릭터를 숨기고 별도 이미지 레이어로 합성한다. 원본 법당 DOM·캐릭터 선택·명상·108배 상태는 변경하지 않는다.
- 변형 좌표와 크기는 캔버스 너비 기준, 회전은 도 단위다. 두 손가락의 중심을 기준으로 이동·회전·확대하며 포인터 수가 달라지면 현재 위치로 기준을 다시 잡는다.
- 기존 낙서·스티커의 y 좌표는 높이 기준을 유지하고 변형 경계에서 변환한다. 캔버스 해상도나 모바일 폭이 달라도 같은 결과를 저장한다.
- 크기는 너비의 4–80%, 중심은 캔버스 범위로 제한한다. 최대 100개 꾸밈, 최근 30개 변경 되돌리기. 배경·포즈 이미지를 기록마다 복제하지 않는다.
- 선택 테두리는 DOM 오버레이다. PNG는 합성 캔버스만 저장하므로 조작부·테두리가 들어가지 않는다.
- 사용자 사진 자동 업로드 없음. 공유 취소 시 편집 유지, 파일 공유 미지원 시 PNG 다운로드. 닫으면 편집 상태는 사라진다.

## 검수

- Chromium 모바일 에뮬레이션 360·390·430px와 데스크톱1440px: 가로 넘침 없음, 시각 검수 통과.
- CDP 실제 터치 입력: 캐릭터 이동·핀치 확대·회전, 연꽃 스티커 이동·핀치 확대·회전 확인.
- 말풍선 선택·키보드 이동·회전, 포즈 변경 후 위치 유지, PNG 다운로드 확인.
- 저장 PNG와 미리보기 합성 캔버스의 SHA-256 일치. 캐릭터 중복·선택 테두리 혼입 없음.
- 공유 미지원 다운로드 확인. 네이티브 공유 취소는 mock으로 확인.
- 실제 Android·iOS 기기, OS 사진함/공유 앱 완료는 미검증.

## 보존과 롤백

결제·인증·API·DB·음악·108배 세션·캐릭터 원본 자산 변경 없음. 공개 URL·메타데이터·사이트맵 변경 없음.
