# 비주얼 노벨 표지와 네오의 복귀

## 승인된 방향

- 메인은 어두운 문학적 표지. 시작·이어읽기와 회차 선택을 앞에 두고 운명 찻집, 러브 코덱스 인연의 서, 팩폭 전략실만 서비스 링크로 둔다.
- 사용자 후속 요청에 따라 표지 주인공은 기존 인간형 연이 원본이다. 분홍빛·푸른빛 성운과 별빛의 느린 명암 효과를 CSS로 더하고, OS 및 소설의 모션 감소 설정에서는 정지한다. 모바일에서는 연이 초상을 먼저 보여주고 제목·독서 기능·세 서비스를 이어 배치한다.
- 네오는 원본과 같은 **주황빛 갈기, 크림색 몸, 이마의 네 문양, 빨간 망토, 작은 이족보행 체형**이다. 사용자가 실제 사자 같은 디자인을 거부했으므로 그 생성물은 사용하지 않는다. 새 자산은 원본 `neo-cef04fde61.webp`를 참조한 표정 정돈이다.
- 인간형은 기존 은발·남색 의상·은빛 외투의 s4 투명 컷을 그대로 재사용한다. 상담실 자산은 변경하지 않는다.

## 이야기와 형태 계약

연이는 EP.26에서 돌아온다. EP.27 도입, 배 위에서 연이가 네오의 앞발을 받치자 庚 재연결이 수호자의 외형을 복원한다. 외형 복원은 본명과 기억의 봉인을 풀지 않는다. 몸에 남은 상처 역시 사라지지 않는다.

이후 네오는 인간형을 유지한다. EP.28 현실 귀환에서도 신분과 기억의 문제를 안고 사람으로 동행한다. 동료들의 ‘사자님’ 호칭은 EP.27에서 익숙한 별명임을 밝힌다. 다른 동물 캐릭터, 과거의 사자·고양이, 타로의 사자 상징은 그대로다.

EP.42는 처음 얼굴을 보는 사건 대신 지금 아는 얼굴과 과거의 박병하가 연결되는 사건이다. 이름의 대가로 몸이 투명해지고, EP.43의 희생 이후 EP.48에서 존재와 기억을 함께 회복한다. EP.50의 이별과 EP.52의 현실 재회, EP.53의 결말을 유지한다.

정본 비트의 선택적 `neoForm: "lion" | "human"`을 빌더가 위치별 `NEO_FORM_MARKS`로 만든다. 플레이어는 순차 재생·회차 진입·책갈피 복원·되감기에서 동일한 위치 함수를 쓴다. 표정 키는 형태를 되돌리지 않는다. 기존 h* 표정은 호환한다.

70편의 대화와 연결을 편집하고 기존 장면 ID를 전부 보존했다. EP.27의 새 장면은 별도 ID를 사용한다. 원본 대본의 rev를 올려 기존 책갈피를 초기화하지 않는다.

## 자산과 검증

- `node scripts/build-novel-neo-assets.mjs`: 저장된 4×2 표정 원본에서 투명 WebP 8종을 재생성한다. 장면당 360×480, 각 80KB 이내. 공급자 호출과 업로드 없음.
- `npm run novel:build`: 70편, 7,693비트와 형태 표 생성.
- `verify:story-sync`, `verify:novel-runtime`, `verify:novel-player-start`: 정본 일치, 자산 예산, EP.27 전후 형태, 후반 회차, 책갈피 ID 및 메인 회차 선택 검사.
- 화면 확인: 360·390·430·1280px, 모션 감소, 메인 링크·설정, 사자/인간형 전환, EP.42의 인간형 유지.
- 결제·가격·인증·상담 API·DB·운영 배포를 변경하지 않는다. 한국어 정본 편집이며 유료 번역이나 LLM 호출 없음.

분량 보고의 4,000자 권장치와 연출 밀도는 경고 기준이다. 설명을 늘려 기준만 채우지 않으며, 별도의 1,800자 색인 하한 및 동기화 검사는 통과해야 한다.
