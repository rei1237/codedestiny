# 조건부 입묘·시기 분리 정책

- 해석 버전: saju-tomb-conditional-v1. 시기 분리: saju-periods-v1.
- 정본: lib/saju/natal-core/tomb.mjs, analyzeSajuTombs. 원국·대운·세운만 적용한다.
- 기존 원국 격국·용신 판정과 점수는 바꾸지 않는다. 입묘가 원국 글자를 삭제하거나 오행을 바꾸지 않는다.

## 문헌과 서비스 선택

[子平真詮 論墓庫刑沖之說 원문 전재](https://www.kaucim.ai/bazi/ziping-zhenquan/lun-mu-ku-xing-chong-zhi-shuo)는 사묘고의 충을 일률적인 개고·발복으로 설명하는 견해를 비판하며, 투간과 격의 쓰임을 살핀다. 이 자료는 **충이면 모든 장간이 풀린다는 단정을 피하는 근거**이며, 아래 프로그램의 모든 세부 조건을 고전이 규정했다는 뜻이 아니다. 음양간 역행의 묘처 표, 충에 의한 활성화, 생조·통근에 따른 완화와 합충 경합 보류는 이 서비스가 채택한 해석 프로필이다. 다른 학파의 입묘·개고론과 합의된 유일한 정답으로 표시하지 않는다.

[원국 판정 프로필](saju-natal-core-rule-profile.md)의 억부·조후·특수격 순세 후보를 사용한다. 격국 상신·병약 용신은 기존처럼 미평가다. 특정 십성(상관·칠살 등) 자체를 흉신으로 고정하지 않는다. 여기서 기신은 해당 구조의 억부 기신 후보이고, 조후와 충돌하면 방향을 보류한다.

## 묘처 표와 실제 대상

| 묘처 | 천간 |
| --- | --- |
| 辰 | 辛·壬 |
| 戌 | 乙·丙·戊 |
| 丑 | 丁·己·庚 |
| 未 | 甲·癸 |

음양간 순역을 적용한 기존 십이운성 표와 같은 기준이다. 오행별 삼합의 창고(수庫 辰·화庫 戌·금庫 丑·목庫 未)와 구분한다. 예컨대 辰戌충에 辛·丙·壬이 모두 나타날 수 있으나, 명식이나 그 시기의 운에 실제 천간·지장간으로 존재하는 대상만 기록한다. 같은 글자가 다른 자리에 있으면 출처를 각각 남긴다.

## 판정 순서

1. 알려진 천간과 지장간의 각 출현 위치를 모은다. 해당 천간의 묘처가 실제 지지에 있는지 찾는다.
2. 같은 시기 辰戌 또는 丑未의 반대 지지가 있으면 충 자극을 기록한다. 묘처만 있고 충이 없으면 candidate(입묘 후보).
3. 일주·월주 근거가 부족하거나, 묘처의 육합·온전한 삼합/방합·실제 투간한 대상 천간의 합 상대가 충과 경합하면 pending(판단 보류). 합이 무조건 충을 해소했다고 판단하지 않는다.
4. 묘처 밖에 충을 받지 않은 정기·중기 뿌리가 있거나, 월지 본기 오행의 동류·생조가 있거나, 다른 천간에 실효 뿌리를 둔 동류·생조가 남으면 mitigated(완화 조건 있음).
5. 충 자극이 있고 위 보류·완화 조건이 없을 때 activated(입묘 작용). 여기 뿌리나 충을 받은 뿌리는 근거 목록에 남기되 강한 완화 조건으로 사용하지 않는다. 글자를 지우지는 않는다.

각 사건은 target(자리·천간/지장간·십성), tomb(묘처 자리), triggers(충의 자리), period, status, role, roleBasis, verdict, evidence, reasons, mitigations를 가진다. UI와 LLM은 이 판정을 설명하며 별도의 규칙을 생성하지 않는다. LLM 전달용 사본에서는 같은 판정의 출처를 묶고 명시된 열 이름(eventColumns)에 맞춘 표로 전달한다. 원본 사건·뿌리 근거는 보존하며 재투영해도 표와 작용 방향이 사라지지 않는다.

## 희기와 방향

- 억부 용희신 후보를 제한하면 adverse, 기신 후보를 제한하면 beneficial. activated 상태에서만 방향을 낸다.
- 억부와 조후가 상충하거나 구조 미평가이면 undetermined. 성립한 특수격은 순세 후보만 useful로 인정하고 나머지를 임의로 기신으로 만들지 않는다.
- 한 시기 양방향이 함께 작용하면 mixed. 한쪽이 미평가이면 확정 결론을 피한다. 지장간의 수를 세어 다수결로 정하지 않는다.
- 여러 대운·세운을 합쳐 평생 길흉을 만들지 않는다. 각 period의 verdict만 사용하며 다중 시기 묶음의 최상위 verdict는 undetermined다.
- 용신 손상은 도움이 약해질 수 있는 흐름, 기신 억제는 부담을 덜 수 있는 흐름으로 설명한다. 죽음·사고·질병·수익·성공을 예언하지 않는다. 수치 점수·기존 스코어 라벨은 변경하지 않는다.

## 시기와 미상 시각

- 기본 계산은 원국, 각각의 대운, 해당 연도와 기간이 겹치는 대운+세운으로 나눈다. 기간을 모르는 대운은 세운과 자동 결합하지 않는다.
- 교운 연도에는 앞뒤 대운을 각각 평가하며 동시에 넣지 않는다. 대운 날짜·표기를 유지하고 연간 근거를 교운 전후 전체에 단정하지 않는다.
- 명시적인 동시 프레임은 같은 종류의 운을 두 개 넣을 수 없다. 날짜 범위가 알려진 대운과 불일치하는 세운은 거부한다.
- 기본 원국 계산은 컴퓨터의 현재 연도를 자동 주입하지 않는다. 현재 세운을 원하는 호출자는 기준 연도를 명시한다.
- 시주 미상은 알려진 6글자만 대상으로 표시한다. 가능한 12개 시주에서 같은 대상·묘처의 상태/역할/방향이 모두 같을 때만 그 판정을 유지하고, 다르면 pending. 가상 시주는 표시하지 않는다. 정확한 대운 시작일도 만들지 않는다.

## 개고와 투간

개고의 기존 필드명 openedHiddenStems는 호환을 위해 유지하지만 값은 모두 activation:candidate다. 기간별 상담 근거에서는 원국/직전 대운과 달라진 항목만 전달하며, 상세 입묘 표가 이미 있으면 개고 항목 안의 같은 입묘 참조를 중복 전송하지 않는다. 같은 시기 해당 출처의 입묘 근거를 tombEvidence로 연결한다. isFavorableOverall은 null이며 장간 다수결을 없앴다. 원국 투간과 운의 투출, 도충·개고·입묘를 서로 대체하지 않는다. 원국 격국 정체성은 운에 의해 바뀌지 않는다.

## 오행 표시와 역법

surfaceElementCounts는 각 천간·지지를 한 번씩 센다. 알려진 시주는 총 8개, 미상은 총 6개이며 지장간은 합산하지 않는다. 기존 월지 2배 가중 counts(9/7)·ratios는 강약/점수 알고리즘용으로 유지하고, 화면과 명리 프롬프트의 개수는 surface를 쓴다. 분석용 가중치라는 표기를 개수와 구분한다.

역법 정책은 [지역 평균시·23시 환일 계약](../context/saju-time-contract-20260930.md)을 유지한다. 출생 순간의 절입 비교와 보정 일주·시주를 구분한다. 균시차를 적용하지 않으므로 입력 안내에서 진태양시라는 이름을 쓰지 않는다. [한국천문연구원 음양력 정보](https://www.data.go.kr/data/15012679/openapi.do)의 저장된 오프라인 표본으로 음양력·일진을 검증한다. 표본 통과를 모든 연대·해외 지역의 정확도 보장으로 확대하지 않는다.

## 저장 결과·정책 보존

별도 해석 버전을 신규 계산에 저장한다. 기존 natal-core-v1, 사주 역법 및 authority 버전을 바꾸지 않는다. 기존 저장 구매 결과에 입묘 필드가 없으면 새로 계산하지 않으며 기존 자료만 보여준다. authority digest를 그대로 검증하므로 옛 핀을 읽을 때 덧붙이지 않는다. 신규 UI는 저장된 사실만 투영한다. 결제 가격·이용권·월정석·단건 결제·인증·DB·구매 접근 권한은 변경하지 않는다.
