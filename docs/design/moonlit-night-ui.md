# 달빛 아래 나만의 연화당

2026-11-16 사용자 승인 시안: 남색 바탕, 따뜻한 금빛 법당, 연보라·옥빛·연꽃 분홍 강조. 법당·각 활동 패널·홈 진입점에 한정한다. 기존 전신 캐릭터와 풍경 원본은 보존한다.

- 경험 중심 화면: 풍경과 캐릭터가 먼저 보이고 행동은 아래에 모인다.
- 모바일 세로 기본 풍경은 화면 높이에서 조작부 공간을 뺀 중앙 확대 창이다. 실제 좌표계는 기존 3:2를 유지하므로 이동·접지·인증샷 좌표는 변경하지 않는다. 가려지는 소품은 기존 ‘소품으로 시작하기’로 접근한다. overflow:clip으로 포커스 이동이 크롭 중심을 밀지 않게 한다.
- 패널이 열리면 전체 풍경을 작은 3:2 화면으로 보여주고 패널을 이어 배치한다. 가로 몰입 모드는 기존 동작을 유지한다.
- 명상은 옥빛, 기도·확언은 연꽃 분홍, 참배·운세는 금빛, 공통 조작은 연보라. 밝은 강조색 위 글자는 진한 남색이다.
- 제목은 기존 주아체, 조작·본문은 Pretendard. 새 폰트·의존성·이미지 다운로드 없음.
- `space.module.css`의 `--ml-*`, 홈 카드의 `--ml-home-*`가 색상 정본이다. 전역 서비스 테마는 변경하지 않는다.
- 캐릭터 선택·명상·이동·108배 세션, 음악, 기도/확언 기록 및 인증샷 기능은 기존 컨트롤러를 재사용한다.
- `/moonlit-lotus/`의 기존 title/description/H1과 noindex/follow:false, 홈의 직접 내부 링크를 유지한다.
- 롤백은 이 디자인 변경 커밋만 revert하고 CI 통과 SHA로 릴리스한다. 기능 비활성화는 기존 `MOONLIT_LOTUS_ENABLED` 계약을 따른다.

## 인증샷

- 사용자 추가 요청(2026-11-16): 법당 안 다양한 포즈와 스티커 꾸미기.
- 사진용 미소·인사·명상·합장·응원·쉼은 기존 전신 시트의 정적 프레임을 재사용한다. 12지신은 응원에 인사 프레임을 함께 쓴다. `photo-poses.ts`가 매핑 정본이다.
- `stickers-v1/`의 연꽃·초승달·등불·구름·하트·별은 이번 작업에서 직접 작성한 SVG 자산이다. 128px viewBox, 투명 배경, 동일한 크림 외곽선·금빛 선·파스텔 채색을 사용한다.
- 사진을 만들 때 세션을 일시정지하고 복제 DOM에서만 포즈를 바꾼다. 실 캐릭터 상태나 완료 횟수를 조작하지 않는다. 스티커·낙서는 포즈 변경 시 유지되고 닫을 때 폐기된다. 공개 업로드 없이 PNG로 기기에 저장한다.
- 선택한 스티커 크기는 다음 배치에 적용한다. 마지막 스티커는 방향 버튼으로 이동한다. 최대 100개와 기존 낙서 점 제한을 유지한다.
