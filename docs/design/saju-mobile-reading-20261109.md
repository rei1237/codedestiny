# 모바일 사주 읽기 개편과 폰트 로딩 정비

사용자 승인: 2026-11-09 계획 구현. 운영 승격 제외. 원본 및 실제 main의 타 세션 미커밋 변경은 보존하고 격리 워크트리에서 작업했다.

## 구현

- 선택 프로필·무료 일주 기준·4주 축약 명식을 먼저 표시한다. 기존 카드 노드를 명식·기질/운의 흐름/더 살펴보기의 닫힌 details로 이동한다. 원래 ID·리스너·유료 게이트·본문을 복사하거나 삭제하지 않는다.
- 기존 앵커는 부모 details부터 열어 이동한다. 프로필·출생 정보·4주·시간 미상 변경은 초기화하고, 같은 결과의 말투 변경과 계산 메타데이터 추가는 펼침을 보존한다. 12개 언어의 새 메뉴는 언어 전환 시 갱신한다.
- 회색 읽기 토큰을 기존 꽃빛 토큰에 연결하고, 명조와 이용권 카드의 별도 Noto/Myeongjo 지정은 주아체/Pretendard 역할로 연결했다. 한자·기호·전용 이미지 서체는 보존했다.
- 사주 결과·화자 전환에서 제휴 추천 호출을 제거했다. 별도 추천 기능은 유지한다. SNULIFE 사용자 표시만 이용 가능한 풀이로 바꿨으며 혜택·소유권 판정은 보존했다.
- 프로필 사주 진입의 입력 영역 우회 스크롤, 200ms 지연과 준비 폴링을 제거했다. 기존 엔진 준비 promise 후 기존 계산을 실행하고 실패 시 재진입 가능하게 한다. 대기 중 계정 범위가 바뀌면 실행하지 않는다. 타로/자미두수의 기존 선택 프로필 진입과 서비스 선택을 유지한다.

- check:fast 계획 실행. 77개 경계 중 독립 런타임 핀 1건을 공식 restamp 도구로 고쳐 재검증, 나머지76 통과. lint와 typecheck 통과, 최신 main 합친 뒤 typecheck와 프로필 전환 검사도 통과.
- 전체 Node 최초4784개 중4777통과/7실패. 공식 fortune 데이터 준비 누락, 폐기된 추천 재마운트 가정과 VM 동적 import, CSS 캐시 핀을 수정하고 관련60개 모두 통과. 전체 Node 재실행 성공으로 보고하지 않는다.
- 공식 계획의 나머지 계약·인코딩·Worker dry-run 검사 통과. Jest467개 스위트/7920개 테스트 통과(각1개 제외).
- check:pre-push 통과(레지스트리63, 미러 멱등, sitemap1062, llms, SEO 엔티티61, 저장소 위생). 폰트181개 해시·라이선스 및 mobile-detail-nonintrusive 통과.
- 기계 디자인 검사1회:0 anti-patterns, 기존/승인된 글자 크기 advisory. 시각 리뷰의 제목/시간 미상/언어 갱신 결함을 수정했다.

## 성능 측정

동일 로컬 HTTP 서버, 고정된 before 77f8400448d1a5c0d1437ace53a641c69eba3a57 / after 4d2588e21d0394c70c6e6a397b7ea99482236094, 390×844px, 빈 캐시,150ms·200KB/s, 첫30초 관찰, 각각5회 중앙값. 외부 요청·실 API는 차단했다. 운영 RUM 또는 배포 환경 수치가 아니다.

폰트 감소 39.4%, LCP 개선 -0.3%. 폰트25% 목표 충족, LCP10% 목표 미달. 목표 미달은 숨기지 않는다. 공통 정적 셸의 초기 HTML·런타임과 폰트 교체가 LCP에 함께 영향을 주므로 전송량 감소를 체감 로딩 개선으로 단정하지 않는다. 별도 조기 폰트 stylesheet는 앞선 비교에서 렌더 경로를 막아 제거했다.

이전 route.fulfill 방식은 before 텍스트 자산만 직접 주입해 HTTP 조건이 달랐으므로 최종 비교에서 폐기했다. 전체 load/fonts.ready 대기도 부가 로딩과 섞여 고정된 첫30초 관찰로 바꿨다. 로컬 서버는 측정 종료 시 닫힌다.

## 유지한 영역과 전달

결제 가격·이용권/월정석/단건 결제, 인증·혜택·API 응답 타입·DB·계산·LLM·저장 원문·공유 정책을 바꾸지 않았다. 캐시 핀과 공식 미러/사이트맵은 소유 생성 명령으로 갱신했다. 최신 main 프로필 정원 작업도 합쳐 보존했다. main fast-forward push 및 최종 CI 상태는 완료 보고에 기록하며 운영 승격은 하지 않는다.
