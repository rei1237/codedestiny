# 달빛 연화당 초대장·모바일 법당

2026-11-15 승인된 초안 구현. 기존 연이 그림, 기도/확언/기록 저장, 캐릭터 선택, 음악, 참배 세션과 운영 결제·인증·API·DB를 보존한다.

## 변경

- `HomeMoonlitEntry.tsx`, 해당 CSS, `entry-copy.ts`: 초대장 여백과 “오늘의 마음을 조용히 내려놓아요.”, “나만의 연화당으로” 적용. 기존 WebP와 한국어/일본어 소개 재사용.
- `Space.tsx`, `space.module.css`: 640px 최소 장면 폭을 없애 가로 스크롤 제거. 장면 아래 명상·기도·108배·더보기 네 행동을 배치. 확언·운세·기록·꾸미기·음악은 더보기에서 모두 접근 가능. 데스크톱 소품은 작은 표시와 hover/focus 이름, 작은 장면에서는 접이식 메뉴로 제공.
- 모바일 패널이 열리면 장면을 작게 표시하고 입력·저장 조작은 일반 문서 흐름을 유지한다. 가로 배치는 장면과 수첩을 나란히 제공한다. 좁은 세로 화면에서 키보드가 열릴 때 가로 배치로 바뀌지 않도록 가로 전용 조건에 최소 폭 600px를 적용했다.
- `ImmersionControl.tsx`: 사용자가 누른 때만 전체화면과 가로 방향 잠금을 요청. 미지원/거부 시 직접 회전 안내, 다시 누르거나 Escape로 복귀. 자신이 만든 전체화면/방향 잠금만 정리한다. CSS transform으로 화면을 강제로 회전시키지 않는다.
- 화면 회전/축소와 참배/음악 상태는 분리한다. 음악 컴포넌트는 계속 마운트된다.

## 직접 확인

mock 서버 Chromium, `D:/CodeDestiny-Build/moonlit-lotus/immersive-v1/`에 캡처와 관찰 기록 보관.

| 화면 | 문서 가로 넘침 | 네 행동의 아래 끝 |
|---|---|---:|
| 360×740 | 없음 | 662px |
| 390×844 | 없음 | 682px |
| 430×932 | 없음 | 709px |
| 844×390 가로 | 없음 | 382px |
| 1365×900 | 없음 | 883px |

독립 시각 검수에서 360px의 초기 이미지 로딩 중 캡처를 decode 이후 재확인했고 연이 전체 실루엣이 보인다. 가로 축소 장면의 소품 표시 겹침을 제거했다. 기도 패널 입력·두 행동과 홈 카드의 얼굴/연꽃/입장 버튼 잘림 없음. 가로 소품 메뉴의 summary도 세로와 동일한 한 줄 스타일을 공유하도록 마지막 정돈했다.

실제 Chromium 전체화면 진입과 버튼으로 종료, 데스크톱 방향 잠금 거부 시 회전 안내, 더보기의 다섯 행동 노출, 기도 입력을 확인했다. `screen.orientation.lock()`은 일부 브라우저에서 지원되지 않으므로 [MDN 계약](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock)에 따라 기능 감지/거부 처리를 둔다.

실제 Android 기기 확인: `C:/Users/user/AppData/Local/Android/Sdk/platform-tools/adb.exe devices` 결과 연결 기기 없음. **Android Chrome·iOS Safari·앱 WebView 실기기와 실제 화면 키보드는 미검증**이다. 브라우저 모바일 크기 검수를 실기기 검수로 표현하지 않는다.

첫 검사에서 더보기 JSX의 닫는 중괄호 누락을 발견해 수정했다. 수정 후 변경 기반 `check:fast`를 다시 실행했다. 본문·색인 정책은 그대로이며 홈 소스 서명만 sitemap:generate로 갱신했다.

## 이후 요청

사용자가 작업 도중 달빛 연화당 소개 웹툰의 **스토리 승인 후 제작·운영 반영**을 요청했다. 웹툰은 아직 제작하지 않았으며 스토리 초안을 답변에서 제시한다. 이번 UI 수정의 운영 재배포도 이번 턴에서는 실행하지 않는다. 앞선 1회 배포 승인을 재사용하지 않는다.

롤백은 이 UI 커밋만 revert한다. 이전 그림·세션·개인 기록은 변경하지 않았고, 전체 공간 비활성화는 기존 MOONLIT_LOTUS_ENABLED를 사용한다.
