## 유지한 영역과 롤백

가격, 월정석, 이용권, 단건 결제, 인증 API, 회원 DB, 기존 콘텐츠 URL, 다국어 경로를 유지했다. AppVersionGuard는 이전 완료 버전의 `v` 쿼리만 정리하며 결제/복구 매개변수는 보존한다. 기존 CI 실패의 환경 소비자 목록·브랜드 기대값·일주 googlebot noindex도 수정했다.
