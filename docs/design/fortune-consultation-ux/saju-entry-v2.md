# 사주 상담 진입점 v2 에셋

## 목적

사주 상담을 일반 카드가 아니라, 사용자가 자신의 여덟 글자를 펼쳐 질문의 답으로 들어가는 독립적인 첫 장면으로 보이게 한다. 연이의 정체성과 기존 결제·상담 흐름은 유지한다.

## 최종 프롬프트

고급 사주 상담 진입점용 3:2 가로 편집화. 기존 연이의 복숭아빛 꽃돼지 얼굴·분홍 연꽃·갈색 눈·작은 발굽·보라색 비단 스카프를 그대로 유지한다. 달빛이 드는 한국식 서재에서 여덟 칸의 명식 두루마리를 읽고, 한지·옻칠 나무·먹·붓·산수화·매화·연꽃 등잔을 딥 플럼·따뜻한 아이보리·샴페인 골드로 절제해 표현한다. HTML 문구가 놓일 왼쪽 3분의 1은 차분하고 어둡게 비우고 연이는 오른쪽에 둔다. 읽을 수 있는 글자·숫자·UI·로고·워터마크·타로 카드·수정구·보라색 우주·네온 사이버펑크·실사는 넣지 않는다.

## UI 적용

- 데스크톱: 그림을 전체 진입 장면으로 사용하고 왼쪽 음영 위에 제목·가치·가격·CTA를 배치한다.
- 모바일: 16:10 장면을 먼저 보여준 뒤 밝은 한지색 설명 영역으로 자연스럽게 이어진다.
- 가격은 기존 서버 값을 그대로 표시하며, 이미지 안에는 정책 문구나 가격을 넣지 않는다.
