# 숙요 읽기 공간 — 승인된 화면 기준

범위는 홈 프로필의 기본 숙요점 모달이다. 기존 SEO 랜딩 및 다른 운세 모달의 디자인은 그대로 둔다. 모드는 Read이며, 사용자가 본명숙의 기질을 읽고 기존 명반 도구·다른 숙의 해설·관련 글로 자연스럽게 이동하는 것이 목적이다.

승인 방향은 깊은 버건디 배경, 장미색 버튼, 금색 본명숙 표기와 달 정원 장식화다. 네오 모드에는 기존 네오 토큰을 적용한다. 새 외부 폰트나 애니메이션은 추가하지 않는다. 모바일 360–430px를 기준으로 본문을 한 열로 읽고, 넓은 화면에서는 도감과 글 목록만 확장한다.

정보 순서는 상단 바로가기 → 달 정원 이미지 → 기존 프로필과 본명숙 요약 → 공개 기질/관계/일/조언 → 기존 명반·달력·상세 진입 → 27숙 도감 → 관련 글이다. 기본 해석을 접지 않는다. 유료 심층 내용은 원래 상세 진입과 게이트를 사용한다. 도감 해설에는 본명숙과 별도라는 안내를 표시한다.

구현 정본은 js/core/saju/basicFortunePresentation.js와 styles/basic-fortune-library.css의 숙요 전용 규칙이다. 27숙 설명은 기존 엔진 데이터를 재사용하고 글 목록·본문은 기존 insights 원고에서 생성한다. 검색·목록 복귀·원문 링크·읽기 오류 안내를 제공한다.

승인 목업은 preview.html 및 preview-390.png/preview-1040.png다. 실제 적용 화면은 mock 기반 scripts/verify-sukuyo-reading-house.mjs로 재현한다. 실 API나 과금 호출 없이 27숙/26글/기존 컨트롤 보존과 모바일·데스크톱 넘침을 확인한다.
