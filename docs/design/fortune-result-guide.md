# 운세 결과 읽기 안내

## Overview
- 모드는 **Read**. 기존 결과에 안내를 추가하여 운세 체계와 저장 근거를 이해하도록 돕는다.
- 이 문서는 해당 화면의 로컬 기준이다. 전역 PRODUCT.md·DESIGN.md를 대체하지 않는다.
- 사주·자미두수·숙요점·서양 점성술·베다점·타로의 설명과 계산 체계를 구분한다.

## Colors
- 영냥이는 흰 고양이와 남보라·골드를 유지한다. 꿀꿀은 크림 바탕(#fffaf3), 본문(#382c2c), 보조 문구(#71605a), 구분선(#ddcbb6), 로즈 강조(#924657)를 사용한다.
- 색상 정본은 `components/fortune/external-image-guide.module.css`와 `css/paid-editorial-report.css`다.

## Typography
- 제목·저장 수치·상담 발췌는 기존 세리프, 본문은 기존 본문 글꼴을 사용한다. 본문 16px·행간 1.85, 문단 최대 72ch로 읽기 흐름을 유지한다.

## Layout
- 운세 특징 설명 → 저장된 계산 근거와 한계 → 상담 발췌 → 외부 AI 프롬프트 순서다.
- 최대 폭 940px, 내부 여백 24~56px. 삽화는 모바일 중앙 176px, 데스크톱 오른쪽 220px로 배치한다.

## Components
- `ExternalImageGuide.tsx`를 영냥이 `SummaryReport.tsx`와 꿀꿀 `PaidResultImageGuide.tsx`가 사용한다. 레거시는 `js/core/paid-editorial-report.mjs`로 렌더링한다.
- 새 삽화는 내장 `image_gen`으로 제작했다. 기존 `yeoni-moonstone-reward-v1.png`의 꽃돼지 연이 정체성을 참고하여, 책 읽는 연이·연꽃·찻잔·초승달을 투명 배경의 수채화로 그리도록 요청했다.
- `public/assets/mascot/yeoni-reading-guide-v1.webp`는 화면용 640px·132,212바이트, 같은 이름의 원본 PNG는 저장용 2,031,098바이트다. 직접 작성한 `reading-guide-divider.svg`를 장식 구분선으로 사용한다.
- 안내 문구와 프롬프트는 `js/core/fortune-report-content.mjs`에서 12개 로케일로 관리한다.
- 저장 상담은 최대 네 문단을 화면에 발췌한다. 없는 값은 생략하고 계산 근거가 없으면 그 한계를 안내한다.
- 프롬프트는 접힌 상태로 시작하며 펼쳐 직접 편집한다. 주 행동인 복사 버튼은 항상 노출하고, 원본 캐릭터 PNG 저장은 보조 링크로 둔다. 복사 결과·실패 시 수동 복사를 안내한다.
- 서비스 내 결과 PNG 자동 생성은 제거한 상태를 유지하고 외부 이미지 제작은 사용자의 수동 작업으로 안내한다.
- 행동 버튼·링크는 최소 높이 48px, 키보드 초점은 명확한 외곽선으로 표시한다.

## Do's and Don'ts
- 저장된 수치·상담 문장·한계 고지를 보존한다. 새 점수·날짜·해석을 만들거나 카드를 다시 뽑지 않는다.
- 외부 AI로 자동 전송하거나 외부 생성 API를 호출하지 않는다. 사용자가 개인적인 내용을 읽고 삭제한 뒤 직접 전달한다.
- 기존 결과 접근 권한과 공개 링크의 동의·공개 범위·해제 경계를 유지한다. 프롬프트는 소유자용이며 공개 공유 이미지용이 아니다.
- 결제·이용권·월정석·단건 결제 정책과 서버 권한 판정을 바꾸지 않는다.
- 이전 안내 버전: 단위 14개·typecheck·실제 컴포넌트 mock 288조합·레거시 4개 너비 통과, 외부 요청 0건. 새 삽화와 화면 변경의 검증은 진행 중이다.
