# 연이·네오 정적 사주 읽기

사용자가 확정한 기획을 구현하는 범위: 무료 정적 사주, 기존 결과 안의 정적 대운·종합 구매 안내, /ggulggul/ 인라인 영냥이 진입점. LLM 상품의 컨셉·상세·프롬프트·결과, 인생의 책·신년운세 및 공용 상세 템플릿은 제외한다.

## 화면 계약

| 화면 | 구성 |
|---|---|
| 입력 | 기존 폼 앞 모드 선택 → 정원/작전실 한 줄 설명 → 기존 입력·동의 |
| 결과 | 모드 제목·캐릭터·비교 → 공통 명식 → 오행·십성·기질·조후·억부 → 현재 흐름 → 편지 |
| 정적 유료 안내 | 상품명·정본 가격 → 적합한 경우·무료와 차이 → 가상 명식 샘플 → 입력·재열람 안내 → 기존 권한 게이트·CTA |
| 영냥이 | 작은 기존 고양이 이미지 / 상담 목적·API 시작 가격 / 기존 상담·무료 운세 링크 |

연이: 관찰 → 생활 사례 → 작은 실천. 네오: 진단 → 계산 근거 → 행동 기준. 숫자는 공통이며 더 큰 값이 성공 가능성이라는 주장을 하지 않는다. 알려지지 않은 출생시간은 정오 대체와 시간 의존 해석의 제한을 표시한다.

모바일 한 열, 데스크톱 네오 근거와 진단 두 열. 새 폰트와 애니메이션 의존성 없음. 44px 컨트롤, 명시적 이미지 크기, 모션 감소 지원. 영냥이는 인라인 유지이며 고정·닫기 상태를 추가하지 않는다.

## 실제 연결

- index.html이 /ggulggul/ 및 로케일 셸 정본. sync:public으로 public 미러 생성.
- saju-engine.js calculate → G_PILLARS/G_NATAL/G_JOHU/G_POWER/G_JONG. 기존 계산·시기·권한 유지.
- reading-personas.js는 계산된 값의 표시 모델. 모드 전환에서 calculate/LLM/결제/일월운 API 재호출 없음.
- fortuneThemeModeStateV1 기존 설정 유지. 입력 체크박스 컨트롤러를 통해 동작.
- 정적 section_daewun/section_summary 가격은 billing-feature-registry resolver에서 생성. 실제 두 상품 모두 3,000원. 오래된 셸 표시만 정본에 맞춘다.
- 샘플은 고정된 가상 명식이며 잠긴 사용자 결과와 별개. 기존 해금/복구 구조 유지.
- 개인정보 없는 saju_reading_mode_change, saju_static_detail_view 이벤트만 추가.

## 에셋

public/images/saju/README.md에 원본과 생성 출처. 연이는 단서, 네오는 명식 확인 역할. 160px 두 이미지 총 16,982바이트를 미리 로드해 최초 모드 전환에도 이미지 다운로드를 기다리지 않는다. 320px 변형은 향후 고밀도 배치용이며 현재 요청하지 않는다.

## 언어

sajuReading 네임스페이스 129개 키를 기존 authored 사전에 추가. 한국어·영어를 작성하고 그 외 지원 언어에는 영어 공통본을 제공한다. 비한국어에서 새 한국어 문구가 노출되지 않는 검사를 포함하며, 현지어 번역 완료를 의미하지 않는다.
