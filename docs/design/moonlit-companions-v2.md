# 달빛 연화당 동물 친구 · 인증샷

2026-11-15. 기본 캐릭터는 성별에 관계없이 연이이며 사용자가 저장한 수동 선택을 우선한다. 법당 상단의 **캐릭터 꾸미기**에서 연이·영냥이·프로필 친구 또는 15종 동물을 선택한다. 기존 프로필의 성장·해금·결제 데이터는 수정하지 않는다. 공간용 꾸밈은 기존 `cd:moonlit:prefs:<account|profile>`에 저장한다.

## 자산

- 연이 `yeoni/2d-v2`와 1단계 원본, 기존 `space-v1` 배경은 보존한다.
- 새 자산은 `public/assets/moonlit-lotus/companions-v2/manifest.json` 참조. 투명 WebP, 셀 384px, 기본 발 기준선 354px.
- 영냥이는 사용자 `양냥이 프로필 시트.webp` 기준 흰 털·남색 모자와 망토·파란 보석을 유지하고 이름표를 제외했다. idle/greeting/meditation/prayer 16컷, 걷기 16컷, 절 16컷과 정지 그림을 별도 제공한다.
- 쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·강아지·돼지·사자·기린·코뿔소는 기존 프로필 원화를 참조한 종별 4컷 걷기다. 뱀은 기어가는 표현이다. 생성 원본 식별자는 manifest에 기록한다.
- 원본 제작/검수 파일은 `D:/CodeDestiny-Build/moonlit-lotus/companions-v2/`에 보존한다. 모든 종이 16컷이라는 의미는 아니다.

## 동작과 저장

`companions.ts`가 종·원화·걷기 자산을 연결한다. 저장된 프로필 친구는 기존 `petSpriteMarkup` 전체를 사용해 몸과 장식을 유지한다. 이동은 같은 2.4초 경로를 사용하며 화면 위치와 걷기 프레임의 기준을 통일한다. 이동은 횟수 계산에 관여하지 않는다. 동작 전환은 220ms 교차 표시이며 모션 감소 시 생략한다.

일반 동물의 명상은 기존 sleep 원화, 절은 전신을 낮추는 간략 표현이다. 종별 손·무릎 접촉을 그린 큰절 애니메이션은 아니다. 기존 108배 세션의 완료·복원·중복 방지 로직은 변경하지 않는다.

`PhotoStudio`는 현재 풍경을 html2canvas로 캡처해 낙서·하트·별과 합성한 PNG를 기기에 저장한다. 이동 중 촬영은 잠시 비활성화하고 촬영 전 108배를 일시정지한다. 업로드·공개·서버 기록은 없다. 최대 100개 표시, 선당 최대 3,000점, 캡처 배율 최대 2배/폭 1,536px. 캔버스를 닫으면 미저장 꾸밈은 사라진다.

## 전달과 제한

로컬 Chromium에서 영냥이 선택→법당 이동→인증샷→하트 추가→PNG 다운로드를 확인했다. 토끼 선택·저장·연못 걷기·명상도 확인했다. 실제 390px 화면에서 법당과 사진 편집기의 겹침·잘림을 검수했다. 첫 검수에서 전환 wrapper 내부 캐릭터 높이 0과 선택 버튼 대비 문제를 발견해 수정하고, 다운로드 PNG까지 재확인했다. 프로필 서버에서 실제 이용자의 친구를 가져오는 흐름은 운영 계정으로 시험하지 않았다.

새 정적 자산 20개 합계 4,700,852바이트(약 4.48MiB). 15종을 한 번에 다운로드하지 않고 선택된 종만 표시한다. 디코딩 메모리의 실제 기기 측정은 별도다. 자산 검사와 기존 108배 회귀 검사 `node --test __tests__/ui/moonlit-companions.test.mjs __tests__/ui/moonlit-private-space.test.mjs`는 13개 통과했다.

기능 전체는 기존 `MOONLIT_LOTUS_ENABLED` 스위치로 비활성화할 수 있다. 이 변경만 되돌리면 이전 캐릭터 표시로 돌아가며 프로필·108배 원본 기록은 보존된다. 실제 Android/iOS/WebView, 장시간 메모리 및 서버 부하 시험은 미검증이다. 자산은 정적 제공이고 새 서버 API·DB 작업은 없다.
