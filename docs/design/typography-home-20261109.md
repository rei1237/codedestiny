# 폰트 정비와 홈 상담 탐색 통합

- 사용자 승인: 2026-11-09, 주아체 제목 + Pretendard 본문, 두 서비스 전반.
- 디자인 기준: 마지막 첨부의 자주색·금색·꽃 장식 상담 영역. 미적 방향 재선정 없음.
- 기준 커밋: `4ee6c81148d5ccc19afbd0143232aa81d4ad0bcb` (origin/main).
- 작업 격리: `wt/typography-home-20261109-051034`. 원래 체크아웃의 다른 세션 변경은 보존.

## 구현

`brand-typography.css`에서 글꼴 역할을 공유한다. 같은 사이트의 공식 OFL WOFF2 서브셋을 사용하며 원본 URL·SHA-256·라이선스는 `public/assets/fonts/ui/manifest.json`에 기록한다. 다운로드는 재생성 시에만 발생하고 `--check`는 로컬 해시를 확인한다. 한자 local 폴백과 특수 기호·포스터 서체는 보존한다.

홈은 짧은 소개 → 무료 체험 6개 → 통합 상담 선택 순서다. 무료 원/내부 그림은 데스크톱 88/76px, 모바일 80/68px. `renderHomeConsultationPicker`는 기존 대표 상담 8개, 질문별 입구, 기존 5개 고민 그룹의 추천을 가격 키/서비스 ID 기준으로 합친다. 기존 질문 URL·보조 무료 링크·가격 정본을 보존한다. 첫 화면은 연애·관계 3개, 더 보기로 펼치며 모든 상담과 기존 세부 질문 8개에 접근할 수 있다. 자동 카드 이동은 제거되고 기존 달빛 추천 편지는 통합 영역 뒤에 유지된다.

서버 HTML에도 초기 선택과 링크가 있고 탭 변경은 결제·상담 생성·자동 스크롤을 실행하지 않는다. 원래 `cdSignatureConsult`, `cdConcernPick`, `homeConcerns`, 세부 질문 fragment를 보존한다. 결과·입력·내부 소제목·가격은 읽기용 글꼴이며 명식·표·한자는 장식체에서 제외한다.

## 검증 기록

- 로컬 mock 개발 서버 사용. Node 외부 네트워크 가드와 브라우저 API fixtures로 실제 LLM·PG·운영 DB 접근 차단.
- 웹폰트 181개 자산(라이선스 포함), 전체 원본 합계 약 3.83MB. 전체 다운로드량이 아닌 보관 자산 크기이며 실제 로딩은 unicode-range에 따른다.
- 글꼴 해시·기존 공유 폰트 검사, 홈 가격/서비스 레지스트리, 모바일 공용 래퍼 검사 통과.
- 브라우저 mock 검증: 정적 셸 360·390·430·768·1440px 및 진입점·영냥이 메인/보관함/사주·저장 결과의 390·1440px, 총 15개 조합 통과. 결과 본문 17/18px·줄간격 1.8·최대 608px, 200% 확대, 폰트 차단 시 텍스트 표시를 확인했다. 후속 번역·링크 보완 후 홈 5개 폭 재검증도 통과했다.
- 홈 회귀: 360·375·390·430·768·1280·1440px, 고민/세부 질문·더 보기·키보드·6개 무료 입구·기존 딥링크·추천 편지·mock 회원 동작 통과. 12개 언어 사전 일치 검사 통과.
- `check:fast -- --plan` 및 `check:fast` 실행. 결제 경계 77개, 변경 파일 lint·전체 lint 통과. 오래된 카드 구조 검사 수정 및 sitemap 공식 재생성 후 동일 계획을 이어 실행하여 typecheck 통과. 전체 Node 검사 4,774개 중 23개 실패를 확인해 누락 번역·웹툰 링크와 옛 DOM 가정을 수정했고, 해당 12개 파일 100개 검사 모두 통과했다. 나머지 4,751개는 최초 실행에서 통과했다. 전체 Node 검사를 다시 실행했다고 주장하지 않는다.
- 느린 네트워크 단일 mock 측정(390px, 빈 캐시, 150ms·200KB/s): 전후 CLS 0.1114→0.0562, LCP 10,032→10,940ms, 실제 폰트 전송 396,828→996,536bytes. 양쪽 외부 요청을 차단해 이전 외부 폰트는 폴백이므로 운영 성능 비교로 일반화할 수 없다. 새 서체의 전송량과 LCP는 추가 최적화 여지가 있다.
- Next 개발 모드에서 `HomeQuestionDispatch` hydration 속성 및 `HomeDisclosure` key 경고를 관찰했다. 해당 JSX는 이번에 편집하지 않았고, 개발 환경 경고를 운영 영향 없음으로 단정하지 않는다.
- 디자인 검사 168건 중 기존/승인된 크기 advisory 167건과 이전 명조 제목 warning 1건을 확인했다. warning의 직접 서체 지정은 소유 CSS에서 공통 제목 토큰으로 수정했다. 별도 시각 검토로 밝은 샘플 제목 대비와 가격 배경을 수정했다.
- 공식 계획 후반의 환경·계약·worker dry-run·인코딩 검사 및 Jest 466개 스위트/7,903개 테스트 통과(스위트·테스트 각 1개 제외). `check:pre-push` 전체 통과: 레지스트리 63개, 미러 멱등, sitemap 1,062개, llms, SEO 엔티티 61개, 저장소 위생.
- 마지막 소유 CSS 점검에서 영냥이 결과 소제목의 중복 `font-family`가 읽기 역할을 덮는 문제를 수정했다. 390/1440px mock 재검증 4개 조합 통과. 결과 h2/h3의 실제 서체가 Pretendard 역할이고 20~24px·600~700 굵기인지도 확인한다. 첫 냉간 개발 서버 실행에서는 결과 로딩이 30초 안에 끝나지 않아 재실행했으며, 냉간 로딩 문제 해결을 주장하지 않는다.

## 전달

원본 체크아웃과 실제 main 체크아웃의 다른 세션 변경을 보존하기 위해 공식 격리 워크트리를 사용했다. 최신 main의 SEO 커밋 `81390e622`까지 합쳤으며, 생성 원장은 합친 소스에서 공식 명령으로 재생성했다. 전달은 검증한 트리를 fast-forward `git push origin HEAD:main`으로 수행하고, 운영 승격은 수행하지 않는다. 최종 CI 상태와 산출물 링크는 완료 보고에 기록한다.

## 변경 경계

결제 정책·가격 레지스트리·인증·API·DB·계산·LLM 프롬프트·저장 원문·공유 동작은 변경하지 않는다. canonical·색인 정책·메타데이터를 보존하며 홈 내부 링크가 사라지지 않도록 비교한다. 기존 검증기의 8장 레일 가정만 통합 카드 및 유지된 대표 상담 8개 기준으로 갱신한다.
