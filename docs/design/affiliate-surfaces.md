# 사이트 내 제휴 광고

- 방향: 별도 추천 서가를 없애고 홈 푸터 바로 위와 기존 완료 결과에 상품 카드를 직접 배치한다.
- 홈: `/`와 `/ggulggul/`에 최대 2개. 입력·생성·결제·관리·정책·블로그에는 새 광고를 추가하지 않는다. 정적 셸에서 결과 화면이 열리면 홈 광고를 숨긴다.
- 결과: 저장·공유 뒤에 관련 실천 조언과 연결되는 상품만 최대 2개. 관련 상품이 없거나 이미지/요청이 실패하면 영역을 숨긴다.
- 사용자 최종 결정(2026-11-01): 알리는 제외하고 쿠팡만 공개한다. 기존 알리 상품·실적 데이터는 보존한다.
- 디자인: 연이 로즈, 네오 달빛, 영냥이 남색·금색의 기존 토큰과 글꼴. 데스크톱 2열·모바일 1열, 실제 상품 사진과 짧은 추천 이유, 판매처 버튼. 고정 배너·팝업·빈 공간 자동 탐색 없음.
- 문구: '풀이를 일상으로 잇는 작은 선택'. 운세를 바꾸는 효능 대신 독서·기록·집중·휴식의 용도를 설명한다. 구매를 권유하기 위한 공포·개운·치료 효과 표현을 추가하지 않는다.
- 이미지: 공식 제휴 자료, 상품·옵션 동일성, 사용 근거를 확인한다. 이미지 없는 자동 광고와 대체 사진은 노출하지 않는다.
- 관리: 상품·이미지·공개 설정과 통계는 기존 관리자/API를 유지한다. 미리보기에는 외부 구매 이동과 통계를 제공하지 않는다.
- 호환: 폐지된 서가 URL은 대표 홈으로 301. 과거 browse 집계는 유지하며 새 footer 집계와 구분한다.

## 2026-11-01 검증

- 실제 React 광고 모듈의 mock 화면 360/390/430/1280px × 연이·영냥이·네오 12개 구성 확인.
- 홈과 정적 셸 푸터 배치, 결과 전환 시 홈 광고 숨김, 미완료·글·비활성·이미지 실패 시 숨김을 검사한다.
- 독립 시각 검수에서 네오 테마와 고지 속성을 보완한 뒤 배포 가능 판정을 받았다.
- 이 문서의 mock 검증은 실제 결제·LLM·구매 전환 검증이 아니다. 운영 배포 상태는 운영 기록을 따른다.
