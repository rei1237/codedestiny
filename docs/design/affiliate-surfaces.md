# 제휴 추천 화면

## Direction contract
- THESIS: 상담에서 일상으로 이어지는 취향 탐색. 판매처 배너를 나열하는 광고판 대신 자체 선택 기준을 먼저 읽는다.
- OWN-WORLD: 영냥이의 남색·앤틱 골드, 기존 명조와 원화. 꿀꿀 운세는 로즈·꽃돼지 연이와 독립된 이름·홈 복귀를 유지한다.
- STORY: 어느 브랜드의 추천인지 → 어떤 목적의 선택인지 → 판매처와 조건 → 명시적인 외부 이동.
- FIRST VIEWPORT: 상단 브랜드와 복귀, 여백 있는 문장과 캐릭터, 눈에 보이는 광고 고지, 관심사 탐색. 승인 전 공개면은 준비 안내만 표시한다.
- FORM: 기존 영냥이 세계를 이어받은 편집형 선택 서가. 브랜드와 판매처는 별도 축이며 비쿠팡 제휴는 관리 미리보기 전용이다.
- FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

전역 DESIGN.md를 바꾸지 않는 지역 확장이다. 캐릭터 원본은 변경하지 않는다. 영냥이는 기존 hero-800.webp, 연이는 기존 fortune-tea-house/renewal/yeoni-tea-welcome.webp를 참조한다. 새 판매 이미지나 제휴사 로고는 제작하지 않는다.

쿠팡 외 제휴사는 계약·공식 도메인·고지·이미지 이용권·취소 조건을 검수한 이후 별도 서버 어댑터가 필요하다. 이 화면 설정만으로 외부 링크를 활성화할 수 없다. 계정·카탈로그·분석·결제 정책은 기존 승인 전 상태를 유지한다.

## 운영과 확장
- 운영 광고 OFF, AF7837486 그대로. 상품/DB/계정/결제/로그인/상담 복구는 변경하지 않음.
- 관리자 > 생활 추천 > 구성 미리보기: 브랜드와 제휴 구성을 선택한다. 여러 제휴사의 이름은 실제 계약 업체가 아닌 화면 예시다.
- 현재 외부 이동 검증은 쿠팡만 지원한다. 새 제휴사에 대해 이름만 등록해도 URL 권한이 생기지 않는다. 미등록 또는 prototype 이름도 미리보기 전용으로 닫힌다.
- 공식 공급사별 API/DB 어댑터, 계약별 광고 고지와 검증 URL 규칙, 실제 이미지/링크는 다음 승인 범위다.
- /recommendations/?brand=yeongnyangi 와 ?brand=ggulggul 은 개인정보 없는 표시 설정이다. 상담 복귀 값은 기존 동일 탭 저장소를 사용한다.
- 되돌리기: 이 기능 커밋만 revert. 기존 RECOMMENDATIONS_RELEASED=false를 유지한다.
