# 달빛 예화 홈 v2

사용자가 승인한 2026-11-03 목업의 구현. 첫 행동은 고민 선택이며, 기존 꽃돼지와 달빛 예화의 선화·로즈를 유지하고, 홈 안내 제목은 기존 display 글꼴을 사용한다. 픽셀 아트는 사용하지 않는다.

## 소스와 경계

- `lib/marketing/yehwa-home.mjs`: 공개 홈과 정적 앱이 공유하는 표시 그룹·마크업. 연애·관계(love/compatibility), 돈·일(money/career), 나의 성향(self), 앞으로의 흐름(today/life), 가족·생활(family).
- `js/core/service-registry.js`: 서비스명·설명·가격·태그·진입의 기존 정본. `build-home-funnel.mjs`가 정적 마크업과 공개 홈의 JSON을 함께 생성한다. 최대 세 카드만 먼저 보여주며 전체 운세는 기존 통합 검색으로 연결한다. 기타 항목과 DOM 컬렉션 검색을 삭제하지 않는다.
- `js/core/yehwa-home.mjs`: 표시 전용 3단계 튜토리얼. 프로필·인증·결제·첫 이용 보상 상태를 기록하지 않는다. 기존 프로필 안내를 대신 완료 처리하지 않는다.
- 보관함은 `/records/`와 `/yeongnyangi/library/`를 구분한다. 결과를 복제하거나 새로 생성하지 않는다.
- 기존 Neo 테마와 영냥이 밤색 토큰을 유지한다. 목업의 별도 다크 토글을 새로운 권한·테마 상태로 도입하지 않는다.

## 자산

홈 메인: 기존 `public/images/home/illustrated/yeoni-character-{320,480,800}.webp`의 책을 읽는 꽃돼지와 `yeoni-moon-garden` 배경을 유지한다. 모바일·다크 모드도 기존 배경 변형을 사용한다. 별도 꽃돼지 이미지와 아틀리에 에셋은 브랜드·첫 방문 안내 및 튜토리얼 영역에 사용하고 메인 이미지를 대체하지 않는다.

대화 원본: 사용자 소유 연이 아틀리에 `atelier-release/assets/illustrated/talking/yeoni_pig.webp`. 1280×384, 가로 4셀, 셀마다 320×384. SHA256 `90ce057c759fb0854a575d3e3a018e1caf3a69433290c111da9baabfd4e2edaa`.

사이트 복사본: `public/assets/yeoni/atelier/talking-pig.webp`. 프레임 2→3→2→0, 440ms 단발 동작. 동작 줄이기는 프레임 0. 대사는 처음부터 전부 표시하고 버튼을 지연시키지 않는다. 이미지가 실패해도 안내 문장과 제어는 유지한다.

영냥이 안내는 기존 `hero-480.webp` 정지 원본에 짧은 전체 이미지 등장 동작만 적용한다. 입 모양·앞발 스프라이트로 보고하지 않는다. 루나·루나 언니의 새로운 표정 제작은 별도 후속 범위이며, 아틀리에에서 비활성화된 입 프레임을 복원하지 않는다.

## 검증

`scripts/design/verify-yehwa-home.mjs`: 원본 레지스트리와 파생 JSON 일치, 고민별 목록, 360·390·430·1440px 넘침, 안내 이전·다음·완료·건너뛰기·Escape·포커스 복귀, 기록 분리, 스프라이트 4셀 크기. `YEHWA_FULL_SHELL=1`이면 실제 정적 셸을 로컬 파일 응답으로 렌더링한다. 외부 네트워크는 차단한다.

프로젝트 공식 검증은 `npm run check:fast`, 커밋 후 `npm run check:pre-push`, GitHub CI다. 실제 통과 여부는 실행 결과로 별도 보고한다.

## 이용권과 둥근 형태 보완 (2026-11-03)

기존 꿀단지 그림·가격 비교·선택·적용 조건은 유지한다. 상단 이용권 바로가기를 추가하고 이용권 비교를 고민 탐색 직후로 옮긴다. 600px 이하에서는 꿀단지를 2×2로 표시하며, 홈 카드·안내·이용권의 곡률은 기존 section/card/pill 토큰을 사용한다. 영냥이 이용권 색상·구매 로직은 변경하지 않는다.

SEO: 제목·설명·H1 문구·canonical·hreflang·색인 정책·서비스 링크를 유지한다. 공개 HTML의 이용권 블록 순서와 표시 스타일만 바뀌며 사이트맵 원장 및 정적 미러는 기존 생성기로 동기화한다.
