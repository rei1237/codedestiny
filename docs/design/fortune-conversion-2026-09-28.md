# 질문에서 구매 이해로: 운세 상품 전환 개선

확인일: 2026-09-28 KST. 관찰·코드·mock·실거래를 구별한다. 실결제, 유료 LLM 호출, 운영 DB 변경은 수행하지 않았다. 판매 효과의 승자를 정한 보고서가 아니다.

## 파일럿과 현재 상태

파일럿은 **영냥이 사주 고등어 안내**다. 기존 최저 등급, 공개 무료 진입, 챕터 계약과 보관함이 있고, 사주 기본 화면에 유입이 확인된다. GA4 속성 526361229, 8/31–9/27의 화면 조회에서 사주 기본 124회/활성 사용자 42명, 영냥이 홈 143회/7명, 꿀꿀 신화면 181회/9명, 기존 홈 제목 2.5천회/131명을 관찰했다. 속성 전체 활성 134명, 신규 121명, 이벤트 약 1.3만, 구매자 잠재고객 3명이다. **내부·봇·중복·실패 제거를 검증하지 못했으므로 실제 고객 수나 상품별 구매율로 사용할 수 없다.** 사주가 구매 의향 1위라는 뜻도 아니다.

운영 진입은 `https://code-destiny.com/` → 영냥이, `/ggulggul/` → 꽃돼지 연이의 기존 도구 목록이다. 운영 홈에는 질문 진입, 생선 등급, 공개 예측 기록이 있다. 변경 전 여섯 체계 카드는 명칭과 짧은 설명 중심이고, 상세 팝업은 그림·설명·세 가지 특징·시작 링크 중심이었다. 가격·실제 목차·등급 차이를 팝업 안에서 함께 비교하기 어려웠다. 기존 `/yeongnyangi/1000-won-fortune/`에는 가격·예시·FAQ가 있어 없던 기능으로 취급하지 않았다.

소스와 운영 노출을 대조해 확인한 문제: 공개 기록 섹션은 두 대통령의 2025년을 '맞혔다'고 요약하지만 원문 증거의 독립 검증은 이번에 완료하지 못했다. 꿀꿀 베다 상세 원본에는 5,000년 역사와 전생의 업 해독을 단정하는 문장이 있고, 일반 베다 템플릿에는 출생 차트와 맞지 않는 '질문이 열린 시점' 설명이 있다. 이를 수정했다. 모든 사용자·언어·캐시 조합의 일치까지 검증한 것은 아니다.

질문 → 방법 → 받는 내용의 연결:

- 사주: 반복되는 선택 → 일간·오행·십성 → 기질·재능·관계·행동.
- 자미두수: 일과 관계의 차이 → 명궁·관록궁·부부궁 → 영역별 해석과 자원 관리.
- 숙요점: 끌림과 소진 → 27숙 및 궁합의 양방향 거리 → 기질 또는 두 사람의 거리 조절.
- 서양 점성술: 같은 별자리의 차이 → 출생 차트의 태양·달·상승점·각도 → 태도·감정·관계의 패턴.
- 베다점: 겉과 마음의 모순 → 라그나·달·나크샤트라 → 태도·마음·재능·관계, 참치에서 다샤·보조 차트.
- 타로: 계속할지 멈출지 → 카드 상징과 질문 → 선택 기준과 확인할 현실 신호.
- 영냥이의 방: 입력한 실제 고민 → 상담 종류/질문 렌즈와 계산 근거 → 답·근거·해볼 행동. 질문을 본 척하는 미리보기는 없음.
- 연애·재물·진로 질문형 상담: 각각 관계 기대/수입·지출/재능과 환경의 질문 렌즈를 사용(`reading-v6.ts`). 기존 상품 모두를 같은 문장으로 바꾸지 않음.
- 운명의 찻집·네오·인생 총운 등 별도 유료 서비스: 기존 기능과 노출 유지. 이번 파일럿에서 각각의 실제 유료 결과 품질까지 새로 검증하지 않았으므로 신규 약속·광고 확장은 보류.

등급은 `catalog.ts`·`reading-policy.ts`·`reading-manifest.ts`에서 읽는다. 기본 단일 상담은 고등어/연어/광어/참치, 현재 5/8/11/15챕터. 숫자는 카피 파일에 하드코딩하지 않는다. 궁합·질문 상담 전환 시 다음 화면의 실제 목차가 최종 기준이다. 영냥이는 Family 이용권/단건 결제, 기존 다른 서비스의 이용권·월정석 정책은 변경하지 않는다.

## 구현·비주얼·공유

- `product-curiosity.ts`: 여섯 체계별 질문·방법·가상 예시·한계의 단일 원본.
- `product-offers.ts`: 운영 상품과 목차를 화면 데이터로 변환.
- `ProductGuide.tsx`: 등급별 구성·예시·무료/유료·가격·제공 방식·CTA. '가상의 편집 예시' 명시. 실제 유료 결과 샘플이라고 속이지 않는다.
- `FortuneHome.tsx`: 기존 카드/기능 유지, 질문·기본 가격·챕터 추가, 사주 썸네일 교체. 첫 화면의 기존 질문 대표 진입 유지.
- `/yeongnyangi/readings/{saju,ziwei,sukuyo,astrology,vedic,tarot}/`: 개인정보 없는 공개 상품 공유 주소. 상품별 제목·설명·이미지, 기존 색인 허브와 중복이라 noindex/follow. 구매자 결과·질문·이름·생일·주문 ID를 OG에 포함하지 않음.
- 꿀꿀 `index.html`의 기존 마케팅 템플릿/베다 안내 수정, 생성기 실행으로 배포 미러와 marketing registry 동기화. 번역 키 삭제 없음. 새 한국어 구매 안내는 한국어 경로이며 다국어 완역 완료로 주장하지 않음.
- 창업자 제목의 적중 단정 완화, 소설 배너가 허구임을 바로 표시.

사주 새 그림: 달빛·한지 명식·접힌 기록 문서·흰 고양이 앞발. 생성 프롬프트의 핵심은 'original Korean hanji watercolor, abstract four-pillar birth-chart document, archival letter, moonlight, white cat paw; no lettering, royal insignia or historical accuracy claim'. 경쟁사 자료 미사용. 원본 1장 → sharp WebP 960×640, 102,644 bytes. 기존 사주 캐릭터 중심 이미지에서 문서·기록 중심 장면으로 교체. 다른 다섯 상품은 보유한 서로 다른 영냥이 원화를 유지해 이번에 모두 새로 제작했다고 주장하지 않는다.

## 계측과 판단 보류 지표

버전 `question-scope-v1`. 신규 이벤트에는 service/domain/item_id/content_id/locale/surface만 전달하며 개인 질문·출생정보·결과를 보내지 않는다.

| 단계 | 계측/판정 | 현재 결론 |
|---|---|---|
| 노출→카드 클릭 | 50% 보이는 카드 최초 노출 `product_card_impression`, `product_card_click` | 변경 전 같은 정의의 분모 없음. CTR 비교 불가 |
| 상세→시작 | `product_detail_view`, `product_sample_open`, `product_start_click` | 새 데이터 수집 필요 |
| 상담 준비→로그인 | 기존 view_item/purchase_attempt/login_required/consultation_start와 상품 문맥 연결 | 상품별 로그인의 완전한 연결률 미검증 |
| 결제창→성공 | checkout_pg_opened, 기존 purchase와 서버 주문 대조 | 화면 콜백만으로 성공 확정 금지. 실코호트 미분석 |
| 성공→결과 수령 | 결제 완료 주문 중 저장된 전체 manifest를 다시 읽은 완료 결과 / 완료 주문 | fortune_result_view만으로 완전 수령 단정 금지. 운영 수령률 미확인 |
| 환불·문의 | 같은 구매 코호트의 환불/문의 주문 비율 | 읽기 권한/연결 데이터 확보 전 미측정 |

보고용 코호트는 운영자 테스트·확인된 봇·실고객·미분류를 분리하고 결제 실패는 창 진입 분모에 포함해 별도 원인 분류한다. 1인 반복 클릭/주문·재시도는 세션/주문 기준으로 중복 제거한다. 내부 트래픽 필터 적용 여부를 먼저 확인해야 한다. 계정의 구매자 잠재고객 3명을 성공 주문 3건으로 바꾸지 않는다.

현재 유입에서 임의로 A/B 승자를 선언하지 않는다. 충분한 표본이 확보되면 상품·유입원·기기·버전을 고정한 무작위 분배, 사전 최소표본/기간/주요지표와 수령률 가드레일을 정한다. 이번 순차 도입 전후 비교에는 계절·유입 변화가 섞이므로 인과 효과로 보고하지 않는다.
