# 달빛 연화당 인증샷 일러스트

2026-11-16. 사용자 요청: 캐릭터별 다양한 귀여운 표정과 포즈를 새로 그리고, 꾸민 사진을 저장·공유할 수 있게 한다. 승인된 남색·금빛·연보라·옥빛 UI를 이어간다.

## 자산과 선택 규약

- `public/assets/moonlit-lotus/photo-v1/<character>/<pose>.webp`: 15캐릭터 × 4포즈 = 60장. 각각 투명 512×512, 총 4,243,884바이트, 최대 105,280바이트. 전체를 선로딩하지 않고 선택 캐릭터의 그림을 사용한다.
- 캐릭터: yeoni, cat, hanbi, mouse, ox, tiger, rabbit, dragon, snake, horse, sheep, monkey, rooster, dog, pig.
- 포즈: cheek(볼하트), cuddle(연꽃 방석 안기), tea(찻잔 윙크), hooray(만세). 애니메이션 프레임이 아닌 별도 인증샷 일러스트다.
- `_lib/photo-poses.ts`가 캐릭터 우선순위와 경로를 결정한다. `cat`·`yeoni` 직접 선택이 이전 custom 종보다 우선한다. 기존 6가지 차분한 포즈도 유지한다.
- 생성 도구는 built-in image_gen. 공식 연이·영냥이·사용자 지정 서한비 동물 시트와 기존 12지신 still을 참조했다. 새 의상 대신 기존 종별 특징과 의상을 보존했다.
- 수정 가능한 PNG 원본과 최종 프롬프트는 `D:/CodeDestiny-Build/moonlit-lotus/photo-v1/`에 보관한다. 공통 프롬프트: 같은 캐릭터의 전신 4장, 볼하트/방석 안기/찻잔 윙크/만세, 원래 종·색·체형·의상 유지, 부드러운 그림책 질감, 투명 배경, 문구·이름표 없음. 돼지 발굽·뱀 무사지·새 날개를 추가 지시했다.
- 그림 갱신 시 동일 경로의 WebP와 manifest 실측치를 함께 갱신하고 네 포즈를 어두운 배경에서 검수한다. 원본 2×2에서 개별 그림으로 분할하고 470px 이내에 맞춰 512px 캔버스, 발밑 488px 기준으로 배치한다. 양의 원본 가로 분할은 높이의 46.5%다. 생성 결과의 배경 잔여물·셀 경계 잘림은 자동 알파 검사만으로 판단하지 않는다.

## 촬영과 공유

PhotoStudio는 캡처 복제 DOM에만 독립 그림을 적용한다. 실제 명상·걷기·108배 모션 및 카운터는 변경하지 않는다. 촬영 전 기존 bow.pause를 호출한다. 포즈 변경은 낙서·스티커를 유지한다.

문구 스티커: 마음 충전 중, 오늘도 잘했어, 잠시 로그아웃, 행복 한 모금. 기존 6종 그림 스티커·낙서·크기·되돌리기·키보드 이동을 재사용한다. 편집 결과는 창을 닫으면 사라지며 자동 업로드하지 않는다.

PNG 저장과 기기 파일 공유는 버튼을 직접 눌렀을 때만 실행한다. 파일 공유 미지원은 PNG 다운로드로 대체하고, 공유 취소는 편집 상태를 유지한다. 계정·개인 기록·기도 문구를 별도 첨부하지 않는다.

## 검수와 경계

- 60장 디코딩·투명도·크기 검사, 15캐릭터 선택 경로 및 이전 한비 선택 잔류 회귀 검사.
- 이미지 육안 검수 후 말 배경 잔여물, 양의 셀 경계 잘림 수정 완료.
- Chromium 360·390·430px 및 1440px 편집 화면 가로 넘침 없음. 포즈 변경과 문구 유지, PNG 실제 저장, 공유 미지원 다운로드 확인.
- 실제 선택 UI에서 15캐릭터 모두 촬영하고 4개 썸네일 경로가 선택한 종과 일치함을 확인했다. 새 이미지 URL 차단 시 촬영 실패 안내를 표시하며 빈 사진 편집창은 열리지 않는다.
- 공유 취소는 navigator.share mock으로 파일 1개/image/png 전달 및 취소 안내 확인. 실제 Android·iOS 공유 메뉴는 미검증이다.
- 결제·인증·API·DB·SEO 라우팅/색인 정책은 변경하지 않는다.

## 롤백

인증샷 변경 커밋만 revert하면 이전 6포즈 촬영으로 복귀한다. 야간 UI와 기존 캐릭터 모션 변경은 별도 커밋이므로 유지할 수 있다. 운영 롤백은 저장소의 검증된 SHA 배포 절차를 따른다.
