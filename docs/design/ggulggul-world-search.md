# 꿀꿀 운세 전체 검색의 지역 탐색

기존 전체 검색 안에서 지역 카드 → 공간 소개 → 관련 운세로 탐색한다. 대표 홈과 공개 경로를 바꾸지 않으며, 별도 지도나 서비스 목록을 만들지 않는다.

## 2026-10-19 공간 탐험 표현 개선

사용자가 기존 방향의 고급화와 운영 배포를 승인했다. 검색 화면 안에서만 기존 지역 그림을 아치형 입구로 배치하고, 기존 명조 글꼴·테마 금색 토큰으로 제목과 테두리를 정리했다. 모바일은 가로 탐색, 중간 화면은 4열, 넓은 데스크톱은 8개 지역을 한 줄로 보여준다. 선택 공간은 큰 그림과 소개로 이어지며 결과는 기존 1·2·3열을 유지한다. 별도 지도·이미지 생성·계산·결제 변경은 없다. 움직임 감소 설정에서는 카드 이동 효과를 제거한다.

실제 생성 셸에서 360·390·768·1440px와 두 테마의 탐색·검색·상세·키보드·고정 검색·무료 진입을 mock 검증했다. 별도 시각 검토에서 얼굴과 지역명 잘림, 선택 상태, 공간 소개의 배치에 차단 문제가 없었다. 초기 탐색 화면에서 결과가 아래로 이어지는 구성은 유지한다.

## 구현 경계

- 정본 UI: `templates/home-funnel.html`, `styles/home-funnel.css`, `js/core/home-service-finder.js`. `index.html`의 모바일 개요 조립은 같은 검색 DOM을 옮기는 기존 경로를 사용한다.
- 카탈로그: 서비스 레지스트리 + DOM 타일 + `__cdLazyCards`를 병합하고 기존 목적지 기준으로 중복을 제거한다. 분리된 카드의 원래 컬렉션도 보존한다.
- 저장: `cd.allFortunes.v1`에 선택적 `region`만 추가한다. 이전 저장값은 전체 지역으로 복원한다. 기존 즐겨찾기 저장과 식별자는 그대로 사용한다.
- 검색어 입력은 전체 지역으로 돌아가 그림과 소개를 접는다. 방식·고민 필터는 유지하며 초기화는 세 조건을 모두 해제한다.
- 전체 검색만 서비스명 → 설명 → 보조 질문 → 확인된 담당자 → 기존 가격·CTA 순서로 표시한다. 기존 추천 화면의 질문 우선 순서는 유지한다.

## 지역과 담당자

지역은 탐색용 분류이며 담당자를 뜻하지 않는다. 명시적 상품 분류를 먼저 적용하고, 그 밖에는 기존 체계와 컬렉션을 따른다. 근거가 없는 서비스는 발견의 기록실에 둔다.

| 지역 | 연결 기준 |
| --- | --- |
| 연이의 운명 찻집 | 타로, 찻집, 손금, 연애 비책, 공통 상담 |
| 네오의 전략실 | 사주, 공통 상담 |
| 무성의 별의 궁전 | 자미두수 |
| 서한비의 달빛 정원 | 숙요점, 연애 비책 |
| 윤달의 천문대 | 점성술·베다점, 인생의 책 |
| 인연의 서재 | 인연의 서 |
| 발견의 기록실 | 휴먼디자인 및 다른 분류 근거가 없는 항목 |

초융합은 다섯 마스터의 지역 모두에서 찾을 수 있고 기존 공동 담당자 다섯 명을 표시한다. 휴먼디자인에는 담당자를 추가하지 않는다. 네오와 영냥이는 동일 인물이며 백사자의 영혼 설정을 유지한다.

## 이미지와 번역

기존 상품 이미지와 전담 초상을 우선한다. 승인된 `GGULGGUL_MASTER_ASSETS_WEBP.zip`의 그림은 지역 탐색에만 추가했다. 기능 그림은 장식으로 사용하며 계산 도표로 설명하지 않는다. 지역 이름과 소개는 HTML 텍스트다.

`scripts/design/build-world-search-assets.mjs <압축을 푼 폴더>`가 320/960px WebP 16개를 생성한다. `public/images/home/world-search/provenance.json`에 원본 해시와 변환 정보를 기록한다. 이미지에는 반응형 크기, 명시 크기, 지연 로딩을 지정하며 실패 시 기존 초상 또는 공용 달 문양으로 한 번 대체한 후 그림만 숨긴다. 지역 이름과 버튼은 남는다.

`i18n/authored/worldSearch-01.json`의 25개 키를 기존 12개 언어 사전에 공식 병합기로 반영했다. 기존 두 테마 토큰을 사용한다.

## 검증 재현

```powershell
node --test __tests__/ui/home-service-finder.test.js
npm run sync:public
npm run verify:home-service-registry
npm run verify:paid-gate-ui
npm run verify:mobile-pricing-parity
$env:PLAYWRIGHT_BROWSERS_PATH='C:/Users/user/AppData/Local/ms-playwright'
node scripts/verify-world-search.mjs
npm run check:fast -- --plan
npm run check:fast
# 커밋된 깨끗한 트리에서 실행
npm run check:pre-push
```

검색 회귀 38개와 360·390·768·1440px × 두 테마의 실제 생성 셸 브라우저 검증을 통과했다. 브라우저 검사는 외부 요청을 차단하고 API를 mock한다. 지역 선택, 검색, 유료 상세 미리보기, 무료 입력 진입, 키보드, 44px 터치 영역, 긴 한글 제목, 고정 검색, 번역 전환, 이미지 실패를 확인한다. 캡처와 결과는 로컬 `build-cache/world-search/`에 저장한다.

결제·인증·권한·운세 계산·DB·SEO 정책은 변경하지 않았다. 공식 동기화가 생성한 캐시 버전 외에 메타 의미와 공개 URL은 보존했다. 실제 결제·유료 LLM·운영 DB와 배포는 검증에 사용하지 않는다. 전달은 `codex/ggulggul-world-search` 브랜치이며 main 병합과 운영 배포는 별도 승인 범위다. CI 결과는 해당 커밋의 GitHub Actions 실행 기록으로 확인한다.
