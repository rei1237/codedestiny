# 영냥이 Android 1.0.46 등록 작업 기록

## 확인 기준

2026-09-30 Play Console 화면, 현재 소스, 공개 GET /api/yeongnyangi/products를 대조했다. mock·빌드·운영 구매를 별도 증거로 구분한다. 공개 프로덕션 또는 공개 스토어 게시 승인은 받지 않았다.

|---|---|---|

## 서명·플랫폼

- 패키지: com.codedestiny.app (유지).
- compile/target API 36, min API 24. Billing Library 9.1.0.
- 로컬 기존 업로드 키 SHA-256와 Console 업로드 인증서 일치: `73:C0:04:68:A5:4D:59:9F:42:96:4E:B2:E2:05:BD:EE:50:B1:66:94:45:32:EE:95:55:40:FC:2E:2C:50:14:27`.
- Console에서 Play App Signing 사용 중. 키 재설정 진행 배너는 관찰되지 않음. 새 키 생성·키 교체 없음.
- Google Play 설치본은 Google 앱 서명 키로 서명된다. 로컬 업로드 키 APK를 Play 설치본에 덮어쓰는 것은 업데이트 검증이 아니다. 업데이트 검증은 내부 테스트 45 → 46으로 수행한다.
- 기존 OAuth 복귀 scheme: com.codedestiny.app://auth. 네이티브 singleTask 유지.
- 직접 권한·잠금화면 specialUse foreground service는 기존 선언 유지. Console의 해당 권한 선언을 재확인해야 한다.

## 결제 정책 및 남은 경계

AI 생성 상담·보고서는 앱에서 소비하는 디지털 서비스이므로 기본 구매 경로는 Play Billing이다. 웹 PortOne은 Android 신규 구매 대체 경로로 사용하지 않는다. 대한민국 등의 대체 결제는 프로그램 등록·계약·표시·보고 요건을 별도로 충족해야 하며, 이 계정의 가입 상태는 확인하지 못했다. 따라서 대체 결제 예외를 적용하지 않았다.

- 공식 정책: https://support.google.com/googleplay/android-developer/answer/9858738
- 한국 대체 결제 요건: https://support.google.com/googleplay/android-developer/answer/11222040
- target API: https://developer.android.com/google/play/requirements/target-sdk
- 스토어 자산: https://support.google.com/googleplay/android-developer/answer/9866151

기존 구매 검증·acknowledge·consume·RTDN 경로를 유지한다. 이번 수정은 서버의 기존 상담 주문 연결 복구를 보완한다. 동일 주문 동시 결제·지연 승인·intent TTL 만료·RTDN 환불 후 결과 회수의 실제 Play 검증은 아직 필요하다. 운영 Worker에 이번 변경을 배포하지 않았으므로 후보 앱만 설치해도 서버 수정이 적용되는 것은 아니다.

## Console에서 남은 정확한 절차

1. 개발자 계정 → Android 개발자 인증. 2026-09-30까지 앱 등록 알림 확인. 기존 com.codedestiny.app의 등록 상태와 요구 서류를 확인한다. 새 패키지를 만들지 않는다.
2. 수익 창출 → 제품 → 일회성 제품. cd_content_tier_15가 저장됐는지 먼저 검색한다. 이번 세션은 1,000원 입력 후 적용 권한이 거부됐다. 중복 생성하지 않는다. 한국 가격 1,000원, 구매 옵션 purchase, 일회성/소비형으로 등록·활성화 완료 후 상품 조회를 검증한다.
3. 오마카세 50,000원은 사용하지 않은 새 SKU로 등록한다. 폐기 SKU를 재활용하지 않는다. Console 실제 가격·활성을 확인한 뒤 코드 정본 매핑과 검증 스크립트·등록 문서를 함께 수정한다. 등록 전에는 판매 차단을 유지한다.
4. cd_content_tier_01/02/06/09의 대한민국 구매 옵션 가격을 각각 3,000/5,000/10,000/20,000원과 대조한다. 해외 국가 가격은 Play formattedPrice와 대조한다. 이번 세션이 변경한 것은 tier_06 이름·설명뿐이다.
5. 설정/수익 창출 설정에서 Play Developer API 서비스 계정 권한, 주문 검증 권한, RTDN 연결 상태를 확인한다. 새 자격증명은 채팅·Git·바탕화면 패키지에 넣지 않는다.
6. 사용자 늘리기 → 스토어 등록정보 → 기본 등록정보. 한국어 초안·512px 아이콘·1024×500 기능 그래픽·실제 휴대전화 캡처를 저장한다. 현재 번역 목록부터 확인하며 지원하지 않는 언어를 임의로 추가하지 않는다. 공개 게시/검토 전송은 최종 승인 후 진행한다.
