## 1. 수집 범위 (민감정보를 처음부터 받지 않는 구조)

- 항목: 연도(필수), 체감(특별히 좋았음·특별히 힘들었음·함께 있었음 등, 기존 v1 6분류), 강도 1~3, 분야(복수 아님 — v1 은 항목당 1분야), 짧은 메모(선택, 최대 80자).
- 분야: 직업·사업·재정·관계·학업(기존) + 가족·이사·환경 변화·인간관계·기타(추가 예정). **건강 분야는 두지 않는다**(민감정보).
- 대상: 본인 프로필만(1차). 만 14세 미만은 가입 단계에서 이미 차단된다.

## 2. 선택 동의 바텀시트 (필수 동의와 분리, 처음 입력할 때만)

```
[선택] 맞춤 상담을 위한 인생 경험 정보 수집·이용 동의

· 수집 항목: 좋았던/힘들었던 연도, 체감 강도, 분야, 직접 입력한 짧은 메모
· 이용 목적: 운세·상담 결과의 개인 맞춤 해석, 다이어리 시기별 안내 제공
· 보유 기간: 동의 철회, 해당 프로필 삭제 또는 회원 탈퇴 시 지체 없이 파기
· 처리 방식: AI 상담 생성을 위해 Google LLC(미국)의 Gemini API로 전송될 수 있습니다(국외 이전).
  [학습 미사용] 전송된 정보는 AI 학습에 사용되지 않도록 설정되어 있습니다.  ← 설정 확인 전 삭제
· 동의하지 않아도 모든 운세 서비스를 지금과 똑같이 이용할 수 있습니다.

[동의하고 입력하기]   [다음에 할게요]
```

- 메모 칸 아래 상시 안내: "질병·종교·정치 성향·범죄와 관련된 내용이나 다른 사람의 실명은 적지 말아 주세요."
- 키워드 감지 시 확인 모달(차단 아님): "이 내용은 저장하지 않는 걸 권장해요. 수정할까요?"
- 철회 안내(프로필 설정): "동의를 철회하면 입력한 인생 경험과 이를 바탕으로 만든 맞춤 정보가 함께 삭제됩니다. 이미 받은 상담 결과는 그대로 남고, 이후 결과에만 반영되지 않습니다."
- 동의 이력 저장 항목: 동의 유형(`life_calibration`), 문구 버전, 동의 시각, 철회 시각, 표시 문구.

## 3. 개인정보처리방침 추가 조항 초안

- 선택 수집 항목: 인생 경험 정보(연도, 체감, 강도, 분야, 메모) — 목적: 맞춤 해석·다이어리 시기 안내 — 보유: 동의 철회·프로필 삭제·회원 탈퇴 시까지.
- 국외 이전 표에 인생 경험 정보 추가: 이전받는 자 Google LLC / 국가 미국 / 항목 인생 경험 정보(메모 포함 가능) / 시기·방법 AI 상담 생성 시 암호화 통신으로 전송 / 보유 처리 완료 후 [업체 정책 확인 후 기재] / 거부 방법 선택 동의 거부 또는 철회(거부해도 서비스 이용 가능).
- 파기 절차: 철회·삭제 요청 시 즉시 이용 중지(soft delete) 후 [N]일 이내 완전 삭제(배치). [N]은 P1b 구현에서 확정.
- 정보주체 권리: 프로필 설정에서 열람·수정·삭제·동의 철회. 고객센터로도 요청 가능.

## 4. 이용약관 추가 조항 초안

- 인생 경험 정보는 이용자가 자발적으로 제공하며, 이를 반영한 결과는 참고용 콘텐츠입니다.
- 제공한 정보가 사실과 다르면 맞춤 해석 결과가 달라질 수 있습니다.
- 결과는 의료·법률·투자 판단을 대신하지 않습니다.

- 처리방침·약관 변경은 버전과 시행일을 올리고(현재 `app/privacy-policy/PrivacyPolicyContent.jsx` `PRIVACY_POLICY_EFFECTIVE_DATE`, `app/terms-of-service/TermsContent.jsx` `TERMS_EFFECTIVE_DATE` 와 `worker/routes/auth.js` 의 `AUTH_PRIVACY_VERSION`·`AUTH_TERMS_VERSION` 을 함께 맞춘다), 사이트 공지 + 다음 로그인 배너로 사전 고지한다. 다국어본은 `lib/legal/legalContent.ts`.
