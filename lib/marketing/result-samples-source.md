# 상담 구성과 결과 예시

`result-samples.json`이 비교 화면과 상세 안내의 공통 원본이다. `guide`는 `js/consultation-sample-guide.mjs`가 렌더하며 `scripts/lib/build-visual-details.mjs`를 통해 기존 상품 상세 JSON에도 포함된다. 생성 파일은 `npm run sync:public`으로 갱신한다.

## 출처와 표시

- 사용자가 제공한 원문: https://claude.ai/artifact/PtPUfhaiHM37ebpxtr4nQV (꿀꿀 사주 LLM 결과 원문).
- `kind: result`: 가상 프로필의 입력 또는 결과를 그대로 발췌. 원문 장 제목과 링크를 함께 표시한다. 고객 후기 또는 새 생성 결과로 표시하지 않는다. 생략 부호는 떨어진 문단 사이의 생략을 뜻한다.
- 인연의 서: 개인판 「화해와 회복의 언어」, 궁합판 「갈등의 뿌리」. 현재 `content/product-details/master-love-codex`, `master-love-codex-compat`의 원문 패널과 대조했다.
- 연애 비책: 입력 질문, 「상대에게 다가가는 대화 문장」, 「7일 실천 가이드」. 권장 문장과 피해야 할 문장의 구분을 유지한다.
- 신년운세: 입력 질문, 일·직업에 대한 답변, 준비 조언. 특정 연도의 예시이며 선택 연도에 대한 결과를 보장하지 않는다.
- 인생의 책: 「성격과 내면의 작동 방식」과 「명식의 깊은 판독」의 원문. 구성은 현행 10장·핵심 판독·대운·세운을 기준으로 한다.
- `kind: editorial`: 현재 기능과 원고를 바탕으로 작성한 구성 설명. 모든 문단에 실제 생성 결과가 아니라는 표시를 붙인다.
- 초융합: 현행 `ExpertEvidence`, 결과 차례, `fusion-expert-contract`의 독립 해석·교차 판정·시기/행동·최종 판단 구성을 우선한다. 기존 원문을 개편 후 결과로 전용하지 않는다.
- 네오: 현행 작전실의 진단·반복 패턴·전략을 설명한다. 별도 상품의 제공·배송 조건을 약속하지 않는다.
- 연이: 찻집의 타로·사주·사주 궁합·숙요점 구성만 설명한다. 원문의 fortune-chat 결과는 찻집 결과로 사용하지 않는다.
- 영냥이 기존 4종: 기존 발췌·도식 링크·상품 연결을 유지한다.

## 화면과 검증

밝은 크림·로즈는 비교 및 예시 안내에만 적용한다. 기존 공식 이미지 원본을 재사용하며 마스터가 없는 상품에는 다른 마스터를 배정하지 않는다. 결제 조건은 기존 레지스트리와 제품별 진입 화면을 따른다.

회귀 검사는 `__tests__/ui/consultation-samples.test.mjs`이며 기존 CI의 `test:node` 패턴에 포함된다. 시각 검사는 비교 페이지와 실제 공유 상세 렌더러에서 360·390·430px 및 데스크톱을 확인한다.

## 2026-10-19 영냥이 안내 정리

- 타로 연어 예시 4개는 사용자 제공 2026-10-13 홍보자료의 T 원문 발췌와 대조했다. 카드 해석, 이직 흐름, 대출 상환과 비상 자금 점검, 마지막 메시지를 그대로 인용한다. 약 3.5만 자는 당시 예시 한 건의 분량이며 현재 상품의 고정 분량이 아니다. 공개 원문 링크는 기존 제공 링크를 유지한다.
- 인연의 서는 개인판·궁합판 각각 20개 챕터다. worker 메타데이터의 totalCharTarget 50,000을 목표로 안내하며, PDF 20페이지로 표현하지 않는다.
- 초융합 오마카세의 44개 챕터와 약 12.6만 자 상한 목표는 fusion-book.ts 상수를 사용한다. 다른 운세·등급까지 같은 분량을 보장하지 않는다.
