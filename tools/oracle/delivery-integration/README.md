# 자미 신규 계산의 결제 복귀·생성·전달 통합 검증

운영 기본 OFF, Swiss 차단을 유지하는 **로컬 메모리 통합 검사**다. DB·PG·LLM은 mock이며 실제 서버·계정·환경 파일을 사용하지 않는다. 프로젝트 루트(이번 작업은 전용 감사 워크트리)에서 실행한다.

```powershell
node --test __tests__/ui/ziwei-delivery-integration.test.mjs
node tools/oracle/delivery-integration/verify.mjs
```

`verify.mjs --record`는 이번 실행의 결과와 소스 해시를 `docs/engine-audit/results/delivery-integration-20261102/`에 기록한다. 과거 감사/실 DB 실험 결과를 재생성하지 않는다. 설치·DB 생성·PG·LLM·push·배포 명령은 없다.

## 실제 실행하는 부분

- 기존 허용 소스 핀을 확인한 자미 공개 계산/준비/실행 어댑터.
- 실제 화면의 입력 구성·submit·결제 응답 추출·복귀 콜백·생성·결과 폴링. 결제 복귀 직렬화 함수도 실제 코드를 사용한다.
- 실제 라우트의 입력 정규화/해시, 준비·근거·생성·결과 조회, 주문 입력 대조, 중복/lease 필터, 체크포인트 저장/재조회, 완료 전달, 사용 처리 표식, 공개 결과 변환.
- 실제 근거 변환, 생성용 확정 사실 문장과 `meta.dayun` 보정. 모듈별 private 함수는 독립 스코프에 보존한다.

전체 라우트/결제 실행 파일을 import하지 않는다. TypeScript AST로 해당 선언과 로컬 의존 선언만 추출한다. 외부 모듈 import/동적 import/require/process/eval/WASM은 VM에서 차단하며, 누락된 의존성을 실제 서비스로 폴백하지 않는다. 외부 네트워크 가드도 먼저 적용한다.

## mock 경계와 증명의 한계

- 인증·이용권 판정·접근 토큰·과금 증빙 claim은 mock이다. 본 통합 시나리오는 신규 단건 구매를 대상으로 한다. 가격 숫자는 합성 계약 검사용이며 실제 청구 가격 검증이 아니다.
- 결제창/리다이렉트는 복귀 인수와 mock 영수증 전달로 대체한다. PG 경계 `verifyPgPayment`만 mock으로 응답하고, 주문 소유자·입력 해시/키 대조와 주문 상태 저장은 실제 라우트 코드를 실행한다. PG 조회 횟수는 실청구 횟수가 아니다.
- `generateInitialConsultation`은 명반을 캡처하고 합성 장을 저장하는 mock이다. 모델 품질·실제 모델 프롬프트 전체·완성 분량은 검증하지 않는다. 관련 사실 문장/메타 보정 함수는 별도로 실제 실행한다.
- DB 모델은 메모리 배열이며 unique create·조건부 갱신·조회·실패 주입을 구현한다. 실제 Mongo 동시성 증거는 이전 13번 보고서의 별도 실험이다. 여기서는 실제 DB를 재기동하지 않는다.
- React mount, 실제 브라우저/물리 기기, 공통 결제 런타임 전체, 실 PG 웹훅, 전체 Worker/CI/빌드는 미검증이다. 신규 통합 테스트 13개 중 하나는 mock 조건식의 정확성을 검증한다.
- 기본 OFF 신규 경로와 이미 확정한 v2 준비 기록의 OFF 복귀를 구분한다. v2 fixture 생성에만 승인된 명시적 옵션을 사용하며 실제 라우트는 ON 옵션을 전달하지 않는다.

## 재현한 결함과 수정

신규 준비 명반의 `yearlyLuck.year`는 고정돼도 `resolveCurrentMajorLuckByChartAge`는 재개 시점의 현재 연도로 나이를 다시 계산했다. 2026→2027 복귀에서 근거의 나이가 4→5세로 변했고, 대한 경계에서는 다른 궁/메타정보를 선택할 수 있었다.

실행/표시 경계에서 준비 기록이 확인된 명반의 기준 연도를 WeakMap에 연결한다. 이는 영속 선택을 대체하는 메모리 캐시가 아니다. 매번 저장 명반의 세운 연도에서 복원하는 일시적 표시 문맥이며, 명반 필드·직렬화·스키마·선택 버전은 바뀌지 않는다. 준비 기록 없는 과거 결과는 종전 경로를 유지한다. 모듈 메모리가 사라져도 새 prepare/basis/generate/result 진입에서 동일하게 복원한다.
