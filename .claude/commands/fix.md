# 수정 실행
사용자 요청: $ARGUMENTS

[CLAUDE.md](../../CLAUDE.md)의 위험도로 판정한다. 파일 수만으로 RED로 올리지 않는다.
관련 경로 또는 선택 영역부터 읽고 필요한 호출부만 추적한다.
main 체크아웃에서 직접 수정하고 검증된 단위마다 즉시 커밋한다. 워크트리를 새로 만들지 않는다.
승인된 범위는 재확인하지 말고 수정·검증까지 진행한다.
검증은 npm run check:fast 한 번. UI 관련 검사는 npm run check:ui.
결과는 수정 파일·의도·명령/출력·남은 위험으로 보고한다.
