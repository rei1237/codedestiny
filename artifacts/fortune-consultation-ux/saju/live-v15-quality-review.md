# 사주 v15 실제 생성 편집 검수

## 판정

- **중대 오류로 불합격**. 정적 검증의 `element-causality` 차단을 원문 편집 검수에서도 확인했다. 단순 문체·분량 경고나 정규식 오탐으로 판단하지 않는다.
- 사용자가 승인한 후속 작업 조건인 ‘큰 문제없으면’을 충족하지 못했다. 자미두수·숙요점·서양 점성술·베다점과 해당 이미지 생성은 미착수 상태를 유지한다.

## 실행 범위와 결과

- 사용자 새 승인으로 동일 비공개 fixture의 v15 상담 1건을 실행했다. Gemini 2.5 Flash 5그룹 각각 1회, 총 5회 모두 `STOP`이었다.
- 입력 99,359토큰, 출력 16,258토큰, 본문 21,581자, 병렬 생성 wall time 25,090ms. benchmark에 설정된 입력 $0.30/M·출력 $2.50/M 기준 계산 비용 USD 0.0704527이며 청구 실측이 아니다.
- 실결제·운영 DB 쓰기·자동 재시도·모델 폴백·명시 캐시 생성·운영 승격은 0회다. 승인된 입력 100,000·출력 60,000토큰·USD 1 상한 안에서 종료했다.
- 원본 입력·원문·제공자 응답·요청 해시는 저장소 밖 `D:/Development/fortune-consultation-private/live-v15`에만 보존한다. 공개 증거는 익명 집계와 해석 오류의 요약만 포함한다.

## 원문에서 확인한 중대 오류

- 1·2·4·9·10·11·12장: 화 오행 부재에서 재정 규율·체계적 관리의 어려움과 손실 가능성을 도출한다. 실천 조언의 이유에도 같은 인과를 반복한다.
- 3·5·6·9·10·11장 및 네오 요약: 비견·겁재를 재물 분탈·동업 분쟁·손실의 근거로 사용한다.
- 1·2·3·4장: 정재·상관의 배치를 수입 능력·수익 창출·사업 적합성으로 확대한다.
- 7·8장: 특정 대운 나이와 2026년 세운을 안정적인 수입·사업 및 투자 기회·재물 축적의 유불리와 연결한다.
- 11장: 작은 검증의 예시로 특정 주식을 소액 매수한 뒤 시장 반응을 관찰하도록 제안한다. 일반적인 기록·비용 비교를 넘어 금융상품 거래 행동을 권한다.

## 다음 행동

- v15 사주 단계는 완료로 표시하지 않는다. 이번 5회 생성 승인은 소진됐으며 새 실호출은 추가 승인 없이 하지 않는다.
- 다음 교정에서는 재물 챕터뿐 아니라 중심 성향·십성·오행·대운·세운·캐릭터 요약까지 동일한 근거 경계를 적용해야 한다. 일반적인 관리 조언을 명식의 결함에 대한 처방으로 재연결하거나, ‘작은 검증’을 금융상품 매수로 바꾸지 않도록 실제 실패 유형을 mock 회귀에 반영한다.
- 후속 네 서비스는 사주 실제 검수에서 중대 오류가 없다는 조건을 충족한 뒤 이어간다.
