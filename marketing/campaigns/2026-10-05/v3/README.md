# 스레드 업로드용 설명형 10장

- 정본: `manifest.json`의 이미지 10장과 `posts.json`의 계정별 첫 글·답글.
- 전체 미리보기: `../threads-preview.html`. 별도 서비스 소개 디자인: `../preview.html`.
- 1번은 원본 바이트를 그대로 보존. 2~10번은 1080×1350 JPEG이며, 이미지 자체에 기능 설명과 조건을 담았다.
- `../build-threads-v3.mjs`는 편집용 HTML/CSS와 원고를 생성한다. 생성 후 브라우저를 1080×1350으로 설정하고 글꼴 로딩 후 각 HTML을 캡처한다. `../validate-threads-v3.mjs`로 규격·표지 해시·500자 제한·레이아웃 기록을 확인한다.
- 캐릭터 그림은 기존 `../v2/art/` 원본을 그대로 재사용. 정확한 ImageGen 프롬프트는 `../v2/generation-prompts.json`. 기능 화면은 `../assets/`의 실제 캡처이며 가상 입력 여부를 표기한다.
- 이전 v2 파일은 보존용이며 게시에 사용하지 않는다. 신규 카드에 네오 캐릭터·정치 사례·전체 적중률 주장을 넣지 않았다.
- 2026년 10월 5일 09:00 KST 실행 유지. 운영 가격 9,900원, 월정석 1개=10원, 원하는 수량 할인, 개선 오행 UI의 운영 반영을 확인한 뒤 게시한다. 7번 ‘운영 반영 전’ 문구는 운영 확인 후에만 제거하고 재출력한다. ‘가상 입력 예시’는 유지한다.
- 월정석 30일 유효·현금 출금 불가. 사람 상담 후기와 AI 상담을 구분. 리포트 제작은 외부 도구에 프롬프트를 직접 전달하는 방식이다.
- 실제 서비스 소개는 `/about/`에 연결된다. 가격 숫자는 상시 페이지에 복제하지 않고 현재 상담 선택·결제창 안내로 연결한다. 기존 CMS·정책·운영자 앵커와 다국어 메타데이터를 유지한다.
- 예약은 Codex 후속 실행 `10-5-threads`이며 Threads 네이티브 예약 등록이나 운영 배포 완료를 뜻하지 않는다.
