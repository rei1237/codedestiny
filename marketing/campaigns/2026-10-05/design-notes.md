# 캠페인 표면 디자인 기록

## Overview

사용자가 승인한 연이의 크림·로즈와 영냥이의 남색·금색을 바탕으로, Threads v3 설명형 카드와 실제 `/about/` 소개 화면을 기록한다. 고민에서 출발해 기능·근거·이용 방법을 이해하도록 설명과 실제 UI 예시를 함께 배치했다. 이번 표면의 기록이며 전역 `DESIGN.md`를 새로 정의하거나 변경하지 않는다.

게시 정본은 `v3/manifest.json`의 이미지 순서와 `v3/posts.json`의 계정별 첫 글·답글이다. 카드 갤러리는 `threads-preview.html`, 이전 서비스 소개 디자인은 별도의 `preview.html`로 유지한다. 실제 소개 화면은 `app/about/ServiceIntroduction.jsx`와 `app/about/service-intro.css`에서 렌더링하고, `build-service-intro.mjs`가 정적 JSX·문구 데이터·최적화 자산을 생성한다. 로컬 산출물 완성은 게시 또는 운영 배포 완료를 뜻하지 않는다.

## Colors

밝은 크림·로즈 구간은 고민의 공감, 무료 체험, 가입 안내에 사용한다. 남색·금색 구간은 질문 중심 상담, 초융합, 차트 설명에 사용한다. 두 팔레트는 캐릭터의 역할과 읽기 흐름을 구분하며, 실제 소개 화면의 스타일은 `.cd-service-intro` 범위에 한정한다.

## Typography

제목은 로컬 `Yeongnyangi Myeongjo`, 본문은 `Yeongnyangi Noto`다. v3 카드 제목은 59px, 설명은 주로 25–28px, 조건 안내는 23px로 구성해 이미지 안에서 설명과 조건을 함께 읽을 수 있게 한다. 실제 소개 페이지의 제목은 42–70px, 섹션 제목은 30–46px의 반응형 크기이며 본문은 16px/1.85, 문단 폭은 최대 62ch다. 긴 설명은 짧은 문단과 소제목으로 나눈다.

## Layout

게시 1번은 `assets/official-three-characters.png` 원본을 바이트 그대로 보존한다. 2–10번은 각각 1080×1350 JPEG이며 서비스 소개 → 가입 혜택 → 여섯 체계 → 초융합 → 무료 체험 → 오행 차트 → 상담 보관·리포트 제작 → 사람 상담 후기 → 시작 안내 순서다. 새 아홉 카드에는 그림만 배치하지 않고 기능 설명, 실제 화면, 필요한 조건을 담았다.

실제 `/about/`의 소개 구간은 고민의 공감 → AI 상담 방식 → 여섯 체계 → 초융합 → 무료 타로 → 오행 차트 → 상담 보관·이미지 제작 → 사람 상담 후기 → 가입 안내 → FAQ 순서다. 데스크톱 콘텐츠 폭은 최대 1200px이며 설명과 예시를 두 열로 배치한다. 760px 이하에서는 한 열, 좌우 20px 여백으로 전환한다. 기존 서비스 소개의 CMS 편집, 정책·운영자 앵커와 다국어 메타데이터를 유지한다.

재캡처 후 별도 범용 시각 검토자가 신규 카드 9장 전체와 실제 `/about/` 모바일·데스크톱 캡처 14장을 검토해 SHIP으로 판정했다는 전달을 받았다. 문서 작성자는 화면 검토를 재실행하지 않았다. `v3/about-layout-check.json`에는 360·390·430·1440px에서 가로 넘침 없음, 앵커 존재, h1 한 개가 기록되어 있다. `v3/validation.json`에는 원본 표지 보존과 2–10번의 이미지 규격 검증이 기록되어 있다. 이 증거는 로컬 화면·자산 검증이며 실기기, 실결제 또는 운영 반영 증거가 아니다.

## Elevation & Depth

밝고 어두운 섹션의 대비와 얇은 구분선으로 내용을 나눈다. 실제 소개 화면의 UI 예시에만 은은한 그림자를 적용해 시각적 근거를 구분한다. 카드에서는 설명의 순서와 여백이 우선이며 장식이 조건 안내를 가리지 않게 한다.

## Shapes

실제 소개 화면의 CTA는 둥근 알약 형태, UI 예시는 22px 모서리를 쓴다. v3 카드의 UI 프레임은 20px 모서리다. 체계 설명·초융합 비교·상담 보관 안내는 구분선과 목록으로 읽기 흐름을 유지한다.

## Components

- **CTA:** 무료 운세·무료 타로·영냥이 상담의 실제 주소로 연결한다. 소개 화면의 모바일 주 버튼은 전체 폭, 링크는 최소 44px 높이, 키보드 초점은 외곽선으로 표시한다.
- **캐릭터:** 공식 연이 프로필과 영냥이 원본을 참조해 제작한 `v2/art/` 삽화를 재사용한다. 정확한 생성 프롬프트는 `v2/generation-prompts.json`에 있다. 원본 표지의 세 캐릭터는 유지하되 신규 카드에 네오 캐릭터나 정치 소재를 추가하지 않는다.
- **오행 차트:** `ReadingCharts.tsx`와 `ReadingVisuals.tsx`의 공유 `ElementDistribution`을 사용한 실제 개선 컴포넌트 예시다. 목·화·토·금·수의 값에 색·아이콘·수치를 함께 제공한다. 막대는 최댓값 기준 상대 길이이며 백분율·적중률·미래 점수가 아니다. 가상 입력이라는 표기를 유지한다. 7번 카드의 운영 반영 전 표기는 실제 운영 확인 후에만 제거하고 재출력한다.
- **기능 설명:** 무료 기본 운세·로그인 없는 세 장 타로와 유료 상세 상담의 범위를 구분한다. 모둠은 두 체계 교차분석, 오마카세는 여섯 체계 전체 통합으로 설명하며 체계별 근거를 섞어 단정하지 않는다.
- **후기:** 네오의 사람 1:1 상담에 게시 동의를 받은 후기이며 영냥이 AI 상담 후기로 표현하지 않는다. 개인 경험의 한계를 함께 둔다. 실제 소개 화면에서는 콘텐츠 운영자 안내 앵커로 연결한다.
- **이미지 리포트:** 상담 기반 제작 프롬프트를 사용자가 ChatGPT 등 외부 도구에 직접 전달해 제작하는 방식이다. 외부 이용 조건이 적용될 수 있으며 자동 생성 기능으로 소개하지 않는다.
- **상시 이용 안내:** `/about/`에는 미래 가격·혜택의 숫자를 복제하지 않는다. 최신 가격과 월정석 적용 조건은 상담 선택 화면·결제창으로, 보유량과 유효기간은 계정 안내로 연결한다. 소개 문구는 기존 `about` CMS 이름공간을 사용한다.

## Do's and Don'ts

- **Do:** 게시 전 10월 5일 정책의 운영 가격·월정석 부분 할인·개선 오행 UI 반영을 확인한다. 카드의 가입 혜택·금액·유효기간 안내는 게시 전 확인 대상이며 이 문서는 정책 정본이 아니다.
- **Do:** 게시용 이미지와 원고는 `v3/manifest.json`, `v3/posts.json`, `threads-preview.html`을 대조한다. 이전 `preview.html`과 v2 자료를 최신 게시 묶음으로 혼동하지 않는다.
- **Do:** 이미지 규격·표지 해시·500자 제한·레이아웃 기록은 `node marketing/campaigns/2026-10-05/validate-threads-v3.mjs`로 검증한다. 이 문서화 작업에서는 검증기를 재실행하지 않고 저장된 결과를 확인했다.
- **Don't:** 정치 소재·신규 네오 캐릭터·전체 적중률 주장·성공 보장·공포·무제한 혜택을 추가하지 않는다.
- **Don't:** 로컬 예시·가상 입력·시각 검토를 실결제 검증이나 운영 출시로 표현하지 않는다. 실제 게시 계정과 운영 적용 여부는 게시 전에 별도로 확인한다.
- **Don't:** 상시 소개 페이지에 미래 가격 숫자를 고정하거나, 이 문서를 결제·이용권·월정석·단건 결제·인증·API·DB 정책의 변경 근거로 사용하지 않는다.
