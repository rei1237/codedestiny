## 바로 시작하기

1. `calendar.csv`에서 날짜별 작업을 확인한다. 09:00 알림, 블로그 12:30, 영상·X 19:30, 일요일 결산 20:00이다. 시간은 최적화 실측값이 아닌 초기 실험값이다.
2. `week01.md`에서 게시일과 원고 ID를 찾아 복사한다. 블로그 5편, 한국어 영상 3편, 영어·일본어 영상 각 1편, X 게시 2편이 첫 주 게시 대상이다. 나머지 OSMU 원고는 재활용 후보이며 추가 발행 지시가 아니다.
3. 원고 상태와 영상 상태를 구분한다. 글·대본은 준비됨. MP4·녹음·썸네일 이미지·서비스 화면 캡처는 미제작이다. 영상은 편집 후 소리와 모바일 자막을 확인해야 한다.
4. 실제 업로드 후 `publication-log.csv`에 공개 URL과 확인 시간을 기록한다. 알림을 읽었거나 파일을 열었다고 게시 완료로 바꾸지 않는다.
5. 2~4주 원고는 `template.md`로 해당 게시일 전에 작성한다. 캘린더의 `planned`는 원고 준비 완료를 뜻하지 않는다.

## 제작 기본값

- 주당 블로그 5편, 한국어 원본 영상 3편, 해외 재편집 2편. 하루 60~90분은 예상이며 실제 소요시간을 기록한다. 어려우면 미게시 건을 누적하지 말고 다음 주 수량을 조정한다.
- 영상 1080×1920, 30초 목표. 자막은 한 화면 두 줄 이내, 핵심 문장은 화면 중앙에 배치하고 앱 버튼과 겹치는지 업로드 미리보기로 확인한다. 내레이션 실측 전에는 30초 검증 완료라고 쓰지 않는다.
- 얼굴 없는 구성: 직접 만든 문자 화면과 직접 캡처한 비식별 서비스 화면. 예시 생년월일을 사용하고 계정명·결제 내역·상담 사연은 노출하지 않는다. 카드 이미지를 쓰려면 사용 권한을 확인한다. 기본 대본은 문자만으로 제작할 수 있다.
- 음악은 무음이 기본이다. 플랫폼 내 음원을 썼다면 다른 플랫폼에 그 음원 포함 파일을 그대로 옮기지 않는다. 워터마크 없는 원본으로 각각 업로드한다.
- 연이 새 그림이 필요하면 사용자 지정 정본 `C:\Users\user\Desktop\CodeDestiny-Build\연이 프로필1.png`를 확인한 뒤 별도 제작한다. 이번 패키지는 새 캐릭터 이미지를 만들지 않는다.
- 금요일 영어, 일요일 일본어는 해당 언어의 자막·내레이션·설명·링크를 함께 적용한다. 기존 한국어 채널에는 `[EN]`, `[日本語]` 제목과 언어별 재생목록으로 시험하며 새 계정을 임의 생성하지 않는다.
- 반응 좋은 원본은 공개 48시간 이상 지난 콘텐츠에서 선정한다. 수치가 없으면 첫 주 확정 대본을 사용하고 '인기 콘텐츠'라고 부르지 않는다.

## 링크와 정책

원고의 기본 도착 URL은 한국어 `https://code-destiny.com/ggulggul/`, 영어 `/en/`, 일본어 `/ja/`다. 주제별 `/saju/`, `/tarot/`, `/ziwei/`, `/today/` 안내 페이지도 쓴다. 영어·일본어 진입 페이지의 공개 텍스트는 확인했으나 모든 결과·결제 흐름의 번역을 검증한 것은 아니다. 해외 CTA는 사이트 둘러보기로 한정한다.

실제 가격은 게시일 화면에서 확인한다. 이용권·월정석·단건 결제 정책, 환불 조건, 지급 혜택은 변경하지 않는다. 이 패키지의 CTA는 '전체 무료'를 약속하지 않는다. 무료 기능을 강조하려면 실제 무료 범위를 먼저 확인한다.

추적은 기존 UTM 방식에 맞춰 `utm_source=naver_blog|youtube|tiktok|x`, `utm_medium=social`, `utm_campaign=growth_20261012`, `utm_content=<원고ID>_<언어>`를 사용한다. 개인 사연·생년월일은 넣지 않는다. Threads의 기존 추적 규칙은 바꾸지 않는다. Shorts의 설명·고정 댓글 URL은 클릭 유도로 쓰지 않고 채널 프로필 링크로 안내한다. TikTok 프로필 외부 링크는 계정에서 실제 사용 가능할 때만 안내하고, 없으면 'Code Destiny를 검색해 주세요'로 바꾼다.

## 알림 실행 계약

매일 09:00: 한국 날짜의 `calendar.csv` 행과 게시 로그를 읽고 미완료 당일 작업만 알린다. 완성 원고, 편집 재료, 채널, 시각, 예상 시간을 제공한다. 10월 12일 전에는 계정 프로필·링크 준비 안내만 하고 날짜 운세를 미리 게시하지 않는다. 11월 8일 이후에는 이 4주 표를 반복하지 않고 다음 주 새 일정과 원고를 준비한다. 자동 발행은 기존 Threads Worker만 담당한다.

매주 일요일 20:00: 플랫폼별로 접근 가능한 실측을 기록하고 유지 주제 2개·변경 요소 1개를 제안한다. 게시 직후 일본어 영상은 '관측 시간 부족'으로 표시한다. 통계를 읽을 수 없으면 사용자에게 주간 통계 화면 또는 수치를 요청한다. 광고 수익을 추정해 채우지 않는다. 기존 월요일 SEO 자동화는 수정하지 않는다.

1주차 기준선 → 2주차 첫 문장 → 3주차 CTA → 4주차 주제 배분 순으로 한 변수만 바꾼다. 플랫폼 조회수 정의가 다르므로 채널 간 단순 합산 성과를 내지 않는다. 게시 후 48시간 같은 경과 시점의 조회·시청 지속·외부 방문을 비교한다. 채널 귀속 수익 데이터가 없으면 전체 광고 수익을 특정 게시물 성과로 배분하지 않는다.
