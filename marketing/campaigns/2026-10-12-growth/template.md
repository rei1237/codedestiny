# OSMU 제작 양식과 검수

## 입력

- 날짜(KST), 원고 ID, 언어, 대상 고민, 점술 체계, 게시 채널과 시각
- 해석 근거: 실제 서비스 설명/계산 문서 또는 일반적 성찰. 개인 계산을 하지 않았으면 그 사실을 구분한다.
- 소개 기능과 확인된 도착 URL, 실제 무료 범위, 소재 사용 권한
- 전주 실측과 이번 주 바꿀 변수 하나. 수치가 없으면 없음으로 기록

## 작성 결과

1. 네이버: 키워드와 고민을 함께 담은 제목, 본문 900~1,200자, 짧은 소제목 3~4개, 이미지 2개 배치안·alt, 본문 끝 관련 기능 CTA와 UTM URL. 전체 서비스 무료라는 약속 금지.
2. Shorts: 0~3/3~20/20~30초 표(화면·자막·대사), 제목, 설명, 프로필 안내 고정 댓글. 낭독 녹음의 실제 길이를 확인한 후 자막 타이밍 확정.
3. Threads: 독립 원고 200자 이내, 쉬운 장면·긍정 응원·선택적 질문. 기존 Worker를 대체하는 검수 후보라고 표시하고 추가 발행하지 않는다.
4. X: 짧은 확언 본문과 링크 답글. 'RT하면 복이 온다' 같은 교환 약속 금지. 주 2회 지정 슬롯 이외는 후보 상태.
5. 해외: 영어·일본어 제목·내레이션·자막·CTA를 함께 현지화. 한국의 띠/오행 개념은 설명부터 제공하고 서양 별자리와 혼합하지 않는다.

## 출고 확인

- 날짜·요일·주제·서비스 일치 / 중복 원고 및 실제 게시 URL 확인
- 불안을 자극하는 단정, 상대 마음 확정, 투자 수익 보장, 지어낸 후기 제거
- 이용권·월정석·단건 결제 의미 보존 / 가격은 최신 화면에서 확인
- 링크 응답과 도착 언어 확인 / 한국어 결제 화면까지 번역됐다고 추정하지 않기
- 제목·본문·자막 맞춤법 / 9:16 휴대폰 미리보기 / 음성 실제 길이 확인
- 시각 자료 없으면 '미제작', 게시 확인 안 됐으면 '미게시', 통계 접근 안 되면 빈 값
- 게시 당일 원고와 실제 URL을 publication-log.csv에 연결

## 주간 보고 양식

관측일 / 플랫폼 / 데이터 기간 / 게시 후 경과시간 / 공개 URL / 조회 / 저장 / 댓글(작성자 답글 제외) / 시청 지표 / UTM 방문 / 이용 완료 / 실제 광고 수익(통화 포함) / 데이터 출처.

해석: 무엇을 유지할지 2개, 무엇을 바꿀지 1개, 근거와 표본 한계. 첫 주 수익 목표를 임의로 수치화하지 않는다. 수익이 없어도 0은 보고서에서 확인된 경우에만 기록한다.
