# 영냥이 비공개 시험 안내

현재 준비물: recording/layout-preview.webm (실제 음성 없는 화면 구성 시안), recording/layout-preview.png (정지 화면), recording/stage.html (30초 무음 화면 구성), recording/assets/original.webp (기존 원화 복사), 대기·말하기·눈감기 PNG 후보 세 장, 원본 생성 시트와 provenance.json, 05-video-scripts.md의 30초 실제 녹음 문장.

사용자 수정 요청 반영: 최종 요청에 따라 턱을 괸 자세에서 작은 운명의 책을 앞발로 안고 앉는 포즈로 바꿨다. 원화처럼 시크한 눈매에 작은 미소를 더했다. 과하게 동그란 아기 같은 눈 시안은 최종안에서 제외했고, 모자·옷·색상·캐릭터 정체성은 유지하는 방향이다. stage.html과 PNG 세 장에는 이 새 후보를 사용한다.

완료와 미완료를 구별한다. 이미지 후보 준비는 완료했지만 새 포즈의 상태 간 정합·캐릭터 외형 검수는 미완료다. 첫 단독 말하기 생성은 원화 대비 확대·변형되어 채택하지 않았다. 다음 시트도 후보이며 입 전환이 튀면 완성 자산으로 쓰지 않는다. 무음 화면 시안은 본인 음성으로 녹화한 시험편이 아니다.

## 가장 작은 녹음 요청

05-video-scripts의 30초 표를 본인 목소리로 읽어 WAV 또는 M4A로 저장한다. 앞뒤 2초 침묵을 남기고 BGM·보이스 변조·웹캠을 섞지 않는다. 조용한 같은 거리에서 두 번 읽되 더 자연스러운 한 번을 고른다. 음성이 확보되면 에이전트가 실제 길이에 맞게 자막을 나누고 시험 화면을 완성한다.

## 브랜드 시험: veadotube mini + OBS

1. 공식 배포처에서 무료 veadotube mini와 OBS를 준비한다. 유료 옵션은 구매하지 않는다.
2. veadotube mini의 대기·말하기·눈감기에 세 후보 PNG를 배치한다. 같은 724×724 셀이고 추출 후 재배치하지 않았다. 먼저 키보드/표정 전환으로 귀 끝·모자·눈·발 위치를 확인한다. 외형이 흔들리면 후보 불합격으로 기록한다.
3. 본인 마이크를 선택한다. 5초 조용히 있었을 때 입이 닫히도록 감지 기준을 맞춘다. 작은 목소리·일반 목소리·문장 사이 휴식을 읽어 보고 말끝이 잘리거나 침묵 중 움직이는지 확인한다.
4. OBS는 자동 구성 마법사에서 녹화 용도로 시작한다. 제안 시작값은 1920×1080, 30fps. 성능이 부족하면 1280×720으로 한 번 시험한다. 컴퓨터별 성공은 아직 확인하지 않았다.
5. 장면 소스는 영냥이 창/투명 출력, 배경, 자막, 마이크만 사용한다. 디스플레이 전체 캡처 대신 필요한 창을 지정하고 veadotube UI가 녹화되지 않는지 확인한다.
6. 30초 녹화 후 휴대전화에서 재생한다. 목소리가 또렷하고 자막이 2줄 이내인지 확인한다. 원본 웹캠·알림·데스크톱이 들어가지 않았는지도 확인한다.

veadotube mini는 마이크 반응으로 이미지를 바꾸는 PNG 아바타다. 정밀 얼굴 추적·Live2D 모델이라고 부르지 않는다. 말하면서 눈을 감는 네 번째 상태가 필요하면 우선 자동 눈깜박임을 끄고 대기/말하기부터 검수한 뒤 추가 제작한다.

## 웹캠 시험: VTube Studio 기본 모델

브랜드 시험과 다른 장면·파일을 사용한다. VTube Studio 기본 모델에서 웹캠 추적을 켜고 정면·좌우 고개·깜박임·입 벌리기를 짧게 녹화한다. 워터마크를 유지한다. 원본 카메라 영상을 OBS 소스로 추가하지 않는다. 기본 모델은 영냥이 영상이나 공개 홍보물에 사용하지 않는다.

확인할 것은 눈·입·고개 움직임이 따라오는지, 안경·조명·고개 회전 때문에 끊기는지, 녹화 중 프레임이 불안정해지는지다. 이 결과만으로 영냥이 Live2D가 완성됐다고 하지 않는다. 전용 리깅은 이 시험과 브랜드 검수 후 별도 범위로 판단한다.

| 확인 항목 | 현재 상태 | 통과 조건 |
|---|---|---|
| 원화 외형·모자·비율 | 미검수 | 포즈 변경은 허용, 모자·얼굴 정체성·색상은 원화와 비교하여 사용자 확인 |
| 대기/말하기/눈감기 기준점 | 미검수 | 빠르게 전환해도 위치가 튀지 않음 |
| 본인 음성과 입 전환 | 음성 미수령 | 말끝·휴식·침묵에 자연스럽게 반응 |
| 휴대전화 음성·자막 | 미검수 | 작은 화면에서 두 줄과 원음이 또렷함 |
| 웹캠 추적·성능 | 미실행 | 기본 모델로 눈·입·고개 확인, 녹화 안정 |
| 원본 웹캠 노출 없음 | 녹화 후 확인 필요 | 출력에 원본 카메라·캡처 UI 없음 |
| 사용자 말투·연출 승인 | 대기 | 시험편 확인 후 본편 제작 결정 |
