가격 정본: lib/payment/server-feature-pricing.ts 및 해당 상품 pricing registry. 인연의 서 진입의 PriceBadge와 기존 결제 게이트를 유지한다. 영냥이를 하나의 고정 가격 상품이나 모두 무료인 상담으로 설명하지 않는다.

2026-10-21 정본 함수 조회 스냅샷: 개인판 30,000원, 궁합판 50,000원, 네오 전략실 30,000원, 신년운세 30,000원, 영냥이 고등어 사주 질문 5,000원. 네오 이메일은 질문별 사주 기본 10,000원, 사주·자미두수와 관상 포함 조합 40,000원까지이며 선택·질문 수에 따라 합산한다. 조회에 사용한 함수는 resolveServerFeaturePricing와 neoQuestionPrice다. 이 숫자는 검토 문서의 날짜 붙은 스냅샷이고 UI 하드코딩으로 사용하지 않는다.

네오 이메일 정책 정본: lib/neo-consultation/policy.js (neo-email-20261020-manual), 접수 입력·가격은 app/neo-consultation/NeoConsultationClient.tsx와 그 import. 보통 24시간·접수 집중 시 3일 이내, 일일 한도는 기존 정책에 따른다. 새 답변 본문은 서비스 서버에 보관하지 않으며 수신 이메일에서 확인한다. 기존 신청 재열람 조건은 그대로다.

인연의 서 구성 정본: worker/lib/master-love-codex-prompt.mjs, src/features/master-love-codex. 마스터 정본: components/fortune/master-profiles.ts. 현재 상세 원고: content/product-details/*/manifest.json. 실제 결과 발췌: lib/marketing/result-samples.json. 인연의 서 두 판은 서로 다른 발췌이며 고객 후기와 구별한다.

공개 동선:

- 홈 → 고민 또는 마스터 → 해당 기존 상세·시작 화면. 공통 질문 절차를 추가하지 않는다.
- 인연의 서 콘텐츠 → /master-love-codex/ → 실제 예시 → 개인·궁합 선택 → 기존 로그인·결제.
- 네오 콘텐츠 → 공개 가이드·소개 → /neo-consultation/ → 접수 방식·가격·이메일 전달 확인. 접수 noindex 유지.
- 기존 결과는 꿀꿀 운세 /records/, 영냥이 /yeongnyangi/library/ 및 기존 개별 결과 경로를 보존한다.

카피 원칙: 고민을 먼저 말하고, 체계·마스터·제공 방식을 구체적으로 설명한다. 미래·재회·구매 효과를 보장하지 않는다. 후기 자료가 없는 상품에 후기나 별점·인원수를 만들지 않는다.
