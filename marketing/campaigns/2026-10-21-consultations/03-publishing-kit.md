# 게시 준비와 사용자 검토 시간

외부 게시 전 원고와 해석 검수 필요. 자동 게시·예약·메일 발송을 하지 않았다. WordPress의 기존 초안은 수정하거나 복제하지 않았다. 이 폴더의 글은 네이버 블로그용 신규 원고이며 사이트에는 기존 대표 상세·비교 페이지를 연결한다. 같은 전문을 사이트·WordPress에 동시 게시하지 않는다.

| 순서 | 산출물 | 사용자 시간 | 에이전트 후속 |
|---|---|---|---|
| 1주 | 01 상품표 + 상세 미리보기 + 측정표 | 해석·범위 검토 30분 | 지적 반영 |
| 2주 | 30초 영냥이 시험 원고와 화면 | 원고 10분·녹음 10분·웹캠 시험 15분·평가 15분 | 실제 음성 동기화·재생 검증 |
| 3주 | 연애 패턴 글·본편·쇼츠 2개 | 원고 20분·녹음 20분·완성본 15분 | 편집·자막·게시본 확정 |
| 4주 | 네오 질문 글·본편·쇼츠 2개, 비교·신년 가이드 | 검토 25분·녹음 20분·완성본 15분 | 실제 관측표 정리 |

설정이 길어지면 본편 1편을 다음 주로 옮긴다. 주 2시간을 넘겨 완성도를 맞추도록 요구하지 않는다. 30초 시험이 통과하기 전에 본편 영상들을 대량 렌더링하지 않는다.

YouTube 설명 첫 두 줄: “같은 장면에서 마음이 멀어진다면, 상대의 마음을 추측하기 전에 내 반응을 한 번 적어보세요. 영상 속 일반적인 예시와 개인 상담 결과는 다릅니다.” 다음 줄에 주된 상품 링크 하나, 다음에 “진행 영냥이 · 인연의 서 해석 담당 마스터 · 운영자가 직접 녹음한 해설”.

네오 영상 설명: “결정을 대신 내려주는 답보다, 내가 놓친 조건을 정리하는 질문을 준비합니다. 네오에게 물어봐는 접수 내용을 직접 읽고 AI 분석을 활용해 작성·검수한 이메일 답변이며 실시간 상담이 아닙니다.” 다음 줄에 상품 링크 하나.

썸네일 A: “사람은 바뀌는데 / 왜 늘 같은 끝일까” — 기존 영냥이는 우하단 25%, 관계 장면 2개를 대비. 사연·실제 대화 캡처는 사용하지 않고 편집 예시 문장만 둔다.
썸네일 B: “운세는 들었는데 / 결정은 그대로?” — 선택지 두 장과 미완성 질문 한 줄. 공포·재회 확정·매출 보장 문구 금지.

쇼츠에는 URL 클릭을 가정하는 “아래 링크 클릭” 문구를 고정하지 않는다. 실제 게시 화면에서 가능한 관련 본편 연결 또는 프로필 링크를 확인하고 한 가지 안내로 통일한다. 본편 설명 링크는 앱·모바일에서 직접 눌러 해당 상품으로 가는지 확인한다.

무료 배포 순서: 기존 네이버 블로그 1편 → YouTube 본편 → 같은 설명의 중복이 아닌 서로 다른 질문의 Shorts 2편. 외부 커뮤니티에는 해당 질문에 답하는 글을 먼저 쓰고 운영 규칙이 허용할 때만 관련 링크를 둔다. 홍보 글 대량 복제·자동 댓글·무관한 링크 배포는 운영안에 넣지 않는다.
