## C01

사주에 물이 없다는 말이 마음에 남았나요?

오행의 개수만으로 공감 능력이나 성격을 단정하지 않아요. 일간과 계절, 다른 글자와의 관계를 함께 봅니다.

연이가 어려운 말을 쉬운 질문으로 풀어드릴게요. 저장해두고 내 사주를 읽을 때 다시 펼쳐보세요.

10년 경력 명리학자가 설계·검수한 CODE DESTINY. 기본 사주부터 시작할 수 있어요.
#사주 #오행 #무료사주 #꽃돼지연이 #코드데스티니

대체텍스트: 연이의 사주 노트 01. 꽃돼지 연이가 안내하는 물이 없는 사주? 6장 카드뉴스. 각 장 제목: 사주에 물이 없으면, 마음도 메마를까? / 숫자만 세면 놓치는 게 있어요. / ‘없다’는 말부터 다시 살펴봐요. / 계절과 관계를 같이 읽어요. / 이렇게 물어보면 더 도움이 돼요. / 사주를 쉽게, 연이와 한 장씩.

## C02

자미두수 명반, 어디부터 봐야 할지 막막했다면 세 단계로 시작해보세요.

명궁에서 나의 기본 결을 살피고, 궁금한 영역을 고른 뒤, 다른 궁과 별의 연결을 함께 읽습니다. 한 궁이나 별 하나가 관계와 직업의 결말을 정하지 않아요.

저장해두고 명반을 열었을 때 순서대로 따라가 보세요. CODE DESTINY에서 기본 자미두수를 시작할 수 있습니다.
#자미두수 #자미두수명반 #명궁 #꽃돼지연이 #코드데스티니

## C03

같은 공간에 있어도 서로 느끼는 거리는 다를 수 있죠.

숙요점의 근거리·중거리·원거리는 두 본명숙 사이 배치를 나누는 분류입니다. 실제 거주 거리나 연락 횟수로 정하는 것은 아니에요.

관계 이름으로 결론 내리기 전에, 각자 편한 연락 간격부터 이야기해보세요. 내 본명숙은 CODE DESTINY 기본 숙요점에서 확인할 수 있습니다.
#숙요점 #숙요궁합 #본명숙 #꽃돼지연이 #코드데스티니
