## OpenFate

제목: 명반 읽기 안내에 함께 쓸 수 있는 입력 조건 비교표를 제안드립니다

안녕하세요. 꿀꿀 운세의 WordPress 자료를 편집하고 있습니다. 귀 사이트의 명반 읽기 안내에서 입력 조건과 해석 순서를 나누어 설명한 내용을 확인했습니다.

저희는 두 계산 결과를 비교할 때 양력·음력, 윤달, 시간 경계, 운의 층을 독자가 직접 기록하는 10항목 확인표를 준비했습니다. 특정 도구가 맞다고 단정하는 표가 아니라, 확인된 값과 아직 모르는 규칙을 분리하도록 만든 자료입니다. 읽기 방법을 익힌 독자가 실제 차이를 문의할 때 사용할 수 있습니다.

공개 승인된 원문과 표를 검토하신 뒤 독자에게 도움이 된다고 판단되는 부분만 참고해 주시면 좋겠습니다. 링크 방식이나 게재를 조건으로 요청하지 않습니다. 외부 참고 자료를 받는 편집 절차가 있다면 그 기준을 따르겠습니다.

자료: 공개 전 검토본 `03-input-checklist.html` — 공개 URL 확정 후 발송본에 교체.
소속: 꿀꿀 운세 / CODE DESTINY. 발신자 이름·연락 경로는 운영자가 확인 후 기입.

## Soulmun

제목: 자미두수 명반 입문 글 독자를 위한 비교 기록 양식 제안

안녕하세요. 꿀꿀 운세에서 명반 이용 안내를 준비하고 있습니다. 귀 사이트의 명반 보는 법 글을 읽고, 설명을 따라온 독자가 다른 도구의 결과와 비교할 때 활용할 기록 양식을 소개드리고 싶습니다.

표는 “어느 결과가 정답인가”보다 “두 화면에 넣은 정보와 표시된 기준이 같은가”를 먼저 묻습니다. 입력 날짜·시간뿐 아니라 화면에 없는 설정은 미확인으로 적고, 처음 달라진 지점부터 문의하도록 구성했습니다. 귀 글의 설명을 대체하기보다 독자가 자기 입력을 점검하는 보조 자료가 목적입니다.

자료 사용에 링크나 소개 문구를 강제하지 않으며 편집 판단을 존중합니다. 참고 자료 제안을 받지 않는다면 추가 연락하지 않겠습니다.

자료: `03-input-checklist.html` 검토본. 공개 승인·실제 URL 확인 후 발송.
