# CODE DESTINY 소셜 운영 전략

기준일: 2026-09-09 KST. 사용자 최신 지시가 최초 숙요 중심 지시보다 우선한다.

## 방향
사주를 입구로, 자미두수와 숙요점을 다음 호기심으로 연결한다. 꽃돼지 연이를 보면 CODE DESTINY를 떠올리게 만든다. 사주 45%, 자미두수 20%, 숙요 15%, 그 외 체계·세계관·서비스 20%를 초기 편집 기준으로 사용한다. 시장 점유율에 대한 통계가 아니라 운영 가설이다. '자미두수가 유행한다'는 사용자 관찰이며 성장률을 확인한 것은 아니다.

콘텐츠의 70% 이상은 읽는 것만으로 도움이 되는 설명·질문·관계 팁. 직접 판매는 10% 이내. 첫 주 유료 구매를 재촉하지 않는다. 무료 기본 기능과 유료 상담을 구분한다.

브랜드 기억: **10년 경력 명리학자가 직접 만든 서비스 / 연이가 쉽게 풀어주는 사주 / 자미두수·숙요점까지 다른 관점으로 나를 읽는 곳.**

## 콘텐츠 문법
- Instagram: 1080×1350, 6장, 첫 장은 질문 한 개. 연이의 표정 → 설명 → 실제 행동 → 저장·체험. 연이 이름과 CODE DESTINY를 같은 위치에 반복한다.
- Threads: 실제 운영자의 짧은 2~5문단. 실제 확인하지 않은 상담 일화·고객 발언은 창작하지 않는다. 10년 경력은 사용자 진술과 현재 홈 소개에서 확인. 연이는 별도의 마스코트로 표현한다.
- Reels: 1080×1920, 15초 전후, 첫 2초 Hook. 과도한 점멸 금지. 무음에서도 이해 가능. 저작권 음원 없음.
- Stories: 7일간 투표·퀴즈·질문·링크. 개인정보나 상대 생일을 댓글에 쓰게 하지 않는다.
- 계정 프로필 제안: `10년 경력 명리학자가 만든 CODE DESTINY\n꽃돼지 연이와 사주를 쉽게 🌸\n자미두수·숙요점까지, 나를 읽는 여러 관점\n기본 운세는 아래에서 시작해요 ↓`
- 실제 프로필 편집은 아직 수행하지 않았다. Instagram의 현재 공개 프로필에서 사이트 링크가 보이지 않아 링크 등록 화면 확인이 우선이다. 링크가 없으면 '프로필 링크' CTA로 게시하지 않는다.

1. `C:\Users\user\Desktop\CodeDestiny-Build\연이 프로필1.png`
2. `C:\Users\user\Desktop\CodeDestiny-Build\연이 프로필2.png`

네오 생성·변형도 아래 두 파일을 함께 참조한다.
1. `C:\Users\user\Desktop\CodeDestiny-Build\네오프로필1.png`
2. `C:\Users\user\Desktop\CodeDestiny-Build\네오프로필2.png`

원본의 종족·얼굴·귀·코·눈·발·꼬리·연꽃·스카프·비율을 유지한다. 연이를 사람 캐릭터로 바꾸지 않는다. 귀여움은 표정과 포즈로 표현하고 아기 말투는 남발하지 않는다. 네오는 직설적이되 모욕하지 않는다.

**Instagram 전달용 완성 이미지와 카드뉴스는 JPG 또는 PNG만 사용한다.** WebP는 마스터·중간 원본으로만 보관할 수 있으며 업로드 폴더에 넣지 않는다. 영상은 MP4. 레이아웃 텍스트는 코드로 합성해 한글 정확성을 보장한다.

## 초기 실험
사주: 오행 개수만으로 성격을 정하는 오해 / 십성을 상황의 역할로 읽기 / 출생 시각이 없을 때의 한계.
자미두수: 12궁을 모두 외우지 않고 명궁→관심 궁→함께 보는 구조 순으로 입문.
숙요: 본명숙·관계의 거리. 나크샤트라와 계산 체계를 섞지 않는다.
연이: 시리즈 안내자. 같은 얼굴·연꽃·보라 스카프와 `연이의 사주 노트`를 반복하되 배경·포즈·질문은 바꾼다.

Threads 30일 인사이트에서 월~수 21~24시가 활동 상위로 표시됐다. 신규 편집 게시물은 21:10 KST를 1차 테스트 슬롯으로 사용한다. 기존 일일 운세 자동 게시의 시각·실제 게시 여부를 확인하고 하루 총 1~3개 안에서 조정한다. 기존 Cron은 변경하지 않는다.

## 운영 루프와 게시 권한
HANDOFF → 사이트 변경 → 양 플랫폼 최신 30건 및 content-log → 24시간/72시간/7일 성과 → 제작 → 모바일 크기 검수 → 승인 상태 확인 → 게시 → 실제 URL 기록.
최초 게시 권한은 완성된 콘텐츠를 보여준 뒤 한 번 확인한다. 승인 답변·범위·시각을 HANDOFF에 기록한 후 같은 범위는 반복 질문하지 않는다. 광고비·Boost·Meta Ads·운영 결제·실 LLM 검증은 별도 승인 없이는 금지한다.
통합 자동화 code-destiny-2027 ACTIVE 확인. 매일 07:10 KST 띠별 운세, 21:10 KST 일반 콘텐츠를 운영한다. 신년편은 11/1부터 해당 일요일 21:10 일반 슬롯을 대체하며 11월 전 공개하지 않는다. Codex 실행 예약이며 Meta 자체 예약이 아니다. 로그인과 앱 실행이 필요하다. 일반 콘텐츠 게시도 2026-09-09 사용자 승인 완료. 기존 일일 Worker 게시와 중복하지 않는다.

## 판단 원칙
통계 없는 최고·1위·정확도·전생 확정·재회 보장·조작 후기 금지. '여러 체계가 같게 말하니 사실'이라는 식의 과학적 검증 주장도 금지. 해석을 비교해 스스로 질문을 정리한다는 의미로만 사용한다. 가격·이용권·월정석·단건 결제 정책은 수정하지 않는다.
