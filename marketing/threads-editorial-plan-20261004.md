# Threads 하루 2~3편 운영 기획

2026년 10월 4일 요청을 반영한 @codedestiny_official 발행 기준이다. 독자가 자기 띠를 찾고, 해석의 이유를 이해하고, 경험을 나눌 수 있게 구성한다. 성과 개선은 가설이며 발행 후 관측으로 판단한다. 이 문서는 이전 growth 문서의 Threads 편성·문체 기준보다 우선한다. Instagram 수동 업로드와 기존 신년 일정은 유지한다.

## 하루 편성

| 한국 시각 | 콘텐츠 | 목적과 구성 |
|---|---|---|
| 08:30 | 띠별 오늘 운세 | 대상 띠·대표 출생연도 → 날짜 근거 → 3띠씩 해석과 실천 → 경험 질문 |
| 12:00 | 쉬운 사주 해설 | 익숙한 고민 → 날짜 상징과 한계 → 실천 → 관련 기능 링크 하나 |
| 20:30 | 연이의 마음 노트 | 관계·일·소비·비교의 구체적인 장면 → 확인할 기준 → 답하기 쉬운 질문 하나 |

기본은 독립 원글 3편이다. 예약 캠페인이 정규 슬롯을 대체하거나 근거·중복 검수로 한 편이 보류되면 2편으로 운영한다. 분량을 채우기 위해 보류된 글을 다시 생성하거나 몰아서 발행하지 않는다. 이 시각은 기존 운영을 유지한 시작점이며 최적 시간이라는 실측 결과가 아니다.

Worker가 위 세 슬롯의 발행자다. Codex 07:10·21:10 실행은 준비·공개 이력 확인·성과 기록을 담당한다. Worker가 정상 운영 중이면 별도 아침/저녁 원글을 더 올리지 않는다. 예전 4슬롯 및 가상의 07:00 원글을 전제로 작업을 생략하거나 답글을 달지 않는다. 실제 장애가 확인되어도 타임아웃을 미게시로 간주하거나 즉시 재발행하지 않는다.

원글과 인용 원글은 모두 당일 편수에 포함한다. 같은 원글에 붙이는 본문 답글 4개는 별도 독립 포스팅으로 세지 않는다. 사용자의 수동 게시까지 Worker가 계정 전체 한도로 차단하는 기능은 없으므로, 추가 수동 글이 있는 날은 정규 슬롯을 대체하도록 사전에 조정해야 한다.

## 예약 충돌 처리

- 10월 5일 09:00 소개글은 기존 별도 자동화를 유지하고, 그날 낮 12:00 사주 슬롯을 비운다. 오전 운세와 소개글 사이가 30분인 것은 기존 예약을 보존한 일회성 예외다. 장기적인 시간대 실험으로 해석하지 않는다. 소개글 보류 시에도 낮 슬롯을 급히 채우지 않는다.
- 11월 1일~2027년 1월 3일 일요일은 기존 21:10 신년 글이 20:30 마음 노트를 대체한다. 11월 이전 신년 공개 금지는 유지한다.
- 위 예약 대체는 Worker 코드가 운영에 반영된 뒤 유효하다. 그 전 Codex는 실제 글과 예정 슬롯을 합산하고 추가 원글을 보류한다. 소스 변경·예약 저장을 실제 운영 반영으로 기록하지 않는다.

## 띠별 글의 형식

원글 첫 줄에서 대상 띠와 행동을 부른다. 대표 출생연도를 함께 보여 자기 띠를 빨리 찾게 한다. 출생연도는 대표 예시이며 전체 연령대를 열거하지 않는다. 연초 출생은 사주의 입춘 기준을 확인해야 한다고 짧게 안내한다.

답글은 3띠씩 4개다. 각 띠마다 출생연도, 오늘 일진의 지지와 맺는 관계를 쉽게 설명한 한 문장, 생활에서 해 볼 행동을 쓴다. 12띠를 빠뜨리지 않는다. 빈 줄은 문단 사이 한 줄만 둔다. 원글도 유익한 내용을 담아 답글 열람만 강요하지 않는다.

첨부 예시에서는 대상 호명·출생연도·연속글 구조만 참고한다. 타 계정의 문장·실적·조회수를 가져오지 않는다. 오늘 일진 근거를 월간운세로 확대하지 않는다. 삼합의 일부 지지가 만난 것을 완전한 삼합 성립이나 확정된 인연으로 말하지 않는다. 도화·색상·장신구 효과는 근거 없이 추가하지 않는다.

‘잘 풀림/조심’ 순위표, ‘입 닫아’, ‘인연이 온다’, 상대 마음 확정, 댓글을 달면 복이 온다는 보상 약속은 쓰지 않는다. 친근한 반말을 쓰되 호통과 책임 전가는 피한다.

## 대중적인 주제와 전환

마음 노트는 연락 속도와 약속, 거절, 반복 지출, 친구와의 비교, 사과 뒤의 변화, 휴식, 업무 경계, 익숙함과 편안함, 미루기, 연락 방식, 자기 인정, 선택, 감사, 재회 조건, 노력과 결과의 15개 주제를 순환한다. 과거 최근 30개와 의미가 반복되면 새 글을 억지로 추가하지 않는다.

글마다 질문은 하나다. 예: ‘관심을 느끼는 쪽은 빠른 답장, 꾸준한 약속 중 뭐야?’ 본문과 직접 이어지고 짧게 답할 수 있어야 한다. 공개 댓글에 생년월일·전화번호·민감한 사연을 요구하지 않는다. 독자 댓글에 대한 자동 응답이나 DM은 이번 변경에 추가하지 않는다.

띠별 글과 마음 노트는 본문에서 끝나는 완결형으로 쓰고 링크를 붙이지 않는다. 낮 해설만 기존 기능 링크와 캠페인 식별자를 사용한다. 브랜드 태그 #꿀꿀운세를 원글에 포함한다. 소개글의 가격·월정석·혜택은 기존 정책과 별도 캠페인 검수 규칙을 따른다.

## 비교와 개선

동일 게시물의 24시간·72시간·7일 조회수, 좋아요, 실제 독자 답글, 리포스트·인용, 제공되는 공유 지표를 기록한다. 자기 연속 답글은 독자 참여에서 제외한다. 답글 수에서 자기 답글을 구별할 수 없으면 독자 답글 수는 미확인으로 남긴다. 저장·도달·프로필 방문이 제공되지 않으면 수치를 만들지 않는다.

최소 14일 동안 형식별 표본수와 같은 게시 경과시간의 중앙값을 비교한다. ‘독자 답글/조회수 × 1,000’, ‘리포스트·인용/조회수 × 1,000’을 조회수가 있을 때만 계산하고, 사이트 전환은 별도 지표로 둔다. 조회수 0 또는 미확인이면 비율도 미확인이다. 훅·질문·시간 중 한 변수만 바꾸고, 표본이 적으면 승자를 확정하지 않는다. 반응이 낮다고 하루 발행량을 늘리지 않는다.

Meta는 대화를 만드는 글이 추천될 가능성이 더 높다고 안내한다. 이는 질문형 문안을 시험하는 근거이지 이 계정의 성과 보장이 아니다. [Meta Threads 공식 안내](https://about.fb.com/news/2024/10/find-your-community-with-new-threads-educational-insights/)
