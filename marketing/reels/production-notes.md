# Reels 제작표

1080×1920, 30fps H.264 MP4, 무음, 한국어 자막 내장. WebP 장면을 연결하고 부드러운 확대를 적용. 실서비스 결과를 만들어내지 않으며 캐릭터 설명형 영상이다. 실제 홈 화면은 별도 캡처 보관; 1920px 데스크톱으로 모바일 시연이라고 부르지 않는다.

음악은 플랫폼 내에서 권리 확인 후 추가: 따뜻한 lo-fi, celesta, soft piano, 75~90 BPM, 검색어 moonlight / soft piano / dreamy lofi. 특정 저작권 음원을 다운로드하지 않았다.

## R01 · 사주에 물이 없으면?

- 2초: 물이 없는 사주, / 공감도 못할까?
- 4초: 오행의 개수만으로 / 마음을 단정하지 않아요.
- 4초: 계절과 글자의 관계를 / 함께 살펴봐요.
- 3초: 어려운 사주, / 꽃돼지 연이와 쉽게.
- 3초: CODE DESTINY / 기본 사주부터 시작

캡션: 오행은 성격 점수표가 아니에요. 연이와 사주 용어를 하나씩 풀어봐요. #사주 #오행 #꽃돼지연이 #코드데스티니
