# 홈 질문 카테고리 그림 (연이)

꿀꿀 홈 질문 섹션(`#cdConcernPick`)의 그림 타일 가운데 연이 4장이다. 크기는 960×640 WebP. 나머지 4개 카테고리(돈·일·미래·나 자신)는 이미 QA 를 통과한 영냥이 장면 `public/assets/yeongnyangi/scenes/{wealth,work,journey,self}.webp` 를 그대로 쓴다.

- 붙는 자리: 타일 media 는 16:9 `object-fit: cover` 다. 3:2 원본에서 위아래가 각 7.8%(960 기준 40px, 1536 기준 80px) 잘린다. QA 는 이 크롭 안에 얼굴이 남는지를 따로 봤다.
- 화면 크기: `/cdn-cgi/image/width=240|400|640` srcset 으로 내려가고, 원본은 `onerror` 대체 경로로만 쓰인다.

## 제작

- 날짜·도구: 2026-10-02, Codex CLI 0.156.1 `codex exec` → 내장 `image_gen`, 1536×1024 high.
- 모델: 이름(gpt-image-2)은 codex-image 스킬 문서에 적힌 것이고, 로그로는 확인하지 못했다.
- 참조 이미지: 연이 단독 컷 `yeoni-single-b-ref.png`(저장소 밖 작업 폴더).
- 프롬프트: 영냥이 장면과 한 시리즈로 보이도록 같은 블록 순서로 조립했다. CHARACTER 자리만 연이 블록으로 바꿨다. 블록 정본은 style-bible 「정본 프롬프트 머리말」이다.
  - FORMAT_LANDSCAPE → STYLE_SCENE → 연이 블록 → 장면 문단 → COMPOSITION_SCENE → PALETTE_GUARD → NO_TEXT → LIGHT_SCENE
- 조립된 전문은 원장 `docs/design/home-question-art.jsonl` 의 `prompt` 에 그대로 남겼다. 탈락작 5장과 QA 판정도 함께 있다.
- 그리지 않은 것: 사람(성별·나이 단정 방지), 글자·숫자·하트, 결혼식 소품.
- 원본 PNG 는 커밋하지 않는다. 저장소 밖 `D:\Development\yeongnyangi-tarot-art\home-questions\` 에 있다.
- 생성 상한: 승인 범위는 장당 3회, 총 12회였다. 실제로는 9회를 썼다.
- 인코딩: sharp lanczos3 로 960×640 으로 줄이고 WebP q78 effort 6 으로 저장했다. 4장 모두 q78 에서 140KB 이하였다.

## 남은 결함 (출고는 가능)

출고 기준은 필수 4항목이다: 연이 신원, 금지 요소 없음, 영냥이 장면과 화풍·명도 일치, 16:9 크롭에서 얼굴 유지. 4장 모두 이 4항목을 통과했다. 세부 기준 가운데 못 지킨 것은 아래와 같다.

- 시선: 사랑·인간관계는 연이가 관객 쪽을 본다. 의도는 "편지·찻잔을 내려다봄"이었다.
  - 세 회차에 걸쳐 시선 문장을 Scene 맨 앞으로 옮기고 긍정형으로 바꿨지만 결과는 같았다. 참조 이미지의 정면 시선에 끌리는 것으로 본다.
  - 다음에 다시 그린다면 정면이 아닌 참조 컷을 쓰는 쪽을 먼저 시도한다.
- 키 비율: 사랑 0.466, 인간관계 0.44. 상한 0.42 를 조금 넘는다.
- 결혼: 크롭에서 위쪽 잎 끝 28px 와 달 윗부분 8px 가 잘린다(960 기준으로는 절반).
- 인간관계: 등롱 위끝이 그림 높이의 8.4% 에 걸려 있다. 금색 찻잔에 12px 붓획 덩어리가 있으나 대비 1.5:1 이라 화면 크기에서는 읽히지 않는다.
