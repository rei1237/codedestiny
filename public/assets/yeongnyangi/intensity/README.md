# 영냥이 팩폭 강도 이미지 출처

네오의 팩폭 작전실 강도 선택(`src/features/neo-war-room/data/assets.ts` `intensity`)에 쓰는 256×256 WebP다. 강도는 영냥이 표정과 고추 개수로 보여준다. 예전 사자 휘장 크롭 시트를 대체한다.

| 파일 | 강도 id | 제작 |
|---|---|---|
| soft.webp | soft(순한맛) | 2026-10-30 Codex CLI 내장 image_gen(gpt-image-2)으로 `original/hero-800.webp`를 참조로 넘겨 다시 생성한 원본을 sharp로 256×256 WebP 변환(품질 82). 금빛인 기본맛과 작은 크기에서 갈리도록 빛을 차가운 달빛 청록으로 바꿨다. 눈을 감고 웃으며 두 앞발로 고추 1개를 든 영냥이, 달 원반과 물방울. |
| standard.webp | standard(기본맛) | 2026-10-30 같은 참조로 1회 생성한 1024×1024 원본을 같은 방식으로 변환. 집중한 눈빛, 별 지팡이, 고추 2개, 금빛 불티. |
| hot.webp | roar(매운맛) | 같은 방식. 볼이 달아오른 화끈한 표정, 지팡이에서 나오는 불꽃 소용돌이, 고추 3개. 송곳니·위협 표정 없음. |

규칙: 글자·로고·사람이 들어간 이미지는 넣지 않는다. 귀 2개를 원본 크기로 세어 검수했다. 원본 PNG는 저장소에 두지 않는다.
