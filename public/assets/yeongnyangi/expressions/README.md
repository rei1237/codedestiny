# 영냥이 표정 배지

긴 상담(본문 1만자 이상) 말풍선에 쓰는 128×128 WebP. 원본은 `사주보는 고양이 영냥이/영냥이 표정`이다.

규칙: **글자가 들어간 이미지는 절대 넣지 않는다.** Photoroom 스티커, 라벨이 박힌 표정, 표정 시트는 제외했다. 새 표정을 추가하면 `app/yeongnyangi/_lib/reading-visuals.ts` 의 `EXPRESSIONS` 허용목록에도 넣는다.

| 파일 | 원본 |
|---|---|
| curious | 작은 연냥이표정 관심 |
| smug | 작은 영냥이 건방짐 |
| surprised | 작은 영냥이 놀람 |
| chic | 작은 영냥이 시크 |
| tear | 작은 영냥이 표정 눈물2 |
| calm | 작은 영냥이 표정 진지 |
| welcome | 작은 영냥이 표정 환영 |
| grumpy | 작은영냥이표정 까칠 |
| cool | 작은영냥이표정 시크 |
