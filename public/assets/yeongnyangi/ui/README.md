# 영냥이 상단 메뉴 그림

2026-09-16, 사용자 요청에 따라 ImageGen으로 새로 그린 메뉴 전용 아이콘입니다.
제공받은 `ui 에셋.webp`는 화풍 참고에만 사용했습니다. 기존 원본 파일은 수정하지 않았습니다.

- `nav-readings.webp`: 보라색 점술 카드와 금빛 별
- `nav-room.webp`: 분홍 고양이 젤리발
- `nav-recommendations.webp`: 금빛 초승달과 별

각 파일은 96×96 투명 무손실 WEBP이며 화면에서는 24~28px로 표시합니다.
생성된 가로 그림을 세 칸으로 분리하고 외곽과 연결된 무채색 배경을 제거했습니다.
내부 하이라이트는 유지하며 보라색 배경 위에서 검토했습니다.

생성 지시: 같은 화풍의 단순하고 귀여운 카드·젤리발·달별 아이콘을 가로 세 칸에
각각 배치하고, 분홍·보라·금빛 색상과 부드러운 윤곽을 통일한다. 작은 화면에서도
읽히는 형태로 그리며 글자, 숫자, 버튼 프레임과 과한 장식은 넣지 않는다.
