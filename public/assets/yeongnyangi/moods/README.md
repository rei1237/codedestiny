# 영냥이 표정 바꾸기 포즈

홈 「운세가 끝나도, 머물러도 돼.」와 영냥이의 방에서 `app/yeongnyangi/_original/CatMotion.tsx` 가 「표정 바꾸기」를 누를 때마다 한 장씩 보여 주는 전신 포즈. 360×300 흰 바탕 WebP이며, 아이보리 무대 위에서 `mix-blend-mode: multiply` 로 합성된다.

규칙: **글자가 들어간 이미지는 넣지 않는다.** 라벨이 박힌 원본은 라벨 아래를 잘라냈고, 이름표·족자 글씨가 몸에 겹친 원본은 제외했다. 반짝이·하트·놀람선 같은 장식 기호는 허용한다. 처리 과정은 원본 → 흰 바탕 평탄화 → (라벨 절단) → 모서리 바탕색으로 나눠 순백화 → 밝기 245 이상 순백 → trim → 336×280 contain + 여백 → WebP q80 이다. 원본 폴더는 `사주보는 고양이 영냥이` 이며 원본 PNG는 저장소에 두지 않는다.
