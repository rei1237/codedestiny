# 영냥이 상담 삽화

긴 상담(본문 1만자 이상)의 장 사이와 시기·원국 패널에 쓰는 720×480 WebP.

- 제작: 2026-09-27 Codex CLI `image_gen`(gpt-image-2), 1536×1024. `hero-800.webp` 를 화풍 참조로 썼다.
- 프롬프트에 "no text, letters, numbers, logos" 를 넣었고, 글자가 없음을 확인했다.
- 원본 PNG는 커밋하지 않는다.

| 파일 | 장면 |
|---|---|
| timeline | 망원경으로 별을 보는 영냥이 (시기) |
| balance | 오행 구슬 저울 (균형) |
| guide | 두루마리 지도로 길 안내 (실천) |
| rest | 찻잔 들고 쉬는 영냥이 (쉼표) |
| insight | 수정구를 들여다보는 영냥이 (통찰) |
