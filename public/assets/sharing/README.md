2026-09-28 사용자의 이미지 제작 요청으로 생성한 Code Destiny 전용 그림이다.

- 영냥이: `public/assets/yeongnyangi/original/hero-480.webp` 캐릭터 참조.
- 연이: `public/assets/yeongnyangi/original/ggulggul-fortune.webp` 캐릭터 참조.
- 네오: `public/assets/kakao-crm/neo-depth.png` 캐릭터 참조.
- 제작: Codex 내장 이미지 생성 도구. 기존 얼굴·복장·색상과 편지/찻집/전략가 정체성 유지.
- 글자는 그림에 넣지 않았다. 고객이 승인한 문구는 브라우저 canvas 또는 서버 OG renderer에서 별도 조판한다.
- WebP 1080×1080: 모바일·로컬 저장 카드. JPEG 900×900: 서버 OG의 고정 허용 자산.
- 원본 PNG는 생성 도구 보관 위치에 유지. 이 디렉터리는 웹 배포용 최적화본이다. 기존 캐릭터 자산을 교체하지 않았다.

고객 결과·프로필·질문을 이미지 생성 도구에 전달하지 않았다. 배포 이후 고객 카드마다 AI 이미지를 새로 생성하지 않으므로 카드당 추가 LLM/이미지 생성 호출은 없다.
