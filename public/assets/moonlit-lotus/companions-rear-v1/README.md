# 법당 동물 친구 후면 절하기 v1

영냥이(cat), 서한비(hanbi), 12지신의 2D 후면 절하기. 기존 정면/걷기/명상 및 연이 rear-v3 원본은 보존한다.

- 캐릭터당 down/lower/up 각각 4×4, 총 48개 제작 컷. WebP 1536×1536, 셀 384×384, 바닥 기준 y=354. still.webp는 down:0.
- 참조: 영냥이 `D:/CodeDestiny-Build/양냥이 프로필 시트.webp`, 서한비 동물형 `D:/CodeDestiny-Build/박지은 캐릭터.png`, 12지신 기존 zodiac-v1/*-still.webp. 원본의 종·털색·귀·꼬리·의상과 장식을 유지한다. 영냥이 이름표는 넣지 않는다.
- 화풍: 승인된 연이 `rear-redraw-review/yeoni-proportions-keyposes.png`의 부드러운 2D 채색. 뱀은 팔다리 없이 목과 몸통으로 숙이고, 닭은 날개·두 발로 낮춘다.
- 원본 PNG: `D:/CodeDestiny-Build/moonlit-lotus/companions-rear-v1/<id>/*-source.png`. 각 manifest에 원본 SHA-256·압축 크기·셀 경계를 기록한다.
- 갱신: `node scripts/sprites/prepare-companion-rear.mjs [원본 루트]`. 이미지 제작에는 이미지 생성 도구를 사용하고 패킹은 Sharp를 사용한다. 생성된 파일을 검수 없이 운영에 복사하지 않는다.
- 각 시트의 서 있는 참조 컷으로 균일 배율을 정하고 발 접촉선을 정렬한다. 자세별 크기 늘리기는 하지 않는다. 시트 사이 겹치는 자세는 등록 높이에 따라 재배열한다. 자동 높이 검사는 외형·팔다리 접촉 검수를 대체하지 않는다.
- 셀 경계에 남은 다음 줄 조각은 연결된 본체 영역을 기준으로 제외한다. 가장 낮은 자세는 기존 한 주기 안에서 650ms 머문다. 회복 중 큰 높이 차이는 이미 제작된 중간 자세로 연결한다.
- 타임라인: `app/moonlit-lotus/_lib/companion-rear-timelines.json`. 순서는 해당 manifest의 sheet/frame을 참조한다. 가장 낮은 자세에서 회복 초입 사이에 하강 컷을 역순 재사용한다. 마지막은 정확히 down:0으로 돌아온다.
- 재생: 기존 bow-session 시간만 읽는다. 새 타이머·완료 사건·횟수 집계는 추가하지 않는다. 법당에서 기도/108배 중 후면, 선택한 캐릭터의 세 장만 디코딩한다. 시점 변경·모션 감소는 세션을 재시작하지 않는다.
- 실패: 기존 정지 그림과 다시 불러오기 제공. 캐릭터 id를 React key에 포함해 이전 캐릭터 이미지가 남지 않게 한다.
- 롤백: 이 자산과 연결 코드의 커밋만 revert. 기존 원본 경로는 바뀌지 않는다. 결제·인증·API·DB·검색 색인 정책 변경 없음.
